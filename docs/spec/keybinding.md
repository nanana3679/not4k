# not4k — 키 바인딩 시스템

## 기본 손배치 추천: 엄검중약

기본 프리셋은 약지·중지·검지·엄지를 활용하는 엄검중약을 추천 출발점으로 삼는다. 여러 키의 교대와 손 이동을 익히기 위한 예시이며, 플레이어는 손 크기·키보드·선호에 맞춰 바인딩과 운용을 조정한다([glossary](../context/glossary.md#엄검중약), [RFD 0044](../rfd/0044-keybinding-presets-as-starting-points.md)).

추천 배치에서는 약지·중지·검지가 여러 행의 키를 담당하고, 엄지는 하단의 키를 활용한다. 기본 예시에서 소지에 주 역할을 배정하지 않는 것은 프리셋의 선택이다. 플레이어가 사용하는 손가락을 제한하는 규칙으로 적용하지 않는다.

```
   약  중  검          ← 상단 행
   약  중  검          ← 홈 행
   약  중  검          ← 하단 행
            엄         ← 하단의 키를 활용
```

실제 도달 거리와 사용감은 손과 키보드에 따라 달라진다. 한 배치가 모두에게 편하거나 빠르다고 보장하지 않으며, 조합을 시험해 사용할 키를 고른다. 레인당 2키 이상과 물리 키의 레인 간 중복 금지 규칙은 유지한다.

## 키보드 레이아웃

QWERTY 키보드에서 기본 프리셋을 설명하는 키 영역은 다음과 같다.

```
   Q  W  E        7  8  9
   A  S  D        4  5  6
   Z  X  C        1  2  3
```

왼손은 QWE / ASD / ZXC 영역, 오른손은 789 / 456 / 123 영역(넘버패드)을 사용한다.

각 행은 손가락의 상하 이동에 대응한다:

- **상단 행** (Q W E / 7 8 9): 약지-중지-검지가 위로 뻗는 위치
- **홈 행** (A S D / 4 5 6): 약지-중지-검지의 기본 위치
- **하단 행** (Z X C / 1 2 3): 약지-중지-검지가 아래로 내려가는 위치. 엄지도 이 영역에 접근 가능

### 넘버패드 배치 예시

오른손 넘버패드 예시에서는 3번 레인의 Numpad7을 검지로, Numpad1을 엄지로 처리한다. 위·아래 행의 두 키를 다른 손가락으로 나누어 사용하는 추천안이다. 실제 도달 거리와 손 위치를 확인해 사용할 키를 조정한다.

### 텐키리스 대안 배치 (TKL / 65% / 75%)

넘버패드가 없는 키보드 사용자를 위해, 오른손에 메인 키보드 영역의 3×3 블록을 대안으로 제공한다.

```
   Q  W  E        P  [  ]
   A  S  D        L  ;  '
   Z  X  C        ,  .  /
```

넘버패드 키와의 대응 관계:

| 넘버패드 | TKL 대안 | 행      |
| -------- | -------- | ------- |
| 7 8 9    | P [ ]    | 상단 행 |
| 4 5 6    | L ; '    | 홈 행   |
| 1 2 3    | , . /    | 하단 행 |

이 배치의 근거:

- **세 행의 키 대응**: P[] / L;' / ,./를 넘버패드의 세 행에 대응시켜, 같은 역할의 키를 찾는 기준으로 사용한다.
- **양손의 영역**: 왼손은 QWE / ASD / ZXC, 오른손은 P[] / L;' / ,./ 영역을 기준으로 시작한다. 실제 행의 어긋남과 간격은 사용하는 키보드에서 확인한다.
- **넘버패드 없는 선택지**: 메인 키보드 영역을 활용한다. 실제 키의 유무·위치는 키보드 레이아웃에 맞춰 확인하고 조정한다.
- **손가락 역할의 대응**: 예시에서는 검지·중지·약지의 역할을 대응시킨다. 위치·간격이 달라지므로 전환할 때는 별도로 적응하는 과정이 필요할 수 있다.

게임 설정에서 "오른손 배치"를 넘버패드 또는 TKL 중 선택할 수 있으며, 기본값은 TKL 배치로 한다. 넘버패드 없이 시작할 수 있는 추천안이며, 사용하는 키보드와 선호에 맞춰 조정한다.

## 난이도 등급별 키 배치

### 입문 (Lv.1～3): 4키 중심과 보조키의 짧은 체험

16키 프리셋(레인당 4키)을 기본으로 설정하되, 입문 단계에서는 중지와 검지 4키를 주로 활용한다.

- **레인 1, 4**: 중지 1키를 주로 사용하고, 느리고 단순한 짧은 트릴·더블에서 다른 키도 체험할 수 있다.
- **레인 2, 3**: 검지 1키를 주로 사용하고, 트릴·더블의 짧은 체험에서 엄지 등을 활용한다.

기본 프리셋의 운용 예시이며 사용하는 키와 손가락은 조정할 수 있다. 입문 트릴·더블을 내측 레인에만 한정하지 않고, 실제 독해·연주 부담과 앞뒤 손배치 흐름으로 판단한다([RFD 0057](../rfd/0057-beginner-trill-double-on-outer-lanes.md)).

| 레인 | 왼손 키 (손가락)    | 오른손 키 — 넘버패드 (손가락) | 오른손 키 — TKL (손가락) | 입문 활용도       |
| ---- | ------------------- | ----------------------------- | ------------------------ | ----------------- |
| 1    | Q (약지) + W (중지) |                               |                          | 주로 W, 드물게 Q |
| 2    | E (검지) + C (엄지) |                               |                          | 주로 E만, 드물게 C |
| 3    |                     | 7 (검지) + 1 (엄지)           | P (검지) + , (엄지)      | 주로 7/P만, 드물게 1/, |
| 4    |                     | 8 (중지) + 9 (약지)           | [ (중지) + ] (약지)      | 주로 8/[, 드물게 9/] |

### 초급 (Lv.4～6): 엄지 비중 상승 (6키)

트릴 노트가 빈번해지면서 내측 레인(2, 3번)에서 엄지 사용이 본격화된다. 외측 레인(1, 4번)은 아직 주로 1키만 사용.

### 중급 (Lv.7～10): 8키 입문 — 약지 추가

외측 레인(1, 4번)의 키 교대와 약지 활용이 본격화되는 운용 예시다. 입문의 느리고 단순한 짧은 체험과 구별하며, 외측 트릴이 처음 허용되는 단계라는 뜻은 아니다. 8키를 함께 활용하는 범위를 넓힌다.

| 레인 | 왼손 키 (손가락)    | 오른손 키 — 넘버패드 (손가락) | 오른손 키 — TKL (손가락) |
| ---- | ------------------- | ----------------------------- | ------------------------ |
| 1    | Q (약지) + W (중지) |                               |                          |
| 2    | E (검지) + C (엄지) |                               |                          |
| 3    |                     | 7 (검지) + 1 (엄지)           | P (검지) + , (엄지)      |
| 4    |                     | 8 (중지) + 9 (약지)           | [ (중지) + ] (약지)      |

각 레인의 트릴 처리:

- **1번 레인**: Q-W 교대 (약지-중지)
- **2번 레인**: E-C 교대 (검지-엄지)
- **3번 레인**: 7-1 교대 (검지-엄지) / TKL: P-, 교대 (검지-엄지)
- **4번 레인**: 8-9 교대 (중지-약지) / TKL: [-] 교대 (중지-약지)

### 기본 프리셋: 16키 (레인당 4키)

초기 제공 프리셋은 레인당 4키를 바인딩한다.

| 레인 | TKL (기본) | Numpad |
|------|-----------|--------|
| 1 | Q, W, S, X (4키) | Q, W, S, X (4키) |
| 2 | E, D, C, O (4키) | E, D, C, PageDown (4키) |
| 3 | P, L, ,, R (4키) | Numpad7, Numpad4, Numpad1, R (4키) |
| 4 | [, ], ;, . (4키) | Numpad8, Numpad9, Numpad5, Numpad2 (4키) |

기본값: **TKL 배치**. 초기 제공 프리셋은 조정 가능한 추천 출발점이다.

3～4키 바인딩의 이점:

- **중지 3행 활용**: 외측 레인에서 중지가 상단·홈·하단 3행을 모두 사용하여 트릴 선택지가 넓어진다
- **3키 트릴**: `A → B → C → A → B → C`처럼 세 키를 교대하는 방법을 선택할 수 있다
- **4키 트릴**: `A → B → C → D → A → B → C → D`처럼 네 키에 입력을 나누는 방법을 선택할 수 있다. 실제 편의와 속도는 리듬·배치·숙련도에 따라 달라진다
- **더블 홀드 + 트릴**: 4키 중 2키로 더블 홀드를 유지하면서 나머지 2키로 트릴 처리가 가능하다

## 주키와 보조키 (운용 개념)

시스템은 바인딩된 키를 모두 동등하게 취급하지만(핵심 규칙 2), 실제 플레이에서 유저는 키를 두 층위로 운용한다.

- **주키**: 기본 손 위치에서 주로 사용하는 키.
- **보조키**: 특정 패턴에서만 한정적으로 사용하는 키.

### 16키는 동시 사용이 아니다

16키 프리셋은 **16키를 동시에 쓰라는 뜻이 아니다.** 기본적으로 주로 사용하는 4키(레인당 주키 1개)에 패턴별 보조키를 더해 활용하는 운용을 예로 든다. **동시 활용 8키는 일반적인 운용 예시**이며, 이를 넘겨 활용하는 배치는 흔치 않을 것으로 예상하지만 차트 제작·시스템 검증의 상한으로 두지 않는다([RFD 0058](../rfd/0058-simultaneous-key-count-as-example.md)).

패턴마다 유도되는 보조키가 달라져 차트 전체에 걸쳐서는 최대 16키가 활용될 수 있다. 난이도 체계의 "16키 완전 활용"(최상급)은 차트 전체에서의 활용을 뜻한다. 실제 동시 활용의 부담은 배치별로 확인한다.

### 사운드 볼텍스 손 위치 이동의 키보드 치환

사운드 볼텍스에서는 BT 4버튼만 사용하지만, 손의 위치를 옮기면서 왼손/오른손 분담을 12/34에서 12/23 등으로 바꿀 수 있다. 버튼이 커서 하나의 버튼을 상황에 따라 양손 중 어느 쪽으로도 칠 수 있기 때문이다.

not4k에서는 같은 레인에 여러 키를 바인딩해 손 위치를 바꾸어 처리하는 방법을 제공한다. 기본 Numpad 프리셋에서 오른손이 3·4번 레인을 Numpad7·Numpad8로 치고 있었다면, 2·3번 레인을 PageDown·Numpad7로 처리하는 손배치를 시도할 수 있다. PageDown은 이 예시에서 2번 레인의 보조키다. 실제 키 간격과 이동 가능 여부는 사용하는 키보드에서 확인한다.

기본 프리셋에서 반대편 손 영역에 배치된 키들이 모두 이 손 옮기기용 보조키다.

| 프리셋 | 보조키 (레인) | 손 옮기기 동작 |
| ------ | ------------- | -------------- |
| Numpad | PageDown (2번 레인) | 오른손: 3·4번(Numpad7·8) → 왼쪽 한 칸 → 2·3번(PageDown·Numpad7) |
| Numpad / TKL | R (3번 레인) | 왼손: 1·2번(W·E) → 오른쪽 한 칸 → 2·3번(E·R) |
| TKL | O (2번 레인) | 오른손: 3·4번(P·[) → 왼쪽 한 칸 → 2·3번(O·P) |

즉, 보조키는 "더 많은 키를 동시에 누르기 위한 키"가 아니라, **손 위치 이동이라는 아케이드적 자유도를 키보드에서 재현하기 위한 키**다.

## 추천 배치에서의 키 교대 선택지

### 외측 레인 (1번, 4번)

왼손 예시에서 같은 레인의 키를 다음과 같이 나누어 쓸 수 있다. 사용할 조합은 실제 도달 거리와 다음 입력을 고려해 고른다.

- **Q-W 트릴 (약지-중지)**: 같은 행의 인접한 두 키를 교대하는 예시.
- **W-X 트릴 (중지-엄지)**: 서로 다른 행의 두 키를 교대하는 예시.

### 내측 레인 (2번, 3번)

왼손의 E-C를 검지·엄지로 교대하는 예시를 제공한다. 손가락 조합만으로 높은 속도나 낮은 부담을 보장하지 않으며, 개인의 사용감과 배치에 맞춰 조정한다.

### 고급 테크닉: 엄지 눕힘 (Flat Press)

IIDX의 베차오시(Becha-oshi)처럼 엄지를 눕혀 인접 키 2개를 동시에 처리하는 테크닉.

**예시**: 16bit `12 12 12 12` 배치에서 레인 1에 A·B, 레인 2에 X·Y가 바인딩되어 있다면, 정석적으로는 AX→BY 트릴(검중-약엄 교대)로 처리한다. 그러나 엄지를 눕혀 X와 Y를 동시에 커버하면, AX→B(엄눕힘) 트릴(검중-엄엄 교대)로 전환할 수 있다.

- **검중-약엄 트릴**: 4개 손가락이 모두 독립적으로 동작해야 함
- **검중-엄(눕힘) 트릴**: 엄지가 2키를 한꺼번에 처리하므로 실질적으로 3손가락 교대, 인지 부하가 낮음
- **더블 노트 처리**: 인접 레인의 더블 노트(`[12]`)가 나올 때, 엄지를 눕혀 혼자서 두 레인을 동시에 처리할 수 있음
- 최상급 난이도에서 유용한 고급 입력 방식

### 기본 예시의 손가락 역할

기본 프리셋은 엄지를 하단 키에 활용하는 배치로 시작하며, 소지에 주 역할을 배정하지 않는다. 손가락의 우열이나 특정 자세의 보편적 적합성을 뜻하지 않는다. 플레이어는 바인딩 규칙 안에서 사용할 키와 손가락을 조정한다.

## 튜토리얼과 키 설정

키 추가·손배치 발견을 단계적으로 체험하는 튜토리얼 과정은 두지 않는다. 기본 행 체험, 약지·엄지의 발견, 양손 완성의 단계별 학습 흐름은 사용하지 않는다([RFD 0082](../rfd/0082-no-keybinding-discovery-tutorial.md)).

노트의 연주 방법과 판정 규칙은 [튜토리얼 스펙](tutorial.md)에서 다룬다. 프리셋 선택과 키 설정 기능, 손가락 배치 예시는 유지하며, 실습에 필요한 키가 부족하면 [실습 전 키 설정](#튜토리얼-실습-전-키-설정)을 먼저 수정하도록 안내한다.

## 핵심 규칙

### 1. 레인당 복수 키 바인딩 필수

- 유저는 각 레인에 **2개 이상**의 키를 바인딩**해야** 한다 (최소 요구사항).
- **최소**: 레인당 2키 (총 8키). 트릴과 더블 노트 처리를 위한 최소 조건.
- **기본 프리셋**: 레인당 4키 (총 16키). 초기 제공 프리셋에 적용.
- **확장**: 레인당 4키 이상 바인딩도 **허용한다.** 시스템은 바인딩 수의 상한을 두지 않는다.

### 2. 바인딩된 키는 모두 동등 (시스템 규칙)

- 같은 레인에 바인딩된 키 A, B는 싱글 노트에서 완전히 동등하게 작동한다.
- 시스템 차원에서 "A가 주키, B가 보조키"라는 구분은 없다.
- 트릴 노트에서만 "직전과 다른 키"라는 조건이 붙는다.
- 주키/보조키는 시스템 규칙이 아니라 유저의 **운용 개념**이다. 아래 "주키와 보조키" 섹션 참고.

### 3. 키 충돌 불가

- 하나의 물리 키는 하나의 레인에만 바인딩된다.
- 같은 키를 두 개 이상의 레인에 바인딩할 수 없다.

## UI 설계 요구사항

### 키 바인딩 설정 `[부분 구현 — 키 추가/삭제 가능, 키보드 오버레이 미구현]`

곡 선택 화면에서 여는 설정 모달의 **Controls** 섹션에 위치한다.

- 레인별로 바인딩된 키를 시각적으로 보여주는 인터페이스
- 키보드 레이아웃 위에 현재 바인딩을 오버레이하여 시각적으로 확인 가능 `[미구현]`
- 현재 바인딩으로 플레이 가능한 난이도 등급을 표시 `[미구현]`

### 튜토리얼 실습 전 키 설정

직접 입력 실습에 필요한 키가 현재 바인딩에 부족하면 먼저 키 설정을 수정하도록 안내한다. 실제 설정이 해당 실습의 요구를 충족한 뒤 실습을 시작하며, 실습 중에만 쓸 임시 키를 자동 배정하지 않는다. 자동 시연 프리뷰의 표시용 키 보충을 실제 입력 설정으로 간주하지 않는다. 실습 전 확인·안내는 미구현이다([튜토리얼 스펙](tutorial.md#시연-후-직접-입력으로-통과), [RFD 0081](../rfd/0081-tutorial-demonstration-and-three-practice-successes.md)).

튜토리얼 실습에서는 노트를 보고 직접 사용할 키를 판단하며, 다음에 눌러야 할 키를 미리 알려주는 가이드는 표시하지 않는다. 실제 누른 키의 표시는 유지한다.

### 곡 선택 화면

- 각 곡/차트의 Lv.를 표시
- 현재 바인딩으로 처리할 수 없는 노트 타입이 포함된 경우 안내 메시지 표시 `[미구현]`

### 플레이 중 표시

- **키보드 레이아웃 오버레이**: 게임 플레이 화면 우측 하단에 키보드 레이아웃을 소형으로 표시한다. 실제로 입력되는 키가 실시간으로 하이라이트되어, 관찰자가 게임 플레이 화면만으로 어떤 키를 어떤 타이밍에 누르는지 — 즉 게임의 핵심 메커니즘(레인당 복수 키, 트릴 교대 등)을 직관적으로 이해할 수 있도록 한다.
  - 레인마다 다른 색은 쓰지 않는다([#258](https://github.com/nanana3679/not4k/issues/258)). 레인에 바인딩된 키는 레인 1·3을 기어 금속에 맞춘 차가운 은색, 레인 2·4를 기어 유리관 게이지 같은 하늘색(둘 다 조금 더 밝은 테두리)으로 그려, 처음 보는 사람도 이웃 레인이 번갈아 배정된 규칙(손을 건너는 R·O 포함)을 알아볼 수 있게 한다. PRODUCT.md "네온은 상태에만"에 따라 누르는 동안만 밝은 색으로 밝히며, 이것도 두 계열로 나눠 레인 1·3은 흰색, 레인 2·4는 대기보다 더 밝은 하늘색이다(테두리·번짐 없이 대기 키의 겉 크기만큼 꽉 채움). 바인딩되지 않은 키는 레인 1·3 대기와 같은 은색을 아주 흐리게(화면 투명도 0.07 이하) 그려 자리만 보인다. 색과 투명도 값은 `KEYBOARD_DISPLAY_STYLE`(`src/game/renderer/KeyboardDisplay.ts`) 한곳에서 정한다.
  - 바인딩에 넘버패드 키가 있으면 넘버패드까지, 없으면 TKL 배치를 그린다.
  - 플레이 영역(논리 높이 600)의 오른쪽 아래 구석에 여백 4를 두고 붙인다. 레인·기어와 무관하게 화면 구석 기준이다.
  - 키 한 칸 10(간격 1) 논리 단위가 원래 크기다(TKL 203.5×71.5, 넘버패드 포함 253×71.5). 기어 실루엣 오른쪽 끝에서 여백 8을 둔 빈 곳보다 넓으면 그 폭에 맞춰 줄이고, 0.6배보다 작아야 하면 숨긴다. 0.6배면 키 한 칸이 6 논리 단위(렌더 높이 720에서 화면 약 7px)로, 그보다 작으면 이웃 키를 구분하기 어렵다. 16:9는 TKL·넘버패드 모두 원래 크기, 16:10 넘버패드는 0.96배, 4:3은 TKL 0.80배·넘버패드 0.65배, 5:4 넘버패드는 숨긴다.
  - 키를 누를 때는 그 키의 그림만 바꾸고 키보드 전체를 다시 그리지 않는다.
- 트릴 노트 구간에서 교대 가이드를 표시하는 옵션 (초급자용, 끌 수 있음) `[미구현]`
