# not4k — 옵저버 모드

> **구현 상태: 미구현**

연주 방법을 파악하고 싶거나 동작이 아직 익숙하지 않을 때, 원하는 구간을 반복해 관찰하고 직접 따라 치며 판정을 확인하는 도구. 정식 정의는 [glossary](../context/glossary.md#옵저버-모드-observer-mode)를 따른다.

---

## 존재 이유

어떻게 쳐야 할지 모르는 구간에서는 배치와 연주 흐름을 파악하기 위해 반복하고, 방법을 알아도 동작 자체가 익숙하지 않은 구간에서는 그 동작을 익히기 위해 반복한다. 플레이어가 원하는 구간을 골라 필요한 만큼 확인할 수 있게 한다([RFD 0060](../rfd/0060-observer-for-understanding-and-practice.md)).

이 필요성은 차트 레벨만으로 나누지 않는다. 옵저버를 고난이도 플레이의 필수 사전 계획 절차로 두지 않으며, 낮은 레벨에서도 연주 방법 이해나 동작 숙련을 위해 선택할 수 있다.

반복 구간에서 플레이어가 직접 입력하고 판정 결과를 확인할 수 있어야 한다([RFD 0061](../rfd/0061-observer-input-and-judgment.md)). 입력 없는 관찰로만 한정하지 않는다. 표시·집계·반복 경계의 구체적 동작은 [PRD §12](../prd.md#12-미정-사항)에서 추적한다.

### Play/Observer 경계

Play에 `flightRule`(`altitude` 기반 클리어/실패)이 도입되면서(RFD 0001), **실패 조건 없는 완주·관찰·구간 반복 학습은 Observer 계열이 담당한다.** Play에서 실패할 수 있는 차트를 끝까지 확인하고 싶은 유저는 옵저버 모드를 사용한다. 직접 입력·판정을 확인하는 반복 연습도 옵저버 안에서 제공한다. 개별 노트의 실패 판정으로 학습을 중단하지 않으며 공식 Play 기록과 구별한다. 과거 대안은 [RFD 0001](../rfd/0001-flight-rules-and-observer-boundary.md)에 보존한다.

## 핵심 기능

### 1. 자유 스크롤

차트 내에서 자유롭게 스크롤하여 원하는 구간에 쉽게 도달할 수 있어야 한다.

- 차트 전체를 시간축으로 탐색할 수 있다.
- 스크롤 위치에 따라 현재 시점의 노트 배치가 표시된다.
- 빠른 이동(곡 시작/끝, 특정 시점 점프)을 지원한다.

### 2. 재생

차트를 음원과 함께 재생하여 실제 플레이 흐름을 확인할 수 있다.

- **진입 시 재생**: Auto가 켜진 상태로 기본 전곡 구간을 1.0x로 바로 재생한다. 재생 버튼을 별도로 누를 필요가 없다. 나갔다가 다시 들어올 때도 재생 속도는 1.0x로 초기화하며 마지막 감속 설정을 복원하지 않는다([RFD 0076](../rfd/0076-observer-slowdown-preserves-pitch.md)).
- **재생/일시정지**: 현재 스크롤 위치에서 재생을 시작하고, 일시정지로 특정 시점에서 멈출 수 있다. 일시정지 중에도 자유 스크롤이 가능하다.
- **재생 속도 조절**: 감속 재생(0.25x～1.0x)으로 복잡한 배치를 정밀하게 확인한다. 느리게 재생해도 원곡의 음높이를 유지하며 Auto 관찰과 직접 입력 연습 모두에 적용한다([RFD 0076](../rfd/0076-observer-slowdown-preserves-pitch.md)). 처리 방식과 음질·지연·동기화 검증은 [PRD §12](../prd.md#12-미정-사항)를 따른다.

재생 중 속도를 바꾸면 현재 곡 위치에서 즉시 적용한다. 구간을 처음부터 다시 재생하거나 다음 반복까지 적용을 미루지 않는다. 같은 시도의 재생을 이어가며 수동 집계를 초기화하지 않는다. 이 집계 유지는 속도 변경 자체에만 적용하며, Auto를 켜거나 끄는 전환에서는 수동 집계를 초기화한다.

### 3. 미니맵에서 구간 지정과 반복

오른쪽에는 [에디터와 같은 미니맵](chart-editor.md#미니맵)을 둔다. 차트 전체를 축소해서 보고 여기에서 반복할 구간을 정한다. 지정한 구간을 연습 대상으로 반복하며, 페이드를 위해 구간 앞뒤를 실제 시간으로 각각 최대 3초 더 재생한다([RFD 0062](../rfd/0062-observer-controls-loop-and-exit.md)).

기존 하단 스크롤 바의 시작·끝 마커 방식은 오른쪽 미니맵의 구간 지정으로 대체한다. 기본 구간은 곡 처음부터 끝까지다.

- **시작 핸들**: 구간의 시작 위치를 바꾸어 길이를 조절한다.
- **끝 핸들**: 구간의 끝 위치를 바꾸어 길이를 조절한다.
- **몸통**: 구간 길이를 유지한 채 전체 위치를 옮긴다.

핸들과 몸통은 시간 위치를 자유롭게 지정하며, 박자에 스냅하지 않는다. 에디터의 박자 스냅 설정을 옵저버 구간 조작에 적용하지 않는다([RFD 0062](../rfd/0062-observer-controls-loop-and-exit.md)).

핸들이나 몸통을 드래그하는 동안에는 재생을 멈춘다. 드래그를 놓으면 확정한 구간의 앞 페이드 구간부터 바로 다시 재생하며, 콤보·달성률을 초기화해 새 시도로 집계한다. 드래그 도중의 구간 변경에는 재생을 시작하지 않는다. 따로 구간을 바꾸지 않아도 전곡을 대상으로 직접 나갈 때까지 계속 반복한다([RFD 0064](../rfd/0064-observer-whole-song-loop-and-reset.md)).

### 4. Auto 토글과 직접 입력·판정 확인

Auto 토글을 제공하며, 옵저버 진입 시 기본값은 켜짐이다. 켜져 있으면 자동연주로 관찰하고, 끄면 반복 구간을 직접 따라 치며 각 입력의 판정 결과를 확인한다. 연주 방법을 이해하거나 동작을 익히기 위해 사용할 수 있다. 개별 실패 판정이 나와도 학습을 계속할 수 있다.

Auto를 켜거나 끄면 현재 재생 위치에서 즉시 전환한다. 토글 때문에 구간을 처음부터 다시 시작하거나 앞 페이드 구간으로 돌아가지 않는다. Auto를 켜거나 끄는 전환은 수동 연습을 끊는 경계로 취급해 수동 콤보·달성률을 초기화한다. 수동에서 Auto로 전환하면 기존 수동 집계를 끝내고 초기화하며, Auto에서 직접 입력으로 돌아오면 새 수동 집계를 0부터 시작한다. 재생 위치는 현재 그대로 유지하며 전환은 즉시 적용한다. Auto가 처리한 노트의 점수·이론 가중치는 계속 집계에서 제외한다. ([RFD 0075](../rfd/0075-observer-manual-only-statistics.md)).

Auto를 끄면 진행 중인 바디도 즉시 직접 이어받는다. 현재 바디가 끝날 때까지 자동 유지를 남기지 않으며, 실제로 누르고 있는 키를 기준으로 일반 바디 규칙에 따라 유지 여부를 판단한다.

Auto 중에는 판정만 보여주고 콤보·달성률은 숨긴다. Auto로 처리한 노트는 콤보·달성률 집계에서 제외하며, 해당 점수와 이론 가중치도 달성률 계산에 넣지 않는다. 직접 연습할 때는 수동 연습 부분의 판정으로 집계한 콤보·달성률을 표시한다([RFD 0075](../rfd/0075-observer-manual-only-statistics.md)).

반복 구간이 끝나면 콤보·달성률을 초기화해 다음 반복으로 누적하지 않는다. Retry와 구간 변경도 새 시도로 초기화한다. 전환 경계에 걸친 입력·판정의 귀속과 Auto 전환의 입력 이벤트 처리 세부, 반복 경계의 키·바디 상태 처리는 [PRD §12](../prd.md#12-미정-사항)를 따른다.

### 5. Retry와 종료

- **Retry**: 현재 반복 구간의 시작을 기준으로 다시 재생한다. 선택 구간의 앞 페이드 인 구간을 거쳐 연습 구간에 진입한다. 전곡을 대상으로 사용할 때는 곡 시작을 기준으로 한다.
- **구간·곡 종료**: 수동 연습의 콤보·달성률을 초기화하고 현재 구간을 다시 반복한다. 기본 구간인 전곡도 동일하게 반복하며, 자동으로 모드를 종료하지 않는다.
- **나가기**: 플레이어가 명시적으로 나가면 옵저버를 종료하고 곡 선택으로 복귀한다.
- **리절트**: 옵저버 종료 시 리절트 화면을 표시하지 않는다.

### 6. 페이드 인·아웃

선택한 연습 구간 앞뒤에 **실제 시간으로 각각 최대 3초**를 추가 재생하며, 앞에서 페이드 인하고 뒤에서 페이드 아웃한다. 배속과 무관한 실제 시간 기준이다. 0.5배속을 유지한다면 앞뒤에서 곡 시간으로 각각 1.5초를 재생하는 것이 실제 시간 3초에 해당한다.

실제 재생은 음원 범위 안으로 제한하며, 시작·끝을 벗어나는 부족한 시간은 무음으로 채우지 않는다. 따라서 곡 처음·끝에 가까운 구간에서는 추가 재생 시간이 실제 3초보다 짧을 수 있다. 선택 구간 안을 페이드 때문에 줄이지 않는다. 각 반복은 앞 페이드 구간 → 선택 구간 → 뒤 페이드 구간 순서로 재생한다. Retry도 선택 구간의 앞 페이드 구간을 거쳐 다시 진입한다.

앞뒤 추가 재생 구간에 속한 구간 밖 노트는 표시·판정 대상에 포함하지 않는다. 선택 구간 안의 첫 노트는 확보된 앞 페이드 구간 동안 미리 낙하하는 모습이 보이게 한다. 준비 시간 동안 차트 전체를 숨기지 않으며, 구간 밖 노트의 제외와 선택 구간 노트의 낙하 예고를 구별한다. 음원 시작·끝을 벗어나는 여유 시간을 무음으로 보충해 3초를 유지하지 않는다([RFD 0062](../rfd/0062-observer-controls-loop-and-exit.md)). 일반 Play의 재개·음악 준비 3초는 기존 규칙을 유지한다.

### 7. 구간 경계의 노트 처리

연습 대상 노트는 선택 구간 안으로 한정한다([RFD 0063](../rfd/0063-observer-range-note-clipping.md)).

- 선택 구간보다 먼저 시작하는 롱노트는 시작을 선택 구간 시작에 맞춰 자른다.
- 선택 구간보다 뒤에 끝나는 롱노트는 끝을 선택 구간 끝에 맞춰 자른다.
- 헤드·릴리즈가 구간 밖에 있으면 제외한다. 잘린 시작·끝에 새 헤드·릴리즈를 만들지 않는다.
- 시작 경계에서 잘려 헤드가 없는 바디는 일반적인 헤드 없는 바디와 같은 시작 규칙을 적용한다. 미리 누른 키로 필요한 hold 수를 채워도 되고, 구간 시작에 키를 눌러도 된다. 기존 바디의 시작 허용 범위를 따르며 정확한 한 시각의 새 누름으로 제한하지 않는다.
- 구간 밖의 다른 점수 노트도 연습 대상에 포함하지 않는다.

이 처리는 옵저버의 표시·판정 대상을 정하기 위한 것으로, 원본 차트를 수정하지 않는다. Auto 전환과 반복 경계의 키·바디 상태 처리는 [PRD §12](../prd.md#12-미정-사항)를 따른다.

## 화면 구성

비행 배경 움직임은 일반 플레이와 같은 설정을 사용하며 기본값은 켬이다. 끄면 어두운 고정 배경으로 바꾸고 노트·기어·고도 게이지는 그대로 표시한다. 기어 모션 설정은 독립적으로 따른다([RFD 0100](../rfd/0100-flight-background-motion-setting.md), 설정 런타임 반영 미구현).

노트와 `trillZone` 등 입력 요구를 알리는 시각 표시는 유지하며, 피스 이름 라벨은 표시하지 않는다. 플레이어에게 피스 이름을 사용하는 범위는 튜토리얼 제목 정도다([RFD 0080](../rfd/0080-piece-names-in-tutorial-titles.md)).

| 영역 | 구성 |
|------|------|
| 조작 영역 | Auto 토글 (기본 켜짐), 재생·일시정지, Retry, 기존 속도 조절 |
| 차트 표시 영역 | 노트 흐름과 판정, 수동 연습 중 콤보·달성률 (Auto 중 숨김) |
| 오른쪽 미니맵 | 전체 차트 축소 표시와 반복 구간. 시작·끝 핸들은 길이 조절, 몸통은 위치 이동. 드래그 중 정지, 놓으면 확정 구간의 앞 페이드 구간부터 재생 |
