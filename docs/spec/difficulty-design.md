# not4k — 난이도 설계

이 문서는 not4k의 난이도가 어떤 구조로 상승하는지, 각 등급에서 유저가 무엇을 학습하는지를 정의한다.

---

## 설계 원칙

### 1. 레벨 간 난이도 차이를 구분한다

차트 간 난이도 차이가 레벨과 등급에 드러나도록 구분한다. 같은 레벨에 큰 격차가 몰리지 않도록 하고, 각 등급에서 요구하는 입력과 손배치 판단을 설명한다.

곡의 BPM만으로 차트의 부담을 판단하지 않는다. 실제 입력 속도·간격과 손배치 선택·전환의 복합도, 다음 동작을 읽고 준비할 여유를 함께 확인한다. 초기 수록곡의 BPM 분포는 [참고안](../context/chart-design.md#수록곡-선정과-bpm-분포-참고안)이며 선정의 필수 조건이 아니다([RFD 0052](../rfd/0052-song-selection-by-input-load.md)).

BPM 변화와 비트 분할의 복합은 별개의 요소로 평가한다. BPM이 바뀌는 순간에는 리듬 변화 대응과 복잡한 패턴의 부담이 겹칠 수 있으므로, 요구를 파악하고 손배치를 준비할 여유를 함께 확인한다([RFD 0071](../rfd/0071-subdivision-changes-and-bpm-changes.md)).

<a id="2-저난이도부터-키-교대를-익히게-한다"></a>

### 2. 고급 패턴을 포함해 낮은 부담부터 점진적으로 익히게 한다

속도·밀도·지속 길이·다른 입력과의 조합을 조절해 모든 패턴을 부담이 낮은 형태부터 점진적으로 익힐 기회를 제공한다. 고급 패턴도 해당 수준에서 부담을 낮춘 형태부터 더 빠르거나 밀도·길이·조합의 부담이 높은 형태까지 단계적으로 경험하게 한다. 입문이나 저레벨에만 적용하지 않으며, 고급 패턴의 입문 배치나 모든 차트의 모든 패턴·단계를 의무화하지 않는다. 고정 속도·비율·구간 수와 새 튜토리얼·해금·선행 조건은 정하지 않는다([RFD 0051 후속 명확화](../rfd/0051-beginner-trill-load-and-judgment.md#후속-명확화-고급-패턴을-포함한-모든-패턴의-점진적-학습-2026-10-31)).

트릴 학습 배치의 예로, 노트 밀도가 낮은 차트에서 트릴 노트를 조금씩 배치해, 한 레인에서 키를 교대하는 감각을 익히게 한다. 초급 트릴은 같은 판정 설정 안에서 속도·밀도·지속 길이·다른 입력과의 조합으로 부담을 조절하며, 레벨에 따라 판정 윈도우를 자동 완화하지 않는다. Normal/Easy 설정과 Grace는 별도로 유지한다([RFD 0051](../rfd/0051-beginner-trill-load-and-judgment.md)). 난이도가 올라가면 교대의 빈도와 다른 입력과의 조합을 늘려 가변 손배치를 점진적으로 학습하게 한다.

### 3. 성장 경로가 하나로 연결된다

16키 프리셋(레인당 4키)을 기본으로 설정하되 입문에서는 4키를 주로 활용한다. 활용하는 키가 늘어나도 레인 구조는 항상 동일하며, 이전 등급에서 익힌 차트 독해와 키 교대를 바탕으로 손배치의 활용 범위를 넓힌다.

### 4. 모든 노트 타입은 Lv.1부터 사용할 수 있다

각 차트에 모든 타입을 넣을 필요는 없다. 입문 차트에서도 트릴·더블 등을 필요에 따라 선택해 적은 양으로 배치할 수 있다. 난이도는 타입의 해금보다 사용한 노트와 입력방식의 **빈도·밀도·복합도**로 조절한다([glossary](../context/glossary.md#노트-타입)).

### 5. 단순한 요구에서 실시간 동작 판단을 만든다

시각적으로 제시하는 입력 요구는 단순하고 명확해야 한다. 개별 노트의 구별뿐 아니라 노트 종류·속성·동시 조건의 조합을 해석하는 부담도 낮게 유지한다. 손배치 판단의 깊이는 단순한 요구를 시간적·공간적으로 배치하고 연결해 만든다([인지 부하](../context/glossary.md#인지-부하-cognitive-load), [RFD 0101](../rfd/0101-cognitive-load-and-action-planning.md)).

동작 계획의 난이도는 최상급을 포함해 **한 번 눈에 익힌 뒤 다시 하면 대응할 수 있는 정도**를 지향한다. 해당 난이도의 기본 규칙과 입력방식에 익숙한 플레이어가 초견에서 전환을 놓치더라도, 흐름을 파악한 다음 시도에는 화면의 예고와 현재 손 상태를 바탕으로 다음 동작을 알고 손배치를 시도할 수 있는 수준이다. 실제 속도·정확도를 맞추고 성공하는 데는 반복 연습이 필요할 수 있다. 짧은 사전 경험과 수행 숙련도를 높이는 학습은 포함하며, 긴 손순서를 따로 외우는 과도한 암기 부담은 피한다.

차트 설계·플레이테스트에서는 다음을 확인한다.

- 요구를 알아보는 데 여러 종류·속성·조건을 복잡하게 해독해야 하지 않는가? 처음 읽을 때 실제로 필요한 독해 부담도 차트 Lv.에 반영했는가?
- 구간을 한 번 본 뒤 의도된 연주 방법을 파악하고, 다음 시도에서 더 수월하게 연주할 수 있는가? 실제 수행의 속도·정확도를 익히는 어려움과 구별했는가? 핵심 경험은 [RFD 0045](../rfd/0045-target-players-and-pattern-solving.md)를 따른다.
- 다음 입력을 알아도 손배치를 준비·전환할 여유가 없어 긴 손순서의 암기에 의존하게 되지는 않는가?

---

### 6. 클리어와 특정 랭크 달성 난이도를 함께 검토한다

평가 기준은 클리어 난이도와 특정 랭크 달성 난이도다. 같은 패턴도 비행 규칙과 초반·후반의 배치 위치에 따라 체감과 결과가 달라질 수 있어, 가장 어려운 구간이나 곡 전체의 평균 부담 중 하나만으로 정하지 않는다. 고난도 차트에서는 앞선 연주의 누적 피로로 후반 동작 수행 여력이 줄어 같은 패턴의 실행 부담이 커질 수 있다는 점도 클리어 가능성 평가에 고려한다. 모든 차트의 후반이 일률적으로 더 어렵다는 뜻은 아니며, 정량 피로 수치나 위치별 가중치를 정하지 않는다.

차트 제작에서는 두 척도가 이질적으로 크게 어긋나는 구성을 지양한다. 현재는 이 방향만 채택했으며, 구체적 평가 기준은 [PRD §12](../prd.md#12-미정-사항)에서 미정으로 관리한다([RFD 0048](../rfd/0048-clear-rank-and-chart-position.md)).

## 난이도 체계

- **Lv. (차트 레벨)**: 클리어와 특정 랭크 달성의 어려움을 기준으로 평가하는 차트 난이도 수치. 초견 독해·동작 계획·물리 부하와 비행 규칙·배치 위치를 함께 고려하며, 구체적 기준은 미정이다([glossary](../context/glossary.md#차트-레벨-lv)).
- **PLv. (피스 레벨)**: 개별 피스의 본격 활용 기준 레벨. 충분히 느리고 단순한 짧은 체험은 더 낮은 레벨에서도 허용한다.
- **난이도 등급**: 레벨 구간을 묶은 분류(입문/초급/중급/상급/최상급).
- **난이도명**: 한 곡 안의 차트를 구분하는 `Liftoff → Infiltration → Breakthrough` 순서의 라벨. 각 단계의 비행 시나리오·연출에 대응한다([RFD 0022](../rfd/0022-flight-difficulty-names-and-visuals.md)).

> **용어 규칙**: 차트 단위는 **Lv.**, 피스 단위는 **PLv.**, 구간 분류는 **난이도 등급**으로 통일한다.

## 헤드 없는 바디 패턴의 배치 기준

헤드 없이 시작하는 바디와 싱글→더블 전환(`.-`, `-=`, `o-=`)은 난이도명에 따른 사용 제한을 두지 않는다. 기존 `HARD` 전용 제한과 EASY·NORMAL에서 더블 헤드를 반드시 경유하도록 한 지침은 폐지한다([RFD 0050](../rfd/0050-headless-body-patterns-by-load.md)).

독해 부담과 속도·밀도·지속 길이·다른 입력과의 조합을 기준으로 차트 수준에 맞는지 확인한다. 충분히 느리고 단순한 짧은 체험은 낮은 레벨에서도 허용한다. 처음 읽을 때의 어려움도 차트 Lv.에 반영하며, PLv.를 본격 활용의 기준으로 삼는다. 정의는 [glossary](../context/glossary.md#난이도명-difficulty-name)를 따른다.

차트 구조·판정에 필요한 기존 배치 제약은 유지한다. 경계 뒤 여분 키를 떼야 하는 별도의 구분을 요구하는 배치의 주의사항은 [RFD 0032 §9-4](../rfd/0032-body-held-count.md#9-4-여분-키-구분의-튜토리얼-전달)를 따른다. 느리다는 이유만으로 모든 복합 배치를 낮은 레벨에 허용하는 기준은 아니다.

## 난이도 등급 정의

### 입문 (Lv.1～3)

싱글 90% 이상은 싱글 중심 구성을 설명하는 참고치이며, 필수 비율이 아니다. 노트 비율만으로 허용 여부를 정하지 않고 실제 독해·연주 부담이 해당 차트 수준에 맞는지 확인한다([RFD 0059](../rfd/0059-beginner-single-ratio-as-reference.md)).

| 항목               | 내용                                               |
| ------------------ | -------------------------------------------------- |
| **유저 키 바인딩** | 기본 4키 중심, 보조키의 짧은 체험 (프리셋 예시) |
| **핵심 경험**      | 4레인 인식, 기본 타이밍, "이 게임은 다르다"를 인지 |
| **노트 구성**      | 싱글 중심 (90% 이상은 참고치) / 트릴·더블의 짧은 체험 |

16키 프리셋(레인당 4키)을 기본으로 설정하되, 입문 단계에서는 중지와 검지 4키를 주로 활용하는 예시로 시작한다. 트릴·더블은 내측 2·3번 레인에 한정하지 않으며, 충분히 느리고 단순한 짧은 배치라면 외측 1·4번 레인에서도 허용한다. 독해 부담과 입력 속도·밀도·지속 길이·다른 입력과의 조합, 앞뒤 손배치 흐름이 차트 수준에 맞는지 확인한다. 해당 차트에서 사용할 타입과 레인은 의도에 맞춰 선택한다([RFD 0057](../rfd/0057-beginner-trill-double-on-outer-lanes.md)).

---

### 초급 (Lv.4～6)

| 항목               | 내용                                       |
| ------------------ | ------------------------------------------ |
| **유저 키 바인딩** | 엄지 비중 상승 (6키)                       |
| **핵심 경험**      | `trillZone`이 명확해지고, 더블이 흐름에 삽입 |
| **선행 학습**      | 4레인 인식, 기본 타이밍                    |

엄지의 비중이 점점 높아지는 단계다. `trillZone`이 입문보다 길어지고 빈번해지며, 더블 노트가 리듬의 강조점에 삽입된다. 롱노트 끝 탭(PLv.4)이 본격 활용되기 시작한다. 내측 레인(2, 3번)에서 검지+엄지를 적극 활용하게 되지만, 외측 레인(1, 4번)은 아직 주로 1키만 사용한다.

---

### 중급 (Lv.7～10)

| 항목               | 내용                                 |
| ------------------ | ------------------------------------ |
| **유저 키 바인딩** | 8키 입문 (약지 추가)                 |
| **핵심 경험**      | 앵커 본격화, 롱노트 중 탭 등장  |
| **선행 학습**      | 트릴 처리, 더블 노트 처리, 엄지 활용 |

외측 레인(1, 4번)에 약지가 추가되어 8키를 본격적으로 사용하기 시작하는 단계다. 앵커가 본격화되어, 한 손이 트릴을 처리하는 동안 반대 손이 복잡한 배치를 담당하는 구조가 등장한다. 롱노트 중 탭(PLv.7)을 본격 활용해 한 레인 내 복합 입력을 처리한다. 낮은 레벨의 느리고 단순한 짧은 체험과 구별한다.

반복 입력의 키 교대와 다른 레인의 입력을 조합하고, 바디 유지 중 같은 레인에 다른 입력을 더하는 손배치를 익히는 난이도대다.

---

### 상급 (Lv.11～13)

| 항목               | 내용                                   |
| ------------------ | -------------------------------------- |
| **유저 키 바인딩** | 8키 활성화                             |
| **핵심 경험**      | 수평 이동·가변 분할 등장. 모든 피스가 복합 결합 |
| **선행 학습**      | 8키 기본 활용, 홀드 중 탭 처리       |

모든 피스가 복합적으로 결합된다. 비트 복합 트릴(PLv.10)이 앵커와 결합하여 트릴 측 손의 부담이 동적으로 변화한다. 수평 이동(PLv.11)으로 담당 레인을 바꾸거나, 가변 분할(PLv.11)로 1/3 등의 손배치를 유지하는 처리가 등장한다. 분담을 유지하는 부담과 손을 옮기는 부담을 구분하며, 가변 분할에 수평 이동이 반드시 동반되지는 않는다. 양손의 물리적 교차는 필수 조건이 아니다. 높은 인지/물리 부하가 동시에 요구된다.

---

### 최상급 (Lv.14～15)

| 항목               | 내용                                    |
| ------------------ | --------------------------------------- |
| **유저 키 바인딩** | 16키 완전 활용                          |
| **핵심 경험**      | 새 피스 없이 빠른 손배치 전환과 복합 입력 수행 |
| **선행 학습**      | 모든 피스의 복합 처리                   |

상급까지 익힌 피스를 복합적으로 처리하며 빠른 손배치 전환을 수행한다. 한 레인에서 바디를 유지하면서 Point를 처리하는 배치가 높은 밀도로 등장하고, 레인당 4키 바인딩(16키 프리셋)을 활용한다. 새 피스를 추가하기보다 기존 피스를 이어 처리하는 판단과 수행 숙련도를 요구한다. 시각적 요구는 단순하고 명확하게 유지하며, 한 번 흐름을 익힌 뒤 다음 동작을 알고 손배치를 시도할 수 있어야 한다. 실제 속도·정확도를 맞추는 데는 반복 연습이 필요할 수 있다.

"16키 완전 활용"은 16키를 동시에 사용한다는 뜻이 아니다. 패턴마다 유도되는 보조키가 달라져 **차트 전체에 걸쳐** 최대 16키가 활용된다는 뜻이다. 동시 활용 8키는 상한이 아닌 일반적인 운용 예시이며, 이를 넘는 활용은 흔치 않을 것으로 예상한다. 실제 부담은 배치별로 확인한다([주키와 보조키](keybinding.md#주키와-보조키-운용-개념), [RFD 0058](../rfd/0058-simultaneous-key-count-as-example.md)).

이 단계에서는 익힌 입력방식과 보조키를 함께 활용하는 손배치의 범위를 넓힌다.

## 등급 간 전이 설계

각 등급의 경계에서 유저가 느끼는 "벽"을 최소화하기 위한 원칙:

### 1. 온보딩 차트

각 등급의 최초 곡들은 새로운 피스를 매우 낮은 밀도로 도입한다. 예를 들어 초급의 첫 곡은 릴리즈탭이 곡 전체에서 4～8회만 등장하고, 나머지는 입문 수준의 배치로 구성된다.

### 2. 플레이어가 선택하는 키 활용 안내

플레이어가 도움말·튜토리얼을 선택했을 때, 같은 레인의 반복 노트를 여러 키로 나누어 처리하는 방법을 설명하고 체험할 수 있게 한다. 같은 차트도 키 활용에 따라 처리 방법과 체감이 달라질 수 있음을 보여준다. 실패 결과만으로 연주 방법을 자동 조언하거나 도움말·튜토리얼을 열지 않는다([RFD 0054](../rfd/0054-player-requested-playing-guidance.md)).

### 3. 난이도 표시

곡의 난이도 표기에 Lv.와 난이도 등급을 명시한다. IIDX에서 12레벨 내부의 격차를 게임이 설명해주지 않아 유저가 외부 자료에 의존해야 했던 문제를 방지한다.
