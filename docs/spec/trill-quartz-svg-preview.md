# 석영 Trill SVG 미리보기

선택한 [6번 시안](../../assets-lab/classic/references/trill-quartz-approved.png)의 포인트·바디를 편집 가능한 SVG로 재구성한다. 끝 터미널은 바디와 같은 재질을 마름모로 자른다. 독립 미리보기와 [Lab의 Classic 튜토리얼 재생기](note-asset-lab.md)에 적용한다. 게임의 기본 스킨과 판정은 변경하지 않는다.

## 에셋

포인트1개와 바디·끝 터미널의 대기/켜짐/실패6개는 모두 `viewBox="0 0 1000 200"`이며 같은 최대 너비를 갖는다. 비트맵을 포함하지 않고 기본 색면·반사광·켜짐의 내부 발광을 별도 그룹으로 편집할 수 있다.

| 파일 | 표현 |
| --- | --- |
| `assets-lab/classic/sources/point-trill.svg` | 밝은 흰색 석영 절삭면, 상하대칭 100:20 마름모 실루엣 |
| `assets-lab/classic/sources/body-trill.svg` | 회색 음영의 불투명 석영 두 면, 무늬·측면 띠 없는 수직 반복 타일 |

| `assets-lab/classic/sources/body-trill-on.svg` | 켜짐 시안의 넓고 부드러운 흰 내부광을 가진 반복 바디 |

켜짐·실패는 [켜짐 승인 시안](../../assets-lab/classic/references/trill-body-on-approved.png)과 [실패 승인 시안](../../assets-lab/classic/references/trill-body-failed-approved.png)을 기준으로 재구성한다. 기본 대기 바디·끝 터미널과 흰 포인트는 이전 파일을 그대로 보존한다. 켜짐은 흰빛이 폭의 일부를 차지하고 길이 전체에 연속된다. 실패는 면의 명암과 약한 반사만 남기며 균열·무늬·경고색을 추가하지 않는다.

시작 터미널은 만들지 않는다. 바디의 색과 반사는 가로 위치에만 의존하므로 세로 길이에 따라 늘리지 않고 반복한 뒤 남는 부분을 자른다. 바디와 터미널은 같은 SVG 표면 생성 함수를 공유한다. 전체 면을 불투명하게 밑칠해 축소 시 두 면의 중앙에 알파 틈이 생기지 않게 한다.

이미지젠 원본의 색감·절삭면을 기준으로 벡터를 재구성한 결과이며 픽셀 단위 자동 추적은 아니다. 원본의 불규칙한 비율 대신 요청한 100:20 비율로 좌표를 정의한다.

## 미리보기

경로: `/assets-lab/classic/trill-quartz-preview.html`

- 개별 SVG 7개와 전체 ZIP, 선택한 상태의 조립 SVG를 다운로드한다.
- 대기·켜짐·실패 버튼으로 바디와 끝 터미널, 짧은 길이 비교, 다운로드를 함께 바꾼다. 초기 상태는 켜짐이다. 포인트와 너비·길이는 유지한다.
- 세 상태의 단품과 너비100px 조립을 나란히 표시한다. 이 비교는 선택 버튼과 독립적으로 각 상태를 유지한다.
- 너비는 60–260px, 바디 길이는 0–320px로 조절한다. 기본값은 200px·220px이다.
- 포인트와 터미널의 높이는 항상 너비의 1/5이다. 바디도 같은 너비로 반복한다.
- 조립 길이는 두 마름모 중심 사이 거리이다. 바디는 위 터미널의 좌우 꼭짓점 높이부터 아래 포인트의 좌우 꼭짓점 높이까지 채운다. 길이 0에서는 흰 포인트가 터미널을 덮는다. 이는 미리보기 배치 규칙이며 게임 모델의 새 규칙이 아니다.
- 너비 100px에서 길이 0·13·83·167px를 함께 비교한다.
- 접은 영역에서 선택한 원본과 터미널 재질 수정 시안을 확인한다.
- 모바일에서는 개별 에셋과 조립을 세로로 배치하며 실제 크기 비교 영역만 가로로 스크롤한다.

## 생성·검증

저장소 루트에서 `node scripts/build-trill-quartz.mjs`를 실행한다. 생성기는 위7개 원본 SVG와 `assets-lab/classic/downloads/`의 상태별 조립 SVG·ZIP만 출력한다. ZIP 생성에는 Python 3 표준 라이브러리를 사용한다.

`pnpm build:classic`을 실행하면 같은 원본을200×40 PNG로 변환해 `/lab/note-assets?design=classic`에 반영한다. 재생 차트의 `트릴`·`트릴 롱`으로 실제 낙하 모습을 확인한다. 대기는 기존 회색, 유지 중에는 내부광이 켜진 상태, 실패하면 어두운 상태를 바디·끝 터미널에 함께 사용한다.

재생기의 트릴 포인트는 마름모 하단 두 변을 따라 최대 알파36%의 그림자가6.4px 동안 부드럽게 사라지도록 표시한다. 싱글·더블의 가로 그림자를 그대로 적용하면 바디와 하단 윤곽이 섞여 잘려 보이므로, 동일한 그림자 텍스처를100px 너비의 하단 경로에 맞춘다. 원본 SVG·PNG와 포인트의100×20 크기는 유지한다. 트릴 바디·터미널은 앞 구간의 켜짐을 이어받지 않고 실제로 유지 중인 자기 구간만 켠다. `note-assets.spec.ts`는 구간별 켜짐, 하단 양쪽 그림자의 감쇠, 바디·터미널 위의 포인트 픽셀 보존을 실제 그래픽 렌더링으로 검증한다.

- [단위 테스트](../../assets-lab/classic/trill-quartz.test.ts): 공통 너비, 캡 높이, 소수 길이, 길이0 배치, 상태별 발광 분리. `states.test.ts`는 런타임 상태가 대응 원본을 사용하는지 검증한다.
- [브라우저 테스트](../../e2e/lab/trill-quartz-svg.spec.ts): 다운로드7종, 순수 벡터, 상하대칭 실루엣, 모든 상태의 반복 경계·재질 일치·명암 차이·조립 내부 알파,390px 모바일 상태/치수 조절. `note-assets.spec.ts`는 생성 PNG와 대응 원본 SVG를 픽셀 비교한다.
- SVG 그라디언트의 Chromium 디더링은 색 차이 최대3/255를 허용한다. 재질 비교는 마름모 외곽에서2원본픽셀 이상 안쪽에서 수행한다. 밝은 발광을 클리핑한 외곽은 안티앨리어싱 알파가255로 반올림되기도 하므로 알파 값만으로 내부를 판별하지 않는다. 외곽 안티앨리어싱을 제외한 조립 내부는 알파255여야 한다.
