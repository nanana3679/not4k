# not4k — 스코어링 시스템

[RFD 0037](../rfd/0037-explicit-score-notes-and-body.md)의 **채택 계약·일반 기본 경로 구현·검증**을 반영한다(판정 코어·세션 정산은 #342, 실제 재생·결과 연결은 #346·#347). 정식 정의는 [glossary](../context/glossary.md#점수-항목과-무점수-miss), 설계 기대값은 [명시적 점수 노트 판정 사례](explicit-note-judgment-cases.md)를 따른다. 과도기 구형 점수·입력 설명과 이전 사례 결과는 별도로 보존하며 새 구현의 정답으로 사용하지 않는다. 미정 사항·실제 이행은 [PRD §12](../prd.md#12-미정-사항)에서 추적한다.

## 새 모델의 점수 범위

명시 탭·릴리즈·틱 노트만 점수 항목을 만들고 바디 정상 완료는 무점수다. 바디 실패의 원인 Miss와 연결 항목의 종속 0점은 구별한다. 아래 [명시 점수 항목과 무점수 바디](#명시적-점수-항목과-정산)의 채택 계약을 따른다.

### 핵심 원칙

1. **더블 노트는 가중치를 가진다**: 더블 노트는 독립된 싱글 판정 × 2로 처리되므로, 자연스럽게 싱글 노트의 2배 비중을 차지한다. 별도의 보너스 없이도 더블 노트를 정확하게 입력해야 할 동기가 발생한다.

2. **초급 트릴의 부담은 배치로 조절한다**: 같은 판정 설정 안에서 속도·밀도·지속 길이·다른 입력과의 조합을 조절해 키 교대를 익히게 한다. 차트 레벨이 낮다는 이유로 판정 윈도우를 자동 완화하지 않는다. Normal/Easy 설정과 Grace의 별도 타이밍 완화, 교대 실패의 `goodTrill` 규칙은 유지한다([RFD 0051](../rfd/0051-beginner-trill-load-and-judgment.md)).

3. **입문 등급(Lv.1～3)은 기본 입력·판정 규칙을 낮은 부담으로 익히는 단계**: 낮은 밀도와 단순한 입력 조합으로 not4k의 기본 규칙을 경험하게 한다. 기존 4K와 같은 스코어링 감각이나 학습 없이 적응하는 것을 전제로 두지 않는다. 같은 판정 설정 안에서 배치의 부담을 조절한다.

## 판정 윈도우와 점수

| 등급 | Normal | Easy | 점수 |
|---|---:|---:|---:|
| Perfect | ±41ms | ±50ms | 3 |
| Great | ±82ms | ±100ms | 2 |
| Good | ±120ms | ±150ms | 1 |
| `goodTrill` | Good 안의 교대 실패 | 동일 | 1 |
| Miss | 적격 입력 부재·유지 실패 | 동일 | 0 |

일반 탭과 명시 릴리즈는 누름의 등급별 창을 공유하며 앞뒤 대칭이다. Good 경계값은 포함하고 그 밖 입력은 해당 대상을 소비하지 않는다. Bad 등급과 매칭 구간은 사용하지 않는다. Grace 탭·릴리즈는 같은 Good 최대 창 안에서 실제 down/up을 요구하고 타이밍 등급은 Perfect다. 기존 트릴 교대 실패 `goodTrill`은 유지한다. 틱 노트는 바디 상태에 따른 Perfect/종속 0점 정산이며 독립 창·타이밍 등급을 만들지 않는다.

표의 수치는 현행 설정이다. 대표 사례는 Normal과 임시 유지 유예 20ms를 명시해 사용하며 새로운 최종 튜닝 값을 확정하지 않는다. 구형 `holdOnly`의 Perfect/Miss 상태 판정은 아래 과도기 범위에서만 보존한다.

## 명시적 점수 항목과 정산

**채택 계약·일반 기본 경로 구현·검증(판정 코어·세션 정산 #342, 실제 재생·결과 연결 #346·#347).** 명시한 탭·릴리즈·틱 노트가 요구 한 몫당 점수 항목 하나와 이론 가중치 3을 만든다. 더블은 두 항목이다. 바디의 항목 수·가중치는 0이며 정상 유지·종료·경계 자체에 점수·콤보·고도 회복을 만들지 않는다. 새 모델에는 `holdOnly`를 두지 않고 주기적인 자동 유지 점수도 만들지 않는다.

바디 hold 수와 명시 릴리즈 수를 같게 강제하지 않는다. double 바디 끝에 릴리즈 하나만 있으면 그 항목 하나만 분모에 넣는다. single 바디의 double 릴리즈도 수량 차이만으로 금지하거나 자동 보정하지 않는다. 2→1 감소에서 다룬 예시는 싱글 릴리즈 하나이며 감소량에서 숨은 항목을 생성하지 않는다.

같은 더블 릴리즈의 두 항목은 일반/Grace 종류를 공유한다. 일반·Grace를 한 항목씩 섞은 조합은 허용하지 않으며 두 항목의 개별 정산과 노트의 공통 종류를 구별한다.

각 항목은 한 번만 정산한다. 입력 시각·실패 횟수·정산 순서는 전체 이론 가중치를 바꾸지 않는다.

| 결과 | 점수·분모 | 확정 효과 |
| --- | --- | --- |
| 일반 탭·릴리즈 성공 | Perfect 3 / Great 2 / Good 1점, 원래 가중치 3 | 항목별 성공·콤보·고도·타이밍 효과 |
| Grace 탭·릴리즈 성공 | 유효 입력의 타이밍 등급 Perfect 3점, 원래 가중치 3 | 실제 down/up 요구, FAST/SLOW·타이밍 오차 없음 |
| 틱 노트 성공 | 틱당 Perfect 3점, 원래 가중치 3 | 콤보 +1·일반 Perfect 고도 기여·Perfect 글자·해당 레인 일반 타격 효과, 타이밍 없음 |
| 탭·릴리즈의 일반 실패 | 원래 항목 0점·원래 가중치 | 원인 Miss·콤보 단절·고도 손실 |
| 바디 시작·유지 실패 | 새 항목·분모·직접 감점 없음 | 원인 실패 효과를 한 번만 적용 |
| 실패에 종속된 미처리 릴리즈·틱 노트 항목 | 원래 항목 0점·원래 가중치로 한 번 정산 | 추가 Miss 통계·콤보·고도·판정 글자·성공 타격 효과 없음. 실패 표시는 남음 |

Grace의 타이밍 면제는 기존 트릴 교대 실패 `goodTrill`을 없애지 않는다. 구체적인 고도 회복량과 `flightRule`별 실패 정책은 [PRD §12](../prd.md#12-미정-사항)의 별도 후속 범위다.

### 틱 노트의 정산 시점

틱 노트는 바디와 같은 판정 상태에 정산만 연결한다. 자체 down/up 소비·독립 허용 창·기한은 없다.

- 정상 유지 중이면 틱 시각에 Perfect로 정산한다. 이른 down만으로 미래 틱을 미리 성공시키지 않는다.
- 최초 시작 판단·유지 유예 중이면 바디 결과를 기다린다. 유효한 늦은 시작·회복 뒤 성공하고 확정 실패 뒤 종속 0점으로 정산한다.
- 유효한 이른 정상 종료에서는 그 종료 몫에 속한 남은 틱을 같은 시점에 함께 Perfect로 정산한다. 뒤 바디 소속의 경계 틱을 포함하지 않는다.
- 일반 릴리즈가 Good이어도 틱 노트 성공은 Perfect다. 틱 노트 Good 예외를 만들지 않으며 이미 성공한 틱은 이후 실패로 되돌리지 않는다.

틱 노트만 합법 위치에 추가·제거해도 기존 바디 진행·탭/릴리즈 배정·바디 실패 효과는 같아야 한다. 바뀌는 것은 명시 틱 항목의 정산과 성공 효과다. [ENJ-05～08·18](explicit-note-judgment-cases.md#enj-05)에서 대기·실패·이른 종료·늦은 시작을 대조한다.

### 실패 종속의 범위

실제로 시작하지 않은 바디에 붙은 릴리즈는 끝 창 안 up만으로 성공하지 않는다. 정상 완료한 바디의 릴리즈는 자기 창까지 기다리고, 누락하면 릴리즈만 Miss다. 바디 완료 자체로 성공시키거나 완료한 바디에 새 유지 실패를 더하지 않는다.

double 전체 끝의 릴리즈 두 항목은 바디 한 몫 실패 시 하나만 기회를 잃는다. 전체 끝의 항목이 하나뿐이면 건강한 몫 하나로 기회를 보존한다. 2→1 감소의 싱글 릴리즈는 끝나는 실패 몫에 귀속하고 건강한 몫은 뒤 single로 이어지므로 같은 방식으로 처리하지 않는다. 이미 닫힌 기회는 재누름으로 돌아오지 않는다. [ENJ-09～15](explicit-note-judgment-cases.md#enj-09)와 [RFD 0037 §4](../rfd/0037-explicit-score-notes-and-body.md#4-경계실패-종속)를 따른다.

## 새 모델의 입력과 효과

탭 노트가 가장 이른 적격 down을, 명시 릴리즈가 가장 이른 적격 up을 소비한다. 바디·틱 노트는 입력을 소비하지 않으며 같은 down의 hold도 바디 조건에 참여한다. 숨은 연결 release의 up 자동 소비는 없다. 바디의 실제 시작·종료와 같은 키 재누름 예외는 [게임 코어](game-core.md#새-모델의-입력과-바디-진행)를 따른다.

확정 효과는 항목별로 한 번 적용한다. 현재 콤보는 확정 순서와 같은 timestamp·phase 묶음의 Miss 우선을 유지한다. 같은 확정 시각의 대표 판정 글자는 가장 낮은 등급이며 종속 0점은 후보가 아니다. 대표 등급 안에서 타이밍 표시가 허용된 실제 입력을 우선하고 여러 개면 raw 오차의 절대값이 가장 큰 입력을 사용한다. 틱·Grace에 오차를 만들거나 다른 등급에서 빌리지 않는다. 대표 표시 선택과 각 항목의 점수·통계·콤보·고도·타격 정산은 별개다. [ENJ-07·16·17](explicit-note-judgment-cases.md#enj-16)을 따른다.

## 과도기 구형 점수·입력 계약

아래는 구형 읽기·편집과 현행 런타임/이전 논의를 대조하기 위한 기존 설명이다. 새 모델의 정답으로 적용하지 않으며 구형 항목·기존 사례 결과는 자동 변환하지 않는다. 제거 시점은 [RFD 0037 §8](../rfd/0037-explicit-score-notes-and-body.md#8-구형-차트와-과도기)을 따른다.

### 구형 점수 항목과 정산

차트 컴파일 시 head, 실제 감소·마지막 release, 명시된 `holdOnly`를 점수 항목으로 만들고 각 이론 가중치는 3이다. double head는 두 항목이다. 일반 2→1 감소는 release 한 항목이고 같은 끝에 `holdOnly`가 있으면 앞 double의 상태 항목 두 개다. 일반 connection 성공에는 점수·콤보·고도 회복이 없다.

각 항목은 ID로 한 번만 정산한다. 입력 시각, 실패 횟수, 정산 순서가 전체 이론 가중치를 바꾸지 않는다.

| 결과 | 점수·분모 | 실패·표시 |
|---|---|---|
| head·실제 release·`holdOnly` | 원래 항목을 해당 등급으로 정산 | 해당 판정 효과 |
| 무점수 유지·연결 Miss | 획득 점수 차감과 분모 추가 없음 | Miss 통계·고도 손실·콤보 단절 1회 |
| head Miss 등으로 종속 끝점 실패 | 원래 끝 항목을 0점·원래 가중치로 정산 | 추가 끝 Miss·고도 손실·콤보 이벤트 없음 |

이미 건강하게 승계한 unit은 별도 head Miss 때문에 종속 실패로 정산하지 않는다. 활성화한 unit도 실패 시점과 끝점에서 두 번 패널티를 받지 않는다. 차트·입력별 기대값은 [NJ-S01～S03](note-judgment-cases.md#nj-s01)을 따른다.

### 구형 입력별 판정

Point는 해당 레인에서 Good 창과 물리 키 자격을 충족한 가장 이른 대상이 down을 소비한다. double은 서로 다른 두 물리 키를 요구하고 두 성공을 별도 기록한다. head 없는 미처리 시작은 down을 소비하되 시작 점수는 없다. raw held로 양수 바디를 독립 시작하지 않는다.

실제 release는 준비·창·누름의 권한을 충족한 가장 이른 끝 하나가 up을 소비한다. 일반 여분 up은 소비하지 않는다. 같은 물리 키도 유효한 새 head·미처리 시작으로 새 누름의 권한을 얻으면 남은 release를 처리할 수 있다. 임의 재누름에는 권한이 없다.

연결용 up은 유효한 교대 몫만큼 FIFO로 보정하여 뒤 release에서 제외한다. 모호한 up은 후속 head의 기한까지 보류할 수 있으며, 실제 release로 확정될 때는 원래 up의 시각으로 등급을 계산한다. `holdOnly` 완료는 up을 소비하지 않는다.

트릴 교대 세트에는 head를 소비한 키만 등록한다. 같은 timestamp의 여러 적격 head 중 최고 등급 입력 하나만 교대를 인정하고 나머지는 `goodTrill`이다. 구간 귀속과 실패 초기화는 [트릴 경계 설명](../context/trill-boundary-input.md)을 따른다.

## 현재 콤보와 Full Combo

성공한 점수 판정은 현재 콤보를 1 증가시키고 Miss는 끊는다. `goodTrill`은 Good처럼 콤보를 유지한다. 무점수 connection 성공은 증가시키지 않으며 무점수 유지 Miss도 끊는다. 종속 0점 정산은 별도 콤보 이벤트가 아니다.

보류 판정은 확정 순서로 반영하며 원래 입력 시각으로 소급하지 않는다. 같은 timestamp·phase 확정 묶음에 Miss와 성공이 함께 있으면 Miss 우선으로 현재 콤보는 0이다. 최대 콤보수 통계는 제공하지 않는다.

곡을 끝까지 연주하고 무점수 유지 실패를 포함해 Miss가 없으면 Full Combo이다. 미완주 플레이는 종료 시점까지 Miss가 없더라도 Full Combo로 인정하지 않는다. 점수 항목을 모두 Perfect로 처리하고 무점수 연결만 실패한 **100%이지만 Full Combo가 아닌 결과**를 허용한다. 이를 막기 위한 Miss 감점이나 콤보 점수 보너스는 없다.

`Liftoff`는 Miss 없이 완주하면 고도의 클리어 조건을 충족하도록 게이지 상승량을 설정한다. 풀콤보 조건을 충족했지만 고도 때문에 실패한 완주를 허용하지 않으며, 풀콤보 자체의 완주·Miss 0 조건은 유지한다([RFD 0093](../rfd/0093-liftoff-no-miss-completion-clears.md)).

## 올퍼펙트

종료한 플레이의 클리어 상태는 실패·성공·풀콤보·올퍼펙트 중 하나이며, 올퍼펙트와 풀콤보를 모두 충족하면 올퍼펙트 하나로 표시한다([RFD 0092](../rfd/0092-exclusive-play-outcome-and-chart-display.md)).

올퍼펙트는 곡을 끝까지 연주하고 모든 점수 노트를 Perfect로 처리하며, 무점수 바디 실패를 포함한 Miss가 한 번도 없는 경우에만 인정한다. 점수 항목이 모두 Perfect여도 무점수 바디에서 Miss가 발생하면 올퍼펙트로 인정하지 않는다([glossary](../context/glossary.md#올퍼펙트-all-perfect), [RFD 0090](../rfd/0090-song-end-presentation-before-results.md)).

## FAST/SLOW 표시

raw 입력 오차의 절댓값이 Perfect 창 절반을 넘을 때 음수는 FAST, 양수는 SLOW이다. Normal은 20.5ms, Easy는 25ms가 기준이다.

- 일반 탭과 명시 릴리즈의 원래 입력 시각을 사용한다. 확정을 기다려도 확정 시각으로 타이밍을 바꾸지 않는다.
- 틱 노트, Grace(`goodTrill` 포함), 입력 없는 Miss, 종속 0점 정산에는 FAST/SLOW·타이밍 오차가 없다. 구형 `holdOnly`도 기존대로 제외한다.
- 판정 텍스트 아래 FAST는 파란 계열, SLOW는 빨간 계열로 표시한다. 설정으로 표시를 끌 수 있고 결과 화면에 횟수를 집계한다.

## 곡 도중 실패로 종료된 결과

곡 도중 실패로 종료되면 판정 통계는 종료 시점까지 실제로 확정된 판정만 집계한다. 미처리 노트를 종료 때문에 새 Miss로 채우지 않는다. 최종 달성률의 분모는 기존대로 차트 전체 점수 항목의 이론 가중치 합을 사용한다([RFD 0090](../rfd/0090-song-end-presentation-before-results.md)).

종료 시점에 이미 확정된 Miss는 통계에 포함하며, 이후 노트나 판정 대기 항목은 새로운 Miss 통계로 추가하지 않는다. 풀콤보는 완주한 플레이에서만 인정하므로 곡 도중 실패 종료에는 부여하지 않는다([RFD 0090](../rfd/0090-song-end-presentation-before-results.md)).

## 차트별 최고기록

결과 화면의 기록 갱신 안내는 최고 점수를 갱신했을 때만 표시한다. 해당 차트 버전·판정 설정에 기존 기록이 없으면 첫 기록에도 최고 점수 갱신 표시를 보여준다. 첫 기록이 0점이어도 같은 기준을 적용한다. 기존 최고 점수를 넘기면 결과 화면의 갱신 안내와 함께 이전 최고 점수 대비 증가분을 +1,234점 형식으로 표시한다. 증가분은 이번 점수에서 이전 최고 점수를 뺀 값이다. 점수가 기존 최고 점수와 같거나 낮으면 점수 차이는 표시하지 않는다. 기존 기록이 없는 첫 기록에는 갱신 안내만 표시하고 증가분은 표시하지 않는다. 클리어 상태 갱신은 별도로 안내하지 않는다.

로그인한 플레이어의 완주 기록뿐 아니라 `flightRule`에 따라 곡 도중 실패로 종료된 기록도 점수 기록과 랭킹 반영 대상에 포함한다. 곡 도중 실패로 종료되면 그때까지 얻은 점수를 반영한다. 더 높은 점수라면 최고기록을 갱신하며, 해당 플레이의 클리어 여부는 점수와 별도로 판정한다. 기존에 달성한 클리어 기록은 유지한다. 플레이어가 직접 중단한 Quit·Retry 경로는 기록을 남기지 않는다.

차트별 최고기록은 해당 차트에서 얻은 최고 점수이며, 더 높은 점수를 얻으면 갱신한다. Normal과 Easy의 최고 점수·클리어 여부·풀콤보 여부는 판정 설정별로 분리해 보존한다. 한 설정에서 달성한 기록으로 다른 설정의 기록을 갱신하지 않는다. 클리어·풀콤보 여부는 최고기록과 독립적으로 보존하고, 같은 판정 설정 안에서는 미러 사용 기록도 같은 차트의 기록으로 합친다([개인 플레이 기록](../context/glossary.md#개인-플레이-기록), [RFD 0085](../rfd/0085-chart-records-and-detailed-history-visibility.md)). 기록 저장·표시 구현은 [PRD §12](../prd.md#12-미정-사항)에서 추적한다.

노트 배치가 바뀌면 기존 최고 점수·클리어 여부·풀콤보 여부는 이전 차트 버전의 기록으로 보관하고, 수정된 차트 버전의 기록은 새로 쌓는다. 랭킹도 차트 버전별로 분리해 새로 집계하며, 이전 버전의 기록을 수정된 버전의 순위에 반영하지 않는다. 곡·차트 선택과 랭킹에는 현재 차트 버전의 새 기록만 표시한다. 이전 버전 기록의 조회 화면과 표시 방식은 이번 출시 전 설계 범위에서 제외한다.

곡이 공유하는 BPM·음원 정렬 오프셋을 수정하여 실제 입력 시각이 달라지면, 영향을 받는 각 차트의 기록과 랭킹을 새 버전으로 분리한다. 이전 기록은 보관하고 새 버전에 승계하지 않는다([RFD 0095](../rfd/0095-song-shared-bpm-and-audio-offset.md)).

제목·아티스트·자켓 같은 곡의 표시 정보만 수정하면 기존 기록·달성 여부·랭킹을 유지하며, 기록용 차트 버전을 분리하지 않는다([RFD 0096](../rfd/0096-song-shared-display-metadata-and-records.md)).

차트를 삭제해도 기존 플레이 기록·최고기록·달성 여부는 원래 차트 버전에 보관하고, 삭제된 차트는 곡·차트 선택과 현재 랭킹에서 제외한다. 삭제한 차트를 다시 등록하면 새 차트로 취급해 기록을 새로 쌓으며, 이전 기록은 승계하지 않는다.

삭제 전에 시작한 플레이나 이미 완료된 미전송 결과는 삭제 후에도 원래 차트 버전의 기록으로 접수·보관한다. 이 기록은 현재 랭킹에 반영하거나 재등록된 차트에 연결하지 않는다. 로그인 등 기존 기록 접수 요건과 Quit·Retry 중단 기록 제외는 그대로 적용한다. 삭제 후 기록 보존 정책은 [RFD 0097](../rfd/0097-preserve-records-after-chart-deletion.md)을 따른다.

## 랭킹 동점 처리

랭킹에는 같은 차트 버전·판정 설정에서 최고 점수와 독립적으로 보존한 풀콤보·올퍼펙트 달성 배지를 표시한다. 미러 사용 여부는 같은 기록으로 합친다. 올퍼펙트를 달성했으면 풀콤보 대신 올퍼펙트 배지만 표시하며, 일반 성공·실패는 표시하지 않는다. 배지는 최고 점수를 낸 특정 플레이의 상태로 제한하지 않는다. 100점 풀콤보 뒤 110점 실패를 기록하면 랭킹에는 110점과 풀콤보 배지를 함께 표시한다. 같은 점수로 올퍼펙트를 새로 달성해도 배지를 갱신하며, 해당 점수의 최초 달성 시각과 동점 순서는 바꾸지 않고 최고 점수 갱신 안내도 표시하지 않는다. 랭킹의 기록 수치는 점수만 표시하고 달성률은 표시하지 않는다. 순위는 점수만으로 정렬하며 동점은 해당 점수의 최초 달성 순서로 정한다. 배지의 유무·종류는 순위에 영향을 주지 않는다.

같은 점수에서는 해당 점수를 먼저 달성한 플레이어가 앞 순위에 오른다. 같은 점수를 다시 달성해도 그 점수의 최초 달성 시각을 유지한다. Normal/Easy별 랭킹 분리와 표시 경로는 [랭킹 정의](../context/glossary.md#랭킹)를 따른다.

## 달성률과 랭크

### 달성률 (Achievement Rate)

```text
실시간 달성률 = 획득 점수 / 지금까지 정산한 항목의 이론 가중치 × 100%
최종 달성률 = 획득 점수 / 전체 차트 점수 항목의 이론 가중치 × 100%
```

점수 항목이 있는 차트에서 아직 정산한 항목이 없어 실시간 분모가 0이면 실시간 달성률은 0%다. 무점수 Miss는 분모를 늘리지 않는다. 종속 릴리즈·틱 노트 항목의 0점도 원래 항목의 가중치를 정산하며 중복 정산하지 않는다. 종료 시 아직 미정산 항목이 있더라도 최종 분모는 전체 이론치이다. `flightRule`에 따라 곡 도중 실패로 종료된 경우에도 같은 최종 분모를 사용한다.

### 점수 항목이 없는 차트

일반 플레이용 차트에는 점수 노트가 최소 1개 필요하다. 전체 차트의 점수 항목이 0개이면 일반 플레이 진입을 차단하며, 공식 기록·랭킹 대상으로 삼지 않는다([RFD 0091](../rfd/0091-normal-play-requires-score-note.md)).

제작 중 저장·에디터 테스트와 튜토리얼의 바디 연습에는 이 제한을 적용하지 않는다. 아래 무점수 재생·비율 숨김은 해당 제작·학습 경로에서 유지한다. 일반 플레이의 새 진입 제한은 미구현이다.

제작·학습용 재생에서는 [RFD 0039](../rfd/0039-unscored-chart-results.md)에 따라 전체 이론 가중치 합이 0인 유효한 차트도 재생을 허용한다. 바디의 실제 시작·유지·완료·실패와 원인 Miss는 그대로 처리하며 자동 점수를 만들지 않는다.

이 차트의 플레이 중 달성률과 결과의 달성률·랭크는 표시하지 않는다. `ScoreManager`의 내부 분모 0 계산값 0·F를 결과로 노출하거나 100%·SSS로 대체하지 않는다. 새 테스트 플레이와 공식 결과 모두 최종 이론 가중치가 0일 때 비율·랭크 영역을 숨긴다. 실제 세션·화면과 공식 결과를 연결하고 단위·브라우저 테스트로 검증했다. 일반 플레이의 분모 0 처리 경로는 RFD 0091의 진입 제한이 구현되기 전까지 남아 있는 현행 동작이다.

기준은 전체 이론 가중치이며 아직 정산한 항목이 없어 실시간 분모만 0인 상태와 구별한다. 점수 항목이 있는 차트에서 모든 항목을 놓쳤다면 기존대로 0%·F다. Full Combo의 기존 Miss 기준은 바꾸지 않는다.

### 랭크 (Rank)

| 랭크  | 달성률 기준 |
| ----- | ----------- |
| **SSS** | ≥ 99.5%   |
| **SS**  | ≥ 99.0%   |
| **S**   | ≥ 97.0%   |
| **AAA** | ≥ 95.0%   |
| **AA**  | ≥ 90.0%   |
| **A**   | ≥ 85.0%   |
| **B**   | ≥ 80.0%   |
| **C**   | ≥ 70.0%   |
| **D**   | ≥ 60.0%   |
| **F**   | < 60.0%    |

**10단계 랭크를 채택한 이유**: SSS～F의 10단계는 유저의 성장 과정에서 충분한 중간 목표를 제공한다. SSS(99.5%)는 사실상 올퍼펙에 가까운 달성도이며, F(60% 미만)는 차트를 완주했지만 대부분의 노트를 놓친 상태를 나타낸다. 90%대에 AAA/AA/A 세 단계를 두어, 중급～상급 유저의 미세한 성장도 가시적으로 반영한다.

**랭크 산출은 달성률 단일 기준**: 달성률 하나만으로 랭크가 결정되며, 시스템이 단순하고 직관적이다.

### 달성률·랭크와 `flightRule`의 관계

달성률·랭크와 `flightRule`(클리어/실패)은 **서로 다른 축**이다(RFD 0001).

- **달성률·랭크**: 연주 정확도의 측정. `flightRule`과 무관하게 산출된다.
- **`altitude`·클리어/실패**: `flightRule`의 상태. 달성률이나 랭크를 대체하지 않는다.

`flightRule`의 클리어/실패는 랭크 산출에 영향을 주지 않는다. [RFD 0022](../rfd/0022-flight-difficulty-names-and-visuals.md)의 `Liftoff / Infiltration / Breakthrough` 이름·연출 배치는 점수 가중치를 변경하지 않는다. 종전 `Survival`의 Perfect-only 회복 규칙은 새 단계에 자동 승계하지 않으며, 세부 고도 규칙은 [PRD §12](../prd.md#12-미정-사항)에서 추적한다.
