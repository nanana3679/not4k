# RFD 0074: 물리 부하에 동작 수행의 어려움을 포함한다

**Status:** Accepted (2026-10-28) · 용어·루트 컨텍스트·개요·피스·노트 시스템 반영 (2026-10-28)

## 기존 결정과 문제의식

용어집과 피스 명세는 물리 부하를 손과 손가락의 피로로 설명했다. 이 정의만으로는 피로가 쌓이기 전에도 발생하는 빠른 입력, 손가락의 독립적인 움직임, 손 이동 등의 수행 어려움을 충분히 설명하지 못한다.

## 검토한 대안과 채택안

피로만 가리키는 안 대신, 물리 부하를 요구된 동작을 실제로 수행하는 데 드는 신체적 부담으로 정의한다. 입력 속도, 손가락의 독립적인 움직임, 손 이동과 자세 전환, 힘과 지구력 등을 포함한다. 순간적인 수행 어려움과 누적 피로를 모두 다룬다.

연주 방법을 알아도 동작 자체가 익숙하지 않거나 요구 속도로 수행하기 어려울 수 있다. 어느 손·손가락·키를 사용할지 판단하는 동작 계획 부담, 입력 시점을 정밀하게 맞추는 타이밍 정밀도와의 기존 구분은 유지한다. 각 부담은 실제 연주에서 함께 발생할 수 있다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 `CONTEXT.md`, overview, 피스 명세, 노트 시스템의 설명을 맞춘다. 물리 부하를 피로만으로 한정한 현행 정의가 남지 않는지 확인한다. 피스별 부하 등급은 대표 배치의 참고값으로 유지하며 런타임 코드는 변경하지 않는다.
