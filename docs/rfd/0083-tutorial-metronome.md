# RFD 0083: 튜토리얼은 메트로놈에 맞춰 시연·실습한다

**Status:** Accepted (2026-10-29) · 용어·컨텍스트·튜토리얼·PRD·에셋·MVP·기술 스택 문서 반영 (2026-10-29) · 첫 입력 전 4박 준비 구간 반영 (2026-10-29) · 4박 준비는 처음 시작에만 적용 (2026-10-29) · 반복 구간 자체의 다음 입력 준비 여유와 첫 재생 앞의 별도 4박 구분 명확화 (2026-10-31)

## 기존 결정과 문제의식

에셋 목록과 MVP 스코프에는 튜토리얼 전용 곡이 필요하다고 적혀 있었고, 기술 스택의 파일 구조 예시도 전용 음악 파일을 포함했다. 현재 공개 도움말은 오디오 없는 자동 시연이며, 새 직접 입력 실습의 리듬 안내와는 구별해야 한다.

## 검토한 대안과 채택안

예제용 음악을 사용하는 안과 메트로놈의 박자 소리만 사용하는 안을 검토하고, 시연과 직접 입력 실습 모두 메트로놈에 맞춰 진행한다. 예제 차트의 박자와 메트로놈, 화면의 노트와 판정 시간을 맞춘다. 처음 재생을 시작할 때만 첫 입력 전에 메트로놈을 4박 들려주는 준비 구간을 둔다. 반복 예제의 구간 자체에 다음 입력을 준비할 여유를 포함한다. 별도의 4박 준비 구간은 첫 재생 앞에만 두며, 이후 패턴을 반복할 때는 다시 추가하지 않는다(사용자 확인, 2026-10-29).

튜토리얼 전용 음악의 작곡·수급·음악 파일 배치는 요구하지 않는다. 박자 소리의 구체적 구현 방식은 이 결정에서 정하지 않는다. 실제 플레이용 수록곡의 음원 요구는 유지한다.

음악적 맥락을 함께 제시하는 효과는 줄어들지만, 별도 곡 제작 없이 예제의 입력 리듬에 집중할 수 있다.

## 영향과 검증

glossary, 루트·게임 컨텍스트, 튜토리얼 스펙과 PRD에 메트로놈 시연·실습을 반영한다. 에셋 목록·MVP·기술 스택에서 튜토리얼 전용 음악 요구를 정리한다. 현재 공개 도움말과 새 설계를 구별하며 런타임 코드는 변경하지 않는다. 향후 구현에서는 메트로놈·노트·판정의 동기화와 시연·직접 입력 전환 및 반복 중 박자 일관성을 검증한다.
