# RFD 0016: 선택 모델 개정 — 일반 노트·`trillZone` 유닛 공존과 실행 시점 파생

**Status:** Accepted (2026-07-07) — 모바일 실기기 검증에서 나온 사용자 결정. 열린 질문은 §9.

## 관련 문서

- [`docs/context/glossary.md`](../context/glossary.md) — "`trillZone` 선택"(동질성 규칙 원 기록), "SelectionSlice"(정규화 게이트). **이 RFD가 두 항목을 개정한다.**
- `src/editor/CONTEXT.md` — "`trillZone` 선택" 요약 정의. 동기화 대상.
- 선례: SelectionSlice(선택 단독 소유자 + 정규화 게이트, 2026-07-06 구현) — 이 RFD는 그 게이트의 **규칙**을 바꾸는 것이지 소유권 구조를 바꾸지 않는다.

---

## 1. 기존 결정

1. **동질성**: 한 선택은 동질적이어야 한다 — 일반/트릴 노트 혼합 불가, 서로 다른 `trillZone` 혼합 불가 (glossary "`trillZone` 선택").
2. **선택 시점 파생 주입**: 구간 단위 선택(`zones`)이 서면 내부 트릴 노트를 `selection.notes`에 채워 이동·삭제·복사가 notes만 읽게 한다 (`selectZoneUnit` → SelectionSlice 게이트의 구간 파생).
3. **박스는 노트만 집는다**: `trillZone` 유닛은 트릴 핸들 탭으로만 선택된다.
4. **터치 드래그**: 노트 위에서 시작한 드래그는 탭토글 후보로 예약되고, slop을 넘으면 무효(박스 미발동). 토글 래치는 롱프레스 다중선택에서만 켜진다.

## 2. 문제의식 (2026-07-07 모바일 검증)

- 구간을 박스로 아예 선택할 수 없다 — 구간이 섞인 영역을 통째로 옮기려면 핸들을 하나씩 탭해야 한다.
- 일반 노트와 구간을 **함께** 선택·이동·삭제할 수 없다 — 동질성 규칙이 구간 유닛까지 노트와 동급으로 배타 처리한다.
- 엑스트라 레인처럼 노트 밀도가 높은 곳은 드래그 시작점이 노트에 걸려 박스가 자주 안 뜬다.
- 박스로 여러 개를 선택한 뒤 탭으로 선택을 토글할 수 없다(래치가 롱프레스에서만 켜짐).

## 3. 핵심 결정

> **`trillZone` 유닛은 노트가 아니라 선택의 독립 축이다. 일반 노트·엑스트라 노트와 공존할 수 있고, 유닛의 내부 노트는 선택에 주입하지 않고 이동·삭제·복사 동사가 실행 시점에 파생한다. 개별 트릴 노트 선택만이 배타 모드로 남는다.**

## 4. 채택 모델

### 4.1 선택 불변 (정규화 게이트 새 규칙)

`selection = {notes, extraNotes, zones}`. 게이트(`normalizeSelection`)는:

1. 세 집합 모두 범위 밖 인덱스 제거 (기존 유지).
2. `notes`의 종류를 최소 인덱스 노트로 판정(기존 `filterHomogeneousSelection`):
   - **일반 모드** (최소 인덱스가 일반 노트): 트릴 노트는 떨군다. `zones`·`extraNotes`와 **공존 허용** (신규).
   - **트릴 노트 모드** (최소 인덱스가 트릴 노트): 같은 구간의 트릴 노트만 남긴다(기존). **`zones`는 비운다** — 개별 트릴 선택은 구간 유닛과 혼합 불가 (사용자 결정 b).
3. **구간 파생 주입 폐지**: `zones`가 있어도 `notes`에 내부 노트를 채우지 않고, `extraNotes`를 비우지 않는다.

### 4.2 실행 시점 파생

이동(드래그·`moveBySnap`·`moveByLane`)·삭제(`deleteSelected`)·복사(`copy`/`cut`)는 실행 시점에 `zones`의 내부 노트(구간에 **포함**된 노트 — `zoneContainedNoteIndices`, 기존 기준 유지)를 파생해 함께 처리한다:

- **이동**: 구간을 평행이동하면 내부 노트도 같은 오프셋으로 동반 이동. **beat 오프셋은 선택 전체(일반 노트·엑스트라 포함)가 공유하고, 레인 오프셋은 앵커 축에만 적용된다** — 드래그는 잡은 쪽 축(메인 앵커면 `lane`, 엑스트라 앵커면 `extraLane`)에만, `moveByLane`은 메인·엑스트라 각자 축으로 평행이동. 어느 쪽이든 막히면(레인·타임라인 범위 밖) 전체 no-op. 결과 차트는 변이 게이트(`validateChart`)가 검증 — 위반이면 커밋 거부(기존 장치 재사용)하고 chart·extraNotes를 함께 롤백.
- **삭제**: 구간 삭제 시 내부 노트 동반 삭제 (기존 구간 단위 삭제와 동일 의미, 이제 일반 노트와 함께도 가능).
- **복사**: 구간 + 내부 노트 + 일반 노트를 함께 클립보드로.

### 4.3 박스의 구간 픽업

박스와 같은 레인에서 박 구간이 **겹치는**(포함 아님 — 사용자 결정 a) `trillZone`은 유닛으로 선택된다. 구간 내부의 트릴 노트는 박스가 개별로 집지 않는다(유닛으로 들어온다). 겹침 판정은 기존 `trillZoneOverlapsNote`와 같은 폐구간 겹침.

### 4.4 터치 상호작용

- **드래그 승격**: select 모드에서 노트/엑스트라 노트 위에서 시작한 터치 드래그도 slop을 넘으면 박스로 승격한다(탭이면 기존대로 토글/선택). 롱프레스 이동과의 우선순위: 롱프레스가 먼저 발화하면 이동, slop 초과가 먼저면 박스.
- **토글 래치**: 박스 선택이 비어있지 않게 끝나면 래치 on. "선택이 비면 off"는 기존 규칙 유지.

## 5. 대안 검토

- **파생 주입 유지 + 일반 노트 공존**: `notes` 안에서 "구간에서 온 트릴"과 "직접 선택한 일반"을 구분할 수 없어(Set<number>) 이동 가둠·동질성 판정이 모두 깨진다. 기각.
- **트릴 개별 선택까지 전면 혼합 허용**: 트릴 쌍 확장·구간 가둠(`_trillMoveZone`) 규칙과 충돌하고, "다른 구간 트릴+일반" 이동의 의미가 정의되지 않는다. 기각(사용자 결정 b도 배타 유지).
- **포함 기준 픽업**: 긴 구간은 화면보다 길어 박스로 포함하기가 사실상 불가능. 기각(사용자 결정 a).

## 6. Trade-off

- 구간 유닛 선택 시 **내부 노트의 개별 하이라이트가 사라진다**(notes에 없으므로). 구간 하이라이트(SELECTED_OUTLINE + 핸들 bump)가 선택 표시를 전담한다. 필요해지면 렌더러가 zones에서 파생 하이라이트를 계산하는 후속.
- 동사마다 실행 시점 파생이 붙어 구현이 분산될 수 있다 — `SelectMode` 안에 파생 헬퍼 하나(`effectiveNoteIndices()` 류)로 모아 leverage를 유지할 것.
- 박스가 트릴 노트를 개별로 집지 않게 되므로, 트릴 노트만 골라 조작하려면 클릭/탭(개별 트릴 모드)을 써야 한다.

## 7. 케이스 검증 (회귀 테스트 목록)

- 게이트: 일반+zones 공존 유지 / 트릴 노트 모드에서 zones 비움 / 일반 모드에서 트릴 노트 탈락 / zones가 notes를 주입하지 않음 / extra와 zones 공존.
- 박스: 겹치는 구간 유닛 픽업 / 다른 레인 구간 미픽업 / 구간 내부 트릴 노트 개별 미픽업 / 일반 노트+구간+엑스트라 동시 픽업.
- 동사: 구간+일반 혼합 이동 시 내부 노트 동반·오프셋 일치 / 혼합 삭제 시 내부 노트 동반 / 이동 결과 위반 시 커밋 거부 / 복사·붙여넣기 왕복.
- 터치: 노트 위 드래그 slop 초과 → 박스 / 박스 후 탭 토글 동작 / 선택 비면 래치 off.
