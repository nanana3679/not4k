# RFD 0061: 옵저버의 직접 입력과 판정 확인

**Status:** Accepted (2026-10-28) · 용어·옵저버·게임 코어·MVP·PRD 반영 (2026-10-28) · Auto·미니맵·Retry·종료는 [RFD 0062](0062-observer-controls-loop-and-exit.md)에서 후속 채택 (2026-10-28) · 콤보·달성률 표시 확인 (2026-10-28) · 옵저버 런타임 미구현

**집계·표시 후속 결정:** [RFD 0075](0075-observer-manual-only-statistics.md)는 Auto 중 콤보·달성률 숨김과 Auto 노트 집계 제외를 확정했다. 수동 집계는 반복 구간이 끝나면 초기화하며 Retry·구간 변경에도 초기화한다. Auto 전환만으로 같은 반복 안의 수동 집계를 초기화하지 않는다.

## 기존 결정과 문제의식

[RFD 0060](0060-observer-for-understanding-and-practice.md)은 연주 방법을 모르겠거나 동작이 익숙하지 않을 때 원하는 구간을 반복하는 목적을 확정했다. 그러나 기존 옵저버 명세와 PRD는 입력 없는 관찰로만 설명했다.

사용자는 반복 구간을 직접 따라 치고 판정도 확인할 수 있어야 한다고 승인했다.

## 검토한 대안

- 입력 없는 관찰만 제공한다. 동작을 직접 익히고 그 입력의 판정을 확인하는 요구를 충족하지 못한다.
- 옵저버 안에서 직접 입력과 판정 확인을 지원한다. 관찰과 연습의 표시·반복 동작을 구체화해야 한다.

## 채택안과 trade-off

옵저버는 차트를 관찰하는 것과 함께, 원하는 구간을 직접 따라 치고 판정 결과를 확인하는 연습을 지원한다. 이 반복 연습을 위해 별도 모드명을 추가하지 않는다.

실패 조건 없이 차트를 관찰·학습하는 기존 Play/Observer 경계는 유지한다. 연습 중 개별 노트의 실패 판정을 확인하는 것과 `flightRule`에 의해 플레이가 중단되는 것은 구별한다. 옵저버의 연습을 공식 Play 기록으로 취급하지 않는다.

판정과 함께 콤보·달성률도 표시한다(사용자 확인, 2026-10-28). 반복·Retry마다 콤보·달성률을 초기화하는 규칙은 [RFD 0064](0064-observer-whole-song-loop-and-reset.md)에서 후속 채택했다. 집계 범위의 세부와 반복 경계의 키·바디 상태 처리는 별도로 정한다. 남은 구체적 동작은 [PRD §12](../prd.md#12-미정-사항)에서 단일 추적한다. 구현 상태는 미구현으로 유지한다.

## 영향과 검증

- glossary를 권위 정의로 보완하고 루트·Gameplay `CONTEXT.md`, 용어 표기표, 옵저버·게임 코어·MVP·PRD를 맞춘다.
- RFD 0001·0060의 후속 결정에 직접 입력·판정 지원을 연결한다. 당시 대안의 본문은 보존한다.
- 입력 없는 관찰로만 한정하거나 직접 입력 지원 자체를 미정으로 남긴 현행 문구와 관련 링크를 확인한다. 런타임은 변경하지 않는다.
