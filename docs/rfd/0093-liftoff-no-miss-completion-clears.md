# RFD 0093: Liftoff는 Miss 없이 완주하면 클리어 조건을 충족하도록 설정한다

**Status:** Accepted (2026-10-30) · glossary·컨텍스트·게임 코어·스코어링·PRD 문서 반영 (2026-10-30), 실제 비행 규칙·게이지 수치 미구현

## 기존 결정과 문제의식

`Liftoff`는 고도 0에서 시작하고 곡 중 게임 오버 없이 곡 종료 시 고도로 클리어 여부를 판단한다. 클리어 상태를 실패·성공·풀콤보·올퍼펙트 중 하나로 정하면서, Miss 없이 완주했지만 고도 조건에 실패한 경우의 표시를 질문했다.

사용자는 해당 질문이 Liftoff를 뜻하는지 확인하고, 그런 상황이 성립하지 않도록 게이지 상승량이 설정되어 있다고 전제했다.

## 검토한 대안과 채택안

`Liftoff`에서는 Miss 없이 곡을 끝까지 연주하면 반드시 클리어 조건을 충족하도록 게이지 상승량을 설정한다(사용자 확인, 2026-10-30). Good이나 `goodTrill`이 포함되어도 Miss 없이 완주한 플레이에는 이 전제를 적용한다.

따라서 Liftoff에서 풀콤보 조건을 만족한 완주가 고도 조건 때문에 실패하는 경우는 허용하지 않는다. 실패와 풀콤보 중 무엇을 우선 표시할지 정하는 대신, 게이지 설정에서 그런 충돌을 배제한다. 올퍼펙트도 풀콤보 조건을 충족하므로 같은 전제를 따른다.

풀콤보의 기존 완주·Miss 0 조건에 별도의 클리어 성공 조건을 덧붙이는 결정은 아니다. Liftoff의 게이지 설정에 대한 불변식이다. 고도 0 시작·곡 종료 기준·곡 중 게임 오버 없음은 유지하며, 다른 단계에 같은 게이지 규칙을 자동 적용하지 않는다.

정확한 상승량·감소량·클리어 기준값 등은 이번 결정에서 정하지 않는다. 남은 비행 규칙과 수치는 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

## 영향과 검증

glossary·루트 및 Gameplay 컨텍스트·게임 코어·스코어링·PRD를 동기화한다. [RFD 0092](0092-exclusive-play-outcome-and-chart-display.md)에서 제기한 Liftoff의 클리어 실패·풀콤보 충돌은 이 전제로 정리한다.

향후 비행 규칙을 구현·튜닝할 때 Miss 없는 완주가 Good·`goodTrill`을 포함해도 클리어 조건을 충족하는지 검증한다. 이번 작업은 문서 반영이며 런타임·테스트 코드는 변경하지 않는다.
