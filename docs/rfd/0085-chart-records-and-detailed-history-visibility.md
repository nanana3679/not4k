## 기존 결정과 문제의식

태도 문서는 개인 기록을 사실로 보관하고 기본적으로 타인에게 공개하지 않는 방향을 정했다. 다만 개인에게 보여주는 경로까지 모두 메뉴 깊숙이 두는 것으로 읽히는 문장이 있었다.

사용자는 차트별 최고기록과 클리어 여부, 풀콤보 여부는 바로 보이고 나머지 기록은 메뉴 안쪽에 둔다고 정리했다.

## 검토한 대안과 채택안

모든 기록을 기본 화면에서 숨기거나 상세 이력을 모두 앞에 표시하는 대신, 곡·차트 선택에서 해당 차트의 최고기록·클리어 여부·풀콤보 여부를 바로 확인할 수 있게 한다. 세 항목을 보기 위해 별도 상세 기록 화면에 들어갈 필요가 없어야 한다.

플레이 기록 저장은 로그인한 플레이어에게 제공한다. 비로그인 플레이는 허용하되 플레이 기록을 저장하거나 랭킹에 등록하지 않는다. 기존 인증 방침을 유지한다(사용자 확인, 2026-10-29).

최고기록은 해당 차트에서 얻은 최고 점수이며, 더 높은 점수를 얻으면 갱신한다(사용자 확인, 2026-10-29).

플레이 횟수는 통계창에서 확인하도록 한다(사용자 확인, 2026-10-31). 첫 클리어 시점 등 다른 상세 기록은 예시이며 저장 항목으로 확정하지 않는다. 통계창의 진입 위치와 남은 세부는 [PRD §12](../prd.md#12-미정-사항)에서 단일 관리한다. 이전의 메뉴 안쪽 경로 방침은 이 결정으로 구체화하며 특정 메뉴 계층을 요구하지 않는다. 타인의 기록을 기본 화면에 노출하거나 개인 기록을 타인에게 기본 공개하는 것으로 확대하지 않는다.

최고기록·클리어 여부·풀콤보 여부는 서로 다른 플레이에서 달성해도 각각 독립적으로 보존한다. 새 최고기록을 세운 플레이에서 클리어나 풀콤보를 달성하지 못해도 기존 달성 여부는 지우지 않는다. 최고기록을 갱신하지 못한 플레이에서 처음 클리어·풀콤보를 달성한 경우에도 해당 달성 여부를 보존한다(사용자 확인, 2026-10-29).

Normal과 Easy의 최고 점수·클리어 여부·풀콤보 여부는 판정 설정별로 분리해 보존한다. 한 설정에서 달성한 기록으로 다른 설정의 기록을 갱신하지 않는다. 판정 범위가 다른 두 설정을 합치면 더 넓은 창에서 달성한 기록이 다른 설정의 성과까지 대체할 수 있으므로, 개인 기록은 분리하는 방식을 채택한다(사용자 확인, 2026-10-29).

같은 판정 설정 안에서는 미러 사용 여부와 관계없이 같은 차트의 기록으로 합쳐 보존한다. 미러를 사용한 플레이와 사용하지 않은 플레이 모두 같은 최고기록의 갱신 대상이며, 클리어·풀콤보 달성 여부도 함께 보존한다. 기록을 미러 여부에 따라 별도 항목으로 나누지 않는다(사용자 확인, 2026-10-29).

차트 선택에 필요한 기본 기록에 접근하기 쉬워지는 대신, 기본 화면에는 세 항목을 읽기 쉽게 배치해야 한다. 중립적인 사실 표시 원칙은 유지한다. 상세 기록의 항목·화면 등 남은 세부는 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

차트 선택에서는 올퍼펙트를 달성하면 풀콤보 표시 대신 올퍼펙트를 표시한다. 플레이마다 실패·성공·풀콤보·올퍼펙트 중 하나를 표시하는 클리어 상태의 정의는 [RFD 0092](0092-exclusive-play-outcome-and-chart-display.md)를 따른다.

### 결과 화면의 갱신 안내

결과 화면의 기록 갱신 안내는 최고 점수를 갱신했을 때만 표시한다. 클리어 상태 갱신은 별도로 안내하지 않는다. 클리어 상태 자체의 표시와 풀콤보·올퍼펙트의 종료 연출은 갱신 안내와 구별한다. 최고 점수와 클리어 상태의 독립 보존 정책은 그대로 적용한다(사용자 확인, 2026-10-30).

해당 차트 버전·판정 설정에 기존 기록이 없으면 첫 기록에도 최고 점수 갱신 표시를 보여준다. 첫 기록이 0점이어도 같은 기준을 적용한다. 기존 기록의 부재와 이미 저장된 0점 기록을 구별한다. 기존 기록이 있으면 더 높은 점수일 때만 갱신하며 동점의 최초 달성 시각은 유지한다(사용자 확인, 2026-10-30).

기존 최고 점수를 넘기면 결과 화면의 갱신 안내와 함께 이전 최고 점수 대비 증가분을 +1,234점 형식으로 표시한다. 증가분은 이번 점수에서 이전 최고 점수를 뺀 값이다. 점수가 기존 최고 점수와 같거나 낮으면 점수 차이는 표시하지 않는다. 기존 기록이 없는 첫 기록에는 갱신 안내만 표시하고 증가분은 표시하지 않는다(사용자 확인, 2026-10-30).

### 클리어에 실패한 플레이의 기록

로그인한 플레이어가 곡을 끝까지 연주했다면 클리어에 실패해도 점수 기록과 랭킹 반영 대상에 포함한다. 더 높은 점수라면 최고기록을 갱신하며, 해당 플레이의 클리어 여부는 점수와 별도로 판정한다. 기존에 달성한 클리어 기록은 유지한다. 클리어 성공한 플레이만 점수 기록·랭킹에 포함하는 방식 대신, 완주한 플레이의 점수와 클리어 성과를 독립적으로 보존한다(사용자 확인, 2026-10-30).

`flightRule`에 따라 곡 도중 실패로 플레이가 종료된 경우도 그때까지 얻은 점수를 기록과 랭킹에 반영한다. 로그인한 플레이만 저장하는 기존 조건을 유지하며, 더 높은 점수이면 최고기록을 갱신한다. 플레이어가 직접 중단한 Quit·Retry 경로는 기록을 남기지 않는 기존 규칙을 유지한다. 최종 달성률은 기존대로 차트 전체의 이론 가중치를 분모로 계산하며, 연주한 부분만으로 다시 환산하지 않는다(사용자 확인, 2026-10-30).

### 판정 설정별 랭킹

Normal과 Easy 모두 차트별 랭킹을 제공하며, 두 판정 설정의 순위는 따로 집계한다. 각 설정에서 달성한 기록만 해당 설정의 랭킹에 반영한다. Normal만 랭킹 대상으로 제한하는 대안 대신, Easy에서도 같은 설정을 사용하는 플레이어끼리 기록을 비교할 수 있게 한다(사용자 확인, 2026-10-29). 랭킹은 플레이어가 선택해 확인하는 경로로 제공한다.

랭킹의 기록 수치는 점수만 표시하며 달성률은 표시하지 않는다. 순위는 같은 차트 버전·판정 설정의 최고 점수로 비교하며, 동점은 해당 점수를 먼저 달성한 순서를 유지한다. 같은 차트에서는 최종 달성률의 분모가 같으므로 점수와 달성률의 순서는 같다(사용자 확인, 2026-10-30).

본인의 기록이 상위 목록 밖에 있더라도 내 순위와 점수는 별도로 표시한다. 상위 목록에 포함되어야만 내 기록을 확인할 수 있는 방식으로 제한하지 않는다(사용자 확인, 2026-10-30).

랭킹은 창을 열 때 최신 기록을 불러오며, 같은 랭킹 창을 열어둔 동안에는 자동 갱신하지 않는다. 창을 닫았다 다시 열면 최신 기록을 다시 불러온다. 실시간으로 순위가 바뀌는 방식 대신 창을 여는 시점의 기록을 확인하도록 한다(사용자 확인, 2026-10-30).

랭킹을 불러오지 못하면 랭킹 창 안에 오류 안내와 재시도 버튼을 표시한다. 재시도 버튼을 누르면 현재 대상의 랭킹 조회를 다시 시도한다. 창을 닫았다 다시 여는 조작만으로 재시도를 대신하지 않는다(사용자 확인, 2026-10-30). 이 버튼은 플레이 결과의 기록 전송 재시도와 구별한다.

랭킹에는 같은 차트 버전·판정 설정에서 최고 점수와 독립적으로 보존한 풀콤보·올퍼펙트 달성 배지를 표시한다. 미러 사용 여부는 같은 기록으로 합친다. 올퍼펙트를 달성했으면 풀콤보 대신 올퍼펙트 배지만 표시하며, 일반 성공·실패는 표시하지 않는다. 배지는 최고 점수를 낸 특정 플레이의 상태로 제한하지 않는다. 100점 풀콤보 뒤 110점 실패를 기록하면 랭킹에는 110점과 풀콤보 배지를 함께 표시한다. 같은 점수로 올퍼펙트를 새로 달성해도 배지를 갱신하며, 해당 점수의 최초 달성 시각과 동점 순서는 바꾸지 않고 최고 점수 갱신 안내도 표시하지 않는다. 랭킹의 기록 수치는 점수만 표시하고 달성률은 표시하지 않는다. 순위는 점수만으로 정렬하며 동점은 해당 점수의 최초 달성 순서로 정한다. 배지의 유무·종류는 순위에 영향을 주지 않는다. 같은 점수에서도 달성 여부가 다를 수 있으므로 점수와 별도로 달성을 보여준다. 플레이어가 별도로 여는 랭킹의 점수·FC/AP는 달성 사실의 표시로 허용하며, 실력을 평가하는 칭호·감정 문구·과장 보상으로 확대하지 않는다. 이전의 랭킹 클리어 상태 미표시 방침을 이 결정으로 대체한다(사용자 확인, 2026-10-31).

### 랭킹의 플레이어 이름

랭킹에 표시할 플레이어 이름은 닉네임으로 한다. 처음 로그인할 때 닉네임이 없으면 Guest 뒤에 6자리 숫자 난수를 공백 없이 붙인 이름을 자동 생성한다. 자동 생성하는 기본 이름은 기존 닉네임과 겹치지 않게 생성한다. 닉네임 입력을 필수로 요구하지 않는다. 생성한 이름은 계정에 유지하며 이후 로그인에서는 기존 닉네임을 사용한다. 예: Guest482731. 접두어 Guest는 기본 닉네임의 문자열이며 로그인 상태와 구별한다. 사용자가 직접 변경하는 닉네임은 다른 계정과 중복되어도 허용한다. 자동 생성 때의 충돌 방지는 모든 닉네임에 전역 고유성을 요구하는 정책이 아니다. 닉네임이 같아도 플레이어별 기록과 순위는 구분한다. 닉네임은 이후 변경할 수 있으며, 변경해도 해당 플레이어의 기존 기록과 순위를 유지한다. 닉네임을 변경하면 기존 랭킹에 표시되는 이름도 새 닉네임으로 바뀐다. 랭킹은 조회 시점의 현재 닉네임을 표시하며, 이미 열린 창에서는 기존 갱신 정책에 따라 다음 조회 때 반영한다. 닉네임 변경 위치는 게임 설정의 프로필 탭으로 한다([RFD 0094](0094-settings-profile-tab.md)). 닉네임 변경은 프로필 탭의 저장 버튼으로 적용한다. 닉네임의 입력 제약 등은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다(사용자 확인, 2026-10-30).

이 문단의 첫 로그인 기본 닉네임 생성 정책은 [RFD 0106](0106-guest-nickname-before-login.md)에 따라 로그인 전 기기의 Guest 닉네임과 첫 연동 때의 서버 겹침 확인·계정 인계·기기 새 번호 부여로 변경한다.

### 동점 순위

같은 점수에서는 해당 점수를 먼저 달성한 플레이어가 앞 순위에 오른다. 공동 순위 대신 점수 달성 순서로 순위를 구분한다(사용자 확인, 2026-10-29). 같은 점수를 다시 달성해도 그 점수의 최초 달성 시각을 유지한다.

### 차트 수정과 버전별 기록

노트 배치가 바뀌면 기존 최고 점수·클리어 여부·풀콤보 여부는 이전 차트 버전의 기록으로 보관하고, 수정된 차트 버전의 기록은 새로 쌓는다. 랭킹도 차트 버전별로 분리해 새로 집계하며, 이전 버전의 기록을 수정된 버전의 순위에 반영하지 않는다. 이전 기록을 삭제하거나 수정된 차트에 그대로 승계하는 대안 대신, 기존 성과를 보존하면서 서로 다른 배치의 기록을 분리한다(사용자 확인, 2026-10-29). Normal/Easy 분리와 각 설정 안의 미러 통합, 동점 선착순은 같은 차트 버전 안에서 적용한다.

같은 곡의 모든 차트가 공유하는 BPM·음원 정렬 오프셋을 수정하여 실제 입력 시각이 달라질 때도, 영향을 받는 차트의 기록과 랭킹을 새 버전으로 분리한다. 타이밍의 곡 단위 소유와 현행 저장 구조의 이행 경계는 [RFD 0095](0095-song-shared-bpm-and-audio-offset.md)를 따른다(사용자 확인, 2026-10-30).

제목·아티스트·자켓은 곡 단위 공통 정보이며, 이 표시 정보만 수정하면 기록용 차트 버전을 분리하지 않고 기존 기록·달성 여부·랭킹을 유지한다. 소유와 현행 차트 문서의 사본 구분은 [RFD 0096](0096-song-shared-display-metadata-and-records.md)을 따른다(사용자 확인, 2026-10-30).

차트 삭제 후에도 기존 기록과 삭제 전 플레이의 지연 전송 결과를 원래 버전에 보관한다. 삭제된 차트는 선택·현재 랭킹에서 제외하며, 재등록은 새 차트로 취급한다([RFD 0097](0097-preserve-records-after-chart-deletion.md), 사용자 확인, 2026-10-30).

곡·차트 선택과 랭킹에는 현재 차트 버전의 새 기록만 표시한다. 이전 버전 기록의 조회 화면과 표시 방식은 이번 출시 전 설계 범위에서 제외한다. 이전 기록을 보관하는 정책이 과거 버전용 조회 화면의 설계를 요구하는 것은 아니다(사용자 확인, 2026-10-29).

### 기록 전송 실패

로그인한 플레이의 기록 전송에 실패하면 결과 화면에 전송 실패 안내와 **전송 재시도** 버튼을 표시한다. 버튼을 누르면 해당 플레이 결과의 서버 전송을 다시 시도한다. 저장되지 않은 상태를 플레이어가 확인하고 같은 결과의 전송을 직접 재시도할 수 있게 한다(사용자 확인, 2026-10-29). 곡을 다시 플레이하는 Retry와 구별되도록 버튼에는 전송 재시도라고 표시한다.

결과 화면을 나가도 미전송 기록을 브라우저에 보관해 나중에 재전송할 수 있게 한다. 미전송 기록은 해당 플레이를 한 계정과 연결해 보관한다. 결과 화면을 떠날 때 버리는 대안 대신, 완료한 로그인 플레이의 기록을 나중에 전송할 수 있게 보관한다(사용자 확인, 2026-10-29).

다음 접속 때 해당 플레이를 한 계정으로 로그인되어 있으면 브라우저에 보관한 미전송 기록을 자동 재전송한다. 매번 수동 재전송을 요구하는 대신, 원래 계정으로 다시 접속했을 때 전송을 재개한다(사용자 확인, 2026-10-29).

## 영향과 검증

랭킹 배지가 최고 점수를 낸 플레이에 종속되지 않는지, 동점에서 새 올퍼펙트 배지만 반영하고 점수 최초 달성 시각·순위·점수 갱신 안내를 바꾸지 않는지도 확인한다.

glossary를 먼저 갱신하고 루트·게임 컨텍스트, 태도 문서, 게임 코어와 PRD를 동기화한다. 차트별 세 기록의 즉시 표시와 독립 보존, Normal/Easy의 분리, 같은 판정 설정 안의 미러 통합, 통계창의 플레이 횟수 표시와 기존 비공개 원칙을 확인한다. Normal과 Easy 모두 별도 랭킹 대상으로 명시되었는지, 동점은 해당 점수의 최초 달성 순서로 정렬하는지도 확인한다. 노트 배치 수정 뒤 이전 기록을 보관하고 새 버전의 기록·랭킹에 승계하지 않는지도 확인한다. 표시 대상이 현재 버전의 새 기록으로 한정되는지도 확인한다. 로그인한 플레이의 기록 전송 실패에 안내와 전송 재시도 조작이 정의되어 있는지도 확인한다. 결과 화면을 나간 뒤에도 해당 계정의 미전송 기록을 브라우저에 보관하는지도 확인한다. 다음 접속 시 원래 계정으로 로그인되어 있을 때 미전송 기록을 자동 재전송하는지도 확인한다. 이번 변경은 개인 기록·랭킹 정책의 문서 반영이며 기록 저장·집계·화면 구현은 변경하지 않는다.
