## 기존 결정과 문제의식

사용자는 이벤트 편집에서 버그가 반복되므로 되도록 일반 노트와 같은 방식으로 취급하도록 요청했다. [RFD 0067](0067-chart-event-names.md)는 이름을 통일했으나, 기존 선택 상태에는 이벤트 축이 없고 클릭·삭제는 훅의 별도 분기였다. 구간 이벤트의 끝 리사이즈만 `SelectMode`에 들어 있었다.

[RFD 0016 §3-4 D1](0016-editor-selection-handle-model.md)의 클립보드는 노트·구간의 시간 범위와 겹치는 이벤트를 자동 수집하고 박자 변경은 제외한다. 이벤트를 직접 선택할 수 있게 한 뒤에도 이를 유지하면 선택하지 않은 데이터가 복사되고 이벤트만 복사하지 못한다.

## 검토한 대안

- 개별 이벤트 버그만 고친다. 선택·키보드·클립보드의 분기가 남는다.
- 이벤트를 `chart.notes`에 넣는다. 판정·저장 모델과 레인 의미까지 바꾸므로 요청 범위를 넘는다.
- 저장 모델은 유지하고 기존 선택·편집 흐름에 이벤트를 포함한다. 노트의 기존 특수 규칙과 이벤트의 초기 설정 보호는 각각 유지하되 공통 조작은 같은 경로에서 처리한다.

## 채택안과 trade-off

**후속 결정:** 아래 초기 설정의 개별 선택·가로 이동·복사 허용은 [RFD 0082](0082-initial-timing-events-not-selectable.md)로 대체됐다. 현재는 모든 선택에서 제외하고 더블클릭 모달에서 값만 편집한다. 같은 RFD의 변경 결정(2026-11-01)으로 초기 BPM은 보조 레인 1, 박자는 2에 고정하고, 불러올 때 그 자리와 겹치는 일반 이벤트를 빈 보조 레인으로 옮긴다. 정리 결과는 Undo·Redo·미저장 표시에서 제외한 로드 기본 상태로 삼고, 저장 전 서버·원본 파일은 쓰지 않는다.

이벤트를 `Selection.events`로 직접 선택한다. 클릭·Shift 추가·Alt 해제·토글·박스·전체 선택을 지원하고, 노트·구간과 함께 이동·복사·잘라내기·삭제한다. 포인터와 키보드는 같은 선택을 읽는다. Ctrl+A에서는 0박 초기 BPM·박자만 제외해 기존 노트 전체 이동을 유지한다. 초기 설정의 개별 선택·값 편집·복사는 계속 허용한다. 구간 이벤트는 끝 리사이즈를 지원하며 이동·붙여넣기·리사이즈의 프리뷰·Esc 취소·undo/redo는 기존 편집 트랜잭션을 사용한다. 이벤트 속성은 기존 더블클릭 모달에서 편집한다.

이벤트의 가로 이동은 `editorLane`만 바꾸며 보조 레인 안에서 제한한다. `chart.notes`와 `chart.events`의 저장·인덱스 공간은 합치지 않는다. 0박 초기 BPM·박자는 시간 이동·삭제·잘라내기를 막고 값 편집·보조 레인 간 이동·복사는 허용한다. 초기 설정을 포함한 묶음의 시간 이동은 전체를 거부해 상대 간격을 보존한다. 묶음 삭제·잘라내기는 초기 설정을 남기고 나머지 선택 항목에 적용하며, Cut의 클립보드에도 지운 항목만 담는다. 이 예외로 기존 Ctrl+A → Delete의 노트 전체 삭제를 유지한다.

클립보드는 **명시적으로 선택한 이벤트만** 복사하며 박자 변경도 포함한다. RFD 0016의 시간 범위 자동 수집·박자 변경 제외·붙여넣은 이벤트의 가로 이동 제외를 이 결정으로 대체한다. 선택한 이벤트의 시작 박도 붙여넣기 기준 박 계산에 포함한다. 이는 선택하지 않은 BPM이 노트에 딸려오는 동작을 없애는 의도된 변경이다. 마디 경계·겹침 같은 의미 위반은 기존 낙관적 편집과 저장 검증을 따른다.

## 영향과 검증

이벤트의 같은 보조 레인 배치 겹침은 후속 [RFD 0078](0078-event-placement-overlap.md)을 따른다. 공통 선택·편집과 초기 설정 보호는 이 결정을 유지한다.

- glossary·에디터 컨텍스트·편집 스펙·RFD 0016의 후속 결정을 동기화한다.
- `SelectionSlice`, `TimelineSpace`, `SelectMode`, `ClipboardManager`, `DeleteMode`, 포인터 조립과 렌더링을 연결한다.
- 실제 store·좌표 공간·편집 모드의 통합 테스트로 이벤트 단독/혼합 조작, 초기 설정 보호, 선택하지 않은 이벤트의 비복사, 취소·undo를 검증한다. UI 조작은 E2E로 확인한다.
