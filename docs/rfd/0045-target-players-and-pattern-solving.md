# RFD 0045: 배치의 의도 이해와 패턴 파훼를 즐기는 플레이어

**Status:** Accepted (2026-10-28) · PRD·설계 의도·소개 문구 반영 (2026-10-28) · 여러 방법의 시험에서 배치 의도 이해와 재도전의 수월함으로 핵심 경험 설명 정정 (2026-10-28)

## 기존 결정과 문제의식

PRD는 반복 입력의 부담 때문에 다른 처리 방법을 찾는 기존 리듬게임 유저를 1차 타깃으로 정했다. 손배치 선택의 재미를 중심으로 설명을 정리한 뒤에도, 타깃은 기존 플레이의 부담을 전제로 제한되어 있었다.

사용자는 손배치를 직접 선택하고 바꾸는 재미를 원하는 기존 리듬게임 유저로 타깃을 잡는 데 동의했고, 패턴을 파훼하는 데 보람을 느끼는 유저를 추가했다.

이후 핵심 경험을 명확히 했다. 여러 방법을 이리저리 시험하는 과정보다, 패턴을 한 번 본 뒤 의도된 연주 방법을 파악하고, 다음 시도에서 더 수월하게 연주하는 경험이다. 앞서 문서에 쓴 시험·탐색 중심의 설명을 이 뜻으로 정정한다.

## 검토한 대안

- 반복 입력의 부담을 주된 조건으로 유지한다. 입력의 편의는 설명하지만 배치를 이해하고 연주하는 보람을 충분히 설명하지 못한다.
- 여러 처리 방법의 시험·탐색을 중심에 둔다. 손배치 선택의 자유는 설명하지만 사용자가 원하는 의도 파악과 다음 시도의 수월함을 정확히 담지 못한다.
- 배치의 의도를 이해한 뒤 더 수월하게 연주되는 경험을 기준으로 삼는다. 손배치 선택은 이 경험을 수행하는 수단으로 설명한다.

## 채택안과 trade-off

1차 타깃은 **배치의 의도를 이해하고 패턴을 파훼하는 데 보람을 느끼는 기존 리듬게임 유저**다. 패턴을 한 번 본 뒤 의도된 연주 방법을 파악하고, 다음 시도에서 더 수월하게 연주하는 경험을 중심에 둔다. 다중키 바인딩과 가변 손배치는 이 흐름을 수행하는 입력 구조다.

반복 입력의 부담을 나누려는 동기도 포함하되 타깃의 필수 조건으로 두지 않는다. 패턴 파훼의 보람은 [RFD 0101](0101-cognitive-load-and-action-planning.md)의 독해·동작 계획·수행 숙련도와 연결한다. 긴 손순서의 과도한 암기를 요구하는 방향으로 바꾸지 않는다.

타깃을 특정 불편에 한정하는 명료함 대신, 한 번 본 뒤 의도된 연주 방법을 파악하고 다음 시도에서 더 수월하게 연주할 수 있는지 설계·플레이테스트에서 확인해야 한다. 시각적 입력 요구는 단순하고 명확하게 유지한다. 실제 속도·정확도를 맞추는 숙련에는 반복 연습이 필요할 수 있다. 입문자와 상급 유저에 관한 기존 접근성·도전 범위는 유지한다.

## 영향과 검증

- PRD의 1차 타깃·설계 우선순위와 README·설계 의도·설계 개요의 핵심 경험, 난이도 설계의 플레이테스트 기준을 맞춘다.
- 새 노트·판정·진행 조건을 추가하지 않는다. 문서의 타깃 조건과 링크를 확인한다.
