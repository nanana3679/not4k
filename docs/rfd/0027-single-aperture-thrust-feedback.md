# RFD 0027: 하나의 분출구와 색으로 구분하는 추진부 입력 표현

**Status:** Accepted (2026-09-29) · 사용자 방향 분출을 반영한 외형 3종·Lab 비교 교체 및 모바일·데스크톱 E2E 검증 (2026-09-29) · 저장소 반영, 이전 탐색 보관 페이지는 용량 때문에 제외 (2026-10-04, PR #210)

## 기존 결정과 문제

추진부 아이디어는 입력하면 추진부가 활성화되어 빛이 분출되는 방향으로 선택했다. 초기 정지 시안은 싱글의 한 줄과 더블의 두 줄, 서로 다른 셔터 열림 정도나 두 원형 분출구로 상태를 구분했다.

사용자는 싱글과 더블이 계속 빠르게 반복되어 기구가 서로 전환할 시간이 없음을 지적했다. 분출구가 한 개에서 두 개로 바뀌는 표현은 이 사용 장면에 맞지 않는다.

## 검토한 대안

- 하나와 두 개의 분출구·빛줄기를 상태별로 전환한다: 정지 도안에서는 읽히지만 전환 동작과 별도 형상을 요구한다.
- 두 분출구를 고정하고 빛을 합치거나 나눈다: 구멍 수를 바꾸지는 않지만 싱글·더블을 구분하는 합치기·갈라지기 시간이 남는다.
- 하나의 분출구를 공유하고 이펙트 색만 전환한다: 같은 형상을 유지한 채 입력 상태를 즉시 표현할 수 있다. 이 안을 채택한다.

## 채택한 표시 규칙

- 각 버튼에는 연속된 구멍 하나만 둔다. 내부 칸막이·두 코어·두 출구로 한 개와 두 개를 세어 구분하게 만들지 않는다.
- 싱글과 더블은 같은 위치·크기·형상의 분출구를 사용한다. 셔터·조리개·입력면의 활성 상태 형상도 동일하다.
- 이펙트는 하나의 같은 분출 형상이며, 싱글은 연파랑, 더블은 금색 계열로 구분한다. 두 갈래 광선이나 출구 추가로 더블을 표현하지 않는다.
- 분출은 **화면 앞의 사용자를 향한다**. 사용자는 단일 분출구 비교의 3번에서 방향만 선택했으며, 원형 구멍과 버튼 외형은 마음에 들지 않는다고 명시했다. 아래로 흐르는 분출로 되돌리지 않고, 정면을 향한 출구·가까워지는 빛을 다른 외형으로 탐색한다. 원형 구멍은 채택 조건이 아니다.
- 싱글↔더블은 현재 이펙트 색만 즉시 바꾼다. 중간 대기·닫힘·재개방, 기구 이동 완료 대기, 빛의 합치기·갈라지기 단계를 넣지 않는다.
- 입력으로 추진부가 활성화된다는 아이디어를 유지한다. 구체적인 외형과 대기↔활성 모션 등 남은 선택은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

색만으로 상태를 구분하므로 색각 차이에 따른 구분력은 별도 접근성 정책의 검토 대상이다. 이번 작업에서 다른 판정·입력·비행 규칙을 추가하지 않는다.

- 이전 셔터·덮개·두 분출구 도안과 단일 분출구의 초기 3개 도안은 저장소 반영 시 이미지와 보관 페이지를 제외하고, 실제 생성 요청 JSON만 `assets-lab/classic/revisions/thrust-button-study-20260929/`에 남긴다.
