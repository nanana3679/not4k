# RFD 0077: 피스 PP-004의 이름을 롱노트 끝 탭으로 통일한다

**Status:** Accepted (2026-10-29) · 용어·컨텍스트·피스·개요·난이도·PRD 반영 (2026-10-29) · 트릴 연결 없이 성립 확인·정의와 선행 학습 반영 (2026-10-29)

## 기존 결정과 문제의식

피스 `PP-004`의 제목은 롱노트 끝 교대 → 트릴 연결, 본문 이름은 롱노트 끝 교대에서 트릴로였으며 PRD와 개요는 릴리즈탭으로 표기했다. 입력방식명과 피스명이 섞여 있었다.

## 검토한 대안과 채택안

기존의 긴 이름이나 롱노트 후 트릴 등의 후보 대신, 사용자가 선택한 롱노트 끝 탭으로 피스 이름을 통일한다. 릴리즈탭은 입력방식명으로 유지하고 피스 목록에는 롱노트 끝 탭을 사용한다.

후속 확인에서 트릴로 이어지지 않아도 피스가 성립한다고 정했다. 롱노트가 끝날 때 같은 레인의 다른 키로 탭하는 키 교대 배치를 정의로 삼고, 트릴 연결은 선택적인 활용 예시로 둔다. 필수 구성에서 트릴을 빼고 선행 학습에서도 짧은 트릴(`PP-001`)을 필수로 요구하지 않는다.

`PP-004`와 PLv.4는 유지한다. 새로운 노트 타입이나 판정 규칙을 추가하지 않는다. 피스 명세에 남아 있던 구형 `termination` 등급 상향 설명은 현행 노트·바디의 일반 규칙 참조로 정정하며, 이 피스라는 이유로 별도 판정 상향을 만들지 않는다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 `CONTEXT.md`, term-map, 피스 정의, 개요, 난이도 설계, PRD의 이름과 참조를 맞춘다. 교차 검토 보고서에는 입력방식·피스 명칭 구분의 해결을 반영한다. 입력방식을 설명하는 릴리즈탭은 일괄 치환하지 않는다. 런타임 코드는 변경하지 않는다.
