## 1. 기존 결정과 문제의식

- RFD 0001과 RFD 0005는 차트 난이도명과 `flightRule`을 별도 축으로 분리하고, `Liftoff / Survival` 2종 규칙을 두었다. 차트 난이도명은 `EASY / NORMAL / HARD`를 임시 채택했다.
- RFD 0021은 낮은 고도에서 시선을 아래로 회전하는 연출을 채택했지만, 시나리오별 배치를 아직 나누지 않았다.
- 사용자는 비행 시나리오의 이름이 곡 안에서 차트를 구분하는 난이도명이기도 하다고 설명하고, 상위 단계를 추가하기를 요청했다. 시선 각도를 유지하는 시안, 낮아질수록 아래로 회전하는 시안, 저고도를 유지하는 비행을 서로 다른 단계에 배치한다.
- 명칭과 순서를 비교한 뒤 사용자는 `Liftoff → Infiltration → Breakthrough` 순서와 아래 연출 배치를 명시적으로 확정했다. 속도·각도는 추후 직접 조절할 예정이며 구현은 지금 하지 않도록 요청했다.

## 2. 대안

| 대안 | 검토 결과 |
| --- | --- |
| `Liftoff / Survival`과 별도의 차트 난이도명 유지 | 난이도명에 비행 시나리오를 함께 담으려는 현재 의도와 다름 |
| `Liftoff → Breakthrough → Stealth` | 저공비행을 최상위에 둘 수 있으나, 후속 명칭 비교에서 채택하지 않음 |
| `Liftoff → Infiltration → Breakthrough`, 중간에 저공비행 배치 | 이름의 의미와 연결되지만 저공비행을 최상위에 두려는 구상과 다름 |
| `Liftoff → Infiltration → Breakthrough`, 최상위에 저공비행 배치 | 이름의 단계감과 사용자가 선호한 연출 배치를 함께 유지하므로 채택 |

## 3. 채택안

세 이름은 **한 곡 안에서 차트를 구분하는 난이도명이며, 각 단계의 비행 시나리오와 연출에도 대응**한다. `Lv.`는 차트의 절대적 난이도 수치로 유지한다. 난이도명과 `flightRule`을 완전히 별개인 분류로 설명하던 종전 결정은 이 연결 관계로 대체한다.

| 순서 | 이름 | 의미 | 확정 연출 |
| --- | --- | --- | --- |
| 1 | `Liftoff` | 이륙 | 시선 각도를 유지한 채 고도가 변하며 고도를 확보하는 느낌. 낮아져도 지면을 향해 크게 회전하지 않음 |
| 2 | `Infiltration` | 침투 | 낮아질수록 시선이 지면을 향해 꺾임. 지평선이 위로 사라지고 지면이 평면에 가까워지는 시안 06의 방향 |
| 3 | `Breakthrough` | 돌파 | 낮은 고도에서 전방을 보며 계속 비행. 가까운 지면과 빠르게 지나가는 광원 속에서 안정된 자세를 유지하는 숙련 비행 |

`Breakthrough`의 정상 연출은 저고도 비행이다. 따라서 화면에 보이는 낮은 고도 자체를 모든 시나리오에 공통된 실패 직전 상태로 해석하지 않는다. `altitude` 상태와 시각 고도·실패 위험의 구체적인 대응은 후속 규칙 설계에서 다룬다.

공통 아트 디렉션은 어두운 명도와 2D 아니메·메카닉 모티브다. 초기의 남색·청색 바탕과 시안 광원은 기준 시안이며, 후속 사용자 요청에 따라 난이도별 색상 배합과 광원 밀도에 차이를 둔다. 실제 기체가 등장할 필요는 없다. 중앙 4레인·판정선·노트 속도는 배경 연출의 영향을 받지 않는다.

### 난이도별 시각적 차이

사용자는 특히 `Breakthrough`에 지평선이 없고 화면 맨 위까지 광원이 지나가기를 요청했다. 전방을 보는 지속 저공비행은 유지하며, 상단을 비어 있는 하늘이나 움직임 없는 원거리 점으로 남기지 않는다. 이는 화면 구성의 요구이며 카메라 각도 수치를 확정한 것은 아니다.

사용자는 `Breakthrough`에 주홍을 사용하는 것도 괜찮다고 평가했다. 주홍을 돌파의 팔레트 후보로 수용하며, 황백색 하이라이트·이륙의 청록·침투의 청보라 및 구체적인 밀도 순서는 제작 제안이다. 세 배합 전체나 정확한 색상값을 확정한 것으로 확대하지 않는다. 비교 방향은 [아트 디렉션 기록](../design/art-direction-notes.md#난이도별-색상과-광원-분포)에 남기며 세부 조정은 [PRD §12](../prd.md#12-미정-사항)에서 추적한다.

사용자는 후속으로 돌파의 광원이 지면뿐 아니라 시점과 비슷하거나 더 높은 곳에도 있으면 어떨지 제안했다. 지면·시설 측면·상부 광원의 높이 차이를 [시연 10](../design/art-direction-notes.md#돌파의-광원-높이-시연-10)에서 비교한다. 후속 피드백에서 사용자는 기둥 같은 구조물이 너무 많고 광원만 있어도 된다고 평가했다. [시연 11](../design/art-direction-notes.md#구조물을-뺀-광원-중심-시연-11)에서는 기둥·지지대와 그에 따른 가림을 제거하고 높이별 광원 흐름을 유지한다. 후속으로 사용자가 광원이 선이 아닌 면이면 어떨지 제안하여 [시연 12](../design/art-direction-notes.md#선과-면-광원-비교-시연-12)에서 실제 넓이가 있는 발광 면을 비교한다. 사용자는 이어서 배치가 직각적이라 빠른 속도에서 빨려드는 느낌이 부족하고 면 내부에 선이 보인다고 평가했다. [시연 13](../design/art-direction-notes.md#원근-흐름과-단색-발광-면-시연-13)에서는 돌파의 일정한 행·열을 풀고 면의 긴 방향을 진행 방향에 맞추며, 내부 하이라이트와 잔광 비침을 제거한다. 높이 비율·광원 수·면의 크기와 비율은 탐색값이다.

## 4. 결정의 범위

- 세 이름·순서·차트 난이도명과의 관계·연출 배치를 확정한다. `Stealth`와 `Survival`은 현재 단계 이름으로 사용하지 않는다.
- RFD 0021의 하향 시점은 `Infiltration`에 배치한다. 모든 시나리오의 공통 카메라 규칙으로 적용하지 않는다.
- `Liftoff`의 기존 관대한 역할과 곡 중 게임 오버 없음은 이번 결정에서 변경하지 않는다. 기존 고도 0 시작·곡 종료 기준 모델은 규칙 설계의 유지 사항이다.
- 종전 `Survival`의 Perfect-only 회복·0 도달 실패 규칙을 새 `Infiltration` 또는 `Breakthrough`에 자동으로 승계하지 않는다. 같은 `Breakthrough` 이름을 다시 사용한다는 사실만으로 과거 규칙 전체가 복원되지는 않는다.
- 실제 충돌·레이더 탐지 판정, 새로운 조작, 실패 조건이나 점수 산식을 추가하지 않는다. 실제 게임의 차트 데이터·화면·에셋 연결은 변경하지 않는다. 후속 사용자 요청에 따른 별도 움직임 시연은 [시연 09](../design/art-direction-notes.md#난이도별-움직임-시연-09)와 [시연 10](../design/art-direction-notes.md#돌파의-광원-높이-시연-10)으로 기록하며 게임 구현과 구분한다.
- 속도·카메라 각도·고도 범위·전환 곡선은 이번 확정의 대상이 아니다. 세부 규칙과 데이터 이행의 미정 사항은 [PRD §12](../prd.md#12-미정-사항)에서 단일 추적한다.

## 5. Trade-off

차트 이름과 비행 경험이 연결되어 세계관과 난이도 선택을 함께 전달할 수 있다. 대신 기존 2종 규칙·임시 난이도 라벨의 데이터와 문서는 이행이 필요하다. 기존 라벨을 문자열만 바꿔 일괄 대응시키지 않는다.

`Breakthrough`는 낮은 고도를 지속하므로 고도 상승만으로 성공을 표현하는 공통 모델을 그대로 사용할 수 없다. 안정된 자세와 가까운 지면의 속도감으로 숙련 비행을 전달하고, 실패 위험 표현은 판정 규칙을 정할 때 함께 설계해야 한다.
