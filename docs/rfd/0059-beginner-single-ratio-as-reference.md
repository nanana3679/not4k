# RFD 0059: 입문 싱글 90%는 구성 참고치

**Status:** Accepted (2026-10-28) · 난이도·노트 시스템·PRD·교차 검토 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

입문 차트의 노트 구성을 싱글 90% 이상으로 설명해 엄격한 비율 제한으로 읽힐 수 있었다. 실제 배치의 부담으로 판단한다는 제작 원칙과 수치의 역할을 구별할 필요가 있었다.

사용자는 90%를 싱글 중심 구성을 설명하는 참고치로 두는 방향을 승인했다.

## 검토한 대안

- 싱글 90% 이상을 필수 비율로 유지한다. 단순하지만 실제 배치의 어려움을 비율만으로 판단하게 할 수 있다.
- 싱글 중심 구성을 권장하고 90%는 참고치로 둔다. 제작·플레이테스트에서 실제 부담을 확인해야 한다.

## 채택안과 trade-off

입문 차트는 싱글 중심 구성을 기본 예시로 삼으며, 90% 이상은 구성 참고치다. 비율만으로 차트를 허용하거나 금지하지 않는다. 독해 부담과 입력 속도·밀도·지속 길이·다른 입력과의 조합이 해당 차트 수준에 맞는지 확인한다.

모든 타입을 각 차트에 넣을 필요는 없다. 낮은 레벨의 느리고 단순한 짧은 체험, 외측 레인 트릴·더블의 허용 기준은 유지한다. 새 비율이나 정량 문턱을 만들지 않는다.

## 영향과 검증

- 난이도 설계·노트 시스템·PRD의 비율 표현을 참고치로 맞춘다.
- 교차 검토 문서의 과거 입문 구성 권고도 현재 채택 기준으로 해결 상태를 갱신한다.
- 런타임·차트 데이터·검증 동작은 변경하지 않는다. 비율의 강제 표현과 관련 링크를 확인한다.
