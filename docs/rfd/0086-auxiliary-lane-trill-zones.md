# RFD 0086: 보조 레인에도 메인과 같은 trillZone 적용

**Status:** Accepted (2026-10-29) · 보조 구간 저장·편집·검증·게임 제외 구현 (2026-10-29)

## 기존 결정과 문제의식

[#362](https://github.com/nanana3679/not4k/issues/362)는 보조 레인에도 `trillZone`을 두도록 요청한다. 사용자는 트릴 노트·바디의 구간 포함, 시작 트릴 탭 필수, 릴리즈 금지를 메인과 동일하게 적용하기로 확인했다. [RFD 0018 §3-2](0018-unified-lane-model.md#3-2-규칙--레인-조건표)의 메인 전용 범위를 바꾼다.

## 검토한 대안

- 보조 구간은 표시만 추가한다. 같은 구성물이 메인/보조에서 다른 배치 의미를 갖는다.
- 보조 노트가 있는 범위에 구간을 자동 생성한다. 기존 파일을 읽는 것만으로 사용자의 배치 의도를 바꾼다.
- 메인과 같은 배치·편집 규칙을 적용하고, 기존 구간 밖 트릴은 위반으로 표시해 사람이 수리한다.

## 채택안과 trade-off

- `TrillZone.lane`은 1 이상의 정수로 확장하고 `chart.trillZones` 한 배열에서 메인·보조 구간을 다룬다. 메인 판정 레인은 기존 1～4이며 경계 산술은 `laneAxis`만 소유한다.
- 트릴 노트·바디는 같은 레인의 한 구간에 시작·끝까지 포함되어야 한다. 일반 노트·바디·릴리즈는 그 구간에 놓지 않는다. 트릴 바디의 시작 트릴 탭 필수·길이 0 제한·틱 노트 금지·같은 레인 구간 겹침 금지를 보조에도 동일하게 적용한다. 구형 항목은 구형 의미, 명시 항목은 현재 의미로 검증하며 자동 변환하지 않는다.
- 기존 보조 트릴이 구간 밖에 있으면 의미 위반이다. 파일을 열어 수리할 수 있고 낙관적 편집·해칭·저장/플레이 차단을 그대로 사용한다. 구간이나 노트를 자동 생성하지 않는다.
- 생성·클릭/박스 선택·몸통 이동·끝 리사이즈·복사·Cut·Delete·Esc·Undo/Redo는 기존 구간 흐름을 사용한다. 이동 범위는 현재 보이는 메인·보조 레인이며, 붙여넣기는 필요한 보조 레인을 확장한다. 보조 레인을 줄이면 구간도 노트처럼 숨기고 데이터를 보존한다. 미니맵 밴드는 기존 보조 노트와 같이 제외하고 위반 지시자는 전체 문서 진단을 사용한다.
- 기존 메인/보조 두 파일을 유지한다. 메인 파일에는 메인 노트·구간만 저장하고, `.extra.json`의 선택 필드 `extraTrillZones`에 `{ extraLane, beat, endBeat }`를 저장한다. `extraLane`은 1부터, 박은 기존 문자열이며 버전 정책은 유지한다. 새 필드가 없으면 빈 보조 구간이다. 별도 보조 파일이 있으면 보조 데이터의 권위이며, 없는 경우에만 메인 내장 보조 자료로 돌아간다. 형식 오류를 빈 구간으로 바꾸지 않는다.
- dirty·저장·Save As·불러오기·자동 레인 확장에 보조 구간을 포함한다. 메인 구간만 있는 기존 파일의 출력은 보존한다.
- 게임의 입력·판정·점수 분모·렌더링에는 보조 노트·구간을 넣지 않는다. 원본문서의 전체 검증은 유지하므로 보조 위반도 저장·테스트 플레이를 막지만, 수리된 보조 구간을 추가해도 메인 연주의 판정·기록은 같다. 판정 엔진 자체는 바꾸지 않는다.

## 영향과 검증

- glossary·shared/editor 컨텍스트·편집/저장 스펙과 RFD 0018·0038의 후속 범위를 동기화한다.
- 공용 구간 타입·JSON 왕복·파일 분리/병합·dirty·레인 자동 확장·게임 경계를 연결한다.
- 전 레인 트릴 검증과 에디터 생성·선택·이동·리사이즈·해칭을 동일한 레인 좌표로 처리한다.
- 단위·통합 테스트로 형식·경계·기존 파일·저장 왕복·수리·Undo·게임 제외를 검증하고, UI E2E 스펙에 보조 구간 생성·편집·저장·재불러오기를 추가한다.
