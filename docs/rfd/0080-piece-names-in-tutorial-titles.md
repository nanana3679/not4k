# RFD 0080: 플레이어에게 피스 이름은 튜토리얼 제목 정도에만 사용한다

**Status:** Accepted (2026-10-29) · 용어·컨텍스트·튜토리얼·피스·옵저버·에셋 목록·PRD 문서 반영 (2026-10-29)

## 기존 결정과 문제의식

피스 이름은 제작·분석 문서에서 배치와 동작 계획을 설명하는 공통 용어다. 플레이어에게 어디까지 노출할지는 정하지 않았으며, 에셋 목록의 피스 구간 표시도 이름 표시와 입력 요구의 시각적 구분을 명확히 나누지 않았다.

## 검토한 대안과 채택안

플레이 중 피스 이름을 표시하거나 도움말 본문 전반에서 분류 용어로 사용하는 안 대신, 플레이어에게는 튜토리얼 제목 정도에만 사용한다. 본문은 실제로 어떤 키를 누르고 유지하며 전환하는지 설명한다. 피스 이름의 암기를 연주 방법 이해의 조건으로 삼지 않는다.

제작·분석 문서에서는 공식 피스 이름과 ID를 계속 사용한다. 일반 플레이·옵저버에 피스 이름 라벨을 추가하지 않는다. 노트 이름과 `trillZone` 등 입력 요구를 알리는 기존 시각 표시는 이 제한의 대상이 아니다. 모든 튜토리얼 제목을 피스 이름으로 바꿔야 한다는 뜻도 아니다.

이름을 반복 노출해 분류를 익히게 하는 효과는 줄어들지만, 실제 연주 방법의 이해에 안내를 집중할 수 있다.
