# RFD 0039: 무점수 차트의 재생과 결과 표시

**Status:** Accepted (2026-10-25) · 계약 문서 반영 (2026-10-26) · 재생·결과 구현은 #346(테스트 결과)·#347(공식 결과) · 명시 테스트의 무점수 재생·비율 숨김 구현 (2026-10-26, PR #346) · 일반 결과의 비율·랭크 숨김 검증 (2026-10-26)

## 배경과 문제

[RFD 0037](0037-explicit-score-notes-and-body.md)은 바디를 무점수 구간으로 분리하고 명시 Point·릴리즈·유지 노트만 점수 항목으로 만든다. 따라서 바디만 있는 유효한 차트는 점수 항목 수와 전체 이론 가중치가 0이다. 이를 플레이 불가로 취급할지, 완주 결과의 달성률·랭크를 어떻게 표시할지는 후속 결정으로 남아 있었다.

공용 `ScoreManager`는 분모가 0일 때 내부 계산값 0과 이에 대응하는 F를 반환한다. 이를 그대로 표시하면 점수로 평가할 대상이 없는 플레이를 전부 실패한 플레이와 같은 0%·F로 보이게 한다. 반대로 100%·SSS를 표시하면 평가할 대상 없이 최고 성과를 부여하게 된다.

사용자는 “바디만 있는 차트도 플레이는 허용하고, 달성률·랭크는 표시하지 않는다”는 제안을 승인했다(2026-10-25).

## 결정

1. 점수 항목이 없는 유효한 명시 차트도 재생할 수 있다. 점수 항목을 만들기 위해 바디에 자동 점수를 추가하거나 차트를 자동 수정하지 않는다.
2. 기준은 전체 차트의 이론 가중치 합이 0인지이다. 실시간 처리 분모가 아직 0이거나, 모든 점수 항목을 놓쳐 획득 점수가 0인 경우와 구별한다.
3. 무점수 차트에서는 플레이 중 달성률과 결과의 달성률·랭크를 표시하지 않는다. 내부 계산의 0·F를 0%·F로 노출하거나 100%·SSS로 대체하지 않는다.
4. 바디의 시작·유지·완료·실패 판정과 원인 Miss는 그대로 처리한다. 무점수라는 이유로 판정이나 실패 사실을 없애지 않는다. Full Combo의 기존 Miss 기준도 바꾸지 않는다.
5. 점수 항목이 있는 차트는 기존 달성률·랭크 규칙을 따른다. 모든 항목을 놓친 결과는 0%·F로 표시한다.

이 결정은 재생 허용과 표시 규칙을 정한다. 기록 저장·최고 기록 비교·랭킹의 모델 간 호환은 [PRD §12](../prd.md#12-미정-사항)의 별도 후속 범위다. 일반 곡의 기본 경로 전환은 구현 기록(아래 영향과 검증)을 따른다.

## 검토한 대안과 trade-off

| 안 | 결과 | 판단 |
| --- | --- | --- |
| 점수 항목이 없으면 재생 거부 | 달성률의 정의가 없는 플레이를 차단한다 | 유효한 바디 차트의 재생까지 막으므로 채택하지 않는다 |
| 재생 후 0%·F 또는 100%·SSS 표시 | 기존 숫자·랭크 UI를 그대로 사용한다 | 평가 대상 부재를 실패 또는 최고 성과로 표현하므로 채택하지 않는다 |
| 재생 허용, 달성률·랭크 숨김 | 실제 바디 판정은 수행하고 성과 지표는 표시하지 않는다 | 채택. 결과 소비자가 전체 이론 가중치 0을 구별해야 한다 |

## 영향과 검증

glossary의 점수 항목 정의, 루트·Gameplay CONTEXT, 스코어링·게임 코어 스펙과 구현 계획을 동기화한다. 계약 문서 PR(#340)은 계약만 반영했고, 새 테스트 재생과 일반 공식 결과의 구현·브라우저 검증은 각각 #346·#347에서 수행했다(2026-10-26).

무점수 바디의 정상 완료·실패·분모 0, 원인 Miss·Full Combo와 점수 항목 전부 Miss의 0%·F를 구별해 검증한다. 공용 점수 계산의 내부 숫자 타입을 이 결정만으로 바꾸지 않는다.
