# RFD 0087: 차트·음원 로딩 실패 후 재시도와 곡 선택 복귀를 제공한다

**Status:** Accepted (2026-10-29) · glossary·컨텍스트·게임 코어·기술 스택·PRD 문서 반영 (2026-10-29), 자동 재시도와 실패 화면의 재시도 조작 미구현 · 차트 형식·검증 오류의 복귀 전용 처리 문서 반영 (2026-10-29) · 로딩 진행 중 취소·복귀 조작 제외 문서 반영 (2026-10-29) · 응답 없는 로딩의 시간 초과 실패 처리 문서 반영 (2026-10-29), 제한 시간 처리 미구현 · 차트 파일 전송 실패의 최대 3회 자동 재시도 문서 반영 (2026-10-29) · 자동 재시도 횟수 표시 문서 반영 (2026-10-30) · 백분율 대신 현재 작업 표시 문서 반영 (2026-10-30), 작업 안내 미구현 · 관리자 전용 에디터 권한에 맞춘 오류 안내 문서 반영 (2026-10-30)

## 기존 결정과 문제의식

게임 코어와 PRD는 음원 로딩을 최대 3회 자동 재시도한 뒤에도 실패하면 곡 선택으로 돌아가도록 설명했다. 같은 곡을 다시 불러오려는 플레이어도 곡 선택으로 이동해야 하는 흐름이었다.

## 검토한 대안과 채택안

본 플레이의 차트 파일 전송 실패에도 음원 로딩 실패와 같이 최대 3회 자동 재시도를 적용한다(사용자 확인, 2026-10-29). 모두 실패하면 실패 화면에 오류 안내와 **재시도**, **곡 선택으로 돌아가기** 버튼을 제공한다. 플레이어가 고른 조작에 따라 같은 곡·차트의 로딩을 다시 시도하거나 곡 선택으로 돌아간다(사용자 확인, 2026-10-29).

자동 재시도 중에는 현재 재시도 횟수와 최대 횟수를 **재시도 1/3**처럼 표시한다. 첫 자동 재시도에서 1/3으로 시작하고 재시도가 진행될 때 갱신한다. 재시도 진행 상황을 플레이어가 확인할 수 있게 한다(사용자 확인, 2026-10-30).

로딩 안내는 백분율 진행률 대신 **차트 불러오는 중**·**음원 준비 중**처럼 현재 진행 중인 작업을 표시한다. 자동 재시도 횟수 표시는 함께 유지한다(사용자 확인, 2026-10-30).

실패 후 곡 선택으로 복귀시키는 방식 대신, 실패 화면에서 다음 조작을 선택하도록 한다. 조작 하나가 추가되지만 같은 곡을 다시 선택하는 과정을 거치지 않고 로딩을 재시도할 수 있다.

### 로딩 진행 중 조작

본 플레이 로딩이 진행 중일 때는 사용자 취소와 곡 선택 복귀 조작을 제공하지 않는다. 로딩과 자동 재시도는 성공 또는 실패가 확정될 때까지 진행한다. 실패 화면에서는 앞서 정한 재시도·곡 선택 복귀를 제공한다(사용자 확인, 2026-10-29).

### 응답 없는 로딩

본 플레이 로딩에서 응답이 없는 상태가 제한 시간 동안 이어지면 해당 로딩 시도를 실패로 처리한다. 차트 파일 전송과 음원 로딩의 시간 초과에는 자동 재시도와 최종 실패 화면의 선택 규칙을 적용한다. 무기한 기다리는 흐름 대신 제한 시간 뒤 실패를 확정한다(사용자 확인, 2026-10-29). 제한 시간 수치는 실제 파일의 로딩 시간을 확인한 뒤 구현 단계에서 정하며 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

### 차트 형식·검증 오류

차트 자체의 형식·검증 오류에는 자동 재시도나 수동 재시도를 제공하지 않고, 오류 안내와 **곡 선택으로 돌아가기** 버튼만 표시한다. 파일을 다시 전송받아도 같은 오류가 반복되는 차트 내용의 문제이므로, 음원 로딩 실패의 재시도 흐름과 구별한다(사용자 확인, 2026-10-29). 차트 파일을 서버에서 받아오지 못한 전송 실패를 형식·검증 오류로 분류하지 않는다.

에디터는 관리자만 접근할 수 있다. 차트 형식·검증 오류가 나면 일반 플레이어에게는 다른 차트 선택을 안내하고, 관리자에게는 에디터에서 수정할 수 있다는 안내도 제공한다. 관리자 전용 접근 권한은 기존 방침을 유지한다(사용자 재확인, 2026-10-30). 오류 화면의 조작은 곡 선택 복귀를 유지한다.

## 영향과 검증

glossary를 먼저 갱신하고 루트·Gameplay 컨텍스트, 게임 코어·기술 스택·PRD를 동기화한다. 현재 `LoadingScreen`은 오류와 곡 선택 복귀 버튼을 제공한다. 오류 안내의 권한별 문구, 현재 작업 안내, 자동 재시도와 수동 로딩 재시도는 미구현이다. 이번 작업은 문서 반영이며 런타임·테스트 코드는 변경하지 않는다.

차트 형식·검증 오류의 복귀 전용 처리와 차트 파일 전송·음원 로딩 실패의 최대 3회 자동 재시도·그 이후 선택을 구별하고, 이번 결정을 구현 완료로 표시하지 않는지 확인한다.
