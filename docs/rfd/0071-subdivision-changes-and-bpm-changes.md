# RFD 0071: 비트 복합과 BPM 변화를 별개로 평가한다

**Status:** Accepted (2026-10-28) · 용어·루트 컨텍스트·차트 설계·피스·난이도·PRD 반영 (2026-10-28)

## 기존 결정과 문제의식

차트 설계 문서는 비트 복합 트릴을 설명하면서 BPM이 일정하다고 전제했다. 사용자는 비트 복합과 BPM 변화는 별개이며, BPM이 변하는 순간에는 복잡한 패턴을 배치하기 어려울 수 있다고 설명했다.

## 검토한 대안과 채택안

BPM이 일정한 구간만 비트 복합 트릴로 분류하는 안 대신, 서로 다른 비트 분할의 복합을 기준으로 정의한다. BPM 변화 여부를 성립 조건으로 두지 않는다. BPM 변화만으로 비트 복합 트릴이 되는 것도 아니다.

BPM 변화에 대응하는 부담과 비트 분할·손배치의 복합 부담을 구분해 평가한다. BPM이 바뀌는 순간에는 복잡한 패턴의 부담이 겹칠 수 있으므로, 리듬을 파악하고 다음 동작을 준비할 여유가 있는지 확인한다. 복잡한 패턴을 일률적으로 금지하는 규칙으로 확대하지 않는다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 `CONTEXT.md`, 차트 설계, 피스 정의, 난이도 설계, PRD의 설명을 맞춘다. BPM 고정이 비트 복합의 필수 조건으로 남지 않는지 확인한다. PLv.10, BPM과 스크롤 속도의 독립 정책, 입력·판정 코드는 변경하지 않는다.
