# RFD 0023: 돌파 시연의 고도별 구조물 여유

**Status:** 사용자 요청으로 충돌 판정 없는 근접 연출 비교안 채택 (2026-09-09) · 별도 시연의 기본 근접 연출·기존 비교 토글·아래 고도 조절 구현, 단위 290개·근접 브라우저 54개·가로 보기 196개 검증 (2026-09-09).

## 기존 결정과 문제

[시연 35](../design/flight-concept.md#63-세로-폭을-유지하고-a-높이만-이동--시연-35)는 가까운 단면과 시점을 고정하고 원거리 `A`만 이동했다. 흐름 방향은 바뀌지만 가까운 구조물과의 수직 간격은 일정하다. 사용자는 높으면 구조물 위로 안전하게 지나가고 낮으면 부딪힐 듯 스치는 시연을 요청했으며, **충돌 판정은 필요 없고 연출만 필요하다**고 명시했다.

## 대안과 채택안

- 속도·경고색·흔들림 강화: 구조물과의 거리보다 별도의 위기 효과로 읽히므로 채택하지 않는다.
- 기존 대칭 구조물 속에서 시점만 상승: 높은 고도에서 천장이 가까워지는 문제가 있다.
- **하단 구조물과 시점의 수직 간격을 변화**: 비교 시연의 기본값으로 채택한다. 기존 고정 시점은 끄기 비교로 보존한다.

시점은 회전하지 않고 상승한다. 가까운 바닥과 천장은 유지하고, 성긴 외곽 구조물은 바닥 쪽 입체 장갑 덩어리로 구성한다. 낮을 때는 옆면·모서리가 눈높이에 걸리고 높을 때는 윗면이 아래로 지나간다. 원거리 `A` 이동은 약한 보조 흐름으로 남긴다. 상단에도 기존 광원 흐름이 있고 하늘·지평선은 만들지 않는다. 구조물 배치와 전진 속도·중앙 레인·판정선·노트 시간은 고도로 재추첨하거나 가속하지 않는다.

## Trade-off와 범위

기존의 고정 시점·대칭 구조물과 다른 공간 연출이므로 같은 화면의 비교 토글로 되돌릴 수 있게 한다. 사각뿔의 원거리 수렴과 단면별 광원 합성은 여전히 시연용 근사다. 고고도도 돌파의 저공 범위 안이며, 최저 구간의 근접감은 게임 실패 의미가 아니다. 충돌체·피해·실패·점수·입력·경고 기능은 만들지 않는다. 이륙·침투·게임 본편·원본 이미지는 변경하지 않는다. 수치는 시연용이며 제품 상태 대응은 [PRD §12](../prd.md#12-미정-사항)에서 계속 관리한다.
