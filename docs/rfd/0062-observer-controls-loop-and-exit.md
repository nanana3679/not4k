# RFD 0062: 옵저버의 Auto·미니맵·구간 반복과 종료

**Status:** Accepted (2026-10-28) · 문서 반영 (2026-10-28) · 선택 구간 앞뒤 각 3초 추가 재생·페이드 확인 (2026-10-28) · 구간 밖 노트 제외·경계 자르기는 [RFD 0063](0063-observer-range-note-clipping.md)에서 후속 채택 (2026-10-28) · Auto 기본 켜짐 확인 (2026-10-28) · Auto 현재 위치에서 즉시 전환 확인 (2026-10-28) · 미니맵 구간 변경 시 앞 3초부터 즉시 재생 확인 (2026-10-28) · 진입 즉시 재생·미니맵 드래그 중 정지와 해제 시 재생 확인 (2026-10-28) · Auto 해제 시 진행 중 바디 즉시 직접 유지 확인·문서 반영 (2026-10-28) · 앞뒤 페이드의 실제 시간 각 최대 3초 기준 확인·문서 반영 (2026-10-29) · 옵저버 런타임 미구현 · Auto 전환 집계 유지 철회 및 수동 콤보·달성률 초기화 반영 (2026-10-31) · 드래그 해제 즉시 재생 철회, 시작 핸들 기준 화면 갱신·정지 유지·재생 버튼으로 선택 시작점 직접 재생 반영 (2026-10-31) · 선택 시작점 직접 재생 결정 철회, 구간 수정 후 재생·Retry 모두 앞 최대 3초 준비 구간 사용으로 재결정 (2026-10-31) · 앞뒤 페이드 구간 재생 `AudioEngine.playSection` 구현 (2026-10-31, 런타임 미연결)

**후속 결정:** [RFD 0064](0064-observer-whole-song-loop-and-reset.md)는 아래의 곡 종료 시 자동 퇴장을 기본 전곡 구간·명시적 종료까지 반복하는 흐름으로 대체했다. 반복·Retry의 콤보·달성률 초기화도 채택했다. Auto·미니맵·페이드·리절트 생략 규칙은 유지한다.

**집계·표시 후속 결정:** [RFD 0075](0075-observer-manual-only-statistics.md)는 Auto 중 콤보·달성률 숨김과 Auto 노트 집계 제외를 확정했다. 수동 집계는 반복 구간이 끝나면 초기화하며 Retry·구간 변경에도 초기화한다. Auto를 켜거나 끄는 전환에도 수동 콤보·달성률을 초기화하고, 직접 입력으로 돌아오면 새 수동 집계를 0부터 시작한다.

## 기존 결정과 문제의식

직접 입력·판정 확인을 채택한 뒤에도 관찰과 연습의 전환, 구간 선택 UI, Retry와 종료 흐름은 구체화되지 않았다. 기존 명세는 하단 스크롤 바의 마커로 반복 구간을 지정하고, 곡이 끝나도 모드를 종료하지 않는다고 설명했다.

사용자는 Auto 토글, 에디터와 같은 오른쪽 미니맵, 미니맵에서 지정한 구간만 반복, 페이드 인·아웃 3초, Retry 시 구간 시작으로 복귀, 곡 종료 시 모드 종료, 종료 시 리절트 생략을 지정했다. 페이드는 선택 구간 앞뒤로 3초씩 추가 재생하며 적용하는 방식이라고 확인했다.

## 검토한 대안

- 기존 하단 스크롤 바 마커와 곡 종료 후 대기 흐름을 유지한다. 사용자가 지정한 미니맵 기반 조작·종료와 다르다.
- Auto와 오른쪽 미니맵을 중심으로 구간 반복·Retry·종료를 구성한다. 에디터와 익숙한 탐색 UI를 활용하되 반복 경계의 세부 동작은 정해야 한다.

## 채택안과 trade-off

- Auto 토글로 자동연주 관찰과 직접 입력 연습을 전환한다. 옵저버 진입 시 기본값은 켜짐이며, Auto 상태로 바로 재생한다(사용자 확인, 2026-10-28). 켜거나 끄면 현재 재생 위치에서 즉시 전환하며 구간을 다시 시작하지 않는다. 수동 콤보·달성률은 전환 때 초기화한다([RFD 0075](0075-observer-manual-only-statistics.md)의 후속 결정, 2026-10-31).
- 오른쪽에 에디터와 같은 미니맵을 두고 반복 구간을 지정한다. 시작·끝 핸들은 구간 길이를 조절하고 몸통은 길이를 유지한 채 위치를 옮긴다. 시간 위치는 자유롭게 지정하며 박자 스냅을 적용하지 않는다(사용자 확인, 2026-10-28). 지정한 구간만 반복한다. 시작·끝 핸들이나 몸통을 드래그하는 동안 재생을 멈추고, 화면 패턴은 현재 선택 구간의 시작 핸들 위치를 기준으로 갱신한다. 끝 핸들만 바꿔 시작 위치가 같으면 화면의 기준 위치도 그대로이며, 시작 핸들이나 몸통을 옮기면 새 시작 위치를 따른다. 드래그를 놓아도 정지 상태를 유지한다. 이후 재생 버튼을 누르면 선택 구간 시작에 앞선 최대 3초 준비 구간부터 재생해 페이드 인 후 선택 구간에 진입한다. 이 준비 구간은 배속과 무관한 실제 시간 기준이며 실제 음원 범위까지만 사용하고 부족한 시간은 무음으로 보충하지 않는다. 드래그 해제 즉시 재생하던 기존 방침은 이 결정으로 대체한다(사용자 확인, 2026-10-31). 기존 하단 스크롤 바 마커 방식은 대체한다.
- Retry는 지정 구간 시작에 앞선 최대 3초 준비 구간을 거쳐 다시 진입한다. 전곡을 대상으로 사용할 때도 실제 음원 시작 경계 안에서 같은 원칙을 적용한다.
- **당시 종료 정책 — RFD 0064로 대체:** 곡이 끝나면 옵저버를 종료하고 곡 선택으로 복귀한다. 종료 시 리절트를 표시하지 않는다. 전곡을 끝없이 반복하거나 곡 종료 후 대기하는 기존 설명은 폐지한다.
- 선택 구간 앞뒤로 실제 시간 기준 각각 최대 3초를 추가 재생하며 앞에서 페이드 인, 뒤에서 페이드 아웃한다. 배속과 무관하게 실제 시간 3초를 기준으로 한다(사용자 확인, 2026-10-29). 배속이 일정한 경우 속도 비율을 r로 두면 앞뒤에서 추가로 재생할 곡 시간은 각각 최대 3r초다. 0.5배속에서는 곡 시간 1.5초가 실제 시간 3초에 해당한다. 실제 음원이 있는 범위까지만 재생하고 시작·끝 밖의 부족한 시간은 무음으로 보충하지 않는다(사용자 확인, 2026-10-28). 선택한 연습 구간은 유지한다. 반복과 Retry는 앞 페이드 구간을 거쳐 연습 구간에 진입한다. 구간을 드래그한 뒤 명시적으로 재생할 때도 같은 앞 준비 구간을 사용한다. 직전의 선택 시작점 직접 재생 결정은 철회하고 이 준비 구간 사용으로 대체한다(사용자 확인, 2026-10-31). 기존 Play의 재개·음악 준비 3초와 같은 계약으로 취급하지 않는다.

구간 지정과 Retry는 전체 곡을 처음부터 다시 시작하는 부담을 줄인다. 추가 재생 구간의 노트 제외와 경계 자르기는 [RFD 0063](0063-observer-range-note-clipping.md)을 따른다. Auto 전환의 입력 이벤트 처리 세부, 콤보·달성률 집계 범위와 반복 경계의 키·바디 상태 등 남은 사항은 [PRD §12](../prd.md#12-미정-사항)에서 단일 관리한다. 미구현 상태를 유지한다.

### 후속 확인: Auto를 끌 때 진행 중인 바디

진행 중인 바디가 끝날 때까지 자동 유지를 남기는 안 대신, Auto를 끄는 순간부터 직접 이어받는 안을 채택했다. 자동 유지는 종료하고 실제로 누르고 있는 키를 기준으로 일반 바디 규칙에 따라 유지 여부를 판단한다. 현재 바디의 끝이나 다음 노트까지 전환을 미루지 않는다. Auto 전환 시 수동 콤보·달성률을 초기화하며, 직접 입력으로 돌아오면 새 수동 집계를 0부터 시작한다. Auto 전환의 입력 이벤트 처리 세부와 반복 경계의 상태는 [PRD §12](../prd.md#12-미정-사항)에서 계속 추적한다.

- RFD 0061에 후속 결정을 연결한다. 런타임·에디터 미니맵·일반 Play의 흐름은 변경하지 않는다.
- 하단 스크롤 바 마커 방식과 곡 종료 후 대기, Retry의 무조건 곡 시작 복귀 등 상충하는 현행 설명과 관련 링크를 확인한다.
