# RFD 0104: 키 추가·손배치 발견을 위한 튜토리얼 과정은 두지 않는다

**Status:** Accepted (2026-10-29) · 용어·컨텍스트·키 바인딩·튜토리얼·에셋 목록·PRD 문서 반영 (2026-10-29) · 에셋 목록의 잔여 단계별 키 확장 표현 정리 (2026-10-30) · 키 부족 시 시연 허용·직접 입력 비활성화·이유 표시 및 수동 전환 유지 반영 (2026-10-31)

## 기존 결정과 문제의식

키 바인딩 스펙에는 기본 행 체험, 약지·엄지의 발견, 양손 완성으로 이어지는 학습 과정이 있었다. 튜토리얼 스펙과 PRD는 이 과정을 노트 메커니즘 학습과 병행하거나 결합하는 것으로 설명했다.

사용자는 키 추가·손배치를 익히는 안내를 노트 튜토리얼에 합칠지 별도로 둘지에 대해 해당 과정 자체를 두지 않기로 했다.

## 검토한 대안과 채택안

키 바인딩 학습을 별도 과정으로 두거나 노트 연주법 학습에 통합하는 대신, 단계별 키 추가·손배치 발견을 위한 튜토리얼 과정을 제거한다. 튜토리얼은 노트의 연주 방법과 판정 규칙을 시연·직접 입력으로 배우는 흐름으로 구성한다.

실습에 필요한 키가 부족하면 실제 키 설정을 먼저 수정하도록 안내하는 [RFD 0081](0081-tutorial-demonstration-and-three-practice-successes.md)의 규칙은 유지한다. 현재 키 설정으로 실습할 수 없어도 시연은 이용할 수 있다. `직접 입력 / 시연` 토글의 직접 입력 옵션을 비활성화하고 키가 부족한 이유와 실제 키 설정을 수정하는 경로를 안내한다. 실제 설정이 요구를 충족하면 직접 입력 옵션을 활성화하지만 자동으로 실습에 전환하지 않으며, 플레이어가 직접 선택해야 한다. 별도 실습 시작 버튼이나 임시 키 자동 배정은 추가하지 않는다. 시연용 표시 키 보충은 실제 실습의 키 요건을 충족한 것으로 취급하지 않는다. 최초 프리셋 선택, 키 설정 기능, 조정 가능한 프리셋·손가락 배치 예시도 유지한다. 여러 키 교대나 유지 중 탭 같은 실제 연주 방법은 노트 튜토리얼에서 다룬다.

학습 과정은 단순해지지만, 키 설정 자체를 단계별로 체험시키는 과정은 제공하지 않는다. 필요한 키의 부족과 설정 수정 방법을 안내할 수 있어야 한다.

## 영향과 검증

glossary와 루트·게임 컨텍스트를 동기화하고 키 바인딩 스펙의 단계별 발견 과정을 제거한다. 튜토리얼 스펙과 PRD의 두 학습 과정 병행·결합 설명 및 관련 미정 항목을 정리한다. 기존 공개 튜토리얼 목록과 런타임 코드는 변경하지 않는다. 단계별 키 추가 과정이 현행 요구로 남지 않는지, 필요한 키 설정 안내와 노트 연주법 학습이 유지되는지 확인한다.
