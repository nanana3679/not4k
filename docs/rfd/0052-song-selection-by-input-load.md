# RFD 0052: 수록곡은 BPM 분포보다 실제 입력 부담으로 선정

**Status:** Accepted (2026-10-28) · 수록곡·난이도 설계 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

차트 디자인 문서는 높은 BPM의 곡이 손배치 판단 시간을 압축한다고 설명하고, 초기 15곡을 평균 155 BPM·약 130～180 BPM으로 구성한 뒤 고BPM 곡을 추가하는 방향을 전제했다.

실제 입력 간격은 BPM과 비트 분할·배치의 조합으로 달라지며, 화면의 스크롤 속도도 BPM과 독립이다. 사용자는 기존 BPM 분포를 참고안으로 두고 실제 입력 속도와 손배치를 판단할 여유를 곡·차트의 선정 기준으로 삼는 안을 승인했다.

## 검토한 대안

- 정해진 초기 BPM 분포와 고BPM 곡의 후속 추가 순서를 유지한다. 구성을 간단하게 정할 수 있으나 실제 차트의 부담을 충분히 반영하지 못한다.
- BPM 분포는 참고안으로 보존하고 실제 배치의 부담으로 선정한다. 곡별 차트 제작과 플레이테스트가 필요하다.

## 채택안과 trade-off

수록곡과 차트는 실제 입력 속도·간격, 손배치 선택·전환의 빈도와 복합도, 다음 동작을 읽고 준비할 여유를 기준으로 선정한다. BPM이 높아도 입력 간격을 넓게 구성할 수 있고, 낮아도 촘촘하거나 복합적인 배치는 어려울 수 있다.

기존 15곡·평균 155 BPM·표준편차 10 BPM·약 130～180 BPM과 구간별 곡 수는 참고안으로만 남긴다. 선정의 필수 조건이나 할당량으로 사용하지 않으며, 180 BPM 이상 곡을 반드시 후속 업데이트로 미루는 순서도 두지 않는다.

간단한 BPM 수치 대신 실제 차트의 독해·동작 계획·물리 부하를 확인해야 한다. 이는 새 장르 비율이나 곡 수·발매 일정을 확정하는 결정이 아니다.

## 영향과 검증

- `docs/context/chart-design.md`의 선정 근거와 참고 분포, `docs/spec/difficulty-design.md`의 난이도 설명을 맞춘다.
- BPM·비트 분할·스크롤 속도의 기존 정의와 런타임은 바꾸지 않는다. 공식 용어를 새로 도입하지 않는다.
- 고BPM을 곧바로 높은 입력 부담으로 단정한 문구와 후속 수록 전제가 남지 않는지, 참고안의 상태와 관련 링크를 확인한다.
