# RFD 0058: 동시 활용 8키는 운용 예시

**Status:** Accepted (2026-10-28) · 용어·키 배치·난이도·PRD 설명 반영 (2026-10-28)

## 기존 결정과 문제의식

기존 문서는 16키 프리셋에서도 동시 활용이 최대 8키 수준이며 16키를 동시에 사용하는 구간은 없다고 설명했다. 일반적인 운용 설명과 차트 제작의 상한을 구별하기 어려웠다.

사용자는 8키가 예시이며, 실제로 이를 넘겨 활용하는 배치는 쉽지 않을 것이라고 정리했다.

## 검토한 대안

- 동시 활용 8키를 차트 제작의 상한으로 둔다. 기존 설명을 강한 제약으로 해석하게 된다.
- 일반적인 운용 예시로 설명한다. 실제로 8키를 넘는 활용은 흔치 않을 것으로 예상하되 하드 상한으로 사용하지 않는다.

## 채택안과 trade-off

동시 활용 8키는 일반적인 운용을 설명한 예시다. 8키를 넘겨 활용하는 배치는 흔치 않을 것으로 예상하지만, 8키를 차트 제작이나 시스템 검증의 상한으로 두지 않는다.

16키 프리셋은 바인딩해 둔 전체 키 수이며, 이를 동시에 모두 쓰도록 요구한다는 뜻이 아니다. 패턴마다 사용하는 주키·보조키가 달라져 차트 전체에서 활용하는 키의 범위가 넓어진다. 실제 동시 활용의 부담은 배치별로 확인한다.

이 결정은 더블 노트가 서로 다른 두 키를 요구한다는 입력 조건이나, 다른 노트·바디의 구조 제약을 바꾸지 않는다. 특정 조합의 입력 수 계산과 게임 전체의 상한을 구별한다. 8키 초과 배치를 권장하거나 모든 키의 사용을 요구하는 결정도 아니다.

## 영향과 검증

- glossary의 보조키 정의, 루트 `CONTEXT.md`, 키 바인딩·난이도·노트 시스템·PRD의 관련 설명을 맞춘다.
- 런타임·프리셋의 실제 바인딩·구조 검증은 변경하지 않는다.
- 일반 운용의 예시가 하드 상한으로 읽히지 않는지, 16키 전체 활용과 동시 활용의 구별 및 관련 링크를 확인한다.
