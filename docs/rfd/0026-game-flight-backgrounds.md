# RFD 0026: 난이도명과 공개 비행 시연의 인게임 적용

**Status:** 채택 (2026-09-23, 사용자 인게임 적용 요청) · 이름 표시·세 배경 연결 및 정지·재시작 검증 완료 (2026-09-23) · 사용자 요청으로 이전 격자 배경·Lab 시연·프리셋 저장 경로 제거 (2026-09-23)

## 기존 결정과 문제

RFD 0022에서 채택한 `Liftoff / Infiltration / Breakthrough`와 공개 Lab의 배경이 실제 게임에는 연결되지 않았다. 사용자는 기존 인게임 난이도명과 배경을 현재 시연으로 교체하도록 요청했다. 이에 이름·연출 구현 보류를 해제한다.

## 대안과 채택안

- 기존 차트 파일과 DB 키를 일괄 개명하면 저장 경로·선택 복원·기존 링크가 깨질 수 있다. 저장 식별자는 유지하고 표시와 배경 선택에서 `EASY → Liftoff`, `NORMAL → Infiltration`, `HARD → Breakthrough`를 해석한다.
- 네 번째 기존 라벨 `EXPERT`는 차트 충돌을 피하도록 별도 이름과 순서를 유지하며 돌파 배경을 사용한다. 새 차트 선택지는 세 공식 난이도명으로 제공한다.
- 에디터의 Save As도 같은 난이도명을 사용한다. 현재 난이도의 별칭은 선택할 수 없으며 기존 별칭 차트를 덮어쓸 때는 확인 후 해당 저장 식별자를 유지한다.
- 배경을 유사하게 다시 만드는 대신 공개 시연의 기하·광원·잔광·이미지를 재사용한다. 게임의 프레임 루프가 시간을 공급하고 중앙 레인 뒤의 별도 캔버스에서 렌더링한다. 시연의 조절 UI와 자체 재생 루프는 가져오지 않는다.
- 기존 임시 고도 모델과 기어 게이지를 함께 유지한다. 새 실패·회복 규칙, 패턴 제한, 점수·랭킹 변경과 원격 데이터 마이그레이션은 이 작업에 포함하지 않는다.

## Trade-off

기존 라벨은 저장값과 화면 표시가 다르지만 기존 곡과 에디터 링크가 계속 동작한다. 순수 시연 모듈을 게임에서도 번들링하므로 향후 시연 수정은 게임 검증도 필요하다. 필요한 이미지만 빌드 에셋으로 포함하고 Lab 페이지나 설정 패널은 배포 의존성으로 두지 않는다.

## 이전 배경 정리

후속 삭제 요청에 따라 사용하지 않는 격자 배경 구현, 두 Lab 시연과 프리셋 저장 API를 삭제했다. 새 배경이 사용하는 고도 계산은 `flightAltitude`로 이름을 정리하고 같은 계산을 유지한다.
