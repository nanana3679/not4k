# RFD 0082: 초기 BPM·박자 설정을 선택 대상에서 제외

**Status:** Accepted (2026-10-29) · 선택 정규화·모드·초기 설정 모달 구현, 전체 단위 5,633개·이벤트 E2E 8개 검증 완료 (2026-10-29) · 타입 검사·Lab 빌드 통과 (2026-10-29) · 위 구현·검증은 별도 [PR #369](https://github.com/nanana3679/not4k/pull/369)의 기록이며 이 문서 분할 PR은 런타임 변경 없음 (2026-10-31)

## 기존 결정과 문제의식

[RFD 0068](0068-common-event-editing.md)은 초기 BPM·박자의 개별 선택·가로 이동·복사를 허용하고 시간 이동·삭제·Cut을 보호했다. 이해 확인 중 사용자는 초기 이벤트를 아예 선택하지 못하게 하자고 요청했다. 초기 설정 때문에 노트와 이벤트의 혼합 조작이 달라지는 예외를 줄인다.

## 검토한 대안

- 개별 선택과 혼합 명령의 예외를 유지한다. 초기 설정을 선택하면 일반 노트의 시간 이동까지 막힌다.
- Ctrl+A에서만 제외한다. 클릭·박스·터치에서 같은 문제가 남는다.
- 초기 설정을 모든 선택에서 제외하고 속성 편집만 허용한다. 공통 조작은 일반 노트와 선택 가능한 이벤트만 대상으로 한다.

## 채택안과 trade-off

- 0박의 `BpmChangeEvent`·`TimeSignatureChangeEvent`는 클릭·Shift·Alt·터치 토글·롱프레스·박스·Ctrl+A 선택에서 제외한다. `SelectionSlice` 정규화도 초기 설정을 제거해 직접 store 쓰기나 선택 복구가 우회하지 못하게 한다. 0박의 다른 종류 이벤트는 선택할 수 있다.
- 초기 설정은 선택에 들어가지 않으므로 선택 기반 이동·복사·Cut·Delete의 대상이 아니다. 기존 직접 삭제·시간 이동 가드는 방어적으로 유지한다.
- 더블클릭 속성 편집은 유지한다. 초기 설정 모달에서 값과 보조 레인(`editorLane`)을 편집할 수 있게 해, [RFD 0078](0078-event-placement-overlap.md)의 기존 파일 겹침을 선택·드래그 없이 수리한다. 레인은 현재 보조 레인 범위의 정수만 허용하며 박 위치와 종류는 바꾸지 않는다. Cancel은 원본을 보존하고 Save는 기존 Undo 경로를 사용한다.
- 저장 파일을 읽을 때 초기 설정을 자동으로 재배치하지 않는다. 선택 불가와 속성 모달 편집은 독립적인 경로로 처리한다.

## 영향과 검증

- glossary·에디터 컨텍스트·편집 스펙과 RFD 0068의 후속 결정을 동기화한다.
- `SelectionSlice`·`SelectMode`에서 초기 설정의 선택을 차단하고, 모달·속성 저장에 초기 설정 레인 수리 경로를 연결한다.
- store 정규화·클릭/수식자/박스/터치·혼합 이동·복사·Cut·Delete·Undo의 단위/통합 테스트와 초기 설정 더블클릭·모달 레인 수리·저장 E2E로 검증한다.
