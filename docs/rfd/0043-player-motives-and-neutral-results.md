# RFD 0043: 플레이 목적의 선택과 담백한 결과 표시

**Status:** Accepted (2026-10-28) · 태도 문서의 원칙·근거 설명 반영 (2026-10-28)

## 기존 결정과 문제의식

`stance.md`는 플레이를 "자기 자신과의 싸움"으로 규정하고, 의미 있는 비교는 과거의 자신과의 비교뿐이라고 설명했다. 실패 시 감정, 연습의 의미, 계급이 동기에 미치는 영향도 일반화했다. 같은 문서의 선택적 랭킹과 PRD의 경쟁을 원하는 타깃 설명은 이러한 단정과 맞지 않는다.

사용자는 기록 갱신이든 경쟁이든 목적은 플레이어가 정하고, 게임은 결과를 담백하게 보여주는 방향을 승인했다.

## 검토한 대안

- 자기 기록 갱신만을 의미 있는 목적으로 규정한다. 담백한 UI의 근거는 단순해지지만 플레이어가 경쟁이나 다른 재미를 선택하는 이유까지 게임이 평가하게 된다.
- 플레이 목적의 선택과 기본 UI의 구성을 구별한다. 다양한 목적을 인정하면서도 게임이 기본으로 제시할 정보와 문구를 정할 수 있다.

## 채택안과 trade-off

플레이 목적은 플레이어가 정한다. 기록 갱신, 경쟁, 패턴 탐색 등 어떤 목적을 택하는지나 결과에서 무엇을 느껴야 하는지를 게임이 규정하지 않는다. 게임은 판정·기록을 담백하게 표시하고 다시 선택하거나 시도할 수 있게 한다.

기존의 기본 개인 기록 표시와 선택적 랭킹, 격려·훈계 문구 제한, 일일 보상·종합 계급 시스템의 불채택, Observer 명칭은 유지한다. 이 구성은 게임의 UI 선택으로 설명하며, 경쟁이 무의미하거나 연습이라는 말이 부족함을 뜻한다는 근거를 사용하지 않는다. UI가 담백하다는 사실만으로 플레이어의 동기나 감정이 특정 방향으로 정해지는 것은 아니다.

하나의 플레이 목적을 중심 서사로 설명하던 단순함을 줄이는 대신, 이후 설계에서도 기능의 목적과 플레이어의 심리를 구별해야 한다.

## 영향과 검증

- `docs/context/stance.md`의 중심 원칙과 심리·동기에 관한 설명을 갱신하고 정형 변경 이력을 남긴다.
- 금지·허용 항목, 기능의 채택·불채택과 이름은 보존한다. UI 동작·코드는 변경하지 않는다.
- 현재 원칙에서 배타적 자기 비교·감정 단정을 제거했는지와 기존 목록·문서 링크가 유지되는지 확인한다. 과거 변경 이력은 당시 기록으로 보존한다.
