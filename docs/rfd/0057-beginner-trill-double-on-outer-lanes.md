# RFD 0057: 입문 트릴·더블의 외측 레인 체험 허용

**Status:** Accepted (2026-10-28) · 용어·난이도·키 배치·노트 설계 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

난이도 설계는 입문 트릴·더블을 내측 2·3번 레인에만 배치하도록 제한했다. 키 배치 설명도 외측 트릴과 약지의 사용이 중급에서 처음 등장하는 것처럼 서술했다.

사용자는 충분히 느리고 단순한 짧은 배치라면 입문에서도 외측 1·4번 레인의 트릴·더블을 허용하고 실제 부담으로 판단하는 방향을 승인했다.

## 검토한 대안

- 내측 레인 전용 제한을 유지한다. 프리셋의 한 가지 학습 순서를 고정하지만 낮은 부담의 외측 체험도 막는다.
- 외측 레인에서도 짧은 체험을 허용하고 실제 부담을 확인한다. 제작·플레이테스트에서 키 활용과 앞뒤 흐름을 함께 살펴야 한다.

## 채택안과 trade-off

입문 차트의 트릴·더블은 내측 레인에 한정하지 않는다. 외측 1·4번 레인에서도 충분히 느리고 단순한 짧은 체험을 허용한다. 독해 부담, 입력 속도·밀도·지속 길이·다른 입력과의 조합, 앞뒤 손배치 흐름이 해당 차트 수준에 맞는지 확인한다.

내측과 외측을 모두 사용하거나 모든 타입을 각 차트에 넣어야 하는 것은 아니다. 기본 프리셋의 손가락 활용 순서는 조정 가능한 예시로 설명한다. 중급의 외측 키 교대 본격 활용과 입문의 짧은 체험은 구별한다.

고정된 레인 구분 대신 실제 부담을 확인해야 한다. 트릴 교대·더블의 입력 조건, 기존 구조 검증과 PLv. 수치는 유지한다. 수평 이동 등 다른 피스의 별도 제약을 없애는 결정은 아니다.

## 영향과 검증

- glossary를 먼저 갱신하고 루트 `CONTEXT.md`, 설계 개요, 난이도 설계, 키 바인딩, 노트 시스템을 동기화한다.
- 저장·문서 검증 코드에서 차트 Lv.에 따른 내측·외측 제한은 발견되지 않았다. 이번 변경은 제작 지침에 한정하며 런타임 동작을 바꾸지 않는다.
- 내측 전용·중급 첫 등장으로 읽히는 현행 문구를 확인하고 관련 링크를 검증한다.
