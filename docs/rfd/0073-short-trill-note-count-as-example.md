# RFD 0073: 짧은 트릴의 노트 수는 예시

**Status:** Accepted (2026-10-28) · 용어·피스·PRD 반영 (2026-10-28)

## 기존 결정과 문제의식

짧은 트릴(`PP-001`)을 피스 명세는 트릴 노트 4개, PRD는 2～4개로 설명했다. 사용자는 개수를 정의의 제한으로 통일하는 대신 예시로 두기로 했다.

## 검토한 대안과 채택안

4개 또는 2～4개를 필수 조건으로 삼는 안 대신, 짧은 구간에서 트릴 키 교대를 익히는 배치로 설명한다. 2～4개는 대표 예시이며, 이 범위를 벗어난다는 이유만으로 피스에서 제외하지 않는다.

짧은 체험에 적절한지는 실제 입력 속도·지속 길이·다른 입력과의 조합을 함께 확인한다. 노트 수가 적다고 자동으로 쉬운 배치가 되는 것은 아니다. 구체적인 노트 수 경계는 새로 정하지 않으며 PLv.1과 트릴 입력·판정 규칙은 유지한다.

## 영향과 검증

glossary에 현재 정의를 두고 피스 명세와 PRD의 고정 개수 표현을 맞춘다. 기존 4개 표기 예시는 유지한다. 노트 수를 성립 조건으로 쓰는 문구가 남지 않는지 확인하며 코드 동작은 변경하지 않는다.
