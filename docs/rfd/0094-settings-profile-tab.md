## 기존 결정과 문제의식

[RFD 0085](0085-chart-records-and-detailed-history-visibility.md)는 기본 닉네임 자동 생성과 이후 변경을 허용했지만 변경 화면은 정하지 않았다. 사용자는 게임 설정에 프로필 탭을 추가하는 방식을 선택했다.

## 검토한 대안과 채택안

게임 설정 화면에 **프로필** 탭을 추가하고, 해당 탭에서 닉네임을 변경할 수 있게 한다(사용자 확인, 2026-10-30). 별도의 독립 화면으로 분리하는 방식 대신 기존 설정 안에 변경 경로를 둔다.

닉네임의 길이는 1～16자이며, 빈 이름이나 16자를 초과하는 이름은 저장할 수 없다. 닉네임은 앞뒤를 포함해 공백을 허용하지 않는다. 특수문자와 이모지는 허용하지 않으며, 포함되어 있으면 저장을 거부하고 오류를 표시한다. 공백이 있으면 자동으로 제거하지 않고 저장을 거부하며 **닉네임에는 공백을 사용할 수 없습니다.**라고 안내한다. 입력값은 유지하여 사용자가 직접 수정할 수 있게 한다. 프로필 탭에서 닉네임을 입력한 뒤 저장 버튼을 눌러 변경을 적용한다. 입력 중인 값은 저장 버튼을 누르기 전까지 실제 닉네임에 반영하지 않는다(사용자 확인, 2026-10-30).

닉네임은 랭킹에 표시되는 계정 정보이므로 서버 저장 성공 후 실제 이름의 변경을 확정한다. 저장에 실패한 새 이름을 변경 완료로 표시하지 않기 위한 정책이다. 로컬에 먼저 적용한 뒤 서버에 동기화하는 게임 설정과 적용 시점을 구별한다([RFD 0102](0102-device-local-input-and-visual-offsets.md), 사용자 확인, 2026-10-30).

닉네임 저장에 실패하면 입력한 이름을 유지하고 오류를 표시한다. 기존 닉네임은 유지하며 같은 저장 버튼으로 다시 시도할 수 있다. 새 닉네임은 저장이 성공했을 때 적용한다. 저장에 성공하면 설정과 프로필 탭을 유지하고 저장 완료 안내를 표시한다. 설정을 닫으면 저장하지 않은 닉네임 입력 초안을 버리고, 다시 열 때 현재 닉네임을 표시한다.

이 탭에서는 닉네임 변경과 로그인·로그아웃을 제공한다. 첫 로그인 시 Guest 뒤에 6자리 숫자 난수를 붙여 자동 생성하는 정책과 중복 허용, 이름 변경 후 기존 기록·순위 보존, 기존 랭킹에 현재 이름을 표시하는 정책은 [닉네임 정의](../context/glossary.md#닉네임)를 따른다.

비로그인 상태에서도 설정의 프로필 탭을 표시하며, 탭 안에 로그인 버튼을 제공한다. 프로필 탭에서 로그인에 성공하면 설정과 프로필 탭을 유지하고, 현재 닉네임을 편집할 수 있는 화면으로 전환한다. 로그인에 실패하면 프로필 탭을 유지한 채 탭 안에 오류를 표시하며, 같은 로그인 버튼으로 다시 시도할 수 있다. 사용자가 로그인을 취소한 경우에는 오류를 표시하지 않고 비로그인 상태의 프로필 탭으로 돌아온다. 로그인 상태에서는 같은 탭에 로그아웃 버튼을 제공한다. 프로필 탭의 로그아웃 버튼을 누르면 별도의 확인창 없이 로그아웃을 실행한다. 로그아웃이 완료되면 설정을 닫고 타이틀 화면으로 이동한다. 로그아웃 후 게임 설정의 유지는 [RFD 0102](0102-device-local-input-and-visual-offsets.md)을 따른다. 로그인 버튼으로 기존 로그인 흐름에 진입한다(사용자 확인, 2026-10-30). 닉네임 입력 제약 등 남은 세부는 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

## 영향과 검증

상세 입력·저장·로그인 흐름은 [게임 코어 스펙](../spec/game-core.md#설정의-프로필-탭-미구현)에 모으고, PRD·에셋 문서에는 요약과 링크를 둔다.
