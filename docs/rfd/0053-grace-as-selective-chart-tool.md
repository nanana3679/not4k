# RFD 0053: Grace의 선택적 활용과 연출 목적

**Status:** Accepted (2026-10-28) · 용어·설계 개요·노트·차트 제작 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

기존 문서는 복잡한 손배치와 정밀한 타이밍을 함께 요구하면 난이도가 불합리하게 높아진다고 설명했고, 차트 제작 지침은 교대 구간에 Grace를 배치하도록 서술했다. 이는 Grace의 활용 범위를 손배치 전환에 한정하거나 적용을 의무로 해석하게 할 수 있다.

사용자는 두 부담을 함께 요구하는 패턴도 해당 레벨에 맞으면 허용하고, Grace를 학습·부담 조절에 선택적으로 사용하는 방향을 승인했다. 연출 목적으로도 사용할 수 있으며, 손배치가 단순해도 해당 난이도에 비해 리듬이 복잡하거나 입력 속도가 빠르면 사용할 수 있다고 덧붙였다.

## 검토한 대안

- 복잡한 손배치·교대 구간에 Grace를 의무 적용한다. 해당 구간에서 정밀한 타이밍까지 요구하는 패턴을 제한하고 다른 활용 목적을 충분히 설명하지 못한다.
- 학습·부담 조절·연출을 위해 선택적으로 적용한다. 차트의 목표 난이도와 구간의 의도를 함께 검토해야 한다.

## 채택안과 trade-off

Grace는 학습, 특정 구간의 부담 조절, 연출을 위해 제작자가 선택하는 도구다. 복잡한 손배치와 정밀한 타이밍을 함께 요구하는 패턴도 해당 레벨에 맞으면 허용하며, 손배치 전환이나 교대라는 이유만으로 Grace를 의무 적용하지 않는다.

손배치가 단순해도 해당 난이도에 비해 리듬이 복잡하거나 입력 속도가 빠르면 Grace를 사용할 수 있다. 곡의 강조점이나 구간의 연주 흐름을 드러내는 연출 목적의 사용도 허용한다. 항상 어려운 구간에만 배치해야 하는 것은 아니다.

Good 창 안의 실제 입력, 트릴 교대, 바디 유지 조건 등 기존 판정 규칙은 유지한다. Grace 릴리즈도 실제 뗌을 요구한다. 노트의 종류·속성·시각 효과를 새로 추가하는 결정은 아니다.

제작자는 Grace 유무에 따른 타이밍 정밀도 부담과 실제 입력 수행의 부담을 구별하고 차트 수준에 맞는지 확인해야 한다. 의도하지 않은 탭·교대 up과 릴리즈의 간섭을 피하는 기존 제작 지침은 유지한다. 구형 `holdOnly`를 새 바디에 붙이거나 모든 교대 up을 면제하는 의미로 해석하지 않는다.

## 영향과 검증

- glossary를 먼저 갱신하고 루트 `CONTEXT.md`, 설계 개요, 노트 시스템, 차트 제작 지침을 동기화한다.
- 기존 RFD의 교대·판정 사례는 당시 결정 기록으로 보존한다. 판정 수치·엔진·에디터 동작·스킨은 변경하지 않는다.
- 복합 부담을 일률적으로 불합리하다고 단정하거나 Grace를 의무 적용하는 현행 설명이 남지 않는지, 리듬·속도·연출의 활용과 기존 입력 조건, 관련 링크를 확인한다.
