# RFD 0078: 같은 보조 레인의 이벤트 겹침을 배치 위반으로 처리

**Status:** Accepted (2026-10-29) · 공용 검증·해칭·저장/플레이 차단 연결 구현, 전체 단위 5,623개·타입 검사·Lab 빌드 통과 (2026-10-29) · 이벤트 E2E 7개(기존 편집 6개·겹침 수리 1개) 검증 완료 (2026-10-29) · 결정 문서는 [PR #379](https://github.com/nanana3679/not4k/pull/379)로 먼저 main에 반영, 위 구현·검증은 [PR #369](https://github.com/nanana3679/not4k/pull/369)의 작업 (2026-10-31) · 초기 설정 로드 자동 분리를 RFD 0082의 후속 예외로 채택·문서 반영 (2026-10-31), 해당 자동 분리 런타임은 후속 구현

## 기존 결정과 문제의식

기존 편집 스펙은 서로 다른 종류의 이벤트가 같은 위치에 겹치는 것을 허용한다. [RFD 0068](0068-common-event-editing.md)의 이벤트 공통 편집을 검토하며 사용자는 이벤트끼리 겹치면 배치 위반으로 처리하기를 요청했고, 같은 보조 레인에 한정하는 범위를 승인했다. 겹친 이벤트 중 뒤쪽 항목만 몸통 클릭으로 잡히는 문제를 배치 진단으로 드러낸다.

## 검토한 대안

- 종류가 다른 이벤트의 겹침을 계속 허용한다. 같은 보조 레인에서 편집 대상이 가려진다.
- 레인과 관계없이 동시 이벤트를 금지한다. 초기 BPM과 박자 설정이나 서로 독립적인 동시 이벤트도 배치할 수 없다.
- 같은 보조 레인의 겹침을 종류와 관계없이 위반으로 처리한다. 동시 이벤트는 보조 레인을 나누어 배치한다.

## 채택안과 trade-off

- 모든 `ChartEvent`의 배치 겹침을 `(editorLane ?? 1)` 기준으로 검사한다. 서로 다른 종류, 시점·구간의 조합, 튜토리얼 이벤트도 포함한다.
- 시점 이벤트와 길이 0 구간은 점으로 본다. 양수 길이 구간은 시작을 포함하고 끝을 제외한다. 같은 점, 점과 구간 시작·내부, 구간끼리의 실제 교집합은 위반이며 끝과 다음 시작이 맞닿는 배치는 허용한다. 화면 두께나 클릭 허용 오차는 배치 판정에 사용하지 않는다.
- 보조 레인이 다르면 이 배치 위반은 없다. 같은 박의 같은 종류 BPM·박자 중복, 같은 종류 `text`·`auto`·`stop`의 시간 겹침, 같은 입력을 요구하는 튜토리얼의 겹침은 기존 의미 제약을 유지한다. 레인을 나누어 의미 모순을 우회할 수 없다.
- 기존 `eventOverlap` 진단과 원본 이벤트 인덱스 refs를 사용해 양쪽 항목을 빨간 해칭으로 표시한다. 기존 중복·튜토리얼 입력 진단이 같은 쌍을 설명하면 진단을 중복 추가하지 않는다.
- 낙관적 편집은 유지한다. 생성·이동·리사이즈·붙여넣기로 겹친 상태를 확정·선택 해제할 수 있고, 저장·플레이는 위반이 남으면 차단한다. 기존 파일의 일반 이벤트는 자동으로 레인을 옮기지 않고 열어 수리한다. 겹친 0박 초기 BPM·박자 설정만 [RFD 0082](0082-initial-timing-events-not-selectable.md)에 따라 불러올 때 빈 보조 레인으로 분리한다. 이 정리는 불러온 기본 상태로 취급하고 Undo·Redo·별도 미저장 표시에서 제외하며, 저장 전 서버·원본 파일은 바꾸지 않는다.

## 영향과 검증

- glossary와 편집·공유 컨텍스트, 편집 스펙에 배치 겹침과 기존 의미 겹침의 차이를 반영한다.
- 공용 이벤트 검증을 확장해 구형·명시·혼합 문서가 같은 규칙과 refs를 사용한다.
- 점·구간·동일 구간·분수·기본 레인·경계·다른 레인·튜토리얼의 단위 테스트와 편집·해칭·저장 차단·수리 E2E로 검증한다.
- 내장 튜토리얼·Lab 샘플과 정상 배치를 전제로 한 테스트의 초기 박자 설정은 보조 레인2로 분리한다. 겹치던 튜토리얼 입력도 보조 레인만 조정하며 입력 시각·키·노트는 유지한다. 사용자 파일 로드의 일반 이벤트 자동 보정은 추가하지 않는다. 초기 BPM·박자 설정의 보조 레인 분리만 RFD 0082의 후속 예외로 적용하며, 박 위치·값과 다른 의미 위반은 유지한다.
