# RFD 0044: 기본 키 배치를 추천 출발점으로 정의

**Status:** Accepted (2026-10-28) · 용어·키 바인딩 문서·PRD 반영 (2026-10-28)

## 기존 결정과 문제의식

키 바인딩 문서는 엄검중약을 인체공학적으로 자연스러운 전제로 설명하고, 자세 교정이나 재학습이 필요 없으며 특정 손가락 조합의 속도 상한이 높다고 단정했다. 프리셋의 의도와 플레이어마다 달라지는 적응·수행을 구별하지 못했다.

사용자는 기본 배치를 손배치 학습의 추천 출발점으로 두고, 손 크기·키보드·선호에 맞춰 조정해서 쓰는 방향을 승인했다.

## 검토한 대안

- 기본 배치를 보편적으로 적합한 기준으로 설명한다. 안내는 단순하지만 실제 사용자의 조정과 학습을 설명하기 어렵다.
- 기본 배치를 입력 구조를 익히는 추천안으로 설명한다. 시작할 예시는 제공하면서 실제 편의와 적응은 플레이어가 확인한다.

## 채택안과 trade-off

엄검중약은 약지·중지·검지·엄지를 활용하는 기본 프리셋의 추천 배치다. 기본 예시에서 소지에 주 역할을 배정하지 않는다는 뜻이며, 플레이어의 손가락 사용을 강제하는 규칙으로 설명하지 않는다. 손 크기·키보드·선호에 따라 바인딩과 운용을 조정한다.

TKL·Numpad의 키 대응은 프리셋의 설계 의도로 설명한다. 서로 같은 자세나 무학습 전환, 낮은 부담·높은 속도를 보장하지 않는다. 튜토리얼도 사용할 조합을 시험하는 예시로 안내한다. 하나의 정답 자세를 제시하는 단순함 대신, 추천안과 조정 가능성을 함께 설명해야 한다.

## 영향과 검증

- glossary·루트 `CONTEXT.md`·`docs/spec/keybinding.md`·PRD의 정의와 근거 표현을 맞춘다.
- 기본 TKL 선택과 16키 프리셋의 실제 키 목록, 레인당 2키 이상·하나의 물리 키는 하나의 레인에만 바인딩하는 규칙은 유지한다.
- 코드·판정·설정 동작은 변경하지 않는다. 프리셋 표와 계약 보존, 문서 링크를 확인한다.
