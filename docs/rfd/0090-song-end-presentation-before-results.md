# RFD 0090: 곡 종료 시 성공·실패 연출 후 결과 화면으로 이동한다

**Status:** Accepted (2026-10-30) · glossary·게임 컨텍스트·게임 코어·PRD·에셋 문서 반영 (2026-10-30) · 곡 도중 실패 확정 시 즉시 종료·실패 연출 후 결과 이동 문서 반영 (2026-10-30) · 종료 연출 3초 이내·건너뛰기 없음·완료 후 자동 이동 문서 반영 (2026-10-30) · 실패 종료 시 확정된 판정만 통계 집계 문서 반영 (2026-10-30) · 풀콤보에 완주 조건 필수 문서 반영 (2026-10-30) · 풀콤보·올퍼펙트 전용 연출로 일반 클리어 연출 대체 문서 반영 (2026-10-30) · 달성 표시 명칭의 추후 결정 문서 반영 (2026-10-30) · 올퍼펙트의 완주·모든 점수 노트 Perfect·Miss 0 조건 문서 반영 (2026-10-30) · 중복 달성 시 올퍼펙트 연출만 표시 문서 반영 (2026-10-30), 종료 연출·곡 도중 실패 처리 미구현

## 기존 결정과 문제의식

게임 상태 흐름은 플레이에서 결과 화면으로 이동하는 경로를 설명했지만, 그 사이 성공·실패를 어떻게 보여줄지는 정하지 않았다. 사용자는 곡 종료 시 성공·실패 연출을 보여준 뒤 이동하는 방식을 선택했다.

## 검토한 대안과 채택안

곡이 종료되면 해당 플레이의 클리어 성공·실패에 맞는 연출을 보여준 뒤 결과 화면으로 이동한다(사용자 확인, 2026-10-30). 종료 연출은 클리어 여부를 표현하며, 점수에 따른 랭크와 구별한다.

성공·실패 연출은 모두 3초 이내로 짧게 표시하며 건너뛰기 조작을 제공하지 않는다. 연출이 끝나면 자동으로 결과 화면으로 이동한다. 연출을 건너뛸 수 있게 하는 방식 대신 3초 이내로 짧게 구성한다(사용자 확인, 2026-10-30). 구체적인 시각·음향 표현은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

풀콤보·올퍼펙트를 달성하면 일반 클리어 연출 대신 해당 달성의 전용 종료 연출을 보여준다. 풀콤보와 올퍼펙트 조건을 모두 충족하면 올퍼펙트 종료 연출만 보여준다(사용자 확인, 2026-10-30). 전용 연출도 3초 이내로 표시하며 건너뛰기 없이 완료 후 결과 화면으로 이동한다. 달성 표시 명칭은 추후 결정하며, 그동안 문서에서는 풀콤보·올퍼펙트로 지칭한다. 제안된 노 미스·CLEAN FLIGHT·PERFECT FLIGHT 명칭은 채택하지 않았다(사용자 확인, 2026-10-30). 공식 표시 명칭은 [PRD §12](../prd.md#12-미정-사항)에서관리한다. 무점수 차트의일반 플레이는 [RFD 0091](0091-normal-play-requires-score-note.md)로 제외하므로 공식 달성 예외는 두지 않는다.

곡 도중 `flightRule`의 실패가 확정되면 즉시 곡 재생과 입력 판정을 종료하고, 실패 연출을 보여준 뒤 결과 화면으로 이동한다. 실패가 확정된 뒤에도 곡 끝까지 연주하는 방식은 채택하지 않는다(사용자 확인, 2026-10-30). 이 규칙은 실패 확정 후의 종료 시점을 정하며, 낮은 시각 고도 자체를 모든 단계의 실패 조건으로 두지 않는다. 단계별 실패 조건·결과 정산의 남은 세부는 [PRD §12](../prd.md#12-미정-사항)를 따른다.

곡 도중 실패로 종료되면 판정 통계는 종료 시점까지 실제로 확정된 판정만 집계한다. 미처리 노트를 종료 때문에 새 Miss로 채우지 않는다. 최종 달성률의 분모는 기존대로 차트 전체 점수 항목의 이론 가중치 합을 사용한다. 종료 후 남은 노트를 Miss로 일괄 정산하는 방식 대신 종료 시점의 실제 판정 통계를 보존한다(사용자 확인, 2026-10-30).

풀콤보는 곡을 끝까지 연주하고, 무점수 유지 실패를 포함해 Miss가 한 번도 없는 경우에만 인정한다. 곡 도중 실패로 종료된 플레이는 종료 시점까지 Miss가 없더라도 풀콤보로 인정하지 않는다. 판정 통계를 실제 확정분만 보존하는 것과 풀콤보 인정 조건을 구별한다(사용자 확인, 2026-10-30).

올퍼펙트는 곡을 끝까지 연주하고 모든 점수 노트를 Perfect로 처리하며, 무점수 바디 실패를 포함한 Miss가 한 번도 없는 경우에만 인정한다. 점수 노트를 모두 Perfect로 처리했어도 바디에서 Miss가 발생하면 인정하지 않는다(사용자 확인, 2026-10-30).

Quit·Retry와 옵저버 종료의 기존 결과 화면 생략 규칙은 유지한다. 클리어에 실패한 플레이의 기록·랭킹 반영은 [RFD 0085](0085-chart-records-and-detailed-history-visibility.md)를 따른다.
