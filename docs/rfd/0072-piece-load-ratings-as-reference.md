# RFD 0072: 피스별 부하 등급은 대표 배치의 참고값

**Status:** Accepted (2026-10-28) · 용어·루트 컨텍스트·피스 평가 기준 반영 (2026-10-28)

## 기존 결정과 문제의식

피스 메타데이터는 `cognitive_load`와 `physical_load`를 등급으로 기록한다. 설명에서는 실제 배치에 따라 평가한다고 했지만, 카탈로그의 등급은 피스 자체의 고정값으로 읽힐 수 있었다. 사용자는 이 등급을 참고값으로 두기로 했다.

## 검토한 대안과 채택안

피스 종류마다 고정 등급을 부여하는 안 대신, 카탈로그의 대표 배치를 설명하는 참고 등급으로 둔다. 같은 피스라도 입력 속도·밀도·지속 길이·키 바인딩·앞뒤 손배치·다른 입력과의 조합이 달라지면 실제 부하를 다시 평가한다.

기존 카탈로그의 등급은 유지하며 참고값이라는 적용 범위를 명시한다. 등급만으로 개별 구간의 부담이나 차트 Lv.를 확정하지 않는다. 간단한 표만으로 평가를 끝낼 수 없으며 실제 배치와 수행 조건을 함께 확인해야 한다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 `CONTEXT.md`와 피스 명세의 평가 기준을 맞춘다. 물리 부하 표에서도 비트 분할 하나로 등급을 확정하는 표현을 실제 입력 부담에 따른 예시로 고친다. 카탈로그 값과 PLv., 런타임 코드는 변경하지 않는다.
