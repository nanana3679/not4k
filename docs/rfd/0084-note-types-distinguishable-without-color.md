# RFD 0084: 노트 종류는 색 없이도 형태·표식으로 구분한다

**Status:** Accepted (2026-10-29) · 용어·루트 컨텍스트·노트 시스템·에셋·PRD 문서 반영 (2026-10-29) · 유지 중·실패 같은 상태의 색 이외 구분은 개선 목표로 유보 (2026-10-29)

## 기존 결정과 문제의식

PRD의 색각 이상 대응 정책은 미정이었으며 별도 표시 모드를 검토하는 방향으로 남아 있었다. 에셋 목록에는 싱글·더블의 강조 방식으로 색상을 사용하는 안도 포함되어 있었다. 기본 노트 디자인이 색에만 의존해도 되는지 분명하지 않았다.

## 검토한 대안과 채택안

기본 표현에서는 색에 의존하고 별도 옵션에서 형태·표식을 보완하는 안 대신, 색을 구별하지 않아도 노트 종류를 모양·표식으로 알아볼 수 있는 것을 기본 디자인 원칙으로 삼는다. 색상은 구분을 보조할 수 있으나 유일한 단서로 사용하지 않는다.

구체적인 외곽 모양이나 내부 표식을 이번 결정으로 확정하지 않는다. 기존 디자인의 입력 요구를 단순하고 명확하게 읽을 수 있어야 하며, 표식을 더하는 과정에서도 [독해 부담을 낮추는 원칙](0101-cognitive-load-and-action-planning.md)을 유지한다. 노트 종류 구분에 관한 결정이며 실제 에셋이 이미 이 기준을 충족한다고 선언하지 않는다.

롱노트의 유지 중·실패 같은 상태도 색 이외의 단서로 구분할 수 있으면 좋지만, 이를 모든 상태의 필수 조건으로 확정하지 않는다. 실제 화면에서 검토할 개선 목표로 둔다. 기존의 밝기·투명도·코어 점등을 우선 살펴보고, 상태마다 표식을 추가해 독해 부담이 늘어나는지도 함께 확인한다. 구체적인 상태 표현을 이번 결정으로 바꾸거나 추가 표식을 의무화하지 않는다(사용자 확인, 2026-10-29).

기본 에셋에서 종류 구분을 검토해야 하는 제작 부담이 생기지만, 구분 방법을 별도 옵션에만 맡기지 않을 수 있다. 구체적 표현과 검증, 추가 표시 옵션의 필요성은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 컨텍스트, 노트 시스템·에셋 스펙과 PRD를 동기화한다. 과거 에셋·판정 모델의 기록과 새 원칙을 구별하며 런타임 코드나 이미지 자산은 변경하지 않는다. 실제 에셋의 검증에서는 색 구분에 의존하지 않은 종류 식별과 플레이 중 가독성·독해 부담을 확인한다.
