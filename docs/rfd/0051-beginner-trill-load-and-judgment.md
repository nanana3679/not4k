# RFD 0051: 초급 트릴의 부담은 판정 완화 대신 배치로 조절

**Status:** Accepted (2026-10-28) · 용어·스코어링·난이도·노트 설계 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

스코어링 문서는 초급 트릴의 판정이 관대해야 한다고 설명했다. 레벨에 따라 트릴의 판정 윈도우를 별도로 완화한다는 의미로 읽힐 수 있으나, 현재 런타임은 설정한 Normal/Easy 판정 윈도우를 사용한다.

사용자는 레벨별 판정 완화 대신 같은 판정 설정 안에서 속도·밀도·길이·다른 입력과의 조합으로 초급 트릴의 부담을 조절하는 안을 승인했다. 기존 Normal/Easy 설정과 Grace는 유지한다.

## 검토한 대안

- 초급 레벨의 트릴 판정 윈도우를 자동으로 넓힌다. 같은 노트의 타이밍 기준이 차트 레벨에 따라 달라진다.
- 판정 설정은 유지하고 배치의 부담을 낮춘다. 학습 배치의 적정 부담은 제작·플레이테스트에서 확인해야 한다.

## 채택안과 trade-off

초급 트릴은 같은 판정 설정 안에서 속도·밀도·지속 길이·다른 입력과의 조합을 조절해 키 교대를 익히도록 구성한다. 차트 레벨이 낮거나 초급 트릴이라는 이유로 판정 윈도우를 자동 완화하지 않는다.

Normal/Easy의 설정별 차이와 Grace에 의한 타이밍 정밀도 완화는 별도로 유지한다. Grace도 실제 입력과 키 교대 조건을 면제하지 않으며, 교대 실패의 기존 `goodTrill` 규칙은 바꾸지 않는다.

고정된 레벨별 완화 대신 실제 배치의 부담을 확인해야 한다. 트릴이 항상 쉽거나 반복적이라는 가정도 두지 않는다([RFD 0042](0042-trill-rules-and-pattern-repetition.md)).

## 영향과 검증

- glossary의 판정 윈도우 정의와 루트 `CONTEXT.md`, 스코어링·난이도·노트 설계 문서에 반영한다.
- `ExplicitPlayRuntime`은 설정한 `judgmentMode`의 윈도우를 세션에 전달한다. 이번 변경은 문서에 한정하며 판정 수치·엔진·기록 처리를 바꾸지 않는다.
- 초급 트릴의 자동 판정 완화로 읽히는 문구가 남지 않는지, Normal/Easy·Grace·교대 조건이 유지되는지, 문서 링크를 확인한다.
