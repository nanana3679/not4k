# RFD 0064: 옵저버의 기본 전곡 반복과 시도별 집계 초기화

**Status:** Accepted (2026-10-28) · 용어·옵저버·게임 코어·MVP·PRD 반영 (2026-10-28) · 옵저버 런타임 미구현

**집계·표시 후속 결정:** [RFD 0075](0075-observer-manual-only-statistics.md)는 Auto 중 콤보·달성률 숨김과 Auto 노트 집계 제외를 확정했다. 수동 집계는 반복 구간이 끝나면 초기화하며 Retry·구간 변경에도 초기화한다. Auto 전환만으로 같은 반복 안의 수동 집계를 초기화하지 않는다.

## 기존 결정과 문제의식

[RFD 0062](0062-observer-controls-loop-and-exit.md)는 구간을 지정하지 않은 전곡 재생이 끝나면 옵저버를 종료하도록 정했다. 콤보·달성률을 표시하기로 한 뒤에도 반복과 Retry에서 집계를 초기화할지는 정하지 않았다.

사용자는 반복이 다시 시작되거나 Retry할 때 콤보·달성률을 초기화하는 데 동의했다. 구간을 따로 지정하지 않아도 곡 처음부터 끝까지를 구간으로 잡고 직접 나갈 때까지 반복하는 방향으로 종료 규칙도 수정했다.

## 검토한 대안

- 구간 미지정 시 곡 종료와 함께 나간다. 부분 구간과 전곡의 반복 흐름이 달라진다.
- 전곡을 기본 구간으로 두고 명시적으로 나갈 때까지 반복한다. 반복의 종료 시점은 플레이어가 선택한다.
- 집계를 반복 간 누적한다. 이전 반복의 콤보·달성률과 현재 시도의 결과가 섞인다.
- 반복과 Retry마다 초기화한다. 각 시도의 결과를 독립적으로 확인할 수 있다.

## 채택안과 trade-off

옵저버의 기본 구간은 곡 처음부터 끝까지다. 미니맵에서 구간을 바꾸면 해당 구간을 반복하고, 따로 바꾸지 않으면 전곡을 반복한다. 곡이나 구간이 끝나도 자동으로 모드를 종료하지 않으며, 플레이어가 나갈 때까지 반복한다.

반복이 다시 시작되거나 Retry하면 콤보·달성률을 초기화하고 새 시도로 집계한다. 이전 반복의 집계를 누적하지 않는다. 미니맵에서 구간을 바꿔 새 구간의 앞 페이드 구간부터 다시 재생할 때도 새 구간의 시도로 초기화한다. 구간 시작을 기준으로 다시 진입하는 Retry와 앞뒤 페이드·노트 범위 규칙은 유지한다. 페이드의 각 최대 3초는 [RFD 0062](0062-observer-controls-loop-and-exit.md)의 후속 확인에 따라 배속과 무관한 실제 시간 기준이다.

명시적으로 종료하면 곡 선택으로 복귀하며 리절트는 표시하지 않는다. 기존 공식 Play 기록과의 경계도 유지한다. Auto 기본 켜짐과 사용자가 고른 구간을 초기화하는 결정은 아니다. Auto를 켜거나 끄는 조작은 재생 위치와 기존 콤보·달성률을 유지한다([RFD 0062](0062-observer-controls-loop-and-exit.md)의 후속 확인).

판정 집계 범위의 세부, Auto 전환과 키·바디 상태 등은 [PRD §12](../prd.md#12-미정-사항)에서 계속 추적한다. 런타임은 미구현이다.

## 영향과 검증

- glossary와 루트·Gameplay `CONTEXT.md`, 옵저버·게임 코어·MVP·PRD의 종료·기본 구간·집계 설명을 맞춘다.
- RFD 0061·0062에 후속 결정을 연결하고 당시 종료 정책을 현행 규칙으로 복원하지 않도록 표시한다.
- 곡 종료 시 자동으로 모드에서 나간다는 현행 문구와 집계 초기화의 미정 상태가 남지 않는지 확인한다. 런타임은 변경하지 않는다.
