# RFD 0050: 헤드 없는 바디 패턴은 실제 부담으로 배치 판단

**Status:** Accepted (2026-10-28) · 제작 지침·튜토리얼·저장 명세의 난이도명 제한 폐지 (2026-10-28)

## 기존 결정과 문제의식

기존 문서는 헤드 없이 시작하는 바디와 싱글→더블 전환(`.-`, `-=`, `o-=`)을 `HARD` 전용으로 제한했다. 새 난이도명으로 제한을 옮길지는 미정이었다.

사용자는 난이도명으로 제한하기보다 실제 독해·연주 부담이 낮게 구성됐다면 낮은 레벨에서도 짧게 경험할 수 있도록 정리하는 안을 승인했다. 이는 PLv.를 본격 활용의 기준으로 삼는 [RFD 0046](0046-piece-levels-and-early-exposure.md)의 방향을 해당 패턴에도 적용하는 결정이다.

## 검토한 대안

- 기존 `HARD` 전용 제한을 유지하거나 `Breakthrough`로 옮긴다. 실제 배치의 부담과 별개로 낮은 난이도명의 체험 배치를 제한한다.
- 난이도명 제한을 없애고 실제 독해·연주 부담으로 판단한다. 낮은 레벨의 짧은 체험을 허용하되 플레이테스트가 필요하다.

## 채택안과 trade-off

헤드 없이 시작하는 바디 패턴은 기존·새 난이도명에 따른 사용 제한을 두지 않는다. 독해 부담, 속도·밀도·지속 길이·다른 입력과의 조합을 살펴 차트 수준에 맞게 배치한다. 충분히 느리고 단순한 짧은 체험은 낮은 레벨에서도 허용한다.

Save As에서 해당 패턴과 대상 난이도명의 조합만을 이유로 경고하거나 수정을 요구하지 않는다. 차트 구조·판정에 필요한 기존 배치 검증은 유지한다. 고정된 라벨로 판단하는 단순함 대신 제작자가 실제 부담을 확인해야 한다.

이 결정은 바디의 시작·유지·실패 규칙과 PLv. 수치를 바꾸지 않는다. 경계 뒤 여분 키를 떼야 하는 별도의 구분을 요구하는 배치에 관한 [RFD 0032 §9-4](0032-body-held-count.md#9-4-여분-키-구분의-튜토리얼-전달)의 주의사항도 일반적인 헤드 없는 바디 체험과 구별해 유지한다. 튜토리얼 목록과 새 예제 이행은 기존 [PRD §12](../prd.md#12-미정-사항)의 후속 범위를 따른다.

## 영향과 검증

- glossary와 루트 `CONTEXT.md`, 난이도 설계, 피스 정의·표기법, 튜토리얼, 에디터·Save As 명세, PRD를 동기화한다.
- 저장·검증 코드에서 해당 난이도명 전용 경고는 발견되지 않았다. 런타임 동작 변경 없이 문서상의 경고 요구를 제거한다.
- 현행 문서의 전용 제한과 모순되는 안내, 링크를 확인한다. 과거 RFD의 논의 기록과 보관된 시연은 수정하지 않는다.
