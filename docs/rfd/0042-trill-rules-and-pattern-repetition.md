# RFD 0042: 트릴 입력 조건과 패턴의 반복성 구분

**Status:** Accepted (2026-10-28) · 용어·차트 설계·피스 평가 설명 반영 (2026-10-28) · 빠른 트릴에서 양손 고부담 배치 허용 후속 확인·문서 반영 (2026-10-28)

## 기존 결정과 문제의식

차트 설계 문서는 트릴을 한 손이 거의 자동으로 처리하는 낮은 부담의 반복 입력으로 설명하고, "트릴 노트는 쉬운 손을 보장해야 한다"고 규정했다. 앵커도 트릴만으로 구현하는 것처럼 서술했다.

사용자는 트릴도 어려울 수 있고 반복 패턴이 아닐 수도 있다고 명확히 했다. 한 손의 반복 패턴과 다른 손의 복합 패턴을 조합하는 구조 역시 트릴에 한정된 설명이 아니다.

## 검토한 대안

- 트릴을 쉬운 반복 입력으로 제한한다. 교대 조건과 배치의 성질을 혼동하고 복잡한 트릴 배치의 설계 의도를 설명하지 못한다.
- 입력 조건, 패턴의 반복성, 난이도를 구분한다. 트릴은 다양한 배치에 사용할 수 있고 실제 부담은 배치별로 평가한다.

## 채택안과 trade-off

트릴 노트는 직전과 다른 키를 요구하는 입력 조건이다. 일정한 리듬이나 동작의 반복 여부, 단순함, 낮은 난이도를 보장하지 않는다. 한 손의 반복과 다른 손의 복합 처리는 일반적인 패턴 조합으로 설명하고, 트릴을 일정하게 반복 배치한 앵커는 그 한 가지 예시로 둔다.

기존 "쉬운 손 보장" 규칙은 폐기한다. 양손의 역할, 리듬 변화, 속도, 지속 길이, 요구되는 키 교대와 손배치 전환을 함께 평가한다. 예측 가능한 반복을 의도했다면 해당 배치가 그 역할을 하는지 확인하되, 트릴 노트라는 이유로 자동 처리나 낮은 부담을 가정하지 않는다. 타입만으로 판단하던 간단한 기준 대신 배치와 수행 조건을 검토해야 한다.

후속 확인에서 빠른 트릴 구간도 목표 난이도에 맞으면 양손 모두 어려운 배치를 허용하기로 했다. 반대 손의 단순화는 필수 규칙이 아니라 부담을 조절하는 설계 방법 중 하나다. 양손 밀도의 증감 관계만으로 전체 난이도를 확정하지 않고 실제 입력 조합과 흐름을 평가한다.

## 영향과 검증

- glossary와 루트 `CONTEXT.md`에서 트릴 조건과 반복성·난이도를 구별하고, 앵커의 트릴 설명을 예시로 명확히 한다.
- `docs/context/chart-design.md`의 앵커 설명·제작 원칙과 `docs/spec/piece-definition.md`의 평가 설명, PRD의 요약을 맞춘다.
- 판정과 배치 제약, 앵커의 기존 한 레인 반복 정의·PLv.는 변경하지 않는다. 문서의 단정과 상호 링크를 확인한다.
