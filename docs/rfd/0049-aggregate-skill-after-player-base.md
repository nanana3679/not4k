# RFD 0049: 종합 실력 지표는 플레이어 풀이 쌓인 뒤 검토

**Status:** Accepted (2026-10-28) · 검토 유보 결정, 도입 여부는 미정 · 기록 분포에 따른 실력 단계·달성 기준 설정과 종합 지표 도입 판단을 후속 검토 범위로 구분 (2026-10-31)

## 기존 결정과 문제의식

태도 문서는 볼포스형 종합 실력 지표를 불채택하고, PRD는 플레이 데이터 축적 후 검토하며, 게임 코어 스펙은 추후 도입한다고 서술해 결정 상태가 서로 달랐다. 사용자는 플레이어 풀이 쌓여야 검토할 수 있다고 정리했다.

## 검토한 대안

- 영구적으로 불채택한다. 향후 플레이어 구성을 보고 검토하려는 의도와 맞지 않는다.
- 추후 도입을 예정한다. 검토 전에 도입 필요성을 확정하게 된다.
- 플레이어 풀이 쌓인 뒤 도입 필요성부터 검토한다. 현재는 유보하고 실제 플레이어 구성을 바탕으로 판단한다.

## 채택안과 trade-off

여러 차트의 기록을 집계하는 종합 실력 지표는 **플레이어 풀이 쌓인 뒤 검토**한다. 현재 도입을 결정하거나 영구적으로 배제하지 않는다. 검토 조건을 단순한 플레이 데이터 누적량으로 대체하지 않는다.

후속 검토 범위는 두 가지로 구분한다. 하나는 쌓인 기록의 분포를 근거로 플레이어의 실력 단계·달성 기준을 정하는 작업이고, 다른 하나는 여러 차트의 기록을 집계하는 종합 실력 지표의 제공 필요성과 도입 여부를 판단하는 작업이다. 두 작업 모두 플레이어 풀이 쌓인 뒤 검토하며, 엄격한 선후 순서는 정하지 않는다(사용자 확인, 2026-10-31).

차트별 기록과 선택적 랭킹의 방향은 유지한다. 종합 실력 지표의 검토 유보는 XP·종합 티어·공개 배지의 채택을 뜻하지 않으며, 해당 표시 방식의 기존 제한은 유지한다.

현재 실력 단계·달성 기준의 정량 경계나 종합 지표의 산식·UI 명칭·표시 방식을 확정하지 않는다. 실력 단계·달성 기준 설정과 지표 도입 판단은 게임 이용·학습 양상의 성공 관찰 지표([RFD 0056](0056-success-metrics-after-playtesting.md))와 구별한다. 검토 시점과 구체적 기준·도입 여부 등 미정 사항은 [PRD §12](../prd.md#12-미정-사항)에서 단일 관리한다.

## 영향과 검증

- 태도 문서의 원칙 4·3.2·3.4, 스코어링·게임 코어 스펙, PRD의 결정 상태를 맞춘다.
- 플레이어 풀의 규모 기준이나 집계 산식·표시 UI를 확정하지 않는다. 런타임 변경은 없다.
- 불채택·도입 예정으로 단정한 현행 문구가 남지 않는지, 기존 계급 시스템 제한과 관련 링크를 확인한다.
