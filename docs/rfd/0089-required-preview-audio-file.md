# RFD 0089: 곡 프리뷰 전용 음원 파일을 필수로 제공한다

**Status:** Accepted (2026-10-29) · glossary·컨텍스트·게임 코어·에디터·에셋·PRD 문서 반영 (2026-10-29), 곡 프리뷰 재생·필수 여부 검증 미구현 · 로딩 용량을 위한 프리뷰 길이 상한 채택 (2026-10-29) · 최대 15초 상한 확정·문서 반영 (2026-10-29) · 같은 곡 선택 중 프리뷰 반복 재생 문서 반영 (2026-10-29) · 선택 유지 후 프리뷰 로드·재생 문서 반영 (2026-10-29) · 프리뷰 로드 전 1초 대기 확정·문서 반영 (2026-10-29) · 프리뷰의 브라우저 저장·다음 접속 재사용 문서 반영 (2026-10-29) · 최근 재생 순서에 따른 자동 정리 문서 반영 (2026-10-29) · 프리뷰 로딩 실패 시 곡 선택·플레이 진입 허용 문서 반영 (2026-10-29) · 곡 정보 영역의 작은 실패 안내 문서 반영 (2026-10-29) · 튜토리얼·곡 추가 창에서 프리뷰 중단·닫은 뒤 재개 문서 반영 (2026-10-29) · 프리뷰 최소 5초 확정·문서 반영 (2026-10-29) · 프리뷰 파일 앞뒤 0.5초 고정 페이드 유지 확인 (2026-10-29) · 프리뷰 자동 재생 끄기 설정 제외 문서 반영 (2026-10-29) · 일반 설정 창에서 프리뷰 재생 유지 문서 반영 (2026-10-29)

## 기존 결정과 문제의식

게임 코어는 곡 프리뷰에 본편과 별개의 음원 파일을 사용하도록 정했다. 전용 파일이 없을 때 본편의 지정 구간으로 대체할지, 전용 파일을 필수로 요구할지 명확히 할 필요가 있었다.

## 검토한 대안과 채택안

곡마다 본편과 별개의 프리뷰 전용 음원 파일을 필수로 제공한다. 본편 음원의 지정 구간을 대신 재생하는 방식은 사용하지 않는다(사용자 확인, 2026-10-29).

본편의 지정 구간으로 대체하는 대안보다 별도 파일을 준비하는 작업이 필요하지만, 제작자가 허용된 길이 안에서 프리뷰 구간을 고르고, 정해진 페이드를 적용한 파일을 제공할 수 있다. 곡 선택 화면에서 선택한 곡의 프리뷰를 자동 재생하는 기존 방향은 유지한다.

프리뷰는 로딩 용량을 제한하기 위해 음원 파일 한 개의 재생 길이를 **최대 15초**로 제한한다. 15초는 권장 예시가 아닌 필수 상한이다. 최소 길이는 5초로 두어 프리뷰 파일은 5초 이상 15초 이하로 제공한다(사용자 확인, 2026-10-29).

곡 선택 화면에서 같은 곡을 선택한 동안에는 프리뷰 음원이 끝나면 처음부터 반복 재생한다. 선택한 곡이 바뀌거나 곡 선택 화면을 나가면 해당 프리뷰의 재생을 중단한다. 반복 재생 정책은 파일 한 개의 최대 15초 제한과 함께 적용한다(사용자 확인, 2026-10-29).

같은 곡을 1초 동안 선택한 뒤 프리뷰를 불러와 재생한다. 대기 중 곡을 바꾸면 이전 곡의 프리뷰를 불러오지 않고, 새로 선택한 곡을 기준으로 다시 기다린다. 빠르게 곡을 넘길 때 매번 프리뷰를 로드하지 않도록 한다(사용자 확인, 2026-10-29).

한 번 불러온 프리뷰 음원은 브라우저에 저장해 다음 접속에도 재사용한다. 저장된 파일이 없으면 서버에서 불러오고, 프리뷰 파일이 바뀌면 저장본을 갱신한다. 저장된 프리뷰를 재사용할 때도 같은 곡을 1초 동안 선택한 뒤 재생한다. 접속이 끝나면 버리는 방식 대신 브라우저 저장본을 재사용한다(사용자 확인, 2026-10-29). 프리뷰 저장 용량이 차면 마지막으로 들은 지 가장 오래된 프리뷰부터 자동으로 삭제한다. 파일을 처음 저장한 순서보다 최근에 들은 순서를 기준으로 보관한다(사용자 확인, 2026-10-29). 저장 용량의 상한은 실제 프리뷰 파일 크기와 곡 수를 확인한 뒤 구현 단계에서 정하며, [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

프리뷰만 로딩에 실패하면 미리 듣기를 건너뛰고 곡 선택과 플레이 진입은 허용한다. 프리뷰 로딩 실패 안내는 팝업 없이 곡 정보 영역에 작게 표시한다. 본 플레이의 차트·음원 로딩과 검증은 기존 규칙을 따른다. 프리뷰 파일을 필수로 제공하는 콘텐츠 요건은 유지한다(사용자 확인, 2026-10-29).

튜토리얼 또는 곡 추가 창을 열면 곡 선택 화면의 프리뷰 재생과 재생 전 대기를 중단한다. 창을 닫으면 그때 선택된 곡을 기준으로 1초 기다린 뒤 프리뷰를 처음부터 다시 재생한다. 일반 설정 창을 열어도 곡 선택 프리뷰의 재생을 유지한다. 마스터 볼륨을 바꾸면 재생 중인 프리뷰에도 바로 적용한다. 튜토리얼의 메트로놈과 곡 추가 창의 구간 미리 듣기를 곡 선택 화면의 프리뷰와 겹쳐 재생하지 않도록 한다(사용자 확인, 2026-10-29).

곡 추가 창의 파형에서 구간을 지정해 별도의 프리뷰 파일을 생성하는 기존 저작 방식은 유지한다. 생성하는 파일에도 필수 제공·최대 15초 규칙을 적용하며, 곡 추가 상세 문서의 선택 사항·최대 30초 설명은 이 결정으로 대체한다.

프리뷰 파일을 생성할 때 시작 0.5초에 선형 페이드 인, 끝 0.5초에 선형 페이드 아웃을 고정 적용하며, 제작자가 페이드 길이를 조절하는 옵션은 두지 않는다. 기존의 고정 페이드 규칙을 유지한다(사용자 확인, 2026-10-29). `gameplayRange`의 별도 페이드 설정은 기존 규칙을 따른다.

곡 선택 프리뷰의 자동 재생을 끄는 별도 설정은 제공하지 않는다. 기존의 선택 유지 후 자동 재생 방침을 유지한다(사용자 확인, 2026-10-29).

## 영향과 검증

glossary를 먼저 갱신하고 루트·Gameplay·Online services 컨텍스트, 게임 코어·곡 프리뷰 구간 설정·곡 관리·튜토리얼·에디터·에셋·PRD를 동기화한다. 전용 음원 파일의 필수 제공, 본편 지정 구간으로 대체하지 않는 규칙과 파일당 최대 15초 상한, 같은 곡 선택 중 반복 재생과 선택 변경·화면 이탈 시 재생 중단과 선택 유지 후 로드하는 규칙이 일치하는지 확인한다.

이번 작업은 문서 반영이다. 프리뷰 재생·브라우저 저장·필수 여부 검증은 미구현이며 런타임·차트 모델·테스트 코드는 변경하지 않는다.
