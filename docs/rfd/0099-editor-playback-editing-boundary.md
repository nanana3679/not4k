# RFD 0099: 에디터 재생 중 노트·이벤트·타이밍 값 편집과 Undo·Redo를 제한한다

**Status:** Accepted (2026-10-31) · 에디터 컨텍스트·스펙·곡 타이밍 및 드로어 RFD·PRD 문서 반영 (2026-10-31) · 재생 중 길이 조절·Undo·Redo 제한 문서 반영 (2026-10-31) · PR 이해 확인에서 타이밍 값 변경 시 자동 정지를 재생 중 값 수정 차단으로 대체 (2026-10-31), 신규 규칙의 런타임 반영·검증은 후속 작업 · 타이밍 값 수정 후 음원 시각 유지의 이전 결정을 수정 직전 커서의 박 좌표 유지로 대체·문서 반영 (2026-10-31), 커서 기준 전환의 런타임은 후속 구현 · 재생 중 노트·이벤트 편집·Undo·Redo·타이밍 값 수정 차단 구현, 선택 허용 등 세부 기본값은 PRD §12 미정 (2026-10-31, PR #398)

## 기존 결정과 문제의식

[RFD 0095](0095-song-shared-bpm-and-audio-offset.md)·[RFD 0098](0098-song-info-drawer-and-save-scope.md)은 곡 정보 드로어를 열어 둔 채 에디터 재생과 편집 조작을 사용할 수 있도록 정했다. 이는 재생 도중 노트·이벤트를 변경할 수 있다는 의미로 해석될 수 있어, 재생 상태에 따른 편집 제한을 명시해야 한다.

초기 논의에서는 오프셋·BPM·박자표 값을 바꾸면 재생을 정지하고 현재 음원 위치를 유지하도록 정했다. 이후 PR 이해 확인에서 사용자는 오프셋도 재생 중 수정하지 못하게 하는 편이 일관적이며, 수정으로 재생이 자동 정지하는 동작은 어색하다고 지적했다. 이에 타이밍 값도 정지 상태에서 수정하도록 편집 제한을 통일한다(2026-10-31).

후속 이해 확인에서 사용자는 정지 후 타이밍 값을 수정하면 원래 음원 시각이 아니라 수정 직전 커서의 박 좌표를 유지하도록 변경했다. 아래 현재 규칙은 이전의 음원 위치 유지 결정을 대체하며, 직접 일시정지와 재생 중 편집 차단은 유지한다(2026-10-31).

## 검토한 대안과 채택안

에디터 재생 중에는 노트·이벤트의 생성·이동·삭제와 롱노트·구간 이벤트의 길이 조절을 실행할 수 없다. Undo·Redo도 정지 상태에서만 사용할 수 있다. 이 제한은 마우스·터치·키보드 등 입력 방식과 관계없이 적용한다(사용자 확인, 2026-10-31).

오프셋·BPM·박자표의 값도 재생 중에는 수정할 수 없다. 재생 중 수정 시도는 값과 재생 상태를 바꾸지 않는다. 사용자가 직접 일시정지한 뒤 값을 수정한다. 타이밍 값을 수정하기 직전 커서의 박 좌표를 유지한다. 수정 전 타이밍에서 현재 커서의 박을 구하고, 수정 후 같은 박에 해당하는 새 음원 시각으로 커서를 갱신한다. 다시 재생하면 그 위치부터 시작한다. 일시정지 후 사용자가 seek했다면 seek한 뒤 수정 직전의 커서 박을 기준으로 한다. 정지 순간의 박을 계속 고정하거나 수정 전 음원 시각을 그대로 유지하는 규칙은 아니다.

곡 정보 드로어를 열어 두는 것만으로 재생을 막지 않는다. 드로어의 오프셋 입력을 열어 둔 채 에디터의 재생·일시정지를 조작할 수 있어야 하며, 값 수정은 정지 상태에서만 허용한다.

재생하면서 노트·이벤트 변경을 바로 반영하거나 타이밍 값 수정으로 자동 정지하는 대안 대신, 재생 중 해당 편집을 차단한다. 타이밍을 바꿔 확인할 때마다 직접 일시정지와 재생을 조작해야 하지만 편집 가능 상태가 일관된다. 이 결정은 에디터에 적용하며 일반 Play·튜토리얼·옵저버의 입력·반복 규칙을 변경하지 않는다.

## 적용 경계와 후속 검증

이번 작업은 채택 규칙의 문서 반영이며 런타임을 수정하지 않는다. 세부 구현과 추가 제품 결정이 필요한 사항은 [PRD §12](../prd.md#12-미정-사항)에서 단일 관리한다.

[에디터 스펙](../spec/chart-editor.md#재생)·컨텍스트와 PRD를 동기화하고 기존 RFD에는 이 제한을 연결한다. 후속 구현에서는 모든 입력 경로에서 재생 중 생성·이동·삭제·길이 조절·Undo·Redo와 오프셋·BPM·박자표 값 수정이 실행되지 않는지, 수정 시도로 값이나 재생 상태가 바뀌지 않는지, 수정 직전 커서의 박을 새 타이밍의 음원 시각으로 갱신하는지, 정지 후 seek한 경우 새 위치의 박을 사용하는지, 반복 수정에서도 수정 직전 박을 유지하고 Play가 새 음원 위치에서 시작하는지, 드로어가 열린 상태에서 재생·일시정지를 사용할 수 있는지 검증한다.
