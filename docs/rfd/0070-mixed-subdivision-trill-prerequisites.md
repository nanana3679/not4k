# RFD 0070: 비트 복합 트릴의 선행 학습

**Status:** Accepted (2026-10-28) · 용어·루트 컨텍스트·피스·차트 설계 반영 (2026-10-28)

## 기존 결정과 문제의식

피스 `PP-008`의 정의는 하나의 `trillZone`에 서로 다른 비트 분할이 등장하는 배치이지만, 선행 조건은 앵커(`PP-002`)로 지정되어 있었다. 앵커의 양손 역할 분담을 익히는 것과 트릴의 리듬 변화에 대응하는 것은 서로 다른 학습 내용이다.

## 검토한 대안과 채택안

앵커를 반드시 먼저 익히도록 하는 조건을 제거하고, 트릴 키 교대와 리듬 변화 대응을 선행 학습으로 둔다. 앵커 없이도 비트 복합 트릴은 성립하며, 앵커와의 결합은 별도의 복합 활용이다. PLv.10과 입력·판정 규칙은 유지한다.

선행 학습은 필요한 기본 입력이나 리듬 대응을 포함해 설명한다. 피스 간 연결만으로 학습 순서를 표현하는 대신, 실제로 필요한 능력을 명시해야 한다.

## 영향과 검증

glossary를 먼저 갱신하고 루트 `CONTEXT.md`, 피스 정의, 차트 설계의 요약을 맞춘다. 피스 메타데이터의 선행 학습 설명도 기본 입력과 다른 피스를 모두 표현할 수 있게 정리한다. 앵커가 필수라는 조건이 남지 않는지 확인하며 코드 동작은 변경하지 않는다.
