## 1. 배경 (기존 결정과 문제의식)

기존 AGENTS.md·glossary는 **한국어 표준어**를 캐논으로 삼고 영어/코드명을 괄호·백틱으로 병기했다. 예: `트릴 구간 (Trill Zone)` + 코드 `trillZone`.

문제의식:

- **한 개념에 표면형이 셋** — 산문 `트릴 구간` / 괄호 `Trill Zone` / 코드 `trillZone`. 이 머릿속 매핑이 DDD가 없애려는 **번역 seam**이고, 실제로 이 seam에서 드리프트가 터졌다(`src/shared/CONTEXT.md`가 권위 "메시지 이벤트"와 어긋난 "텍스트 이벤트"를 단독 권장, 2026-06-30 정정). 동의어(`트릴 구간` ≈ `Trill Zone`)는 DDD 안티패턴이다.
- **결정적 문제(실사용 피로):** 한국어 표제어 중 상당수는 이 프로젝트가 *발명한 신조어*(공릴리즈·흡수 등)라 **그 자체로 직관적이지 않다.** 한국어로 적어도 의미가 전달되지 않아 독자가 정의를 반복해서 다시 찾게 된다. 즉 발명 신조어에서는 한국어가 직관 이득을 주지 못하면서 표면형만 하나 더 늘린다.

## 2. 핵심 결정 (출처 기반 판별)

**용어를 "출처(provenance)"로 가른다 — 이 프로젝트가 발명한 구성물인가, 원래 존재하는 개념인가.**

| 출처 | 캐논 표기 | 한국어 표제어 | 예 |
|---|---|---|---|
| **프로젝트 발명 구성물** (구현하느라 생긴 신조어·데이터 구조) | **영어 코드 식별자** (`백틱`) | 불필요 | `trillZone`, `emptyRelease`, `consume`, `holdOnly`, `endBeat`, `notes`, `events`, `flightRule`/`Liftoff`/`Survival` |
| **기존 개념** (리듬게임·음악계에 이미 존재, 자연스러운 이름이 있음) | **established 이름** | 자연스러우면 한국어 유지 | 판정, 손배치, 배드말림(Bad Train), 마디/박, BPM |

근거:

- **발명 구성물은 어느 언어로 써도 비직관적 신조어**다 → 한국어로 둬도 정의를 다시 찾게 되어 직관 이득 0, 표면형만 +1, 피로 +. 그럴 바엔 **코드와 일치하는 영어 하나**로 두는 게 seam·동의어를 동시에 없앤다. 발명 구성물 = 코드가 있는 것 = grep도 되는 것이라 이득이 실재한다.
- **기존 개념은 빌려온 것**이라 이미 진짜 이름이 있고, 그 이름(판정·손배치·배드말림)은 실제로 직관을 전달한다 → established 이름을 유지한다. 자연스러운 한국어가 있으면 한국어, 커뮤니티 표준이 영어면(BPM) 영어.
- DDD가 요구하는 것은 특정 언어가 아니라 (a) 번역 seam 제거 (b) 개념당 이름 1개 (c) 전문가가 실제 쓰는 말. 출처 축은 셋을 동시에 만족한다 — 발명품의 "전문가"는 개발자이고 그가 쓰는 말은 코드 식별자, 기존 개념의 전문가는 플레이어이고 그가 쓰는 말은 established 이름이다.

### 2.1 경계 타이브레이커

기존 개념을 not4k가 **고유하게 재구성하며 새 식별자를 부여**한 경우는 **발명 쪽으로 본다(영어)**. 그냥 일반 개념을 가리키면 established 이름을 쓴다.

- 게이지/클리어(기존) → not4k 2종 재편 = 발명 → `flightRule`/`Liftoff`/`Survival`(영어)
- `Good`(기존 판정) + 트릴 교대 실패 변형(발명) = `goodTrill` (식별자는 코드와 일치, **화면 표시 GOOD◇** — ◇는 표시 마커)

### 2.2 코드 없는 발명 용어 (우선순위)

발명이지만 코드 식별자가 없는 용어(피스·입력 기법 등)는 영어로 강제하지 않고 다음 우선순위로 캐논을 정한다:

1. **기존 용어가 있으면** 그것 (엄검중약, 앵커, 가변 분할)
2. **전용 표기 심볼이 있으면** 표기를 정의에 명시 + 구어 이름 유지 (릴리즈탭=`-o`)
3. **둘 다 없으면**(보면 비가시 손동작) 짧은 한국어 이름 (홀드 교대)

**예외(design-first):** 코드가 없어도 **영어 명칭이 설계상 확정됐고 구현 예정**이면 영어를 선행 채택한다. 예: `flightRule`(우산)·`Liftoff`/`Survival`(하위), `altitude`(게임플레이=시각 단일 값).

손·키·패턴 계층 어휘(운지·손배치·손 이동→수평/수직 이동·파지·키 교대), `NM 트릴` 표기 규약, 개명·폐기 용어(건너가기→수평 이동·양손 교대→파지·홀드 이어잡기→홀드 교대)는 [`term-map.md`](../context/term-map.md) §D 참조.

## 3. 표기 규칙

- **발명 구성물**: 산문에서도 영어 코드 식별자를 `백틱`으로 그대로 쓴다. 한국어 표제어를 만들지 않는다(동의어·seam 방지). glossary 정의 본문(설명·근거·예시)은 한국어로 쓰되, 표제어와 본문 속 그 용어 지칭은 영어 식별자로 한다.
- **기존 개념**: established 이름을 캐논으로 쓴다. 한국어 이름이면 한국어, 커뮤니티 영어면 영어.
- **prose(서술·근거·대화 예시)는 한국어를 유지**한다. 이 정책이 바꾸는 것은 *용어 토큰*이지 문서 언어가 아니다.
- 어느 경우든 개념당 표면형 1개, 동의어 금지, glossary에서 1:1 고정.

## 4. 대안 (검토 경로)

이 결정은 다음 순서의 토론·반증을 거쳐 도달했다.

- **A. 전면 한국어(기존 유지)** — 기각. 발명 신조어가 비직관적이라 한국어여도 정의 재조회가 발생(실사용 피로)하고, 구조 용어의 3중 표면형·seam이 남는다.
- **B. 전면 영어(모두 코드 식별자)** — 기각. 기존 개념(배드말림/Bad Train, 손배치, 판정)까지 영어로 강제하면 established 이름의 직관을 버리고, 영어 referent가 없는 토착 구어는 가짜 coin(`badPull` 류, grep 가치 0)을 만든다. 단 *발명 구성물 영역에서는* B를 전면 수용한다.
- **C. 표면형 유무(노출 범위로 계층 분리)** — 에이전트 토론 심판안. 대체됨. "플레이어가 보느냐"로 가르면 *보이는 발명품*(`trillZone`)은 한국어, *안 보이는 발명품*(`holdOnly`)은 영어가 되는 역설이 생긴다. 실제 피로의 원인은 가시성이 아니라 **출처(발명 여부)**였다.
- **D. 출처 기반(채택)** — 발명 구성물=영어 식별자(한국어 표제어 불요), 기존 개념=established 이름. A·B·C의 장점(seam 제거·직관 보존)을 출처라는 단일 축으로 통합한다.

## 5. 결정 경과 및 분류

**경과:** 사용자의 "전면 영어가 낫겠다" 제안 → 영어확대파/한국어보존파 입론 → 외부 deep research(비영어권 DDD 권고, 토스 세종대왕, Fowler/Crowdin 동의어·1:1 매핑) → 반론 → 중립 심판(표면형 안, 안 C) → 사용자가 **출처 축**으로 재정의(발명 신조어는 직관 이득 0이라 영어, 기존 개념만 한국어)하여 안 D 채택.

**분류 (출처 적용):**

| 용어 | 출처 | 캐논 표제어 |
|---|---|---|
| 트릴 구간 → `trillZone` | not4k 고유 트릴 시스템(발명) | `trillZone` |
| 공릴리즈 → `emptyRelease` | 누설 차단 구현(발명) | `emptyRelease` |
| 흡수 → `consume` | 헤드리스 매칭 구현(발명) | `consume` |
| hold-only → `holdOnly` | 끝점 면제 속성(발명) | `holdOnly` |
| 비행 규칙 → `flightRule`/`Liftoff`/`Survival` | 2종 재편(발명) | 영어 |
| `endBeat`/`notes`/`events`/`meta` | 데이터 구조(발명) | 영어 |
| 판정 | 모든 리듬게임 개념 | **판정** |
| 손배치 | 4키 운지 개념 | **손배치** |
| 배드말림 | 기존 개념(Bad Train) | **배드말림** |
| 마디 / 박 | 음악 개념 | **마디 / 박** |
| BPM | 커뮤니티 표준(영어) | `BPM` |

원칙: 한국어는 **"원래 있는 개념"에 한해** 유지하고, 프로젝트가 발명한 구성물은 영어 코드 식별자로 통일한다.
