# RFD 0028: 스킨별 롱노트 켜짐 효과 선언

**Status:** 채택 (2026-10-01, 사용자 결정) · 1단계 `heldEffect` 선언·로딩·렌더링과 glossary·명세 반영 (2026-10-01, PR #187) · 남은 항목: 2단계 Simple 리워크

## 기존 결정과 문제

지금은 모든 스킨이 롱노트 켜짐(홀드) 효과를 표시한다. [glossary `판정 효과`](../context/glossary.md)와 [게임 코어 '포인트 겹침과 연결 바디의 켜짐 표시'](../spec/game-core.md#포인트-겹침과-연결-바디의-켜짐-표시)는 싱글·더블 바디의 켜짐 표시를 후속 연결 구간까지 잇고, Trill은 자기 구간의 실제 유지 상태만 표시한다고 정한다. 스킨 설정 타입(`SkinManifest`)도 `bodySingleHeld`·`bodyDoubleHeld`·`bodyDoublePartialHeldLeft/Right`·`bodyTrillHeld` 같은 켜짐 에셋을 필수로 요구하고, `SkinManager`가 초기화 때 모두 불러온다.

사용자는 켜짐·꺼짐 효과를 복잡하게 느끼거나 원하지 않는 플레이어가 있을 수 있다고 보고, **효과가 있는 스킨과 없는 스킨을 모두 제공**하기로 했다(2026-10-01, #179에서 PRD 미정 사항으로 기록). 효과 없는 스킨은 이 프로젝트에 처음 생기므로, 스킨이 효과 유무를 알리는 방법과 공통 규칙을 함께 바꿔야 한다. 켜짐 에셋을 그냥 빼면 필수 에셋을 불러오지 못해 스킨 초기화가 실패한다.

## 결정

1. **스킨 설정에 효과 유무를 명시한다.** 스킨 테마에 `heldEffect: boolean`을 둔다. 생략하면 `true`로 보고 지금과 같이 동작한다.
2. **`heldEffect: false`인 스킨**
   - 바디·터미널의 켜짐 에셋(`*Held`, `*PartialHeld*`, 켜진 터미널)을 요구하지 않는다. 터미널은 한 종류만 두고 대기·유지에 같은 이미지를 쓸 수 있다.
   - 유지 중에도 대기 바디·터미널을 그린다. unit별 유지 상태와 후속 연결 구간의 켜짐 전파를 시각화하지 않는다.
   - **부분 실패와 실패는 효과 유무와 관계없이 표시한다.** 더블 바디·터미널의 부분 실패 에셋(`bodyDoublePartialFailedLeft/Right`, `terminalDoublePartialFailedLeft/Right`)과 실패 에셋은 그대로 필수다.
3. **켜짐·꺼짐 디자인은 롱노트 바디·터미널에만 둔다.** 포인트에는 두지 않는다(지금도 없다).
4. **표시만 바꾼다.** 입력 매칭, unit 활성화·승계, release, 점수·콤보·판정 효과는 바뀌지 않는다. 키봄·키빔처럼 켜짐과 별개인 피드백도 이 결정의 범위가 아니다.
5. **스킨별 값**

   | 스킨 | `heldEffect` | 비고 |
   | --- | --- | --- |
   | Classic (기본) | `true` | 지금의 바디 켜짐 디자인: 싱글·더블은 트렌치 바디에 중앙 흰빛·주변광(더블 부분 충족은 중앙 흰빛만), 트릴은 반투명 사각 기둥 |
   | Crystal (개발 중, 비공개) | `true` | |
   | Simple (Lab 전용) | `false` | 효과 없는 스킨으로 리워크할 때 적용 |

## 검토한 대안

- **에셋 존재로 판단(기각)**: 켜짐 에셋을 넣지 않은 스킨을 효과 없음으로 보는 방식이다. 스킨 제작자가 에셋만 맞추면 되지만, 실수로 에셋을 빠뜨려도 오류 없이 효과가 꺼져 의도와 실수를 구분할 수 없다. 사용자가 명시하는 방식(1번)을 골랐다.

## Trade-off

효과 없는 스킨에서는 더블을 몇 unit 유지 중인지와 연결 구간이 이어지는지가 화면에 보이지 않는다. 플레이어가 그 정보를 포기하는 대신 덜 복잡한 화면을 고르는 선택이다. 놓친 입력을 알려 주는 부분 실패·실패 표시는 남긴다. 효과 유무는 스킨마다 하나로 정해져 있어, 같은 스킨에서 효과만 끄는 설정은 두지 않는다.

- 문서: glossary `판정 효과`의 켜짐 표시 문단, 게임 코어 '포인트 겹침과 연결 바디의 켜짐 표시', `src/game/CONTEXT.md`의 켜짐 표시 요약, [노트 에셋 Lab 명세](../spec/note-asset-lab.md)의 스킨 에셋 규칙, PRD §12의 해당 미정 항목(이 RFD로 결정되어 제거)

## 구현 순서

1. `heldEffect` 선언, 로딩, 렌더링을 구현하고 테스트용 효과 없는 스킨으로 검증한다. 같은 PR에서 glossary·게임 코어·`CONTEXT.md` 요약을 이 RFD에 맞게 고친다. 코드와 문서가 함께 바뀌도록 문서 수정을 구현 PR로 미룬다.
2. Simple을 효과 없는 스킨으로 리워크하고 `heldEffect: false`를 적용한다.
