# RFD 0060: 옵저버의 구간 반복은 연주 방법 이해와 동작 숙련을 지원

**Status:** Accepted (2026-10-28) · 목적·제작 범위 설명 반영 (2026-10-28) · 직접 입력·판정 지원은 [RFD 0061](0061-observer-input-and-judgment.md)에서 후속 채택 (2026-10-28)

## 기존 결정과 문제의식

옵저버 명세는 고난이도 차트를 플레이하기 전에 손배치를 계획하는 데 초점을 두었다. MVP 문서도 Lv.1～6에서는 불필요하고 Lv.7 이상을 제공하려면 필요한 도구라고 설명했다.

사용자는 어떻게 쳐야 할지 모르겠을 때, 또는 동작 자체가 익숙하지 않을 때 원하는 구간을 반복하는 용도라고 정리했다.

## 검토한 대안

- 고난이도 플레이의 사전 손배치 계획 도구로 한정한다. 낮은 레벨의 규칙 이해와 동작 숙련에 필요한 반복을 충분히 설명하지 못한다.
- 연주 방법 이해와 동작 숙련을 위해 원하는 구간을 반복하는 도구로 설명한다. 사용 필요성을 차트 레벨만으로 판단하지 않는다.

## 채택안과 trade-off

옵저버는 연주 방법을 파악하고 싶거나 동작을 익히고 싶은 플레이어가 원하는 구간을 반복하기 위해 선택하는 도구다. 고난이도에서만 필요한 기능이나 본 플레이 전에 반드시 사용해야 하는 절차로 설명하지 않는다.

자유 탐색·재생·감속·구간 반복의 기존 방향과 Phase B의 제공 계획은 유지한다. Phase A 제외 이유는 초기 기능 범위를 줄이기 위한 선택으로 설명한다.

다만 기존 명세에는 입력 없는 관찰만 적혀 있어, 동작 숙련을 지원할 실제 입력·판정 범위를 확인해야 한다. 그 경계는 [PRD §12](../prd.md#12-미정-사항)에서 단일 추적한다. 이 목적 정리만으로 판정·점수·기록 규칙이나 별도 모드를 확정하지 않는다.

## 영향과 검증

- 옵저버 명세·MVP·태도 문서에 두 사용 목적을 반영하고, 고정된 레벨별 필요성 설명을 제거한다.
- PRD의 기존 입력 없는 관찰 범위와 추가 확인할 사항을 연결한다. 런타임은 변경하지 않는다.
- 사전 계획의 필수성·저레벨에서의 불필요함을 단정한 문구와 관련 링크를 확인한다.
