# RFD 0078: 피스 PP-003의 이름을 롱노트 중 탭으로 통일한다

**Status:** Accepted (2026-10-29) · 용어·컨텍스트·피스·차트 설계·개요·난이도·노트 시스템·PRD 반영 (2026-10-29)

## 기존 결정과 문제의식

피스 `PP-003`은 카탈로그에서 레인 내 분리, PRD와 개요에서는 홀드 중 탭으로 불렸다. 홀드 중 탭은 기존 키를 유지하면서 다른 키로 탭하는 입력방식명이기도 하다. 사용자는 롱노트 끝 탭과 짝을 이루는 롱노트 중 탭으로 피스 이름을 맞추기로 했다.

## 검토한 대안과 채택안

레인 내 분리라는 기존 이름 대신 롱노트 중 탭을 공식 피스명으로 쓴다. 롱노트를 유지하는 동안 같은 레인에 탭 노트가 나오는 배치라는 정의, `PP-003`과 PLv.7은 유지한다.

홀드 중 탭과 홀드 교대는 이 배치를 처리하는 입력방식명으로 유지한다. 피스명을 바꾼다고 기존 키를 계속 누르는 처리만 허용하거나 키 교대를 금지하지 않는다. 배치 이름과 실제 처리 방법을 문맥에 맞춰 구분해야 한다.
