# RFD 0025: 원래 장애물에 고도·높이·중앙 접근만 연결

**Status:** 사용자 요청에 따라 원래 장갑 조각·대각 지지대 복원과 세 연동 구현 착수 (2026-09-09) · 원본 PNG·윤곽 경로 복원, 세 독립 연동·하단 조절 구현 및 단위 360개·브라우저 59개 검증 (2026-09-09).

구현 기록: 원래 미리보기 링크와 만료 시각을 유지해 해당 실행 서버만 재시작했다. 원본 이미지 2종의 SHA-256 보존, 실행 파일 7개의 서버 응답 일치, 저·중·고도의 실제 화면과 모바일 하단 조절을 확인했다. 원본 무연동·블록·9종 비교, 이륙·침투는 보존했다. 본편 적용·실물 휴대폰 성능·사용자 주변시 체감 검증은 포함하지 않는다.

## 기존 결정과 문제

[RFD 0023](0023-breakthrough-visual-clearance.md)의 시점 실험에서 원래 투명 장갑 조각·대각 지지대를 하단 직육면체로 교체했다. 높낮이 연출에 이 형태 교체는 필수가 아니었다. 뒤이은 [RFD 0024](0024-breakthrough-architectural-modules.md)의 건축 모듈과 별도 Three.js 비교는 원래 2D 메카닉 스타일을 복원하는 해결책이 아니었다. 사용자는 원래 장애물에 고도·높이·중앙 접근만 적용하도록 요청했다.

## 대안과 채택안

- 건축 모듈이나 렌더러를 다시 수정: 이번 요청 범위 밖이다.
- 원래 이미지의 세로축만 늘리기: 대각 지지대의 각도와 이미지 비율이 달라져 채택하지 않는다.
- **원래 PNG·알파 윤곽·측면 생성 경로를 복원하고 배치 변환만 분리:** 채택한다. 아래쪽 윤곽을 지면 기준으로 놓고, 원래 두 축의 비율을 유지하는 균등 확대와 시점 높이·설치 평면 이격을 적용한다. 새 구조물·지지대·재질을 만들지 않는다.

고도가 낮을수록 시점이 내려가고 구조물 높이가 최대 130%로 증가하며 설치 평면이 중앙에 접근한다. 세 연동을 각각 끌 수 있고 기본 높이·벽 이격·증가량·접근 강도를 조절한다. 원래 타입·좌우·배치 위상·전진 간격은 고도로 재추첨하지 않는다. 실제 벽과 광원 평면은 중앙으로 옮기지 않는다. 기존 원본 무연동, 하단 블록, 건축 모듈 비교는 명시적인 설정으로 보존하되 기본 화면은 원래 장애물로 복원한다.

## Trade-off와 범위

균등 확대하므로 높이 증가에 따라 진행 방향 길이도 증가한다. 원본 픽셀과 윤곽의 비율은 보존하지만 원래 무연동 시연의 배치 높이·크기까지 그대로라는 뜻은 아니다. 배치 중심의 전진 위상은 유지하고, 원본 조각들 사이의 빈 공간도 보존한다. 건축적 접속을 새로 설계하지 않는다. 높은 고도의 여유는 기본 치수 기준이며 수동 극단값에서는 보장하지 않는다.

기존 2D 이미지 합성·사각뿔 투영 경로를 유지한다. 새 렌더러나 패키지는 추가하지 않는다. 16:9·세 난이도 링크·하단 조절·레인·노트 시간·전진 속도는 유지하고 충돌·피해·실패·게임 본편은 변경하지 않는다. 최종 주변시 체감은 [PRD §12](../prd.md#12-미정-사항)의 기존 미정 사항 범위다.
