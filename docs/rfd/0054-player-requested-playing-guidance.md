# RFD 0054: 실패 후 연주 방법 안내는 플레이어가 선택

**Status:** Accepted (2026-10-28) · 태도·난이도·튜토리얼 문서 반영 (2026-10-28)

## 기존 결정과 문제의식

난이도 설계 문서는 연타로 막힌 플레이어에게 키를 하나 더 활용하고 다시 플레이하라고 제안하는 시스템이 필요하다고 설명했다. 결과를 담백하게 표시한다는 태도 원칙과의 관계, 안내를 여는 주체가 명확하지 않았다.

사용자는 이런 연주 방법 안내를 플레이어가 도움말·튜토리얼을 선택했을 때 제공하고, 실패 결과만 보고 자동으로 조언하지 않는 방향을 승인했다.

## 검토한 대안

- 실패 결과를 근거로 연주 방법을 자동 제안한다. 플레이어가 도움을 요청하지 않은 상황에도 조언이 표시된다.
- 플레이어가 도움말·튜토리얼을 선택했을 때 안내한다. 필요한 설명을 직접 찾을 수 있도록 구성해야 한다.

## 채택안과 trade-off

플레이 결과를 보고 키 활용이나 연주 방법을 자동으로 조언하지 않는다. 해당 안내는 플레이어가 도움말·튜토리얼을 선택했을 때 제공한다. 실패를 이유로 도움말을 자동으로 열거나 튜토리얼로 전환하지 않는다.

도움말·튜토리얼에서는 같은 레인의 반복 노트를 여러 키로 나누어 처리하는 방법 등을 기능적으로 설명하고 체험시킬 수 있다. 결과 화면은 판정·기록과 다음 조작을 표시한다. 실패 원인에 관한 추측이나 재도전을 권하는 말을 붙이지 않는다.

안내를 직접 찾아야 하므로 도움말의 접근 경로와 설명이 명확해야 한다. 구체적인 버튼 추가나 화면 개편을 이 결정으로 요구하지 않는다. 첫 기동 온보딩의 진입 방식은 이번 실패 결과 기반 조언 논의와 별개이며 변경하지 않는다.

## 영향과 검증

- 태도 문서의 원칙 2, 난이도 설계의 키 활용 안내, 튜토리얼·키 바인딩의 학습 흐름 설명을 맞춘다.
- 결과 화면에서 해당 자동 조언은 발견되지 않았다. 이번 변경은 문서에 한정하며 런타임과 기존 첫 기동 흐름을 바꾸지 않는다.
- 자동 제안으로 해석되는 현행 요구와 효과를 단정하는 문구를 정리하고 관련 링크를 확인한다.
