# RFD 0046: PLv.의 본격 활용 기준과 낮은 레벨의 짧은 체험

**Status:** Accepted (2026-10-28) · 용어·난이도·차트 제작 지침 반영 (2026-10-28)

## 기존 결정과 문제의식

PLv.는 피스를 본격적으로 활용하기 시작하는 최소 레벨로 설명되어 있었지만, 차트 제작 지침은 피스의 PLv.가 차트 Lv.를 초과해서는 안 된다고 규정했다. 느리고 단순한 체험과 본격 활용을 구분하지 못하는 설명이다.

사용자는 PLv.7인 피스도 충분히 느리고 단순하게 배치하면 더 낮은 레벨에서 짧게 체험시키는 것을 허용했다.

## 검토한 대안

- PLv.를 등장 가능한 절대 하한으로 사용한다. 배치 판단은 단순하지만 낮은 부담으로 미리 익힐 기회를 제한한다.
- PLv.를 본격 활용의 기준으로 사용한다. 낮은 레벨의 짧은 체험을 허용하되 실제 배치의 부담을 확인해야 한다.

## 채택안과 trade-off

PLv.는 해당 피스가 의미 있는 난이도 요소로 본격 활용되기 시작하는 기준 차트 레벨이다. 피스의 등장을 금지하는 절대 하한으로 사용하지 않는다. 충분히 느리고 단순하게 구성한 짧은 체험은 더 낮은 레벨에서도 허용한다.

차트 Lv.와의 비교만으로 배치를 금지하던 제작 규칙은 이 기준으로 대체한다. 기존 피스별 PLv. 수치는 유지하며, 낮은 레벨에 넣을 때는 실제 속도·밀도·지속 길이·다른 입력과의 조합을 검토한다. 차트 구조·판정·난이도명별 별도 배치 제약을 면제하는 결정은 아니다.

명확한 수치 하나로 허용 여부를 정하는 단순함 대신, 체험 배치의 실제 난이도가 차트 수준에 맞는지 제작·플레이테스트에서 확인해야 한다. 별도의 정량적 문턱은 이 결정으로 만들지 않는다.

## 영향과 검증

- glossary를 먼저 갱신하고 루트 `CONTEXT.md`, 설계 개요, 피스 명세, 노트 시스템, 난이도 설계, 차트 제작 지침을 동기화한다.
- 소스·도구·E2E에서 PLv. 기반 실행 규칙은 발견되지 않았다. 이번 변경은 문서에 한정하며 노트 동작·피스별 수치·기존 배치 검증을 변경하지 않는다.
- 절대 하한으로 읽히는 설명과 첫 등장·본격 활용의 혼동, 관련 문서 링크를 확인한다.
