## 기존 결정과 문제의식

현재 공개 튜토리얼은 자동 시연을 보는 도움말이며, 본 항목 체크를 저장한다. 직접 따라 치는 실습과 통과 기준은 미정이었다. PRD에는 레벨별 튜토리얼 선행 조건도 검토 대상으로 남아 있었다.

사용자는 리듬세상처럼 시연을 본 뒤 실제로 입력을 3번 해 통과하는 학습 흐름으로 바꾸고, 차트 선택의 선행 조건은 일단 빼기로 했다.

## 검토한 대안과 채택안

`AutoEvent`는 튜토리얼 시연용으로만 다룬다. 일반 차트의 연출용 자동연주 기능으로 확대하지 않는다. 새 `직접 입력 / 시연` 토글과 기존 이벤트를 연결하는 구현 방식은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다(사용자 확인, 2026-10-29).

자동 시연만 열람하는 방식 대신, 입력을 배우는 항목은 시연을 본 뒤 제시된 동작이나 짧은 패턴을 직접 연주하고 누적 3회 성공하면 통과하는 방식으로 바꾼다. 단순히 항목을 보았다는 사실과 실제 실습 통과를 구별한다. 성공 횟수는 누적하며 실습 중 실패해도 줄이거나 초기화하지 않는다.

처음 실습에 들어갈 때부터 `직접 입력 / 시연` 토글을 사용한다. 플레이어가 직접 입력을 선택하면 실습으로 넘어가며, 시연 종료만으로 자동 전환하지 않는다. 처음 검토한 별도 실습 시작 버튼은 토글로 통일한다(사용자 확인, 2026-10-29).

실습에 필요한 키가 현재 바인딩에 부족하면 먼저 키 설정을 수정하도록 안내한다. 실제 설정이 해당 실습의 요구를 충족한 뒤 실습을 시작하며, 실습 중에만 쓸 임시 키를 자동 배정하지 않는다. 기존 자동 시연 프리뷰의 표시용 키 보충과 직접 입력 실습의 요구를 구별한다(사용자 확인, 2026-10-29).

실습에서는 플레이어가 노트를 보고 직접 사용할 키를 판단한다. 다음에 눌러야 할 키를 미리 알려주는 가이드는 표시하지 않는다. 시연의 입력 안내와 실습 중 실제 누른 키의 표시를 구별하며, 노트와 `trillZone` 등 입력 요구를 알리는 시각 표시는 유지한다(사용자 확인, 2026-10-29).

튜토리얼의 노트 낙하 속도는 플레이어의 본 플레이 설정에 연동하지 않고 튜토리얼용 고정값을 사용한다. 본 플레이의 설정값은 변경하지 않는다. 구체적인 고정값은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다(사용자 확인, 2026-10-29).

실습을 시작한 뒤에는 성공·실패마다 버튼을 다시 누르지 않고 같은 실습을 자동 반복한다. 실패해도 성공 횟수는 유지하며, 누적 3회 성공하면 반복을 마치고 통과 처리한다. 이미 통과한 항목을 다시 실습해도 새 실습에서 누적 3회 성공하면 반복을 종료하며, 기존 통과 기록은 유지한다. 플레이어는 통과 전에도 모달을 닫을 수 있다(사용자 확인, 2026-10-29).

통과 후에는 현재 항목에 머물며 `다음` 버튼을 누르면 다음 항목으로 이동한다. 통과만으로 자동 이동하지 않는다(사용자 확인, 2026-10-29).

실습 중 시연을 다시 확인할 때는 별도 다시 보기 버튼 대신 `직접 입력 / 시연` 토글로 두 상태를 오간다. 토글로 시연에 다녀와도 이미 쌓인 성공 횟수는 유지하고, 시연의 자동 입력은 성공 횟수에 포함하지 않는다. 직접 입력에서 시연으로 바꿀 때 이미 패턴이 재생 중이면 다음 패턴 시작부터 적용하며, 재생 중이 아니면 바로 적용한다. 시연에서 직접 입력으로 바꿀 때는 현재 재생 위치에서 즉시 적용한다. 시연 도중 직접 입력으로 바꾼 현재 패턴은 성공 집계에서 제외하고, 다음 패턴부터 성공 횟수를 집계한다. 항목별 목표 수치 등 남은 세부는 [PRD §12](../prd.md#12-미정-사항)에서 관리한다(사용자 확인, 2026-10-29). 이 전환 규칙은 튜토리얼에 적용하며 옵저버의 Auto 전환 규칙과 구별한다.

1회 성공 여부는 튜토리얼 항목마다 정한 목표 달성률과 추가 조건으로 판단하며, 이 조건들을 해당 튜토리얼에 표시한다. 실습 한 차례의 결과가 모든 조건을 만족하면 성공 횟수를 1회 더한다. 조건을 한 번 만족한 것만으로 통과하는 방식으로 바꾸지 않는다.

각 통과 조건은 콤보 아래에 줄을 나눠 하나씩 표시한다. 충족한 조건에는 초록 체크 아이콘을, 실패한 조건에는 빨강 X 아이콘을 표시하며 중립 상태는 흰색 글씨로 표시한다(사용자 확인, 2026-10-29). 조건 상태는 연주 도중 실시간으로 갱신한다. 조건 목록 바로 아래에는 성공 횟수 진행도를 `1/3` 형식으로 표시한다. 성공 횟수는 패턴 결과가 확정될 때 집계하며, 성공이 확정되면 진행도도 즉시 갱신한다.

일반 Good은 달성률 계산에 반영하며 발생 자체만으로 실패 처리하지 않는다. 트릴 교대 학습에는 `goodTrill` 0회 조건을 두어 교대 실패를 성공으로 집계하지 않는다. 항목별 구체적인 목표 수치와 추가 조건은 [PRD §12](../prd.md#12-미정-사항)에서 관리한다.

실습 과제는 올바른 연주 방법을 익히는 내용으로만 구성한다. 판정의 실패 사례는 시연으로 설명하고, 실패 동작을 직접 재현해야 통과하는 과제는 두지 않는다. 실습에서 실제로 발생한 실패는 일반 규칙대로 판정하며, 기존의 항목별 달성률·추가 조건으로 성공 여부를 판단한다(사용자 확인, 2026-10-29).

롱노트 중 탭은 기존 키를 유지하는 방법과 유지 키를 교대하는 방법을 모두 시연하고, 각 방법을 따로 실습해 각각 누적 3회 성공해야 통과한다. 성공 횟수를 방법별로 집계하며 서로 합산하지 않는다. 한 방법의 성공으로 다른 방법의 실습을 대신하지 않는다(사용자 확인, 2026-10-29).

실습 기록으로는 항목·연주 방법별 통과 여부만 로그인 여부와 관계없이 브라우저에 저장한다. 로그인하면 항목·연주 방법별 통과 여부를 계정과 동기화해 다른 기기에서도 같은 통과 표시를 확인할 수 있게 한다. 브라우저와 계정 중 어느 쪽에서든 통과한 항목·연주 방법은 합쳐 보존한다. 미완료 실습의 중간 성공 횟수는 동기화하지 않는다. 같은 계정으로 다른 기기에 접속해도 통과 여부를 확인할 수 있게 한다(사용자 확인, 2026-10-30). 비로그인 플레이어도 통과한 항목을 다시 확인할 수 있게 한다(사용자 확인, 2026-10-30). 튜토리얼을 닫았다 다시 열면 미완료 실습의 성공 횟수는 0회부터 시작하며, 1/3·2/3 같은 중간 진행도는 복원하지 않는다. 이미 통과한 항목·연주 방법의 통과 기록은 유지한다. 실습 도중 실패해도 횟수를 유지하는 규칙과 닫은 뒤 재진입하는 초기화를 구별한다(사용자 확인, 2026-10-29). 다른 튜토리얼 항목으로 이동했다 돌아오는 경우에도 미완료 실습의 성공 횟수는 0회로 초기화한다. 같은 항목에서 직접 입력/시연을 토글할 때는 성공 횟수를 유지한다.

튜토리얼 목록에서 통과한 항목에 체크 표시를 붙인다. 시연만 본 항목에는 통과 체크를 붙이지 않으며, 별도의 열람 표시도 두지 않는다. 여러 연주 방법을 각각 실습하는 항목은 필요한 모든 방법을 통과해야 항목 전체를 통과로 표시한다(사용자 확인, 2026-10-30).

튜토리얼을 닫았다 다시 열면 마지막으로 선택한 탭과 항목을 연다. 마지막으로 선택한 탭과 항목을 브라우저에 저장해 게임을 껐다 켜도 복원한다. 로그인하면 마지막으로 선택한 탭과 항목도 계정과 동기화해 다른 기기에서 같은 위치를 이어 볼 수 있게 한다. 기기마다 마지막 열람 위치가 다르면 실제로 가장 최근에 선택한 탭과 항목을 사용한다. 동기화 요청이 나중에 도착했다는 이유로 더 오래된 선택 위치가 최신 위치를 덮어쓰지 않는다. 선택 이력이 없는 최초 진입은 `Basic` 첫 항목에서 시작한다. 항목 위치 복원과 미완료 실습의 성공 횟수 복원은 구별한다. 현재 공개 도움말이 다시 열 때 `Basic` 첫 항목으로 돌아가는 동작을 변경한다(사용자 확인, 2026-10-30).

튜토리얼 완료·통과를 차트 선택의 선행 조건으로 두지 않는다. [RFD 0055](0055-first-launch-tutorial-modal.md)의 처음부터 바로 닫을 수 있는 모달과 수동 재진입 원칙도 유지한다. 실습의 통과 조건과 일반 차트의 이용 조건은 구별한다.

직접 입력을 통해 동작을 익혔는지 확인할 수 있으나, 시연만 보는 방식보다 입력 전환·반복·실패 처리를 설계해야 한다. 기존 열람 체크를 실습 통과로 간주하지 않는다.

## 영향과 검증

glossary, 루트·게임 컨텍스트, 튜토리얼·게임 코어·MVP 스펙과 PRD를 동기화한다. PRD의 미정 사항에서 레벨별 튜토리얼 선행 조건을 제거하고 남은 실습 세부만 관리한다. 기존 공개 튜토리얼과 새 목표를 구별하며 런타임 코드는 변경하지 않는다. 향후 구현에서는 시연·직접 입력 전환, 누적 3회 성공 집계, 열람·통과의 구분과 자유로운 종료·차트 선택을 검증한다.
