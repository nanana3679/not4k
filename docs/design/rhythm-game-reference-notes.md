# Rhythm Game Visual Reference Notes

목적: not4k의 gear/lane/skin 이미지 생성을 위한 레퍼런스 메모이다. 이미지는 저장하지 않고, 공개 링크와 관찰만 기록한다. 아래 내용은 특정 디자인을 복제하기 위한 자료가 아니라 **구조, 밀도, 재질감, 커스터마이즈 단위**를 추상화하기 위한 자료이다.

## Distilled Patterns

- **레인은 sacred scan zone이다.** [DJMAX](https://store.steampowered.com/app/960170/DJMAX_RESPECT_V/), [EZ2ON](https://store.steampowered.com/app/1477590/EZ2ON_REBOOT__R/), [IIDX](https://p.eagate.573.jp/game/2dx/33/howto/play/game_screen.html), [Quaver](https://store.steampowered.com/app/980610/Quaver/) 모두 장식 밀도가 달라도 실제 노트가 지나가는 중앙 영역은 고대비와 반복 가능한 lane separator를 유지한다. not4k gear 프롬프트에서는 `dark readable scan zone`, `clear 4-lane separators`, `decor outside playfield`를 기본 조건으로 둔다.
- **하단은 입력 장치처럼 보여도 좋다.** [DJMAX](https://store.steampowered.com/app/960170/DJMAX_RESPECT_V/), [IIDX](https://p.eagate.573.jp/game/2dx/33/howto/play/game_screen.html), [SDVX](https://p.eagate.573.jp/game/sdvx/vi/howto/index.html)는 하단 receptor 주변을 버튼, 금속, LED, 폭발 이펙트가 모이는 "control deck"처럼 처리한다. not4k는 4개의 lane receptor를 `mechanical bottom input deck`, `rubberized key blocks`, `contained hit sparks`로 실험할 수 있다.
- **게이지는 프레임의 일부가 될 수 있다.** [EZ2ON](https://store.steampowered.com/app/1477590/EZ2ON_REBOOT__R/)과 [SDVX](https://p.eagate.573.jp/game/sdvx/vi/howto/index.html)는 측면 gauge를 playfield와 분리된 상태 정보로 보여준다. not4k의 `altitude`는 `side altitude meter`, `cockpit vertical gauge`, `thin LED fuel bar`처럼 gear frame에 붙이는 방향이 좋다.
- **커스터마이즈 단위는 작게 쪼갠다.** [DJMAX gear pack](https://store.steampowered.com/app/1281330/DJMAX_RESPECT_V__Welcome_to_the_Space_GEAR_PACK/), [EZ2ON PRESTIGE PASS](https://store.steampowered.com/app/1926210/EZ2ON_REBOOT__R__PRESTIGE_PASS/), [Etterna customisation](https://etternaonline.com/), [StepMania noteskin parameter discussion](https://www.stepmania.com/forums/stepmania-development/show/4500?start=16)은 gear/note/panel/judge/combo 또는 noteskin/judgement/theme/playfield를 작은 단위로 다루는 데 참고가 된다. not4k 이미지 생성도 `gear shell`, `lane background`, `receptor deck`, `note skin`, `judgement typography`, `altitude gauge`를 따로 요청한다.
- **테마 폭은 넓혀도 판독 규칙은 고정한다.** 가능한 테마: `sci-fi cockpit`, `glass arcade cabinet`, `premium lounge`, `industrial metal`, `festival neon`, `minimal tournament`, `song-themed frame`, `retro LCD`, `holographic acrylic`. 단, 4레인 경계, 판정선, 하단 receptor 위치는 흔들지 않는다.

## Prompt Guardrails

- 프롬프트에 반드시 포함: `original rhythm game UI`, `4-lane vertical playfield`, `no logos`, `no existing game text`, `readable dark scan zone`, `decorative frame outside lanes`, `bottom receptor deck`, `side altitude gauge`.
- 프롬프트에 선택적으로 포함: `beveled metal`, `tempered glass`, `emissive acrylic`, `holographic trim`, `arcade cockpit HUD`, `minimal tournament skin`, `song-themed cosmetic shell`.
- 피해야 할 표현: `DJMAX-style`, `IIDX-style`, `SOUND VOLTEX-style`, `EZ2ON clone`, 기존 게임 판정명/게이지명/로고/캐릭터/노트 모양을 직접 호출하는 표현.
- 생성 결과 검수 기준: 노트가 떨어지는 4레인 영역이 가장 먼저 읽히는가, 하단 입력부가 4개의 receptor를 명확히 갖는가, gauge가 `altitude` UI로 보이는가, 장식이 판정선과 노트를 가리지 않는가.
