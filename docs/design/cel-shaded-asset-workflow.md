# 셀 채색과 별도 반사광을 사용하는 에셋 제작 기준

같은 스킨 계열의 노트·프레임·버튼은 2D 셀 채색 베이스를 먼저 만들고 반사광·모서리 하이라이트·발광을 별도 SVG 그룹으로 구성한다. 현재 승인된 디자인과 치수는 [Classic 제작 기준](../../assets-lab/classic/README.md)과 [노트 에셋 Lab 명세](../spec/note-asset-lab.md)를 따른다.

## 형태와 채색

- 빠르게 지나가는 작은 에셋에서도 읽히도록 큰 면과 명확한 명암으로 형태를 표현한다.
- 싱글은 연파랑, 더블은 노랑을 고유색으로 사용하며 중립 실버·어두운 금속을 함께 쓴다. 보조색은 적은 양으로 반복한다.
- 포인트는 부드러운 유광과 윗면 반사로 입체감을 주고, 바디는 더 어두운 평면에 가깝게 표현한다. 포인트에는 중심 발광과 사선 유리 반사를 추가하지 않는다.
- 바디는 수직으로 반복할 수 있는 100:20 단위다. 길이가 늘어날 때 같은 타일을 반복하고 남는 부분을 자르며 반사광을 세로로 늘리지 않는다.
- 시작 터미널은 한쪽이 닫힌 직사각형 마감이며 바디와 같은 너비다. 열린 단면에서 색면·금속 띠·중앙광이 이어지고 사선은 45도를 유지한다. 끝 터미널은 시작 전체의 상하반전이다.
- 석영 Trill은 밝은 흰 포인트와 어두운 바디를 구분한다. 끝 터미널은 바디와 같은 재질의 마름모이며 세 파츠의 최대 너비를 같게 한다.

## 빛과 상태

- 채색·반사·발광 그룹을 분리해 고유색과 표면을 유지하면서 빛을 조절할 수 있게 한다. 런타임에서는 합성된 상태별 PNG를 사용한다.
- 싱글·더블의 대기는 중앙 흰빛만 끄고, 홀드를 시작하면 켠다. 더블 부분충족은 중앙 흰빛을 남기고 양옆 노란빛을 끈다. 실패는 발광을 끄고 무채색으로 바꾼다.
- 석영 바디·끝 터미널은 대기·켜짐·실패 원본을 각각 보관한다. 포인트에는 바디와 구분할 수 있는 은은한 하단 그림자를 추가한다.
- Grace는 본체를 줄이지 않는 별도 윤곽선이다. 검정 1px·흰색 1px 보더와 바깥 10px 동안 알파 80%에서 0%로 약해지는 빛을 사용한다.

## 제작·확인

1. 새 디자인은 이미지 시안으로 형태와 재질을 먼저 확인한다. 채택한 이미지를 보존하고 SVG로 재구성한다.
2. 승인 SVG는 `assets-lab/classic/sources/`에서 편집한다. 싱글·더블 시작 터미널은 독립 원본이며 이전 생성기로 덮어쓰지 않는다.
3. `pnpm build:classic`으로 상태별 SVG와 공통 런타임 PNG를 생성한다. PNG는 `public/skins/classic/`, Lab SVG는 `public/lab/note-assets/classic/`에 저장한다.
4. `/lab/note-assets?design=classic`에서 실제 튜토리얼 재생기로 확인하고, 인게임의 `Settings → Skin → Classic`에서도 같은 에셋을 확인한다.
5. 바디 반복 경계, 터미널 접합면, 포인트 겹침과 상태별 가독성을 실제 표시 크기와 휴대폰 화면에서 검증한다.

탐색 중 생성한 전체 이미지와 대화 기록은 로컬 작업 아카이브에 보관한다. 저장소에는 현재 승인된 소스, 비교에 필요한 기준 이미지, 재현 가능한 생성기와 검증을 포함한다.
