# not4k — 설계 의도

## 한 줄 정의

> **not4k는 4개의 레인에 여러 키를 바인딩하고, 차트의 흐름에 맞춰 손배치를 고르고 바꾸는 리듬게임이다.**

단순한 화면에서 배치의 의도를 파악하고 패턴을 파훼하는 보람을 만들고자 한다. 패턴을 한 번 본 뒤 의도된 연주 방법을 파악하고, 다음 시도에서 더 수월하게 연주하는 경험을 즐기는 기존 리듬게임 유저를 중심 타깃으로 삼는다([RFD 0045](../rfd/0045-target-players-and-pattern-solving.md)).

---

## 1. 설계의 출발점

### 반복 입력을 여러 키로 나누어 처리하기

같은 레인에 여러 키를 사용할 수 있으면, 반복 노트를 한 키로 처리하거나 여러 키로 나누어 처리할 수 있다. 이 선택을 다른 레인의 입력과 조합해 손배치의 변화를 만든다. 반복 입력의 부담을 나눌 수 있다는 점도 이 구조에서 기대하는 장점이다.

### 화면 구조를 유지하며 사용하는 키 늘리기

화면에는 항상 4개의 레인만 둔다. 플레이어가 더 많은 바인딩 키를 활용하더라도 같은 레인 구조에서 차트를 읽고, 손배치의 활용 범위를 넓혀가도록 한다.

### 배치의 의도를 파악하고 연주하기

패턴을 한 번 본 뒤 현재 손 상태와 다음 노트의 연결을 바탕으로 의도된 연주 방법을 파악한다. 그 이해를 바탕으로 다음 시도에서 더 수월하게 연주하는 경험을 핵심에 둔다. 같은 노트에 사용할 손·손가락·키를 선택할 수 있는 구조는 이 흐름을 수행하는 수단이다.

---

## 2. 참고한 입력 구조

기존 게임 분석에서는 다음 주제를 참고했다. 상세 분석은 각 자료에 둔다.

| 참고 자료 | 살펴본 주제 |
|-----------|-------------|
| [사운드 볼텍스](../research/soundvoltex.md) | 버튼 간 손 이동과 양손을 나누어 쓰는 입력 |
| [DJMAX 5B](../research/djmax.md) | 중앙 레인 공유와 가변 손배치 학습 |
| [츄니즘](../research/chunithm.md) | 입력 위치의 선택과 홀드 중 다른 입력을 조합하는 방식 |
| [maimai](../research/maimai.md) | 다음 노트를 고려한 손의 동선 |
| [beatmania IIDX](../research/beatmania.md) | 손가락 조합과 배치에 따른 처리 방법의 차이 |

not4k는 이 중 어떤 손·손가락으로 처리할지 선택하는 측면을 PC 키보드의 다중키 바인딩으로 탐색한다.

---

## 3. not4k의 입력 선택

### 기본 구조: 4레인 + 레인당 다중키 바인딩

- 시각적으로는 항상 4개의 레인만 존재한다.
- 유저는 각 레인에 2개 이상의 키를 바인딩한다.
- 싱글 노트는 해당 레인에 바인딩된 키 중 하나로 처리한다.
- 트릴 노트는 직전과 다른 키, 더블 노트는 서로 다른 두 키의 동시 입력을 요구한다. 그 조건 안에서 어떤 키를 사용할지는 유저가 선택한다.

### 배치와 연결에서 생기는 선택

반복 노트에 쓸 키를 교대하거나, 바디를 유지하는 동안 다른 키로 같은 레인의 탭 노트를 처리하거나, 다음 노트를 위해 담당 손을 바꿀 수 있다. 개별 요구는 단순하게 제시하면서, 여러 요구를 이어 처리하는 과정에서 손배치 판단의 깊이를 만든다.

---

## 4. 동작 계획이라는 도전

입력할 키를 선택할 수 있는 만큼, 어떤 손·손가락·키로 처리할지 판단하는 부담이 생긴다. 이것이 not4k가 중심에 두는 동작 계획이다. 풀 정의는 [인지 부하](glossary.md#인지-부하-cognitive-load), 설계 근거는 [RFD 0101](../rfd/0101-cognitive-load-and-action-planning.md)을 따른다.

- **트릴·더블 노트**로 입력 요구를 명시한다. 플레이어는 그 조건에 맞는 키 조합과 손배치를 고른다.
- **난이도 계단**으로 손배치 선택·전환을 점진적으로 익히게 한다. 가장 쉬운 등급에서도 가변 손배치를 조금씩 경험한다.
- **시각적 요구의 단순함**을 유지한다. 종류·속성·동시 조건을 복잡하게 해독하는 데 난이도를 두지 않는다.
- **한 번 눈에 익힌 뒤 재도전하면 대응할 수 있는 정도**를 지향한다. 짧은 사전 경험과 손배치 학습을 허용하며, 긴 손순서의 과도한 암기를 요구하지 않는다.
