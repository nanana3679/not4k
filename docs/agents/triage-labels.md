# Triage Labels

engineering skill들은 다섯 가지 표준 triage 역할을 사용한다. 이 파일은 그 역할을 실제 이슈 트래커 라벨 문자열에 매핑한다.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | maintainer가 이슈를 검토해야 함 |
| `needs-info` | `needs-info` | 제보자에게 추가 정보가 필요함 |
| `ready-for-agent` | `ready-for-agent` | 충분히 명세되어 AFK agent가 바로 작업 가능함 |
| `ready-for-human` | `ready-for-human` | 사람의 구현 또는 판단이 필요함 |
| `wontfix` | `wontfix` | 처리하지 않음 |

skill이 특정 역할을 언급하면 이 표의 오른쪽 라벨 문자열을 사용한다.

라벨 vocabulary를 바꾸려면 오른쪽 열을 실제 GitHub 라벨명에 맞게 수정한다.
