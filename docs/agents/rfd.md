# RFD 작성과 구현 기록

`AGENTS.md`는 RFD가 필요한 조건을 정의한다. 이 문서는 RFD를 작성하거나 구현 진척을 반영할 때만 사용한다.

## RFD 작성

RFD에는 다음 내용을 기록한다.

- 기존 결정과 문제의식
- 검토한 대안
- 채택안과 trade-off
- 영향을 받는 코드와 문서

결정 이후 `CONTEXT.md`와 관련 컨텍스트 문서에는 변경 이력이 아니라 현재 확정된 용어와 규칙을 반영한다. 결정 근거가 필요한 곳에는 관련 RFD 링크를 남긴다.

## 구현 진척 기록

RFD의 구현이 진행되거나 완료되면 문서 상단 `**Status:**` 라인에 마일스톤을 시간순으로 누적한다.

```md
**Status:** Accepted (2026-07-09) · §6-2 박스 감쌈 선택 구현 (2026-07-14, PR #110)
```

`Status`는 완료·미완료 플래그가 아니라 구현 진척 요약이다. 부분 구현이면 잔여 항목을 `Status`나 문서 상단의 "구현 기록" 문단에 명시하고, 항목별 세부 이력은 "구현 기록" 문단에 둔다.
