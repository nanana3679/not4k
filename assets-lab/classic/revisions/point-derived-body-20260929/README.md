# Classic 싱글 롱노트 바디 시안

`sources/point-single.svg`의 푸른 유리와 금속 색을 기준으로 새로 만든 싱글 바디다. 기존 바디와 터미널은 참조하지 않았다. 원본 `body-single.svg`는 1000×200, 게임 텍스처 규격의 `body-single.png`는 200×40이다.

모든 색면과 반사광은 세로로 곧게 이어진다. PNG는 SVG의 가운데 행을 40개 행에 동일하게 복제해 브라우저 렌더링의 미세한 디더링까지 제거했으므로 상하 픽셀이 같다. `/lab/images/point-derived-body-20260929/`에서 포인트 노트와 반복 조립을 확인한다.

이 파일은 디자인 시안이다. 현재 게임의 바디·터미널 상태별 에셋은 변경하지 않았다.
