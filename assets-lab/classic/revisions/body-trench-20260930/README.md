# 트렌치 바디 (2026-09-30 imagegen)

v012 후보의 싱글·더블 바디 원본이다(처음 v009에서 도입). Codex CLI 내장 `image_gen`으로 1024×1536 세로 기둥 이미지를 생성하고(`generated/`, 프롬프트는 `prompt.md`의 `trench`), 가운데 60% 행을 선형광으로 세로 평균해 단면을 뽑은 뒤 좌우 대칭으로 맞춰 1000×200·200×40 타일로 만들었다(`tiles/`). 밝기 보정은 하지 않았다.

- 디자인: 평평한 바깥 면과 가운데 오목한 홈, 홈 안의 가는 빛줄. 모든 요소가 세로 방향이며 위아래로 끊김 없이 반복된다.
- 선택 경위: 1차 6종·2차 10종·3차 세로 전용 9종을 비교한 뒤 사용자가 2차의 트렌치를 선택했다. 가로선 위주 무늬는 포인트와 겹쳐 보여 기각했다.
- 사용: `sources/body-{single,double}-bright.svg`가 `tiles/trench-*-1000x200.png`를 그대로 내장한다. 켜짐 디자인은 추후 결정하며 v012는 기존 생성 규칙의 켜짐 효과를 쓴다.
