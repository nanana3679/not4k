# 트릴 켜짐 바디 frosted-fill (2026-10-01 imagegen)

v014의 트릴 켜짐(홀드) 바디 원본이다. 사용자가 "기둥 느낌을 유지하면서 불 들어오는 느낌", 이어서 "반투명한 사각 기둥 내부에서 빛나는 느낌"을 요청했다.

- 입력: 현재 대기 석영 바디(`sources/body-trill.svg`)를 1024×205로 그려 세로로 쌓은 1024×1536 기둥(`input/body-trill-idle-column-1024x1536.png`). 비교용으로 이전 켜짐 바디도 같은 방식으로 저장했다.
- 생성: Codex CLI 내장 `image_gen`(gpt-6-astra, reasoning xhigh)으로 입력을 편집했다. 1차 6종(core·seam·rails·inner·twin·ice, `prompt.json`)은 기둥 모양은 유지했지만 켜짐이 약하거나 반투명 느낌이 없었다. 2차 5종(`prompt-r2.json`)은 모서리를 앞으로 한 반투명 사각 기둥이 안에서 빛나도록 요청했다.
- 선택: 사용자가 실제 튜토리얼 재생기 시연을 보고 2차의 **frosted-fill**(내부 전체가 조명 상자처럼 빛나는 반투명 기둥)을 확정했다. 원본은 `generated-r2/frosted-fill.png`, 요청문은 같은 이름의 `-output.json`에 있다.
- 추출: 가운데 60% 행을 선형광으로 세로 평균해 단면을 뽑고, 세로로 일정한 1000×200·200×40 타일로 만들었다(`tiles/`). 밝기 보정은 하지 않았다. 원본의 세로 행 평균 표준편차는 0.18(0–255)로 위아래 변화가 거의 없다.
- 사용: `sources/body-trill-on-frosted.svg`가 `tiles/frosted-fill-1000x200.png`를 그대로 내장한다. 석영 켜짐 바디 원본 `sources/body-trill-on.svg`는 석영 미리보기 생성기가 다시 쓰는 파일이라 Classic 빌드 입력에서 뺐다.
- 측정(연결 트릴, 실제 게임 렌더러): 켜진 구간 평균 휘도가 대기보다 +0.153 밝아 이전 켜짐(+0.109)보다 켜짐이 분명하다. 트릴 포인트 경계 2px 대비 하위 5%는 모든 포인트 기준 3.09:1, 켜진 구간에 맞닿은 두 경계만 보면 2.82:1이다(이전 켜짐 3.32:1).

선택하지 않은 생성 원본과 임시 시연 페이지는 PR 크기를 줄이려고 커밋하지 않았다.
