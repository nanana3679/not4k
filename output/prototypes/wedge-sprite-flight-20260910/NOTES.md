# PROTOTYPE — A 관제실 거리별 이미지 비행

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. **한 건물의 거리 4단계 × 시점 고도 2단계를 미리 그려 교체하면, 원하는 미술 스타일을 유지하면서 접근·통과를 표현할 수 있는가?**를 확인하는 독립 시연이다. 기존 비행 시연과 본 게임 소스는 이 실험에 연결하지 않았다.

## 실행

저장소 의존성이 설치된 환경에서:

```sh
cd output/prototypes/wedge-sprite-flight-20260910
npm start
```

Tailscale IPv4에 임의 포트·토큰으로 24시간 공유한다. 현재 접속 링크는 `preview-state.json`에 기록한다. PC와 Tailscale 연결이 유지되어야 한다. 서버는 명시한 HTML·CSS·실행 모듈·에셋 목록·최종 PNG 8장·만료 시각만 제공하며 다른 프로젝트 파일은 제공하지 않는다. 파일은 시작 시 메모리에 읽으므로 변경 후 해당 시연 서버를 다시 실행한다. 이미지 생성기나 Python은 **재생할 때 필요하지 않다**. 배경 제거를 다시 하거나 에셋 검사를 실행할 때 Python 3 + Pillow가 필요하다.

## 조절과 동작

- 처음에는 낮은 시점, 속도 1000%, 크기 100%, 짧은 혼합, 자동 전진이다. 움직임 줄이기 환경에서는 정지로 시작한다. `paused=0`을 명시하면 재생한다.
- 이 시연의 속도 100%는 한 번 통과 24초, 1000%는 2.4초다. 과거 시연의 세계 단위와 동일한 속도라고 보장하지 않는다. 속도 0은 전진만 멈추고, 일시정지는 고도 자동 반복도 멈춘다.
- 낮음/높음 버튼과 고도 슬라이더로 밑면/지붕을 비교한다. 고도는 거리·배치·건물 크기를 다시 추첨하지 않는다. 고도 자동 반복은 12초 주기이며 정지와 URL 복원을 따른다.
- 원거리·중거리·근거리·통과 버튼이나 거리 슬라이더는 해당 위치에서 정지한다. 재생 버튼으로 이어서 움직인다. 정지 지점은 진행 20·65·85.5·96%다.
- 건물 크기 50~200%는 같은 거리에 다른 크기의 건물을 배치하는 비교다. 원근 경로는 고정하고 표시 폭만 조절한다. 가까워지며 화면 밖에 걸쳐도 폭을 줄이지 않고 화면이 잘라 보여 준다.
- `assets.json`의 alpha 경계와 끝 표시등 기준점을 맞춘다. 거리 교체 경계는 진행 48·76·91%, 혼합 폭은 각 경계 ±1.8%다. 고도 42~58%에서 낮음/높음을 혼합한다. 혼합을 끄면 각 경계에서 한 장을 즉시 선택한다.
- 혼합 시 가중치 합은 1이다. 별도 캔버스에 가중 이미지를 더한 다음 배경에 합성하여, 일반 알파 중첩 때문에 공통 실루엣까지 불필요하게 흐려지는 문제를 줄인다. 실루엣 자체의 차이는 해결하지 못한다.
- 고정된 앞쪽 점과 성긴 광원이 열린 공간의 전진만 보조한다. 천장·지표면·물리 충돌은 없다. 중앙 4레인은 공간 점유 참고선이며 차트·판정 기능이 아니다.
- 에셋 8장 목록과 원본 PNG 링크를 시연 하단에 둔다. 상태는 URL query로 복원한다. 자동 진행을 매 프레임 URL에 쓰지는 않고 사용자가 조절할 때 현재 상태를 저장한다.

## 관찰과 한계

미술적인 선·색·조명을 이미지 그대로 재생할 수 있고, 낮음과 높음의 차이는 밑면/지붕으로 나타난다. 1000%에서 네 단계가 실제로 표시되고 반복되는 것을 브라우저에서 확인했다. 창문과 표시등의 밝은 부분을 보존한 투명 배경, 좁은 지지대 구멍, 가장자리 확대도 캡처로 확인했다.

**같은 건물을 의도해도 생성된 시점마다 창살·장갑판·지지대 비율이 조금씩 다르다.** 끝 표시등 위치는 고정되지만 전체 윤곽은 일치하지 않는다. 특히 거리 91%·고도 50%에서 정지하면 네 장이 겹친다(`transition-midpoint.png`). 빠른 비행에서의 체감은 직접 비교해야 한다. 고도 변화가 진행 방향을 역전시키거나 뒷면을 드러내는 자유 시점까지 대응하는 에셋 세트는 아니다.

**사용자 평가 (2026-09-10):** “이 방법으로는 이미지 전환이 자연스러울 수 없겠어.” 거리마다 독립 생성한 그림을 교체하는 방식의 확장은 진행하지 않는다. 사용자는 단순한 입체에 2D 표면 그림을 입히는 방향에 동의했다. 후속 [입체 관제실 시연](../wedge-textured-flight-20260910/NOTES.md)에서 같은 건물을 연속 투영한다. 이 시연과 에셋은 비교 기록으로 보존한다.
