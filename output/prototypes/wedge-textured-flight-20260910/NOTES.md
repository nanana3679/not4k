# PROTOTYPE — 입체 관제실과 2D 표면 그림

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. **같은 입체 건물에 그림을 고정하면, 원하는 아니메풍 표면을 유지하면서 고도와 거리 변화가 연속적으로 이어지는가?**를 확인한다. 사용자는 앞선 거리별 이미지 교체에 대해 “이 방법으로는 이미지 전환이 자연스러울 수 없겠어”라고 평가했고, 단순한 입체 + 표면 그림 방향에 동의했다.

## 실행

```sh
cd output/prototypes/wedge-textured-flight-20260910
npm start
```

PC와 Tailscale 연결이 필요하다. 서버가 출력한 비공개 링크는 24시간 유효하며 현재 주소·만료는 `preview-state.json`에 둔다. HTML·CSS·실행 모듈·Three.js·라이선스·그림 3장·만료 시각만 제공한다. 다른 프로젝트 파일은 열 수 없다. 코드를 변경하면 이 시연 서버를 재시작한다. 해당 서버를 종료한 뒤 `node preview-server.mjs --reuse-link`로 실행하면 아직 유효한 기존 주소와 만료 시각을 유지한다.

Three.js **0.186.0**은 이 저장소의 기존 독립 시연에 설치된 동일 버전을 `vendor/`에 복사했다. 라이선스를 함께 보존한다. 재생에 CDN·이미지 생성기·추가 다운로드가 필요하지 않다. 본 게임과 기존 시연은 별도로 유지한다.

## 구성과 조절

- A 쐐기형 관제실 하나: 닫힌 6면 본체, 앞·뒤 창문/문, 실제 두께의 창틀·4개 창살, 후면 고정부, 대각 지지대 2개, 서비스 발판과 난간, 끝 표시등.
- 본체 정점과 각 면의 UV는 처음 생성한 뒤 그대로 유지한다. 거리별 이미지·메시 교체, 고도별 교체, 서로 다른 건물 그림의 혼합은 없다. 화면 경계·가까운 클리핑은 실제 입체 투영이 처리한다.
- 표면 그림은 [별도 생성한 PNG 3장](../../imagegen/wedge-surface-textures-20260910/README.md)이다. 그려진 선과 조명이 유지되도록 `MeshBasicMaterial`과 면별 고정 색조를 사용한다. 깊이와 가림은 WebGL 깊이 버퍼가 처리한다. 동적 그림자나 사실적인 금속 반사는 적용하지 않는다.
- **비행하기:** 안정된 시선으로 한 건물을 향해 전진한다. 고도 0→100%는 카메라 높이 6.5→18.5의 연속 이동이다. 전방 시선 회전·롤은 없다. 건물 기준 높이 10, 전진 z −120→25. 낮으면 밑면과 지지대가 위쪽에 가까워지고, 높으면 지붕이 아래로 지나간다. 천장·지표면은 없다.
- **건물 둘러보기:** 같은 건물을 중앙에 두고 각도 −70~70°와 고도를 연속 조절한다. 관찰 카메라만 건물을 향한다. 비행 중 거리 값은 보존한다. 고도 자동 반복도 여기서 확인할 수 있다.
- 속도 0~1000%, 기본 1000%. 이 시연에서 100%는 한 번 통과 24초, 1000%는 2.4초다. 이전 시연의 세계 단위와 동일하다는 의미는 아니다. 거리 슬라이더와 원거리·중거리·근거리·통과 버튼은 해당 위치에서 정지한다. 재생 버튼으로 이어서 움직인다.
- 건물 크기 50~180%는 세계상 배율을 변경한다. 같은 전진 거리에서 코끝의 가로 여유 3을 유지하고 뒤쪽 구조물이 바깥으로 커지게 배치한다. 고도·전진·표면 그림을 다시 추첨하지 않는다.
- **표면 그림** 체크를 끄면 같은 입체의 단색 표면과 비교한다. 중앙 4레인은 2D 참고선이다. 성긴 2D 보조 광원은 비행 방향을 보조할 뿐 충돌체가 아니다.
- 모든 조절은 URL query로 복원한다. 움직임 줄이기 환경에서는 정지 시작하고 명시적 `paused=0`은 재생한다. 일시정지는 전진과 고도 자동 반복을 함께 멈춘다. 고도 자동 반복은 12초 주기다. 숨겨진 탭에서 누적 시간을 한꺼번에 진행하지 않는다.
- 16:9 화면 아래에 44px 이상 조절 버튼을 둔다. WebGL 2 미지원·텍스처 로딩 실패·컨텍스트 소실은 화면 안내로 표시한다. 휴대폰에서 동일 링크로 볼 수 있다.

## 이번에 확인한 것

**사용자 평가 (2026-09-10): “와 엄청 자연스러워.”** A 관제실 시연의 움직임과 시점 연결에 대한 긍정 평가다. 단순한 입체에 표면 그림을 고정하는 방향의 자연스러움을 사용자에게 확인했다. 이 평가는 다른 건물의 디자인·배치·본 게임 통합까지 승인한 것으로 확대하지 않는다.

고도·거리·관찰 각도를 바꾸는 동안 건물과 geometry UUID, texture UUID가 유지된다. 카메라 높이 49.9→50→50.1%가 연속적으로 움직이고 비행 시선 회전은 없다. 1000% 재생에서도 가까운 끝을 통과할 때 건물의 실제 배율을 줄이지 않는다. 실제 캡처에서 낮음의 밑면과 높음의 지붕, 두 지지대의 가림 변화, 그림을 끈 비교를 확인했다.

이전 이미지 교체 실험의 서로 다른 윤곽 겹침을 만드는 경로는 사용하지 않는다. 다만 이번 모델은 A 그림의 중요한 형태를 단순화한 시안이다. 면에 붙인 창문 내부는 정지된 실내 그림이므로 실제 실내의 시차는 없다. 원본 콘셉트의 모든 형태·음영을 정확히 재현했다거나 미술 완성도가 확정됐다는 의미는 아니다. 다른 일곱 건물은 이 결과를 평가한 뒤 별도로 모델링할 수 있다.

## 검증

```sh
npm test
npm run check:browser
```

단위 **17개**, 브라우저 **56개** 통과. 페이지·콘솔·CSP 오류 0개. 단위 검사는 닫힌 본체의 12개 모서리 공유·바깥 법선, UV의 앞뒤 상하 유지, 표면 이격, 지지대 두께, 카메라 연속성과 크기/거리 독립, URL·정지를 확인한다.

`browser-check.json`과 캡처에서 실제 WebGL 렌더링·UUID 유지·고도별 픽셀·가까운 통과·1000% 반복·표면 그림 켜기/끄기·둘러보기·새로고침·움직임 줄이기·원본 바이트·비공개 경로를 기록했다. 320·390·844·1440px의 16:9·하단 조절·44px 버튼·가로 넘침도 검사했다. Chromium의 소프트웨어 WebGL 검증이며 실물 휴대폰 성능 평가를 대신하지 않는다.
