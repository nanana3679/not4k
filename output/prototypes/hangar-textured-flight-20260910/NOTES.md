# PROTOTYPE — E 대형 격납고의 근접 비행

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. **작은 건물에서 자연스럽다고 평가받은 ‘고정 입체 + 2D 표면 그림’이, 화면 한쪽을 크게 차지하는 대형 건물의 저고도 근접에서도 이어지는가?**를 확인한다. A 관제실에 대한 사용자 평가 “와 엄청 자연스러워” 이후, 대형 건물 하나로 확장하는 제안에 “ㅇㅋ” 응답을 받아 제작했다. E 디자인 자체에 대한 후속 평가는 아직 받지 않았다.

## 실행

```sh
cd output/prototypes/hangar-textured-flight-20260910
npm start
```

PC와 Tailscale 연결이 필요하다. 서버가 출력하는 비공개 링크는 24시간 유효하며 현재 주소·만료는 `preview-state.json`에 둔다. HTML·CSS·명시한 실행 모듈·Three.js·라이선스·PNG 다섯 장·만료 시각만 제공한다. 이 시연 서버를 종료한 뒤 `node preview-server.mjs --reuse-link`로 실행하면 유효한 기존 주소와 만료를 유지한다. 파일은 시작할 때 메모리에 읽으므로 실행 코드·그림 변경 시 이 서버를 재시작한다.

Three.js 0.186.0과 라이선스는 기존 A 시연에서 복사했다. 기존 A, 다른 비행 시연, 본 게임은 별도다. 추가 외부 CDN 없이 재생한다.

## 건물과 움직임

- E 대형 격납고 시안 (`../../imagegen/size-distance-altitude-eight-20260910/05-large-near-low.png`, 로컬 보관)의 두꺼운 양쪽 벽·깊은 개구부·돌출된 상부를 단순화했다. 둥근 모서리 대신 평평한 면과 잘린 모서리를 사용한다.
- 본체는 닫힌 입체 세 개다. 벽 전면에서 30 뒤로 물러난 내부 벽, 전면보다 7 돌출된 상부, 깊이가 다른 트러스 세 열, 내부 통로·발판·난간을 실제 입체로 둔다. 내부 창문 속 장면과 작은 표면 홈은 그림이다.
- 6개 층에 작은 출입문 12개를 둔다. 문 높이 2.8은 A 관제실과 같으며 건물 본체는 높이 약 58이다. 사람 크기의 단서를 통해 대형 모듈의 규모를 표현한다. 단위는 시연의 임의 세계 단위다.
- [새 표면 그림](../../imagegen/hangar-surface-textures-20260910/README.md)은 외벽·밑면 두 장이다. A의 장갑판·문·창문 세 장을 재사용한다. 같은 정점·UV·텍스처를 고도와 거리 전체에서 유지한다. 볼록한 8각 끝면은 삼각형 팬, 사각 표면은 세분화 격자로 렌더링한다.
- **비행하기:** 건물은 z −300→100으로 전진한다. 고도 0→100%는 카메라 높이 36→70이며 시선은 수평 전방으로 고정된다. 기본 크기에서 저고도는 상부 밑면보다 낮고 고고도는 지붕보다 높다. 카메라를 기울이지 않고 고정된 비대칭 투영으로 소실점을 화면 가로 60%에 둔다. 열린 공간 안에서 왼쪽에 큰 건물이 지나간다. 세계를 막는 천장·지표면은 없다.
- **건물 둘러보기:** 같은 건물을 중앙에 두고 −70~70° 각도와 고도를 연속 조절한다. 기본 건물이 잘리지 않도록 관찰 반경 94를 사용한다. 비행 진행률과 옆면 거리 설정은 보존한다. 이 관찰 모드에서는 카메라가 건물을 향한다.
- 속도 0~1000%, 기본 1000%. **A와 같은 세계 속도**인 100%에서 약 6.04 길이/초를 사용한다. 대형 E의 이동 구간은 400이므로 1000%는 한 주기 약 6.62초, 100%는 약 66.21초다. 크기가 커졌다는 이유로 세계 속도를 함께 올리지 않는다. 이 기준은 A와 E 두 시연 사이의 비교다.
- 거리 슬라이더와 원거리·중거리·근거리·통과는 정지 비교다. 재생하면 같은 위치에서 이어 간다. 화면 밖으로 걸치는 부분은 원근과 클리핑으로 잘리며 실제 건물 배율을 줄이지 않는다.
- 건물 크기 50~180%, 옆면과의 거리 2~18을 독립 조절한다. 오른쪽 끝 x 34를 기준으로 가까운 끝의 가로 여유를 유지한다. 크기 변경으로 건물 높이도 변하므로 최대 크기의 지붕을 최고 고도에서 항상 넘어선다고 보장하지 않는다.
- 표면 그림 켜기/끄기, 선택 가능한 중앙 4레인 참고선, 12초 고도 상하 반복, 재생·정지, URL 복원을 제공한다. 움직임 줄이기는 정지 시작하며 `paused=0`으로 명시적 재생이 가능하다. 숨겨진 탭에서는 누적 시간만큼 한꺼번에 이동하지 않는다.
- 화면은 16:9, 조절은 아래에 둔다. 원본 PNG 다섯 장을 하단에서 직접 연다. WebGL 2 미지원·그림 로드 실패·그래픽 연결 소실은 안내를 표시한다.

## 확인과 한계

실제 캡처에서 근거리 저고도는 돌출부와 벽이 왼쪽을 크게 채우고, 같은 거리의 고고도는 지붕이 아래로 지나간다. 둘러보기의 낮은 각도에서는 상부 밑면과 내부 트러스, 높은 각도에서는 지붕을 확인했다. 표면 그림을 꺼도 동일한 입체를 관찰할 수 있다.

같은 텍스처를 큰 면에 늘여 붙이므로 일부 세부 척도와 반복은 미술 수정이 필요하다. 고정된 면 색조와 그려진 빛을 사용하며 동적 그림자는 없다. 낮은 고도가 주는 긴장감과 최종 미술 만족도는 사용자의 시연 평가로 확인해야 한다. 이번 단계는 한 건물의 검증이며 여러 건물의 배치·충돌·플레이 규칙을 추가하지 않는다.

## 검증

```sh
npm test
npm run check:browser
```

단위 **23개**, 브라우저 **64개** 통과. 페이지·콘솔·CSP 오류 0개. 단위 검사는 닫힌 입체·외향 법선·8각 면의 삼각분할 면적, 실제 개구부 깊이·상부 돌출·출입문 규모·표면 이격, A와 동일 세계 속도, 고도 연속성·크기와 거리의 독립·URL 복원을 확인한다.

브라우저는 동일 geometry/texture UUID 유지, 고도별 실제 픽셀 변화, 옆면 거리 18→2와 복원, 1000% 통과·반복, 정지·둘러보기·표면 비교·자동 고도·움직임 줄이기, 320·390·844·1440px의 16:9·하단 조절·44px 버튼·가로 넘침, 실행 파일·PNG 제공 바이트 일치와 비공개 경로를 검사했다. 결과는 `browser-check.json`, 실제 화면은 같은 폴더의 `flight-*.png`, `orbit-*.png`, `viewport-*.png`에 둔다. Chromium과 소프트웨어 WebGL 검사이며 실물 휴대폰 성능 평가를 대신하지 않는다.
