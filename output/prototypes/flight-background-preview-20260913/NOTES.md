# LIFTOFF · INFILTRATION · BREAKTHROUGH 공개 배경 미리보기

2026-09-13. 세 난이도의 비행 배경을 한 페이지에서 비교하는 독립 시연이다. 게임 본편과 판정은 변경하지 않는다. 외부 공개 화면에는 영어 장면 탭과 현재 장면의 고도 슬라이더 하나만 표시한다. 이륙·침투 실행 원본은 이 폴더에 보관하고, 돌파는 인접한 `breakthrough-hangar-integration-20260910` 시연과 여섯 장의 저장된 표면 이미지를 재사용한다.

## 실행과 공개

새 체크아웃에서는 먼저 저장소 루트에서 `pnpm install --frozen-lockfile`를 실행한다. 그 뒤 아래 명령으로 미리보기를 연다.

```sh
cd output/prototypes/flight-background-preview-20260913
npm test
npm start
PREVIEW_URL=http://127.0.0.1:<출력된 포트>/ npm run check:browser
```

서버는 기본적으로 `127.0.0.1`의 임의 포트에 바인딩한다. 인터넷에 임시 공개할 때는 출력된 주소를 Cloudflare Quick Tunnel에 연결한다.

```sh
cloudflared tunnel --url http://127.0.0.1:<출력된 포트>
```

Quick Tunnel 주소는 임시 URL이며 영구 배포 주소로 취급하지 않는다. 서버는 실행 HTML·CSS·모듈·PNG만 명시적으로 허용하고, 테스트·문서·프로젝트 파일과 상위 경로 접근은 제공하지 않는다.

## 확정된 비교 기본값

| 장면 | 속도 | 시작 고도 | 배경·표시 |
| --- | ---: | ---: | --- |
| `LIFTOFF` | 300% | 68% | 기존 별밤·지표면, 오브젝트 100%, Secondary 15%, 레인 숨김 |
| `INFILTRATION` | 600% | 23% | 먹구름 봉쇄 공역 하늘·지표면, 오브젝트 100%, Secondary 15%, 레인 숨김 |
| `BREAKTHROUGH` | 1000% | 0% | 먼 건축 배경 확대 300%, 밝기 10%, F 건물·연장·주변 건축·레인 숨김 |

- 공개 UI는 `LIFTOFF`, `INFILTRATION`, `BREAKTHROUGH` 탭과 각 장면의 `altitude` 슬라이더만 보인다.
- 탭을 바꾸기 전 현재 장면의 URL을 기억하므로 장면별 고도 상태를 유지한다.
- 돌파의 배경 확대 속도와 밝기는 UI에서 숨기고 위 기본값으로 고정한다. 돌파 고도 슬라이더는 실제 `flightStudy` 상태를 갱신한다.
- 이륙·침투의 잔광은 과거 프레임을 저장하지 않고 현재 절대 고도에 비례하는 절차적 선분으로 만든다.
- 침투는 별이 없는 먹색·남색 구름층, 청보라 안개와 희미한 감시광으로 구성한 전용 `sky-infiltration.png`를 사용한다. 이륙은 기존 `sky.png`를 유지한다.

## 이륙·침투 GPU 배치

고고도에서 수백 개 광원 면을 Canvas 2D 호출로 각각 그리던 경로를 WebGL 동적 정점 배치로 옮겼다. 광원 본체와 절대 고도 잔광은 한 정점 버퍼에 기록해 한 번의 광원 draw call로 표시하고, 지표면 원근 무늬도 별도 GPU 삼각형 한 장으로 그린다. 두 동적 버퍼를 번갈아 사용하며 용량은 부족할 때만 늘린다.

GPU 경로는 사용자가 선호한 밀도를 유지하기 위해 보이는 광원을 거리나 개수로 자르지 않고 모두 원래 panel 형태로 그린다. 잔광은 현재 프레임 광원 중 가까운 detail을 우선해 최대 160개 선분만 만든다. WebGL을 열지 못하면 기존 Canvas 2D 경로와 `high → balanced → reduced → minimal` 자동 품질 조절로 폴백한다. 돌파는 이미 Three.js 배치 렌더링을 사용하므로 이 변경의 대상이 아니다.

## 검증

- 독립 단위 테스트 200개 통과: GPU 정점 배치, 절대 고도 잔광, 렌더 품질 폴백, 하늘 선택, 공개 UI와 서버 허용 경로·보안 응답·비정상 요청 격리를 포함한다.
- Playwright 브라우저 검사 22개 통과: 1280×720과 390×844에서 영어 탭, 장면별 고도 슬라이더 하나, 동일한 슬라이더 크기, 넘침·콘솔 오류 없음, 돌파 밝기 10%와 고도 50% 변경을 확인한다. 실제 상호작용으로 이륙·침투 고도 렌더와 URL 반영, 장면별 고도 유지, 딥링크 복원, 키보드 조작, 빠른 연속 전환 후 장면 일치, 움직임 줄이기, 장면별 하늘 한 장 로드도 검증한다.
- 자동 브라우저 검사는 실물 휴대폰 GPU 성능과 미술 최종 승인을 대신하지 않는다.
