# Three.js 연결 시설 비교 시연

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-09. **구조 검토용 임시 코드이며 게임 본편에 연결하지 않는다.**

질문: 연속된 벽에서 이어지는 배관·정비 통로의 돌출량과 높이를 바꿔도, 벽 접속과 바닥 지지가 자연스럽게 유지되는가?

## 실행

이 폴더에서 최초 한 번 `npm ci --ignore-scripts --no-audit --no-fund`, 이후 `npm start`.
`three` 0.186.0만 이 폴더에 설치했다. 본편의 package.json·잠금 파일·Pixi 렌더러는 변경하지 않는다.

서버는 Tailscale 주소에만 바인딩하고 무작위 토큰 링크를 출력한다. 컴퓨터가 켜져 있고 같은 Tailscale에서 접속할 때 사용할 수 있으며 24시간 후 종료한다. 명시한 HTML·CSS·실행 모듈·Three.js 런타임만 메모리로 제공한다. 테스트·패키지·로그·접속 상태·폴더 목록은 제공하지 않는다. 파일 수정 후에는 **이 시연의 서버만** 종료한 다음 `npm start -- --reuse-link`로 유효한 링크와 만료 시각을 보존할 수 있다. 이전 비행 시연 서버와 갤러리는 종료하지 않는다.

## 비교 방법

- `?variant=A`, `B`, `C`: 같은 카메라·벽·시설 구간에서 한쪽 돌출을 통로 폭의 10·20·30%로 변경. 중앙 여유는 양쪽 최대 돌출을 보수적으로 동시에 적용한 80·60·40%다. 화면 픽셀 점유율이나 충돌 통과 판정이 아니다.
- 높이 3~10은 분배관 헤더 중심·정비 통로 바닥의 **기준 높이**다. 난간·상부 주 배관·출입문은 그보다 높다. 발은 지면 y=0에 있고 세로 부재 길이만 바뀐다.
- 벽에서 돌출은 한쪽 8~30%, 세계 폭 36에 대한 경간이다. 벽 연결점은 x=±18에 유지하고 발은 지면 위에서 좌우로 이동한다. 밸브·관경·난간 두께는 통째로 확대하지 않는다.
- 시점 고도 0~100%는 눈높이 `2.5 + 15 × a²`로 변환한다. 기본 22%이며 고도 연동은 기본 해제해 순수 치수를 비교한다.
- 저고도 연동을 켜면 `low = 1 − a²(3−2a)`에 따라 높이 최대 +30%, 한쪽 돌출 최대 +5%p를 추가한다. 한쪽 돌출 상한 30%를 유지하며 실제 적용값을 패널에 표시한다.
- 전방/비스듬히 보기·수평 드래그·전진 재생/정지·초기화. 전진은 46 단위 구간을 반복하는 짧은 비교이며 반복 경계에서 시작 위치로 돌아간다. 기본 정지, 입력을 시작해야 재생한다.
- 노란 접속점과 초록 중앙 여유 띠를 켜서 연결·배치를 볼 수 있다. 연결부 숨김은 주 배관·접속판·지지대를 생략하는 설명용 비교이며 이전 렌더러를 재현한 화면은 아니다.
- 16:9 캔버스와 항상 아래에 있는 조절 UI. 크게 보기·Escape, URL 복원. 좌우 화살표는 점유 단계 전환, 슬라이더에 초점이 있으면 해당 입력의 기본 조절을 유지한다.

## 구조와 범위

연속된 좌우 벽·기둥·상부 보·바닥·천장·배관과 정비 통로를 같은 Three.js Scene에서 렌더링한다. 공통 깊이 가림과 전면 구간의 방향광 그림자를 사용한다. 판독 가능한 중립 단색 모델이며 생성 이미지의 사진 같은 재질을 복제하지 않는다.

좌우 공통 주 배관에서 분기하는 지면 접속 배관 2구간, 벽 출입문과 하부 기둥이 있는 정비 통로 2구간을 고정 배치했다. 모든 구간을 장애물로 채우지 않는다. 높이/돌출을 바꿔도 종류·좌우·진행 방향 위치는 재추첨하지 않는다.

기존 9종 전체의 이식·기존 사각뿔 투영·레인·광원 흐름의 이식은 하지 않는다. **일반 원근 카메라로 구조 연결만 비교하는 별도 시연**이다. 원래 비행 시연 링크로 기존 이륙·침투·돌파와 조절을 열 수 있다. 충돌·물리·판정·점수·실패·데이터 저장은 없다. 본편 채택이나 RFD 0024의 기존 실행 방식 교체를 의미하지 않는다.

## 검증

최종 결과: **단위 26개·브라우저 50개 통과, 페이지·CSP·모듈 로딩 오류 0개** (2026-09-09). HTML·CSS·실행 모듈과 서버 응답의 SHA-256 일치도 확인했다.

- `npm test`: 인접 `model.test.ts`의 Vitest 단위 검사. 점유 3단계, URL 입력/복원, 고도 연동 경계, 최소/최대 치수, 벽 접속·지면 발·엘보 연결, 고정 부품 비율, 설비 사이 빈 구간을 확인한다.
- `node browser-check.mjs`: 설치된 gstack browse의 공유 Chromium을 재사용. 320·390·844·1440px의 16:9·하단 패널·URL 복원·크게 보기와 Escape, Three.js 메시·그림, 점유·고도·연결부 비교, 재생·정지, geometry 수 유지, 비공개 경로와 기존 시연 링크를 검사한다. 결과는 `browser-check.json`이다.
- `compare-A/B/C.png`, `altitude-low/high.png`, `connections-oblique.png`, `mobile-controls.png`: 실제 브라우저 캡처. 이미지 생성 결과가 아니다.
- 헤드리스 브라우저 검사는 실제 휴대폰 GPU 성능이나 자연스러움에 대한 사용자 판단을 대신하지 않는다.

검사 도구 주의: `browse js`는 문자열 결과를 JSON 따옴표 없이 출력하므로 JSON 파싱할 값은 객체로 감싼다. 의도한 비공개 경로의 404 검사는 Node fetch로 수행해 페이지 콘솔의 진짜 오류 검사와 분리한다. gstack 학습 기록 명령은 설치본의 `lib/jsonl-store.ts` 누락으로 실패하여 이 메모에 남겼으며 도구 설치본은 수정하지 않았다.

## 결과

연결점과 바닥 접점을 보존하며 두 종류의 시설을 매개변수로 조립할 수 있음을 구현했다. 사용자가 원하는 건축적 자연스러움에 도달했는지는 링크에서 확인받아야 하며, 확인 후 이 비교를 흡수하거나 폐기한다. 제품 상태와 최종 수치의 미정 사항은 기존 [PRD §12](../../../docs/prd.md#12-미정-사항)를 따른다.
