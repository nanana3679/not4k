# 게임 광원 오브젝트와 배치 브레인스토밍 · 23

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

사용자는 시안 22가 게임에서 너무 멀어졌다고 평가했다. 원하는 작업은 풍경의 분위기 개선이 아니라 **어떤 광원 오브젝트를 어떻게 배치할 것인지에 대한 시각적 브레인스토밍**이라고 명확히 했다.

내장 `image_gen`에 시연 18의 실제 난이도별 게임 화면을 참고 이미지로 제공했다. 중앙 4레인과 난이도별 시점을 기준으로 난이도마다 A/B/C 세 안을 생성했다. 각 PNG는 가로 게임 화면 세 개를 세로로 쌓은 비교표다. 각 행은 고도 변화나 시간 순서가 아니라 서로 다른 오브젝트·배치 후보이다.

| 난이도 | 이미지 | 프롬프트 | A · 낱개 | B · 쌍 | C · 무리 |
| --- | --- | --- | --- | --- | --- |
| 이륙 | 비교표 (`./01-이륙-오브젝트-배치.png`, 로컬 보관) | 프롬프트 (`./01-liftoff.prompt.txt`, 로컬 보관) | 드문 수직 면과 작은 단일 면 | 높이가 다른 수직 발광 면 두 개 | 수직·기울어진 면 세 개의 방향성 있는 묶음 |
| 침투 | 비교표 (`./02-침투-오브젝트-배치.png`, 로컬 보관) | 프롬프트 (`./02-infiltration.prompt.txt`, 로컬 보관) | 길이가 다른 가로 면 | 길이와 위치가 어긋난 가로 면 두 개 | 짧은 면 서너 개가 만드는 끊긴 대각선 흐름 |
| 돌파 | 비교표 (`./03-돌파-오브젝트-배치.png`, 로컬 보관) | 프롬프트 (`./03-breakthrough.prompt.txt`, 로컬 보관) | 크기·방향이 다른 개별 삼각형 | 큰 삼각형과 작은 삼각형의 어긋난 쌍 | 높이·깊이가 다른 삼각형 세 개의 묶음과 공백 |

작은 반복 가능한 발광 면을 사용하고, 형태뿐 아니라 한 묶음의 크기, 무리 사이 간격, 가까운 면과 먼 면의 대비를 비교한다. 이륙의 청록·호박색, 침투의 보라·민트색, 돌파의 주홍·청록색은 비교의 기준으로 유지한다. 팔레트의 정확한 선택 비율을 검증하는 결과물은 아니다.

게임의 시점과 레인 판독을 참고한 생성 이미지이며 실제 구현 결과나 플레이 가능한 시연은 아니다. 코드와 앞선 시연은 변경하지 않았다. 특정 후보를 채택하거나 게임 규칙을 바꾸는 결정은 하지 않는다.

생성 원본·참고 이미지 경로는 `manifest.json`에 기록한다. Happy 갤러리는 세 비교표의 전체 보기와 원본·두 손가락 확대를 제공한다. 생성된 행 높이가 일정하지 않아 고정 격자로 자르지 않는다. 기존 Tailscale 연결을 사용하며 임시 링크와 검증은 `gallery-check.json`에 기록한다.
