# A 관제실 — 입체에 붙이는 표면 그림

2026-09-10. 시점별 그림 교체의 부자연스러움을 확인한 뒤, 사용자가 동의한 **단순한 3D 형태 + 2D 아니메풍 표면 그림** 실험용이다. 이전 A 관제실 (`../wedge-distance-altitude-assets-20260910/low-near.png`, 로컬 보관)의 색·선·재질을 참고해 면에 붙일 그림만 새로 생성했다.

| 파일 | 실제 해상도 | 적용 위치 |
| --- | --- | --- |
| `armor.png` | 1254×1254 | 본체·지붕·밑면·후면 고정부·지지대 |
| `window.png` | 2172×724 | 앞·뒤 관제실 창문 |
| `door.png` | 1024×1536 | 앞·뒤 서비스 출입구 |

**생성 모드: 내장 `imagegen`, 스타일 참고 이미지를 사용한 표면 텍스처 생성.** 입력·실제 프롬프트는 [prompts.json](prompts.json), 생성 원본 경로·실제 해상도·SHA-256은 [manifest.json](manifest.json)에 기록했다. 생성 결과를 수정하지 않고 그대로 프로젝트에 복사했다. 이번 그림은 면을 채우는 불투명 이미지이므로 배경 제거·alpha 처리가 필요하지 않다. CLI/API 모델 경로는 사용하지 않았다.

장갑판은 넓고 성긴 판 이음새, 창문은 주황색 조명과 좌석 실루엣, 출입구는 각진 문과 표시등을 포함한다. 실제 입체의 창틀·창살·기둥 두께·대각 지지대가 형태와 가림을 담당한다. 생성 그림은 같은 UV에 계속 붙어 있으며 거리·고도별로 교체하지 않는다. 창문 속 실내는 그려진 이미지이며 별도의 실내 3D 공간은 아니다.

적용 결과는 [입체 관제실 시연](../../prototypes/wedge-textured-flight-20260910/NOTES.md)에서 확인한다. 시연 하단의 세 그림을 누르면 원본을 열 수 있다. 이전 8장 전체를 정밀한 3D 모델로 복원한 결과가 아니라 A 한 종류의 형태와 표면 방식을 검증한 결과다.
