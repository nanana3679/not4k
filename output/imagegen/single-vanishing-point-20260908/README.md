시안 27의 추상적인 형태와 색감을 유지하면서 하나의 소실점에서 광원과 면들이 퍼져 나오도록 요청한 이미지 편집이다. 내장 `image_gen.imagegen`에 난이도별 시안 27의 두 번째 편집 결과를 제공했다.
