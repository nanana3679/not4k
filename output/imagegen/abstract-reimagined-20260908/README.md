첫 편집에는 기체·인물·건축물의 형태가 많이 남아, 배경의 구체적인 대상을 지우고 추상적인 면으로 다시 그리도록 한 차례 더 수정했다. 첫 편집과 프롬프트는 `-v2`가 없는 파일로 보관한다.
