# 먼 건축 배경 그림

사용자는 추가 입체 건축과 별개로, 검게 비어 있는 화면을 먼 건축물이 그려진 배경으로 채우고 싶다고 설명했다. 예전 천장·바닥·벽면 그림처럼 주변 공간의 분위기를 담당하는 이미지다.

`distant-architecture.png`는 내장 imagegen으로 생성한 원본 PNG다. 이전 `lower-depth.png`는 환경 재질 참고, 통합 시연의 `space-alt-0-0-1.png`는 가까운 E의 명암 참고로 사용했다. 참조 스크린샷 자체를 수정하거나 그림에 광원·HUD를 구워 넣지 않았다. 생성 지시문은 `prompt.txt`, 원본 출처와 해시는 `manifest.json`에 기록한다.

위·아래·양옆의 날카로운 기계 건축과 공극이 멀리 겹치는 한 장의 배경이다. 현재 적용은 천장·바닥·벽을 독립된 입체 면으로 복원하는 것이 아니라, 건물과 광원 뒤의 전체 원경 그림이다. 본편 에셋 확정이나 사용자 미술 승인을 의미하지 않는다.

적용 위치: [빛과 A~H 통합 시연](../../prototypes/breakthrough-hangar-integration-20260910/NOTES.md). `backdrop=architecture`로 표시하고 밝기를 비교한다. 기존 입체 주변 건축과 하부 연결은 별도 선택이다.
