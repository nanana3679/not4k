# 돌파 스크린샷 기반 이미지 생성 · 2026-09-09

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

사용자 지정 기본값: 구조물 간격 **4**, 두께 **2**, 벽면 구조물 밝기 **30%**. 외곽 좌우 2면에만 구조물을 놓고, 크기 10%·속도 1000%·직선·고도 중을 유지한다. 바닥·천장 이미지 밝기는 기존 85%다.

1. 실제 시연 스크린샷 (`01-screenshot.png`, 로컬 보관): 1440×810 캔버스. 생성 참고용으로 조절 UI와 임시 레인만 숨겼으며 픽셀 후처리는 하지 않았다. 재생 중 캡처 후보 세 장을 찍고, 바깥 구조물과 짧은 잔상이 보이는 첫 번째를 사용했다.
2. 이미지 생성 결과 (`02-repaint.png`, 로컬 보관): 위 스크린샷을 `referenced_image_paths`로 전달해 **내장 image_gen**으로 생성했다. 공통 소실점과 성긴 외곽 구조물을 유지하며, 어두운 아니메·메카닉 분위기의 형태·명암·재질·빛의 흐름을 다듬는 프롬프트다. 결과는 시각 비교용이며 시연 렌더링에 적용한 에셋은 아니다.

- 전체 프롬프트 (`prompt.txt`, 로컬 보관)
- 생성 방식·원본 경로·설정 (`manifest.json`, 로컬 보관)
- 실제 캡처 시점과 화면 상태 (`capture.json`, 로컬 보관)

새 기본값은 시연의 최초 진입과 처음 설정 복원에 모두 반영했다. 예전 URL에 조절값이 명시되어 있으면 해당 URL 값이 우선한다.
