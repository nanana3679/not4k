# 소형·대형 × 가까움·멀음 × 낮음·높음 — 서로 다른 디자인 8개

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. 사용자 요청은 2×2×2 조합 8개이며, 후속 피드백 “너무 비슷하게 생겨서 디자인이 다양했으면”을 반영하여 각 칸에 다른 건축 실루엣과 용도를 배정한다.

낮음·높음은 카메라의 비행 고도로 해석한다. 낮은 시점은 옆면·아랫면, 높은 시점은 윗면이 읽히도록 요청한다. 크기와 거리는 독립이며 대형 근접 건물이 화면 한쪽을 압도하는 경우를 포함한다.

내장 imagegen으로 이미지 입력 없이 8장을 각각 새로 생성한다. 공통 화풍과 팔레트는 프롬프트로 유지하며 건축 형태·빈 공간·용도를 다르게 지정한다. 같은 건물의 정확한 원근 비교가 아니라 서로 다른 건축 디자인의 구도 시안이다. 실시간 구현·고도 규칙은 변경하지 않는다.

| --- | --- | --- |
| 소형·가까움 | A 쐐기형 관제실 | B ㄱ자 정비 데크 |
| 소형·멀음 | C 수직 설비탑 | D 이중 통로 모듈 |
| 대형·가까움 | E 분리형 대형 격납고 | F 열린 도크 |

정확한 프롬프트 8개 (`prompts.json`, 로컬 보관). 이전 미실행 프롬프트는 prompts-before-design-variation.json에 보존했다.

## 사용자 피드백 — 2026-09-10

사용자는 최종 8종 비교판에 “마음에 들어”라고 답했다. 서로 다른 건축 실루엣과 용도를 갖춘 각진 2D 메카닉 아트 방향을 후속 에셋 제작의 참고 기준으로 남긴다. 크기·거리·고도를 독립적으로 조합하며, 대형 근접 구조물이 화면 한쪽을 크게 점유하는 압박감과 낮음·높음에 따른 옆면·아랫면·윗면의 차이를 유지한다.
