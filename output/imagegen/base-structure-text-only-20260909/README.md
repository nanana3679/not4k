## 구성 기준

글자 모양을 독립적으로 세우는 방식 대신, 하나의 시설에 필요한 배관·정비 통로·골조를 먼저 구성한다. ㄱ·ㅠ·ㅓ·+ 등은 유용한 시설 부재가 연결된 결과로 읽히는 실루엣이며 9종 모두를 한 화면에 강제로 넣지 않는다. 구조 확인을 위해 밝은 회색 계열과 절제된 재질을 요청했다. 스크린샷이나 기존 시안을 입력으로 전달하지 않았고, 이전 구도 보존을 요구하지 않았다.

## 결과에서 읽히는 연결

- 왼쪽 설비실의 배관이 벽 브래킷에 지지되고 분기·엘보를 거쳐 두 수직 관으로 이어진다. 두 관 모두 같은 바닥의 접속부까지 연속된다. 두 다리 사이 아래쪽 가로관은 없다.
- 오른쪽 정비 통로는 출입구·연속된 벽면 통로와 연결되며 하부 보와 기둥이 통행면을 받친다. 난간과 뒤쪽 계단이 이동 경로를 보여 준다.
- 기둥·층 바닥·큰 보·지붕 골조는 전후 방향으로 이어지는 건물 구조를 이룬다. 독립 벽판 대신 두꺼운 벽·기둥·설비실의 깊이가 드러난다. 중앙은 비어 있는 통로다.

큰 구조의 연결을 확인하는 자료이며 생성 이미지의 배관 경로·부재 접합을 공학적으로 검증한 것은 아니다. 원래 요청한 무재질 회색 모형보다 콘크리트 표면 질감과 약한 반사가 남아 있다. 밝은 작업등·높은 상부 연결교·전체 시설 밀도는 구조를 읽기 위한 생성 결과로, 돌파 시연의 새 조명·충돌·고도 규칙을 채택한 것이 아니다. 세부 구조와 형태의 채택은 사용자 확인 전이다.
