## 이후 모델에서 조절할 값

- **설치 높이:** 건물의 층 또는 구조물의 설치 위치. 하강 시 구조물이 상대적으로 높아지는 연출과 연결할 수 있으나 현재 이미지에는 동작이 없다.
- **구조물 높이:** 상판·지지보·교각의 높이와 층간 규모. 전체 이미지를 세로로 늘리는 대신 큰 부재의 치수를 조절하고 난간·계단 등 인간 기준 크기는 유지한다.
- **벽으로부터의 거리:** 연결교의 경간, 발코니의 돌출 깊이, 브리지의 남은 길이. 연결부에서 부재 길이나 반복 단위를 조절하며 벽과 떨어져 떠 있는 형태를 만들지 않는다.
- **중앙 접근:** 배치 평면을 중앙으로 옮기는 후속 연출에서도 건물의 단차나 전면부와 연결된 인상을 유지한다. 화면 중앙을 얼마나 좁힐지는 실제 시연에서 비교할 항목이며 이미지가 검증하지 않는다.

이 값은 제작·배치 조절값이다. 피스톤이나 신축 암을 드러내 구조물이 기계처럼 늘어나는 모습을 의미하지 않는다. 고도 연동, 하단 조절 UI, 입체 모델은 형태 확인 후의 별도 구현 단계다. 자세한 시각 제약은 DESIGN.md (`DESIGN.md`, 로컬 보관)를 따른다.
