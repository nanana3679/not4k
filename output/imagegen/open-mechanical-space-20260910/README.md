# 개방형 메카닉 공간 — 건물 모듈 점유 비교

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. 사용자는 연속된 천장·바닥이 장애물 설계를 경직되게 만든다고 보고, 무한성의 개방된 다층 공간을 참고해 장애물을 작은 배관이 아니라 건물의 한 모듈 크기로 구성하자고 제안했다. 권장 방향에 대한 동의를 받아 시점의 위아래와 2D 메카닉 그림체를 유지한 정적 시안 세 장을 생성했다.

## 범위

내장 `image_gen`으로 B 기준 장면을 설명만으로 생성하고, B를 입력으로 A·C의 가까운 건물 점유를 편집했다. 스크린샷이나 무한성 이미지는 입력하지 않았다. 무한성은 떨어진 건물층과 깊은 공간이라는 구성 아이디어의 참고이며 목조 건축·등장인물·작품 로고를 복제하지 않는다. 전체 입력은 prompts.md (`prompts.md`, 로컬 보관)에 보존한다.

- A — 열린 공간 (`A-open.png`, 로컬 보관): 가까운 건물을 좌우 밖으로 옮겨 개방감을 키우는 안.
- B — 중간 공간 (`B-medium.png`, 로컬 보관): 건물 모듈의 용도와 사이 공간을 함께 읽는 기준안.
- C — 근접 공간 (`C-close.png`, 로컬 보관): 같은 건물의 돌출부가 더 중앙에 접근하는 근접안.

목표 점유는 비교를 위한 대략적인 미술 지시다. 이미지의 실제 픽셀 점유율을 측정한 값이나 구현된 좌표가 아니다. 세 장은 생성 편집 결과여서 동일 프레임의 정확한 기하 변환으로 해석하지 않는다.

## 고정한 요소

2D 아니메 메카닉 패널·선·명암, 차콜/건메탈과 절제된 주황 작업등, 위아래가 안정된 전방 시점, 중앙 레인을 위한 여백, 격납고·관제실·정비 층으로 읽히는 큰 덩어리를 유지한다. 작은 문·창·난간·배관이 건물의 크기를 설명한다. 연속된 바닥·천장 대신 여러 깊이의 시설이 상하 틈으로 이어진다. 각 건물 안에서는 층·보·난간·방이 연결되고, 전체 공간의 물리적 지지는 비현실적이다.

## 아직 구현하지 않은 것

이번 결과는 배경 정적 시안이며 시연 코드·렌더러·게임 본편·고도 규칙·충돌 판정을 바꾸지 않았다. 중앙 레인과 하단 조절도 이미지에 가짜 UI로 그리지 않았다. 배경을 실제 시연에 적용할 때 해당 인터페이스를 유지하는 것은 후속 구현 조건이다. 고고도일수록 넓어지는 느낌은 아직 검증하지 않았으며, 어느 안을 적용할지도 사용자 확인 전이다.

기존 RFD 0025의 장애물 복원 시연과 이전 이미지·갤러리는 덮어쓰지 않는다. 이미지·문서만 추가하므로 Vitest는 재실행하지 않는다.

## 전달 및 확인

세 안 비교 갤러리 (당시 비공개 링크는 로컬 백업에 보관)는 A, B, C 순서다. Happy에서 인라인 이미지가 보이지 않는 문제 때문에 `happy-image-viewer`로 선택한 세 원본만 공유했다. 열람 기기의 Tailscale 연결과 호스트 실행이 필요하며 2026-09-11 08:58 KST에 만료된다. 만료되어도 이 폴더의 원본은 유지된다.

세 이미지의 시각 확인을 마쳤다. A는 멀리 있는 시설이 더 많이 보이고, B는 건물의 용도와 열린 공간이 함께 읽히며, C는 가까운 건물 사이를 통과하는 압박감이 강하다. 이는 정적 구도에 대한 관찰이며 플레이 가독성이나 고도 변화에 대한 검증 결과는 아니다.

갤러리·개별 확대·원본 URL의 HTTP 200 응답을 확인했고, 세 원본 응답의 SHA-256이 각각 로컬 이미지와 일치한다. 휴대폰에서 실제로 열리는지는 사용자 확인이 필요하다.
