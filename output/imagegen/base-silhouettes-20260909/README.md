2026-09-09. **함께 섞어 쓰는 정적 입체 시안 5종.** 하나를 고르는 대안이 아니다. 사용자가 확인한 기지 건축물 방향을 유지하되, 다리에 한정하지 않고 파이프·덕트·설비 기둥·정비 통로로 넓혔다. 실제 모델·고도 연동·하단 조절 UI는 이번에 구현하지 않았다. 기존 미리보기·갤러리·게임 코드는 보존했다.

원형 관, 각진 덕트, 세로 골조와 통행면을 구분해 같은 사각 블록의 길이만 바꾼 느낌을 피한다. 큰 실루엣은 단순하게 읽히되 플랜지·분기·내부 배관·지지보로 입체 깊이와 용도를 표현한다. 필요하면 ㄱ자 덕트·ㅓ자 배관 등 같은 형태를 다른 용도로 변형할 수 있다. 연결교도 사용할 수 있지만 전체 형태군의 필수 소재가 아니다.

## 높이·벽 이격 조절을 위한 기준

설치 높이, 세로 구간 길이, 벽에서 돌출되는 길이를 독립 값으로 나눈다. 직선 구간과 반복 부재를 늘리고 엘보·분기·플랜지·난간 높이는 유지한다. 벽 연결부와 지지부도 이어지게 하며 신축 암이나 피스톤이 튀어나오게 하지 않는다. 고도 하강 시 높이·중앙 접근을 강화하는 논의는 유지하되 이 정적 시안이 움직임을 구현하거나 검증한 것은 아니다. 상세 기준은 DESIGN.md (`DESIGN.md`, 로컬 보관)를 따른다.

## 생성 및 육안 확인

- 내장 `image_gen` 도구로 신규 생성 5회. 각 1536 × 1024 PNG. 입력 참조 이미지·외부 CLI 없음.
- 최종 이미지 5장을 이 폴더에 저장했다. 원본 위치와 전체 프롬프트는 prompts.md (`prompts.md`, 로컬 보관)에 기록했고 원본도 보존했다.
- 다섯 주 형태, 건물 연결부, 원형/사각 단면과 입체 깊이를 육안으로 확인했다.
- 보조 그림은 대체로 정면도이나 C는 덕트 끝면을 보여준다. 도면처럼 투영 방향이나 축척이 일치하는 자료는 아니다.
- 생성된 작은 글자·접합 디테일은 확정 사양이 아니다. D의 표기는 π처럼 보일 수 있으나 의도한 형태는 상부 관에서 두 관이 내려오는 ㅠ이며, 이 문서의 분류를 기준으로 한다.
- 구조 안전·배관 설계 검증 자료가 아니라 게임 환경 콘셉트다. 작은 부품은 실제 메시 제작 시 정리할 항목이다.
