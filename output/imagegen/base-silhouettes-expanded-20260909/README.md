## 조절 기준

ㅠ자에서 지면 접점은 고정한다. 높이를 올릴 때 전체 구조물을 공중으로 옮기지 않고 두 수직 구간을 늘려 상부 관의 높이를 바꾼다. 벽과의 거리는 바닥 평면 위 기초 위치와 벽 연결 구간 길이를 함께 바꿔 맞춘다. 분기·엘보·플랜지·밸브의 비율은 유지한다. 지면 지지형 ㅜ·+도 같은 기준을 적용할 수 있다. 세부는 DESIGN.md (`DESIGN.md`, 로컬 보관)를 따른다.

이 폴더는 정적 디자인 원본을 보관한다. 생성 당시에는 독립 높이·벽 거리 조절이나 고도 연동을 구현하지 않았다. 이후 사용자가 9종 구현을 요청해 [별도 시연의 실제 입체 메시·하단 조절·고도 연동](../../../docs/spec/flight-visual-prototype.md#돌파-건축-구조물-9종)으로 연결했다. ㅠ의 두 지면 접점과 각 시설의 접속·지지 부재를 유지하며, 게임 본편과 충돌 판정은 추가하지 않았다. 결정은 [RFD 0024](../../../docs/rfd/0024-breakthrough-architectural-modules.md)에 기록한다. 이 시안 PNG를 평면 판으로 배치한 것은 아니다.

## 생성 및 확인

- 내장 `image_gen` 도구 사용. D2는 기존 D의 이미지 편집, F·G·H·I는 신규 생성이다. 외부 CLI는 사용하지 않았다.
- 각 1536 × 1024 PNG, 최종 5장을 이 폴더에 저장했다. 원본 위치·편집 입력·전체 최종 프롬프트는 prompts.md (`prompts.md`, 로컬 보관)에 기록했다.
- D2의 주 그림과 보조 그림 모두 두 발이 기초를 통해 연속된 바닥에 닿는 것을 확인했다. 각 신규 시안의 ㅜ·ㅓ·ㅏ·+ 주 실루엣과 지지·접속도 육안으로 확인했다.
- 생성된 보조 그림은 축척이나 상세 부품이 일치하는 CAD 도면이 아니다. 구조 안전·배관 설계를 검증한 자료로 사용하지 않는다.
- F·G·H·I의 생성 배경에 실외 하늘·원경이 포함되어 있다. 이번에 확인하는 것은 구조물과 연결부이며, 이를 `Breakthrough`의 실외 배경이나 지평선 채택으로 해석하지 않는다. 본 시연의 실내 공간 방향은 변경하지 않았다.
