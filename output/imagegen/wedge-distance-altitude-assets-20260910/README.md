# A 관제실 — 거리·고도별 이미지 에셋

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. 사용자가 거리별로 그린 이미지를 교체하는 방식을 요청해 만든 **동일 건물 한 종류의 시연용 8장**이다. 승인된 A 쐐기형 관제실 (`../size-distance-altitude-eight-20260910/01-small-near-low.png`, 로컬 보관)을 기준으로 한다. 다른 건물 종류까지 확장하거나 본 게임에 적용한 결과는 아니다.

| 거리 | 낮은 시점 | 높은 시점 |
| --- | --- | --- |
| 원거리 | `low-far.png` | `high-far.png` |
| 중거리 | `low-middle.png` | `high-middle.png` |
| 근거리 | `low-near.png` | `high-near.png` |
| 통과 | `low-pass.png` | `high-pass.png` |

최종 PNG는 모두 1536×1024 RGBA다. 낮은 시점은 밑면, 높은 시점은 지붕과 서비스 발판을 보여 준다. 거리별 그림은 창문이 있는 옆면의 원근을 달리 요청했다. 이미지 자체는 해상도를 확보하기 위해 크게 그렸고, 화면 크기는 재생기에서 조절한다. 밝은 창문, 뒤쪽 출입구, 두 대각 지지대, 오른쪽 끝 표시등으로 건물의 동일성을 유지한다. 생성 과정에서 창살 간격·장갑판·지지대의 세부와 원근에는 차이가 남았다. 정밀한 동일 3D 모델의 투영 결과로 취급하지 않는다.

## 생성과 배경 제거

- **생성 모드:** 기본 내장 `imagegen`. CLI/API 모델 경로는 사용하지 않았다.
- **실제 프롬프트:** prompts.json (`prompts.json`, 로컬 보관), 입력·원본 경로와 최종 파일 매핑은 manifest.json (`manifest.json`, 로컬 보관). 개별 `*-generation.json`도 보존한다.
- 최초 분리 요청과 배경 제거 재요청 모두 실제 alpha 없이 체크무늬가 그려진 RGB를 반환했다. 원본은 `low-near-initial-source.png`, `low-near-v2.png`와 각 생성 기록으로 보존한다. 이 두 파일은 실행 에셋이 아니다.
- 이를 건물 동일성 참고로 사용해 **흰 단색 배경의 8개 시점**을 별도 생성했다. 수정하지 않은 생성 원본은 `*-source.png`다.
- 사용자가 코드로 배경 제거를 제안한 질문에 **“배경 제거”**라고 명시적으로 답한 뒤, Python + Pillow의 remove-background.py (`remove-background.py`, 로컬 보관)를 적용했다. 흰 영역의 연결 관계와 주변의 따뜻한 조명색을 구분해 바깥 배경·지지대 사이 구멍을 제거하고, 창문·표시등의 흰 발광 중심을 보존한다. 이전 흰 배경이 남는 외곽 1px를 줄이고 가장자리 alpha를 부드럽게 만든다. 불투명 내부 RGB와 원본 해상도는 유지한다.
- alpha-check.json (`alpha-check.json`, 로컬 보관)에 최종 alpha 통계·영역·경계가 있다. 투명 여백과 불투명 본체, 지정한 끝 표시등 기준점의 alpha 255를 검사했다. 이 제거기는 이번 흰 배경·어두운 기계 건물 세트용이며 임의의 사진용 배경 제거기가 아니다.

재생성 없이 배경 제거만 재현:

```sh
python3 output/imagegen/wedge-distance-altitude-assets-20260910/remove-background.py
```

## 시연

[거리별 이미지 비행](../../prototypes/wedge-sprite-flight-20260910/NOTES.md)의 `assets.json`이 alpha 경계와 **오른쪽 끝 표시등 중심**의 원본 좌표를 기록한다. Canvas 2D에서 이 점을 맞추고 이미지 교체·이동·균일 확대만 수행한다. 코드에서 건물의 면·회전·원근을 다시 그리지 않는다. PNG 원본 8장은 시연 하단에서도 확대할 수 있다.

아직 검증이 필요한 미술적 한계는 재생기 NOTES의 관찰에 기록했다. 특히 고도와 거리가 동시에 전환되는 정지 화면에서 윤곽이 여러 개 보이는 현상이 있으며, 자동 검사 통과가 자연스러운 움직임에 대한 사용자 평가를 대신하지 않는다.
