## 모델링에서 분리할 축

- `H`: 구조물 높이. 벽측 세로 레일·슬라이더와 신축 지지부에서 조절하며 고정 비율의 장갑을 늘이지 않는다.
- `D`: 벽에서 통로 안쪽으로 나온 거리. 벽측 고정점은 유지하며 수평 신축 연결부의 길이를 조절한다. `H`와 독립적인 모델 입력으로 둔다.
- 지지대는 양끝 연결을 유지하고, 장갑판·볼트·슬롯의 비율과 개수는 상태 변화로 바뀌지 않도록 모델링한다.
- 좌우 배치는 같은 모델을 미러링한다. 높이와 이격을 고도에 연결하는 곡선은 형태 확인 뒤 별도 시연에서 조절한다.
