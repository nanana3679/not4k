## 관찰한 어색함과 근거

1. 바닥·천장의 이미지 질감에 비해 새 구조물은 균일한 단색 면이라 서로 다른 표현으로 보인다. `architecture-renderer.mjs`는 재질 색과 면 방향의 밝기를 사용하고, 기존 표면은 별도의 이미지 매핑을 사용한다.
2. 기초가 좌표상 지면에 닿아도 접촉 그림자와 주변광 차폐가 없어 따로 올려 둔 모형처럼 읽힌다. 좌표상의 접지 검증은 시각적인 무게감을 보장하지 않는다.
3. 각 모듈의 `building-spine`이 얇은 독립 판으로 끝나서 연결되는 더 큰 건물이 보이지 않는다. 부재 자체의 접속은 있지만 시설 전체의 연속성이 약하다.
4. 광원은 구조물 뒤에 가려지는 대신 합성 순서상 앞에 그려지는 구간이 있어 공간감이 약해질 수 있다. 이는 `flight.mjs`의 건축 합성 뒤 광원 합성 구조와 일치하지만, 어느 정도 거슬리는지는 움직이는 화면에서 별도 판단해야 한다.

위 항목은 캡처와 구현을 근거로 한 시각적 진단이며, 정식 UI 휴리스틱 점수 평가나 사용자 지각 실험은 아니다.
