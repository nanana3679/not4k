공통 단서는 어두운 2D 아니메풍 야간 비행, 기계 외장 면에서 가져온 지면 모티브, 기둥 없이 빛나는 단순한 면, Primary/Secondary 자동 배색, 짧은 면 잔광이다. 기체·인물·게임 HUD는 넣지 않았다.

- 이륙: 넓은 하늘과 지평, 드문 수직 발광 면, 낮은 밀도, 청록·청색에 호박색·살구색.
- 침투: 지면을 내려다보는 시점, 하늘이 프레임 밖으로 사라짐, 가로 면이 섞인 중간 밀도, 청보라에 민트색.
- 돌파: 낮은 고도의 전방 시점, 위·옆·아래로 스치는 삼각형, 먼 곳에 모이는 원뿔 흐름, 가장 높은 밀도, 주홍·산호색에 청록·청백색. 첫 생성의 긴 잔광은 짧은 삼각형 흔적으로 한 차례 수정했다.

팔레트의 80:20은 생성에 전달한 방향이며 그림의 정확한 픽셀·광원 개수 비율을 보장하는 수치가 아니다. 정지 이미지에서 속도와 고도 변화는 시점·크기·잔광으로 표현한 한 장면이다. 사용자의 최종 선택으로 간주하지 않는다.

원본 생성 파일 경로는 manifest.json (`./manifest.json`, 로컬 보관)에 보존한다. Happy 열람에는 재사용 `happy-image-viewer`를 사용한다. 공개 배포 없이 기존 Tailscale 연결에서 세 이미지만 24시간 제공하며, 원본 저장과 난이도별 확대를 지원한다. 임시 링크의 만료 및 검증 결과는 gallery-check.json (`./gallery-check.json`, 로컬 보관)에 기록한다.
