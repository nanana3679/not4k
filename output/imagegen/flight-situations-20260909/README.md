# 비행 상황을 더한 이미지 · 30

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

사용자가 도시를 내려다보는 등의 상황 설명을 추가하기를 요청했다. 시안 29를 입력으로 내장 `image_gen.imagegen`에 난이도별 상황을 설명해 이미지 편집을 요청했다. 상황은 그림을 위한 맥락이며 이미지 위에 설명 문구로 넣지 않는다.

| 난이도 | 추가한 비행 상황 | 이미지 · 전체 프롬프트 |
| --- | --- | --- |
| 이륙 | 밤의 도시를 내려다보며 고도를 높인다. 도시 불빛이 아래로 넓게 펼쳐지고 지평선 위로 하늘도 보인다. | 이미지 (`./01-이륙-도시-상공.png`, 로컬 보관) · 프롬프트 (`./01.prompt.txt`, 로컬 보관) |
| 침투 | 고도를 낮추며 도시의 시설 구역 안으로 내려간다. 시선이 아래로 기울어 지붕·플랫폼·시설 사이의 틈이 가까이 보인다. | 이미지 (`./02-침투-시설로-하강.png`, 로컬 보관) · 프롬프트 (`./02.prompt.txt`, 로컬 보관) |
| 돌파 | 시설 지대에서 낮은 고도를 유지한 채 빠르게 통과한다. 가까운 지붕과 광원이 아래·옆·눈높이·머리 위로 스쳐 지나간다. | 이미지 (`./03-돌파-저공-통과.png`, 로컬 보관) · 프롬프트 (`./03.prompt.txt`, 로컬 보관) |

프롬프트에서 단일 소실점과 난이도별 배색을 유지하며, 광원의 배치를 도시·지붕·시설 표면과 연결하도록 요청했다. 이미지 탐색용 상황 설명이며 게임 구현이나 비행 규칙 변경은 아니다.

생성 원본과 편집 입력의 전체 경로는 `manifest.json`, Happy 갤러리 주소와 열람 검증은 `gallery-check.json`에 보관한다.
