# 열린 위아래 공간 — 배경 구상 두 장

> 이전 미술 탐색의 설명 기록이다. 당시 이미지·실행 코드·검사 결과는 로컬 원본과 백업에 보관한다. [현재 실행 대상과 보관 범위](../../README.md).

2026-09-10. 모듈 구현과 병행하여 새 천장·바닥 배경을 구상해 달라는 요청으로 생성했다. **내장 imagegen의 스타일 참고 생성 모드**이며, 이전 각진 메카닉 시안 (`../open-module-flight-20260910-codex/03-angular-mecha.png`, 로컬 보관)을 화풍 참고로 사용했다. 기존 시연에 적용하지 않은 분위기 시안이다.

- `upper-void.png`: 위쪽에 매달린 거대 시설과 군락 사이의 열린 공극.
- `lower-depth.png`: 여러 높이의 지붕층과 아래로 이어지는 건축의 깊이.

실제 입력 프롬프트는 prompts.json (`prompts.json`, 로컬 보관), 원본 경로·해상도·SHA-256은 manifest.json (`manifest.json`, 로컬 보관)에 보관했다. 생성 결과를 수정하지 않고 프로젝트로 복사했다. CLI/API 경로나 배경 제거를 사용하지 않았다.

두 그림은 중근경까지 포함한 구상이며, 가까이 스치는 건축물을 그대로 원경 이미지에 고정해 쓰는 최종 텍스처가 아니다. 상부는 커다란 공극, 하부는 지붕과 낙차가 읽힌다. 하부의 먼 건축이 수평 띠처럼 모이는 부분은 최종 제작 시 더 끊어야 한다. 구체적인 레이어·시차·가림 계획은 [통합 설계 제안](../../../docs/design/module-integration-plan-20260910.md)을 따른다.

Happy에서는 [8종 시연](../../prototypes/module-fleet-20260910/NOTES.md)의 ‘새 위아래 배경 구상’ 링크로 브라우저에서 확대할 수 있다.
