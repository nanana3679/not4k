# Gameplay

Gameplay 컨텍스트는 유저가 차트를 선택해 플레이하고, 입력이 판정과 결과로 이어지는 경험을 다룬다.
노트 타입, 피스, 난이도 용어는 먼저 루트 `CONTEXT.md`의 Core domain을 따른다.

## Language

**플레이 세션**:
유저가 하나의 차트를 시작해서 결과 화면에 도달하기까지의 한 번의 플레이이다.
_Avoid_: 게임 실행

**곡 선택**:
유저가 플레이할 곡과 차트를 고르는 흐름이다.
_Avoid_: 파일 선택

**플레이 화면**:
차트가 재생되고 유저 입력이 판정되는 화면이다.
_Avoid_: 게임 화면

**결과 화면**:
플레이 세션이 끝난 뒤 판정 집계, 달성률, 랭크, 풀콤보 여부를 보여주는 화면이다.
_Avoid_: 스코어 화면

**입력-노트 매칭**:
유저 입력을 판정 윈도우 안의 노트에 연결하는 판정 전 단계이다.
_Avoid_: 키 이벤트 처리

**가장 이른 노트 매칭**:
판정 윈도우 안에 여러 노트가 있을 때 시간상 가장 앞선 노트가 입력을 먼저 받는 규칙이다.
_Avoid_: 가장 가까운 노트 매칭

**빈 레인 입력**:
시각적으로 비어 보이는 레인에 입력했지만 판정 윈도우 안의 노트와 연결될 수 있는 입력이다.
_Avoid_: 무시 입력

**처리된 노트**:
판정이 끝나 더 이상 플레이어가 읽거나 입력할 필요가 없는 노트이다.
_Avoid_: 지나간 노트

**콤보**:
Bad 또는 Miss 없이 이어진 연속 판정 수이다.
_Avoid_: 연속 입력 수

**풀콤보**:
Bad 또는 Miss 없이 플레이 세션을 끝낸 결과 상태이다.
_Avoid_: 올콤보

**달성률**:
차트에서 얻을 수 있는 총점 대비 실제 획득 점수의 비율이다.
_Avoid_: 정확도

**랭크**:
달성률을 구간별로 요약한 결과 등급이다.
_Avoid_: 난이도 등급

**오디오 오프셋**:
출력 장치의 소리 지연을 보정하기 위해 음악 재생 기준을 이동시키는 설정이다.
_Avoid_: 판정 오프셋

**입력 오프셋**:
입력 장치 지연이나 개인 체감 타이밍을 보정하기 위해 입력 기준을 이동시키는 설정이다.
_Avoid_: 오디오 오프셋

**리프트**:
판정선 위치를 위로 올려 유저의 시야 중심을 조정하는 플레이 설정이다.
_Avoid_: 스크롤 속도

**서든**:
레인 상단 일부를 가려 노트가 보이는 시간을 줄이는 플레이 설정이다.
_Avoid_: 리프트

**게이지**:
플레이 중 실패 여부를 결정하는 생존 지표이다.
_Avoid_: 달성률

## Relationships

- **플레이 세션**은 하나의 **차트**를 대상으로 진행된다.
- **곡 선택**은 **플레이 세션** 전에 곡과 차트를 결정한다.
- **플레이 화면**은 입력을 **입력-노트 매칭**으로 연결하고 판정을 만든다.
- **가장 이른 노트 매칭**은 노트 배치 순서와 판정 순서를 일치시킨다.
- **처리된 노트**는 읽기 부담을 줄이기 위해 플레이 화면에서 제거된다.
- **결과 화면**은 **달성률**, **랭크**, **콤보**, **풀콤보**를 보여준다.
- not4k에는 **게이지**가 없으므로 모든 **플레이 세션**은 끝까지 진행된다.
- **오디오 오프셋**과 **입력 오프셋**은 서로 다른 지연 원인을 보정한다.
- **리프트**와 **서든**은 판정 규칙이 아니라 시야 조절 설정이다.

## Example dialogue

> **Dev:** "빈 레인에서 누른 입력은 그냥 버리면 되나요?"
> **Domain expert:** "판정 윈도우 안에 노트가 있으면 **빈 레인 입력**으로 Bad가 날 수 있어요. 무조건 무시하면 안 됩니다."
>
> **Dev:** "이 플레이는 중간에 많이 틀렸으니 실패 처리하나요?"
> **Domain expert:** "아니요. not4k에는 **게이지**가 없으니 끝까지 진행하고, **결과 화면**에서 달성률과 판정 분포로 피드백합니다."

## Flagged ambiguities

- **랭크**는 결과 등급이고 **난이도 등급**은 차트 레벨 구간이다.
- **오디오 오프셋**과 **입력 오프셋**은 합치지 않는다.
- **게이지**는 현재 존재하지 않는 개념이며, 달성률이나 랭크와 다르다.
