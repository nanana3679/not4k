# Online Services

Online services 컨텍스트는 not4k가 온라인 전용 게임으로 동작하기 위해 필요한 계정, 권한, 곡/차트 에셋, 저장 흐름을 다룬다.
구체적인 차트 구조는 `src/shared/CONTEXT.md`의 Shared chart model을 따른다.

## Language

**온라인 전용**:
곡, 차트, 기록, 랭킹이 서버 연결을 전제로 동작하는 서비스 방식이다.
_Avoid_: 오프라인 우선

**서버 점검**:
새 접속·새 플레이 진입을 막되 이미 재생 중인 곡은 끝까지 진행하고 결과를 표시하는 운영 상태다. 플레이 중에는 점검 안내를 띄우지 않고 결과 화면에서 알린다([glossary](../../docs/context/glossary.md#서버-점검)).

**비로그인 플레이**:
로그인 없이 플레이할 수 있지만 플레이 기록은 저장하지 않고 랭킹에도 등록하지 않는 상태이다. 키 바인딩 등 로컬 설정과 튜토리얼 통과 여부·마지막 선택 탭과 항목은 브라우저에 저장한다([glossary](../../docs/context/glossary.md#튜토리얼)).
_Avoid_: 게스트 계정

**프로필**:
로그인 유저의 서비스 권한과 개인 기록을 연결하는 사용자 정보다. 설정의 프로필 탭은 비로그인 시 기기의 Guest 닉네임과 로그인 버튼, 로그인 시 닉네임 편집과 로그아웃 버튼을 표시한다([glossary](../../docs/context/glossary.md#프로필)).
_Avoid_: 계정

**admin 권한**:
비공개 곡 접근과 차트 편집기 진입 같은 운영 기능을 허용하는 권한이다.
_Avoid_: 개발자 모드

**곡 메타데이터**:
제목·아티스트·자켓은 같은 곡의 모든 차트가 공유하며, 이 표시 정보만 수정하면 기존 기록과 랭킹을 유지한다([glossary](../../docs/context/glossary.md#곡-메타데이터)).

**곡 타이밍**:
같은 곡의 모든 차트가 공유하는 초기 BPM·BPM 변경 목록·박자표·변박 정보·음원 정렬용 오프셋이다. 게임·에디터 공용 로더는 곡 행의 표시 정보·타이밍을 우선하며, 타이밍 NULL 또는 곡 행 없음일 때 파일 타이밍을 유지한다. 에디터 Save·Save As는 변경된 곡을 `save_song`으로 먼저 확정하며, 타이밍 NULL 곡은 매 저장의 이행 확인을 승인하면 변경이 없어도 열린 차트의 타이밍으로 이행한다([glossary](../../docs/context/glossary.md#곡-타이밍)).

**곡 저장**:
곡의 표시 정보·공통 타이밍·음원·프리뷰 및 플레이 구간을 함께 확정하며 차트 저장과 범위를 분리한다. `songs.timing` 정본과 리비전 기반 저장 함수의 DB 계약은 [RFD 0107](../../docs/rfd/0107-song-timing-storage-and-atomic-saves.md), 의미는 [glossary](../../docs/context/glossary.md#곡-저장)를 따른다.

**곡 에셋**:
플레이에 필요한 음원, `gameplayRange`, 자켓 이미지, 프리뷰 음원, 차트 에셋을 묶은 콘텐츠 단위이다. 프리뷰는 곡마다 본편과 별개의 전용 음원 파일을 필수로 제공하고 로딩 용량을 위해 길이를 5초 이상 15초 이하로 제한하며, 한 번 불러온 프리뷰는 브라우저에 저장해 다음 접속에도 재사용한다([glossary](../../docs/context/glossary.md#곡-프리뷰)).
_Avoid_: 차트 에셋

**차트 에셋**:
특정 곡의 특정 난이도에 해당하는 차트 산출물이다.
_Avoid_: 곡 에셋

**공개 곡**:
차트 에셋이 하나 이상 있어 일반 유저의 곡 선택에 노출되는 곡이다. 곡 자체에 공개/비공개 플래그가 따로 있는 것이 아니라, 차트 에셋 보유 여부로 결정된다.
_Avoid_: 비공개 곡

**비공개 곡**:
차트 에셋이 하나도 없어 일반 유저의 곡 선택에서는 숨겨지고 admin에게만 보이는 곡이다. (별도 privacy 플래그가 아닌, 차트 미보유 상태)
_Avoid_: 공개 곡

**플레이 기록**:
로그인한 플레이어의 완주 기록과 `flightRule`에 따른 곡 도중 실패 종료의 획득 점수는 기록·랭킹 반영 대상에 포함하며 클리어 여부는 독립적으로 보존한다. 직접 중단한 플레이는 기록을 남기지 않는다. 유저가 특정 차트 버전에서 얻은 결과로, Normal/Easy별로 분리하고 같은 설정의 미러 기록은 합친다. 노트 배치가 바뀌거나 곡 타이밍 수정으로 실제 입력 시각이 달라지면 이전 기록을 보관하고 현재 버전 기록만 표시하며, 전송 실패 시 결과 화면에서 안내·재시도를 제공하고 화면을 나가도 미전송 기록을 해당 계정과 연결해 브라우저에 보관해 다음 접속 때 원래 계정으로 로그인되어 있으면 자동 재전송한다. 차트 삭제 후에도 기록은 원래 버전에 보관하고 현재 선택·랭킹에서 제외하며 재등록 시 승계하지 않는다([glossary](../../docs/context/glossary.md#개인-플레이-기록)).
_Avoid_: 랭킹

**닉네임**:
플레이어를 표시하는 이름이다. 로그인 전에는 기기의 Guest 닉네임을, 랭킹에는 조회 시점의 계정 닉네임을 표시한다. 새 계정의 첫 연동 때 계정이 기기의 Guest 닉네임을 가져가며(겹치면 새 번호), 직접 변경하는 닉네임은 중복을 허용한다([glossary](../../docs/context/glossary.md#닉네임)).

**랭킹**:
같은 버전·판정 설정에서 점수와 독립 보존한 풀콤보·올퍼펙트 배지를 함께 표시하며, 올퍼펙트가 풀콤보를 대체한다. 배지는 점수 순위·동점 최초 달성 시각에 영향을 주지 않는다. 같은 차트 버전·판정 설정의 최고 점수를 비교하고, 기록 수치는 점수만 표시한다. 차트별 최고 기록을 다른 유저와 비교해 보여주는 순위이다. Normal/Easy 모두 제공하되 차트 버전·판정 설정별로 순위를 따로 집계하고, 동점은 해당 점수를 먼저 달성한 순서로 정한다([glossary](../../docs/context/glossary.md#랭킹)).
_Avoid_: 플레이 기록

**설정 동기화**:
입력·시각 오프셋과 마스터 볼륨을 제외한 계정 설정을 로컬에 먼저 적용한 뒤 서버와 맞추는 흐름이다. 로그아웃 후나 서버 동기화 실패 시에도 현재 설정을 브라우저에 유지하며, 동기화 실패는 안내한다([RFD 0102](../../docs/rfd/0102-device-local-input-and-visual-offsets.md)).
_Avoid_: 로컬 설정 저장

## Relationships

- 튜토리얼 항목 전체 통과 여부는 비로그인도 브라우저에 저장하며 로그인하면 계정과 동기화한다. 마지막 선택 탭·항목은 해당 기기의 브라우저에만 저장하고 계정과 동기화하지 않는다. 게스트 튜토리얼의 항목 전체 통과 기록은 로그인 시 계정당 1회 인계할 수 있다. 이미 인계한 게스트 기록은 다른 계정으로 재인계하지 않는다. 계정에 귀속된 통과 기록은 같은 계정의 여러 기기에서 계속 공유하며, 로컬에 표시된 계정 기록을 게스트 기록으로 재분류하거나 다른 계정으로 인계하지 않는다.  현재 방법·중간 방법 완료·부분 성공은 동기화하지 않고 재진입 시 첫 방법 0회부터 시작한다([glossary](../../docs/context/glossary.md#튜토리얼)).

- not4k는 **온라인 전용**을 기본 서비스 방식으로 삼는다.
- **비로그인 플레이**는 가능하지만 **플레이 기록**, **랭킹**, **설정 동기화**는 제한된다.
- **프로필**은 유저의 **admin 권한** 여부를 알려준다.
- **admin 권한**은 **비공개 곡** 접근과 **차트 편집기** 진입에 영향을 준다.
- 하나의 **곡 에셋**은 여러 **차트 에셋**을 가질 수 있다.
- **곡**은 **차트 에셋**이 하나 이상 있어야 일반 유저에게 **공개 곡**으로 노출된다 — 차트 에셋 게시가 곧 곡 공개이며, 차트가 없는 곡은 admin에게만 보인다.
- **`gameplayRange`**는 원본 음원 중 실제 플레이 세션에서 사용할 시작～끝 구간이며, 값이 없으면 전체 음원을 사용한다.
- **차트 에셋**은 **Shared chart model**의 차트 언어를 따른다.
- **플레이 기록** 중 최고 기록이 같은 차트 버전·판정 설정의 **랭킹**에 반영된다.

## 저장 구현 경계

`20261101000000_song_timing_and_atomic_saves.sql`은 `songs.timing`·`songs.revision`, `charts.chart_path`·`charts.chart_extra_path`·`charts.revision`과 `save_song`·`save_chart`·`create_chart`를 추가한다. 타이밍 NULL은 미이행으로 차트 JSON 폴백 대상이며, 경로 NULL은 기존 결정적 경로를 뜻한다. 새 차트의 리비전은 0, 덮어쓰기 성공 시 1 증가한다. 공용 로더는 `songs.timing`·`revision`을 조회해 게임 시간 계산·에디터 기본 상태 확정 전에 곡 행을 적용한다. 에디터는 곡 소유 값 전체를 같은 응답에서 읽고 반환 리비전으로 기준을 갱신한다. 에디터 곡 저장은 바뀐 미디어를 고유한 새 경로에 먼저 올리고 `save_song`으로 확정한다. `countOtherSongCharts`는 공유 타이밍 변경 확인에 쓸 다른 차트 수를 읽고, `findDifferingSongCharts`는 이행 확인을 위해 다른 차트 파일의 타이밍을 읽고, 없거나 해석할 수 없는 파일은 비교하지 못한 차트로 따로 돌려준다. Save·Save As는 변경된 곡을 먼저 저장하며, 타이밍 NULL 곡은 변경이 없어도 매번 이행을 확인한다. 이행 확인 취소는 곡 변경·대기 파일을 남기고 차트만 저장하며, 이행된 곡의 공통 타이밍 확인 취소·곡 저장 실패는 전체 저장을 중단한다. 차트 원자적 저장·일반 로더의 새 차트 경로 연결은 PR4b 범위다. 앱 배포 전에 PR1 마이그레이션을 적용해야 한다. 열이 없으면 조회 오류로 로드가 실패하며, 누락 열을 NULL로 간주하지 않는다. 이 문서는 운영 DB 적용 완료를 뜻하지 않는다.

`save_chart(p_chart_id uuid, p_expected_revision bigint, p_difficulty_level integer, p_chart_path text, p_chart_extra_path text)`는 UUID·리비전으로 저장하며 곡·난이도명은 바꾸지 않는다. 같은 곡·난이도로 재생성한 차트는 다른 UUID라 옛 저장은 PT404다. 차트 없는 곡은 삭제·같은 text ID 재등록이 가능하므로 곡의 기존 행·신규 행·`save_song`은 공유 `song_revision_seq`를 써서 옛 리비전을 재사용하지 않는다. `save_song` 서명은 유지하며 호출자는 결번이 가능한 반환 리비전을 보관한다.

세 함수는 기존 `public.is_admin()`으로 첫 쓰기 전에 관리자 여부를 확인하고 `security definer`로 실행한다. 에디터의 직접 `songs` UPDATE는 제거했다. `save_song`은 RLS를 우회하도록 설계했으며 기존 RLS를 바꾸지 않는다. 서명·권한·오류 계약과 직접 쓰기의 리비전 제한은 [RLS 정책 문서](../../supabase/RLS_POLICIES.md#곡차트-저장-함수-rfd-0107)를 따른다.

**필수 선행 조건:** `profiles.is_admin` 자기 승격을 차단하는 PR [#396](https://github.com/nanana3679/not4k/pull/396)의 `20261031000000_block_admin_privilege_bypass.sql`에 의존한다. 운영에는 2026-10-31 적용되었고 main에는 2026-11-01 머지되었다. 새 환경에는 시간순으로 먼저 적용해야 하고, 이 보호가 없는 환경에 저장 마이그레이션을 적용해서는 안 된다.

> **Domain expert:** "아니요. **비로그인 플레이**는 허용하되, **플레이 기록** 저장과 **랭킹** 등록을 제한합니다."

## Flagged ambiguities

- **프로필**은 서비스 권한과 기록을 연결하는 정보이고, 로그인 제공자 계정 자체가 아니다.
- **곡 에셋**은 음원·`gameplayRange`·이미지·프리뷰·차트를 포함하는 콘텐츠 단위이고 **차트 에셋**은 그중 특정 난이도의 차트 산출물이다.
- **랭킹**은 비교용 순위이고 **플레이 기록**은 유저의 개별 결과 데이터이다.
- **공개/비공개 곡**은 곡에 붙은 플래그가 아니라 **차트 에셋 보유 여부**로 갈린다. 곡 데이터 자체는 누구나 조회 가능하지만, 차트가 없는 곡은 일반 유저의 곡 선택에서 숨겨진다.
