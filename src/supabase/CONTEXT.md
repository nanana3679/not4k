# Online Services

Online services 컨텍스트는 not4k가 온라인 전용 게임으로 동작하기 위해 필요한 계정, 권한, 곡/차트 에셋, 저장 흐름을 다룬다.
구체적인 차트 구조는 `src/shared/CONTEXT.md`의 Shared chart model을 따른다.

## Language

**온라인 전용**:
곡, 차트, 기록, 랭킹이 서버 연결을 전제로 동작하는 서비스 방식이다.
_Avoid_: 오프라인 우선

**비로그인 플레이**:
로그인 없이 플레이할 수 있지만 플레이 기록은 저장하지 않고 랭킹에도 등록하지 않는 상태이다. 키 바인딩 등 로컬 설정과 튜토리얼 통과 여부·마지막 선택 탭과 항목은 브라우저에 저장한다([glossary](../../docs/context/glossary.md#튜토리얼)).
_Avoid_: 게스트 계정

**프로필**:
로그인 유저의 서비스 권한과 개인 기록을 연결하는 사용자 정보이다.
_Avoid_: 계정

**admin 권한**:
비공개 곡 접근과 차트 편집기 진입 같은 운영 기능을 허용하는 권한이다.
_Avoid_: 개발자 모드

**곡 메타데이터**:
제목·아티스트·자켓은 같은 곡의 모든 차트가 공유하며, 이 표시 정보만 수정하면 기존 기록과 랭킹을 유지한다([glossary](../../docs/context/glossary.md#곡-메타데이터)).

**곡 타이밍**:
같은 곡의 모든 차트가 공유하는 초기 BPM·BPM 변경 목록·박자표·변박 정보·음원 정렬용 오프셋이다. 곡 단위 공유는 채택 규칙이며 런타임 반영은 후속 작업이다([glossary](../../docs/context/glossary.md#곡-타이밍)).

**곡 에셋**:
플레이에 필요한 음원, `gameplayRange`, 자켓 이미지, 프리뷰 음원, 차트 에셋을 묶은 콘텐츠 단위이다.
_Avoid_: 차트 에셋

**차트 에셋**:
특정 곡의 특정 난이도에 해당하는 차트 산출물이다.
_Avoid_: 곡 에셋

**공개 곡**:
차트 에셋이 하나 이상 있어 일반 유저의 곡 선택에 노출되는 곡이다. 곡 자체에 공개/비공개 플래그가 따로 있는 것이 아니라, 차트 에셋 보유 여부로 결정된다.
_Avoid_: 비공개 곡

**비공개 곡**:
차트 에셋이 하나도 없어 일반 유저의 곡 선택에서는 숨겨지고 admin에게만 보이는 곡이다. (별도 privacy 플래그가 아닌, 차트 미보유 상태)
_Avoid_: 공개 곡

**플레이 기록**:
로그인한 플레이어의 완주 기록과 `flightRule`에 따른 곡 도중 실패 종료의 획득 점수는 기록·랭킹 반영 대상에 포함하며 클리어 여부는 독립적으로 보존한다. 직접 중단한 플레이는 기록을 남기지 않는다. 유저가 특정 차트 버전에서 얻은 결과로, Normal/Easy별로 분리하고 같은 설정의 미러 기록은 합친다. 노트 배치가 바뀌거나 곡 타이밍 수정으로 실제 입력 시각이 달라지면 이전 기록을 보관하고 현재 버전 기록만 표시하며, 전송 실패 시 결과 화면에서 안내·재시도를 제공하고 화면을 나가도 미전송 기록을 해당 계정과 연결해 브라우저에 보관해 다음 접속 때 원래 계정으로 로그인되어 있으면 자동 재전송한다. 차트 삭제 후에도 기록은 원래 버전에 보관하고 현재 선택·랭킹에서 제외하며 재등록 시 승계하지 않는다([glossary](../../docs/context/glossary.md#개인-플레이-기록)).
_Avoid_: 랭킹

**랭킹**:
같은 버전·판정 설정에서 점수와 독립 보존한 풀콤보·올퍼펙트 배지를 함께 표시하며, 올퍼펙트가 풀콤보를 대체한다. 배지는 점수 순위·동점 최초 달성 시각에 영향을 주지 않는다. 같은 차트 버전·판정 설정의 최고 점수를 비교하고, 기록 수치는 점수만 표시한다. 차트별 최고 기록을 다른 유저와 비교해 보여주는 순위이다. Normal/Easy 모두 제공하되 차트 버전·판정 설정별로 순위를 따로 집계하고, 동점은 해당 점수를 먼저 달성한 순서로 정한다([glossary](../../docs/context/glossary.md#랭킹)).
_Avoid_: 플레이 기록

**설정 동기화**:
로그인 유저의 설정을 서버와 맞추는 흐름이다.
_Avoid_: 로컬 설정 저장

## Relationships

- 튜토리얼 항목 전체 통과 여부와 마지막 선택 탭·항목은 비로그인도 브라우저에 저장하며, 로그인하면 계정과 동기화한다. 열람 위치가 다르면 실제로 가장 최근에 선택한 위치를 사용한다. 한쪽에서라도 통과한 항목은 합쳐 보존하고 현재 방법·중간 방법 완료·부분 성공은 동기화하지 않고 재진입 시 첫 방법 0회부터 시작한다([glossary](../../docs/context/glossary.md#튜토리얼)).

- not4k는 **온라인 전용**을 기본 서비스 방식으로 삼는다.
- **비로그인 플레이**는 가능하지만 **플레이 기록**, **랭킹**, **설정 동기화**는 제한된다.
- **프로필**은 유저의 **admin 권한** 여부를 알려준다.
- **admin 권한**은 **비공개 곡** 접근과 **차트 편집기** 진입에 영향을 준다.
- 하나의 **곡 에셋**은 여러 **차트 에셋**을 가질 수 있다.
- **곡**은 **차트 에셋**이 하나 이상 있어야 일반 유저에게 **공개 곡**으로 노출된다 — 차트 에셋 게시가 곧 곡 공개이며, 차트가 없는 곡은 admin에게만 보인다.
- **`gameplayRange`**는 원본 음원 중 실제 플레이 세션에서 사용할 시작～끝 구간이며, 값이 없으면 전체 음원을 사용한다.
- **차트 에셋**은 **Shared chart model**의 차트 언어를 따른다.
- **플레이 기록** 중 최고 기록이 같은 차트 버전·판정 설정의 **랭킹**에 반영된다.

## Example dialogue

> **Dev:** "로그인하지 않으면 플레이 자체를 막을까요?"
> **Domain expert:** "아니요. **비로그인 플레이**는 허용하되, **플레이 기록** 저장과 **랭킹** 등록을 제한합니다."
>
> **Dev:** "차트 편집기는 모든 유저에게 보여도 되나요?"
> **Domain expert:** "아니요. **admin 권한**이 있는 유저에게만 진입을 허용합니다."

## Flagged ambiguities

- **프로필**은 서비스 권한과 기록을 연결하는 정보이고, 로그인 제공자 계정 자체가 아니다.
- **곡 에셋**은 음원·`gameplayRange`·이미지·프리뷰·차트를 포함하는 콘텐츠 단위이고 **차트 에셋**은 그중 특정 난이도의 차트 산출물이다.
- **랭킹**은 비교용 순위이고 **플레이 기록**은 유저의 개별 결과 데이터이다.
- **공개/비공개 곡**은 곡에 붙은 플래그가 아니라 **차트 에셋 보유 여부**로 갈린다. 곡 데이터 자체는 누구나 조회 가능하지만, 차트가 없는 곡은 일반 유저의 곡 선택에서 숨겨진다.
