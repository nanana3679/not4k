# Chart Editor

Chart editor 컨텍스트는 차트 제작자가 차트를 만들고 수정하는 작업 언어를 다룬다.
차트 자체의 도메인 구조는 `src/shared/CONTEXT.md`의 Shared chart model을 따른다.

**적용 상태(2026-10-26):** 명시 노트 제작·표시·선택·편집·혼합 저장과 새 테스트 재생을 구현·검증했다. 아래 구형 전용 설명은 과도기 지원의 대조 기록이며 새 동작은 [공식 편집 스펙](../../docs/spec/chart-editor.md#새-에디터-채택-계약)을 따른다.

명시 테스트는 처음부터/커서부터 모두 음악 준비 3초 뒤 시작하고 커서 앞 항목을 Miss 없이 제외한다. 처음부터 테스트는 곡 시간 0에서 자르지 않아 점수 항목·분모가 일반 재생과 같다. 일시정지 재개의 3초 되감기·시작 하한은 [glossary](../../docs/context/glossary.md#일시정지-후-재개)·[테스트 플레이 스펙](../../docs/spec/chart-editor.md#명시-차트의-테스트-플레이)을 따른다.

다음 `holdOnly` 제작 지침은 이전 규칙의 기록으로 남긴다. 구형 항목의 판정·저장·배치 의미는 과도기 읽기·편집을 위해 보존하지만, 새 바디에도 구형 항목 수리에도 `holdOnly`를 새로 배치하지 않는다. 선택 해제 게이트는 구형 구현의 대조 기록이며 새 에디터에서는 의미 위반 항목의 선택 해제·교체를 허용한다.

뗌을 요구하면서 타이밍 등급만 면제할 때는 **그레이스 릴리즈**, 뗌 자체를 요구하지 않을 때는 **릴리즈 없음**으로 구분한다([RFD 0035](../../docs/rfd/0035-release-presence-and-grace.md)·[RFD 0037 §2](../../docs/rfd/0037-explicit-score-notes-and-body.md#2-구성과-점수-의미), 명시 릴리즈의 Grace 제작·판정 구현). 교대 up의 점수 손해를 Grace(`holdOnly`)로 면제하던 제작 지침은 이전 결정이다. 정의는 [glossary](../../docs/context/glossary.md#release-판정)를, 패턴별 적용 범위와 이행은 [PRD §12](../../docs/prd.md#12-미정-사항)를 따르며, 자동 배치 금지는 별도 결정 없이 추가하지 않는다.

## Language

**차트 편집기**:
차트 제작자가 곡의 시간축 위에 노트와 이벤트를 배치하는 도구이다.
_Avoid_: 맵 에디터

**타임라인**:
차트의 시간 흐름을 아래에서 위로 표현하는 편집 공간이다.
_Avoid_: 플레이필드

**노트 레인**:
L1～L4 노트를 배치하는 타임라인 레인이다.
_Avoid_: 보조 레인

**보조 레인**:
BPM, 박자, 메시지 같은 노트 외 요소를 배치하는 타임라인 레인이다.
_Avoid_: 노트 레인

**파형**:
음원의 소리 크기 변화를 타임라인 위에 시각화한 배경 정보이다.
_Avoid_: 그리드

**박자 그리드**:
`BpmChangeEvent`와 `TimeSignatureChangeEvent`를 기준으로 계산되는 시간 눈금이다.
_Avoid_: 스냅

**`Selection.events`**:
이벤트 선택을 노트·구간 선택과 함께 소유하는 축이다. 공통 편집 조작·초기 설정 보호·명시 이벤트 복사는 [glossary](../../docs/context/glossary.md#차트-이벤트)를 따른다.
_Avoid_: 시간 범위에 따른 자동 이벤트 복사

**스냅**:
노트 배치나 이동 위치를 고른 간격(`snapDivision`, 1/N박)의 격자에 맞추는 편집 보조 기능이며, 그 격자의 한 칸도 스냅이라 부른다("한 스냅씩 이동"). 격자 밖 기존 노트도 선택할 수 있다([glossary](../../docs/context/glossary.md#스냅-snap)).
_Avoid_: 히트 테스트

**미니맵**:
차트 전체 타임라인을 축소해서 보여주고 빠르게 이동하게 하는 탐색 도구이다.
_Avoid_: 스크롤바

**뷰포트**:
현재 편집 화면에 보이는 타임라인 영역이다.
_Avoid_: 전체 차트

**`ViewportSlice`**:
뷰포트 상태(zoom·스냅·scrollY·가로 팬)의 단독 소유자다. 쓰기는 `ViewportSlice` 액션만, 클램프·제스처 변환 규칙도 여기 산다. 렌더러는 `ViewportSource`(읽기 전용)로 구독만 한다. 풀 정의는 glossary "에디터 입력".
_Avoid_: 뷰포트 슬라이스(한국어 조어), 렌더러·컨트롤러에 뷰포트 상태 복제 저장, 렌더러에 뷰포트 setter 추가

**`SelectionSlice`**:
에디터 선택 상태(notes·zones·restZones)의 단독 소유자다. 의미 위반 항목의 선택 해제·교체를 허용하며 유효 인덱스·트릴 동질성·독립 `restZones` 정규화를 유지한다. 풀 정의는 [glossary](../../docs/context/glossary.md#selectionslice)를 따른다.
_Avoid_: 선택 슬라이스(한국어 조어), SelectMode·훅에 선택 사본 저장, 필드별 개별 setter

**`TimelineSpace`**:
입력 좌표 공간(픽셀 → 도메인 변환·스냅·히트테스트)을 접은 deep module이다. store·renderer를 모르는 주입 source 기반 라이브 읽기 팩토리(`createTimelineSpace`)로, React 조립은 `useTimelineSpace`가 맡는다. 풀 정의는 glossary "TimelineSpace"(에디터 입력 섹션).
_Avoid_: Projection(그리기 방향, 도메인→픽셀)과의 혼동, 클로저에 store 상태 스냅샷 저장

**재생 커서**:
에디터에서 현재 음원 재생 위치를 나타내는 선이다.
_Avoid_: 판정선

**편집 모드**:
타임라인 입력이 생성, 선택, 삭제 중 어떤 의미를 갖는지 정하는 상태이다.
_Avoid_: 도구

**Create 모드**:
선택한 엔티티를 타임라인에 배치하는 편집 모드이다.
_Avoid_: Add 모드

**Select 모드**:
엔티티를 선택하고 이동하거나 크기를 조정하는 편집 모드이다. down이 무엇을 잡는지 정하는 grab 우선순위 사다리는 `resolveGrab`이 단독 소유하며, 마우스·터치가 `SelectMode.resolveGrabAt`라는 같은 seam을 소비한다(풀 정의는 glossary "resolveGrab", RFD 0016 §6-6).
_Avoid_: Move 모드

**Delete 모드**:
엔티티를 클릭하거나 터치해 삭제하는 편집 모드이다.
_Avoid_: Erase 모드

**고스트 프리뷰**:
아직 확정되지 않은 배치 예정 위치를 반투명하게 보여주는 미리보기이다.
_Avoid_: 실제 노트

**배치 제약**:
차트 의미가 깨지지 않도록 특정 위치나 조합의 배치를 금지하는 규칙이다. 두 층으로 구분한다 — **층1 모델 불변**(`validateChart`: 롱노트 겹침 불가, 트릴 롱 헤드 필수 등 — 어기면 판정 엔진 전제가 깨짐)과 **층2 편집 배치 가드**(`isCreatePlacementBlocked`: 시각 겹침 tolerance 등 UX 정책). 층1은 다시 **구조**(malformed·크래시 유발)와 **의미**(판정 전제 위반)로 갈린다: 구조만 **차트 변이 게이트**가 항상 강제하고, 의미는 편집 중 허용하되 **저장·플레이/프리뷰 진입 게이트**가 강제한다(낙관적 편집, RFD 0017). 풀 정의는 glossary "차트 변이 게이트".
_Avoid_: 렌더링 제한, 두 층의 혼동(층2 규칙을 모델 검증에 넣기)

**차트 변이 게이트**:
현재 구형 구현의 store `setChart`에 내장된 **구조 검증**(`validateChartStructural`: 구간 역전·분자 0 박자표 등 malformed/크래시). 구조 위반만 거부(차트·히스토리 무변)하고 토스트로 사유를 알린다. **의미 위반(겹침·중복·트릴 헤드 등)은 transient로 허용해 커밋**한다 — 라이브 차트는 더 이상 항상 valid가 아니며, 의미 제약은 저장 게이트(`useFileOperations`의 `validateChart`)와 플레이/프리뷰 진입 게이트가 강제한다(RFD 0017). **setChart는 선택도 같은 트랜잭션에서 보정한다** — 노트·구간 **축소** 커밋이면 남은 엔티티를 identity로 재매핑해 지워진 것만 선택에서 빼고(인덱스 밀림 방지), 개수 불변이면 재정규화한다. 선택 인덱스↔차트 범위 불변은 **변이 액션 소관**이라 호출자가 "차트 커밋→선택" 순서를 수동으로 지킬 필요가 없다. 한 조작의 여러 쓰기는 편집 transaction token으로 Undo 한 단위가 되며, 독립 명령은 열린 transaction을 먼저 확정하고 소유자에게 `onInterrupt`로 알린다(풀 정의는 [glossary](../../docs/context/glossary.md#차트-변이-게이트-chart-mutation-gate)). `loadChart`는 구조·의미 모두 열어 수리를 허용한다(경고만). 구조 검증은 setChart에 수렴하며, 새 바디 삭제·축소의 별도 편집 보호는 아래 채택 계약을 따른다.
_Avoid_: setChart 외의 차트 쓰기 경로, 로드 외 목적의 loadChart 사용, "라이브는 항상 valid" 가정, 차트 변이 후 선택 보정을 호출자가 수동으로(변이 액션이 이미 소유)

**선택 해제 게이트** _(제거됨, 대조용 기록)_:
제거 전 `SelectionSlice.setSelection`은 선택에서 빠지는 항목이 의미 위반에 관여한 채 남으면 전이를 거부했다(RFD 0017 §3-5). 새 에디터는 이 제한을 제거해 위반 항목도 해제·교체할 수 있으며, 위반 표시·저장·플레이 검증은 유지한다. 제거 전 구현과 현재 범위는 [glossary](../../docs/context/glossary.md#선택-해제-게이트-deselect-gate)를 따른다.
_Avoid_: 하드 거부로 오해(place-then-fix 유지), 해제를 제스처로 열거(교체·부분해제가 샘), undo·삭제까지 막기

**Extra 노트**:
게임 플레이에는 등장하지 않지만 에디터 보조 레인에 저장되는 제작 보조 노트이다.
_Avoid_: 숨겨진 노트

**`trillZone` 선택**:
`trillZone`을 하나의 유닛으로 선택하는 축이다(몸통 클릭 또는 박스 감쌈 픽업, RFD 0016 §6-2·§6-6). 유닛은 일반 노트·Extra 노트 선택과 **공존**하며, 유닛의 내부 노트는 선택에 주입되지 않고 이동·삭제·복사 시점에 파생되어 동반된다. 개별 트릴 노트 선택만 배타 — 같은 구간의 트릴 노트끼리만 함께 선택할 수 있다. 풀 결정은 RFD 0016.
_Avoid_: 다중 선택

**트릴 핸들**:
Select 모드에서 **`trillZone`**의 끝점을 신축하는 **리사이즈 캡**(끝 박 신축) 하나다. 이동 필은 제거됐고(RFD 0016 §6-6), 구간 이동은 **몸통 클릭으로 선택 후 몸통 드래그**로 한다(노트와 동일).
_Avoid_: 이동 필

**Grace 모드**:
Create 모드의 타이밍 면제 토글이다. 현재 구형 구현은 포인트에 Grace·롱노트에 `holdOnly`를 부여하지만, 새 채택 계약의 탭 노트 드래그는 시작 탭 노트와 끝 릴리즈를 모두 Grace로 만들고 바디에는 플래그를 붙이지 않는다. Grace 릴리즈의 실제 뗌 요구는 유지하며 풀 정의는 [glossary](../../docs/context/glossary.md)를 따른다.
_Avoid_: Grace 노트

**`GestureRecognizer`**:
raw 포인터 입력을 편집·뷰포트 제스처로 인식하는 순수 상태머신이다(입력층/도메인층 2층 분리, 시간 주입으로 시퀀스 테스트). 풀 정의는 glossary "에디터 입력".
_Avoid_: 이벤트 핸들러

**`PointerSample`**:
DOM 포인터 입력을 정규화한 한 건이다. 마우스·터치·펜을 같은 모양으로 `GestureRecognizer`에 넣는다. 풀 정의는 glossary "에디터 입력".
_Avoid_: 포인터 이벤트

**`ViewportGesture`**:
차트를 건드리지 않고 뷰포트만 움직이는 제스처다(zoom·가로/세로 scroll, 서로 배타 잠금). 풀 정의는 glossary "에디터 입력".
_Avoid_: 편집 제스처

**`EditGesture`**:
차트를 편집하는 의미를 갖는 제스처다(현재 `editCancel`·`longPress`). 풀 정의는 glossary "에디터 입력".
_Avoid_: 뷰포트 제스처

## Relationships

- **차트 편집기**는 **Shared chart model**의 차트를 만들고 수정한다.
- **타임라인**은 **노트 레인**과 **보조 레인**으로 나뉜다.
- **파형**과 **박자 그리드**는 차트 제작자가 시간 정렬을 확인하게 돕는다.
- **스냅**은 배치 위치를 정하지만, 엔티티 선택 판정 자체를 대신하지 않는다.
- **미니맵**은 **뷰포트**를 빠르게 이동시키는 도구이다.
- **편집 모드**는 타임라인 입력의 의미를 결정한다.
- **Select 모드**는 이동을 포함하므로 별도의 Move 모드를 두지 않는다.
- **Create 모드**로 배치하는 엔티티에는 노트·이벤트와 함께 **`trillZone`**도 포함된다.
- **`trillZone` 선택**은 몸통 클릭이나 박스 감쌈으로 구간을 유닛 선택하고, 선택 후 **몸통 드래그로 이동**·끝점 **리사이즈 캡으로 신축**하며, 유닛 이동·삭제 시 내부 노트가 동반된다(RFD 0016 §6-2·§6-6). 끝을 줄여 트릴 노트를 구간 밖으로 내보내는 리사이즈는 마지막 유효 위치에서 멈춘다(RFD 0017 추가 4, #344에서 구현).
- **Grace 모드**는 배치 시 노트에 면제 플래그를 부여하며, 어떤 위치·조합이 허용되는지는 **배치 제약**이 정한다.
- 구형 항목을 수리할 때도 손 선택을 미리 암시하고 탭·교대 up과 가까운 릴리즈의 간섭을 피한다. 수리한 끝에서 뗌을 요구하면서 타이밍 등급만 면제하려면 **그레이스 릴리즈**를, 뗌 자체를 요구하지 않으려면 릴리즈 없는 끝을 쓴다. 구형 `holdOnly`를 새로 배치하지 않으며 연결 head가 up을 숨은 연결 release로 소비한다고 기대하지 않는다. 탭 노트의 `grace`와 구분하며 세부는 [새 차트의 제작 계약](../../docs/context/chart-design.md#채택된-새-차트의-제작-계약)과 [RFD 0037 §2](../../docs/rfd/0037-explicit-score-notes-and-body.md#2-구성과-점수-의미)를 따른다. 기존 `holdOnly` 제작 지침은 [이전 규칙의 기록](../../docs/context/chart-design.md#차트-설계-시-주의사항)이다.
- 바디를 시작하는 누름이 같은 레인의 뒤 탭 노트를 의도치 않게 판정하는 배치를 피한다. 시작 입력 범위와 탭 노트 판정 창을 함께 확인하며, 세부는 [차트 디자인 10항](../../docs/context/chart-design.md#10-바디-시작-누름이-뒤-탭-노트를-의도치-않게-처리하는-배치를-피한다)을 따른다. 제작 지침이며 자동 배치 금지는 아니다.
- **고스트 프리뷰**는 확정 전 상태이고 실제 차트 엔티티가 아니다.
- **구형 항목의 배치 제약**은 차트 모델이 성립하지 않는 배치를 막는다 — 트릴 노트는 `trillZone` 안에만·일반 노트는 밖에만 배치하며, `StopEvent` 내 배치와 `restZone`이 덮은 레인·구간의 노트·`trillZone` 공존을 금지한다(의미 위반, 역방향 대칭 — RFD 0019). 트릴 롱노트는 head가 필요하고 양수 길이의 `holdOnly`는 허용하되 길이 0 조합은 금지한다. 양수 길이 끝점과 별도 길이 0 롱노트의 중복, 같은 unit 수로 이어지는 경계 규칙은 [glossary](../../docs/context/glossary.md#holdonly-구-표기-유지-전용-롱노트)와 [사례 NJ-C01～C03](../../docs/spec/note-judgment-cases.md#nj-c01)을 따른다(RFD 0020). validator·편집기의 이행은 [PRD §12](../../docs/prd.md#12-미정-사항)에서 추적한다.

## 새 에디터 계약 요약

다음은 새 에디터에 구현·검증한 편집 계약의 요약이다(명시 차트 테스트 재생은 #346에서 연결). 정의는 [glossary](../../docs/context/glossary.md), 조작별 세부는 [공식 편집 스펙](../../docs/spec/chart-editor.md#새-에디터-채택-계약), 결정은 [RFD 0037 §6](../../docs/rfd/0037-explicit-score-notes-and-body.md#6-위치-관계와-편집)·[§8](../../docs/rfd/0037-explicit-score-notes-and-body.md#8-구형-차트와-과도기)을 따른다.

- 바디는 무점수 유지 구간이고 탭 노트·릴리즈 노트·틱 노트는 명시적 점수 노트다. 일반 탭 노트 드래그는 시작 탭 노트·바디·끝 릴리즈를, 트릴 드래그는 탭 노트·바디만 만든다([RFD 0038](../../docs/rfd/0038-release-notes-in-trill-zones.md)). 빈 위치 틱 노트 배치는 길이 0 싱글 바디+1몫 틱 노트를 만든다. 재클릭의 더블 변경과 몫 수 규칙은 스펙을 따른다.
- 바디를 새로 선택하면 시작 탭 노트·소속 틱 노트·끝 릴리즈도 선택하지만 미선택 개별 노트 클릭은 해당 노트만 고른다. 이미 선택된 노트를 누르면 선택을 유지하고 끌면 선택 전체를 옮긴다(RFD 0016 §6-6). 토글 제외를 보존하고 복사·이동은 실제 선택 집합을 따르며, 관계는 같은 레인의 박 위치에서 도출한다.
- 미선택 끝 핸들도 바디 클릭과 같은 동반 선택을 적용한다. 끝 릴리즈가 바디 끝을 덮으면 겹친 자리는 릴리즈를 잡고 끝 핸들은 그 바로 위 띠에서 잡는다. 이어진 뒤 바디가 그 띠를 덮으면 앞 바디가 선택됐을 때만 띠가 앞 바디 끝 핸들이다(끝 캡 롱프레스는 선택과 무관). 끝 리사이즈에는 선택된 끝 릴리즈만 따라가고 내부 틱 노트·시작 탭 노트는 움직이지 않으며, 틱 노트를 밖으로 보내는 축소는 막는다.
- 미선택 바디 직접 삭제와 선택된 바디 우클릭·Delete의 대상 범위를 구별한다. 소속 틱 노트가 삭제 집합에 없으면 바디 삭제·Cut을 막고 Cut은 클립보드 변경 전에 검사한다. 우클릭 드래그 한 번은 Undo 한 단위이며 도중 Esc는 해당 삭제만 복구·취소한다.
- 의미 위반도 확정·선택 해제·선택 교체할 수 있지만 저장·플레이는 막는다. 구조 위반과 소속 틱 노트를 남기는 바디 삭제·틱 노트를 내보내는 축소·`trillZone` 위반 축소 차단(RFD 0017 추가 4)은 별도 제약으로 유지한다. 길이 0 바디는 단독·틱 노트 조합을 허용하고 탭 노트·릴리즈 조합은 금지한다.
- 과도기에는 미수정 구형 의미와 신형 항목을 함께 편집·저장·재불러온다. main/aux·메타데이터·dirty·Undo 의미를 보존하고 실제 위반은 저장을 막되 구형 항목 존재만으로 혼합 저장을 막지 않는다. 구형 노트 별도 표시는 추가하지 않으며 자동 배치 변환 없이 사람이 수리한다. 새 인게임은 구형 의미가 남은 차트를 차단하고 과도기 종료는 사용자가 알린다.

## Example dialogue

> **Dev:** "스냅이 1/4이면 1/16 위치의 노트는 클릭하기 어렵지 않나요?"
> **Domain expert:** "아니요. **스냅**은 이동과 생성 위치만 보조하고, 선택은 실제 위치 기준으로 해야 합니다."
>
> **Dev:** "노트를 움직이는 Move 모드를 따로 만들까요?"
> **Domain expert:** "아니요. 이동은 **Select 모드** 안의 기능입니다."

## Flagged ambiguities

- **스냅**은 위치 보정이고 **히트 테스트**는 선택 판정이므로 섞지 않는다.
- **재생 커서**는 에디터의 현재 재생 위치이고 **판정선**은 플레이 화면의 판정 기준선이다.
- **고스트 프리뷰**는 실제 차트 엔티티가 아니다.
