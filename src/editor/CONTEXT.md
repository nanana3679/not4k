# Chart Editor

Chart editor 컨텍스트는 차트 제작자가 차트를 만들고 수정하는 작업 언어를 다룬다.
차트 자체의 도메인 구조는 `src/shared/CONTEXT.md`의 Shared chart model을 따른다.

## Language

**차트 편집기**:
차트 제작자가 곡의 시간축 위에 노트, 마커, 이벤트를 배치하는 도구이다.
_Avoid_: 맵 에디터

**타임라인**:
차트의 시간 흐름을 아래에서 위로 표현하는 편집 공간이다.
_Avoid_: 플레이필드

**노트 레인**:
L1~L4 노트를 배치하는 타임라인 레인이다.
_Avoid_: 보조 레인

**보조 레인**:
BPM, 박자, 메시지 같은 노트 외 요소를 배치하는 타임라인 레인이다.
_Avoid_: 노트 레인

**파형**:
음원의 소리 크기 변화를 타임라인 위에 시각화한 배경 정보이다.
_Avoid_: 그리드

**박자 그리드**:
BPM과 박자 마커를 기준으로 계산되는 시간 눈금이다.
_Avoid_: 스냅

**스냅**:
노트 배치나 이동 위치를 선택한 박 단위 눈금에 맞추는 편집 보조 기능이다.
_Avoid_: 히트 테스트

**미니맵**:
차트 전체 타임라인을 축소해서 보여주고 빠르게 이동하게 하는 탐색 도구이다.
_Avoid_: 스크롤바

**뷰포트**:
현재 편집 화면에 보이는 타임라인 영역이다.
_Avoid_: 전체 차트

**`ViewportSlice`**:
뷰포트 상태(zoom·스냅·scrollY·가로 팬)의 단독 소유자다. 쓰기는 `ViewportSlice` 액션만, 클램프·제스처 변환 규칙도 여기 산다. 렌더러는 `ViewportSource`(읽기 전용)로 구독만 한다. 풀 정의는 glossary "에디터 입력".
_Avoid_: 뷰포트 슬라이스(한국어 조어), 렌더러·컨트롤러에 뷰포트 상태 복제 저장, 렌더러에 뷰포트 setter 추가

**재생 커서**:
에디터에서 현재 음원 재생 위치를 나타내는 선이다.
_Avoid_: 판정선

**편집 모드**:
타임라인 입력이 생성, 선택, 삭제 중 어떤 의미를 갖는지 정하는 상태이다.
_Avoid_: 도구

**Create 모드**:
선택한 엔티티를 타임라인에 배치하는 편집 모드이다.
_Avoid_: Add 모드

**Select 모드**:
엔티티를 선택하고 이동하거나 크기를 조정하는 편집 모드이다.
_Avoid_: Move 모드

**Delete 모드**:
엔티티를 클릭하거나 터치해 삭제하는 편집 모드이다.
_Avoid_: Erase 모드

**고스트 프리뷰**:
아직 확정되지 않은 배치 예정 위치를 반투명하게 보여주는 미리보기이다.
_Avoid_: 실제 노트

**배치 제약**:
차트 의미가 깨지지 않도록 특정 위치나 조합의 배치를 금지하는 규칙이다. 두 층으로 구분한다 — **층1 모델 불변**(`validateChart`: 롱노트 겹침 불가, 트릴 롱 헤드 필수 등 — 어기면 판정 엔진 전제가 깨짐)과 **층2 편집 배치 가드**(`isCreatePlacementBlocked`: 시각 겹침 tolerance 등 UX 정책). 층1은 **차트 변이 게이트**가 단독 강제한다. 풀 정의는 glossary "차트 변이 게이트".
_Avoid_: 렌더링 제한, 두 층의 혼동(층2 규칙을 모델 검증에 넣기)

**차트 변이 게이트**:
store `setChart`에 내장된 층1 검증. 위반 차트는 거부(차트·히스토리 무변)되고 토스트로 사유를 알린다. 유일한 예외 통로는 `loadChart`(위반이어도 열어 수리 허용 — 재저장은 저장 게이트가 차단). 새 변이 경로를 만들 때 별도 검증이 필요 없다 — setChart가 곧 게이트다.
_Avoid_: setChart 외의 차트 쓰기 경로, 로드 외 목적의 loadChart 사용

**선택 해제 게이트** _(RFD 0017 §3-5, 미구현/계획)_:
"해제"를 제스처가 아니라 선택 집합의 전이로 본다 — 선택에서 빠지는 노트(`removed=현재−다음`)에 의미 위반이 있으면 그 전이를 거부하고 토스트로 알린다. 화면 밖 위반이 인지되지 못한 채 방치되는 것을 봉쇄. 저장 게이트와 대칭(전역=`setChart`/차트, 국소=`SelectionSlice`/선택 집합). 발화 경계="위반 남긴 채 위반노트를 떨구는 전이"만(면제=전이 후 위반 아니게 됨)이라 undo·삭제·붙여넣기취소(차트 함께 변경해 위반 소멸)는 자동 통과. 풀 정의는 glossary "선택 해제 게이트", 근거는 RFD 0017 §3-5.
_Avoid_: 하드 거부로 오해(place-then-fix 유지), 해제를 제스처로 열거(교체·부분해제가 샘), undo·삭제까지 막기

**Extra 노트**:
게임 플레이에는 등장하지 않지만 에디터 보조 레인에 저장되는 제작 보조 노트이다.
_Avoid_: 숨겨진 노트

**`trillZone` 선택**:
같은 레인에서 **`trillZone`**과 겹치는 노트를 고르면 `trillZone` 단위로 파생되는 선택이다. 한 선택은 동질적이어야 한다 — 일반/트릴 노트를 섞거나 서로 다른 `trillZone`을 섞을 수 없다.
_Avoid_: 다중 선택

**트릴 핸들**:
Select 모드에서 **`trillZone`**을 조작하는 핸들이다. 시작점의 **이동 필**(구간 전체 이동)과 끝점의 **리사이즈 캡**(끝 박 신축)으로 분리된다.
_Avoid_: 리사이즈 핸들

**Grace 모드**:
Create 모드에서 배치하는 노트에 타이밍 면제 플래그를 부여하는 토글 상태이다. 포인트 노트에는 Grace, 롱노트에는 `holdOnly`가 부여된다. 플래그의 판정 의미는 glossary의 "Grace 노트"·`holdOnly`를 따른다.
_Avoid_: Grace 노트

**`GestureRecognizer`**:
raw 포인터 입력을 편집·뷰포트 제스처로 인식하는 순수 상태머신이다(입력층/도메인층 2층 분리, 시간 주입으로 시퀀스 테스트). 풀 정의는 glossary "에디터 입력".
_Avoid_: 이벤트 핸들러

**`PointerSample`**:
DOM 포인터 입력을 정규화한 한 건이다. 마우스·터치·펜을 같은 모양으로 `GestureRecognizer`에 넣는다. 풀 정의는 glossary "에디터 입력".
_Avoid_: 포인터 이벤트

**`ViewportGesture`**:
차트를 건드리지 않고 뷰포트만 움직이는 제스처다(zoom·가로/세로 scroll, 서로 배타 잠금). 풀 정의는 glossary "에디터 입력".
_Avoid_: 편집 제스처

**`EditGesture`**:
차트를 편집하는 의미를 갖는 제스처다(현재 `editCancel`·`longPress`). 풀 정의는 glossary "에디터 입력".
_Avoid_: 뷰포트 제스처

## Relationships

- **차트 편집기**는 **Shared chart model**의 차트를 만들고 수정한다.
- **타임라인**은 **노트 레인**과 **보조 레인**으로 나뉜다.
- **파형**과 **박자 그리드**는 차트 제작자가 시간 정렬을 확인하게 돕는다.
- **스냅**은 배치 위치를 정하지만, 엔티티 선택 판정 자체를 대신하지 않는다.
- **미니맵**은 **뷰포트**를 빠르게 이동시키는 도구이다.
- **편집 모드**는 타임라인 입력의 의미를 결정한다.
- **Select 모드**는 이동을 포함하므로 별도의 Move 모드를 두지 않는다.
- **Create 모드**로 배치하는 엔티티에는 노트·마커·이벤트와 함께 **`trillZone`**도 포함된다.
- **`trillZone` 선택**은 `trillZone`과 겹친 노트를 구간 단위로 선택하고, **트릴 핸들**(이동 필·리사이즈 캡)로 그 구간을 이동·신축한다.
- **Grace 모드**는 배치 시 노트에 면제 플래그를 부여하며, 어떤 위치·조합이 허용되는지는 **배치 제약**이 정한다.
- **고스트 프리뷰**는 확정 전 상태이고 실제 차트 엔티티가 아니다.
- **배치 제약**은 차트 모델이 성립하지 않는 배치를 막는다 — 트릴 노트는 `trillZone` 안에만·일반 노트는 밖에만, `StopEvent` 내 배치 금지, 트릴 롱노트 헤드 필수·`holdOnly` 불가 등(자세한 규칙은 glossary와 RFD).

## Example dialogue

> **Dev:** "스냅이 1/4이면 1/16 위치의 노트는 클릭하기 어렵지 않나요?"
> **Domain expert:** "아니요. **스냅**은 이동과 생성 위치만 보조하고, 선택은 실제 위치 기준으로 해야 합니다."
>
> **Dev:** "노트를 움직이는 Move 모드를 따로 만들까요?"
> **Domain expert:** "아니요. 이동은 **Select 모드** 안의 기능입니다."

## Flagged ambiguities

- **스냅**은 위치 보정이고 **히트 테스트**는 선택 판정이므로 섞지 않는다.
- **재생 커서**는 에디터의 현재 재생 위치이고 **판정선**은 플레이 화면의 판정 기준선이다.
- **고스트 프리뷰**는 실제 차트 엔티티가 아니다.
