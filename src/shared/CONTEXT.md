# Shared Chart Model

Shared chart model 컨텍스트는 게임 클라이언트와 차트 편집기가 공유하는 차트 언어를 다룬다.
개별 노트 타입과 피스의 의미는 루트 `CONTEXT.md`의 Core domain을 따른다.

## Language

**박**:
차트에서 음악적 위치를 표현하는 기본 시간 좌표이다.
_Avoid_: 초, 프레임

**마디**:
박자 마커가 정의하는 박 묶음이며 차트 탐색과 그리드 표시의 큰 단위이다.
_Avoid_: 섹션

**차트 메타데이터**:
곡 제목, 아티스트, 난이도명, Lv., 에셋 참조, 오프셋처럼 차트 전체를 설명하는 정보이다.
_Avoid_: 곡 메타데이터

**시점 마커**:
특정 박 이후의 시간 해석을 바꾸는 BPM 또는 박자 마커이다.
_Avoid_: 구간 이벤트

**BPM 마커**:
특정 박 이후의 BPM을 정의하는 시점 마커이다.
_Avoid_: 스크롤 속도

**박자 마커**:
특정 마디 이후 한 마디가 몇 박인지 정의하는 시점 마커이다.
_Avoid_: BPM 마커

**구간 이벤트**:
시작 박과 끝 박을 가지며 일정 구간 동안 의미가 유지되는 차트 이벤트이다.
_Avoid_: 시점 마커

**`TextEvent`**:
특정 구간 동안 튜토리얼 설명 문구를 보여주는 구간 이벤트이다.
_Avoid_: 메시지 이벤트, 텍스트 이벤트

**`AutoEvent`**:
특정 구간 동안 사용자 입력 없이 노트가 자동 판정되는 구간 이벤트이다.
_Avoid_: 무점수 구간

**`StopEvent`**:
차트 진행을 멈추며 해당 구간의 노트 배치를 금지하는 구간 이벤트이다.
_Avoid_: BPM 변경

**구간 노트**:
시작 박과 끝 박을 가지는 롱 노트 계열의 노트이다.
_Avoid_: 포인트 노트

**`trillZone`**:
트릴 노트가 등장할 수 있는 차트 영역으로, 시작 박과 끝 박을 가지며 자체 입력은 요구하지 않는다. 차트의 1급 구조로 저장된다. 풀 정의는 glossary의 `trillZone` 항목을 따른다.
_Avoid_: 트릴존, 트릴 노트

**`restZone`**:
그 레인이 해당 구간 동안 안 쓰임을 나타내는 레인별 저작 구간(`{ lane, beat, endBeat }`)으로, `trillZone`처럼 차트의 1급 구조로 저장된다. 시각 표시(게임 dim, [RFD 0034](../../docs/rfd/0034-rest-zone-lane-panel.md)로 레인 판넬 전환 예정·에디터 타임라인 빗금) + 에디터 배치 제약만 하고 판정에는 개입하지 않는다. 풀 정의는 glossary의 `restZone` 항목과 [RFD 0019](../../docs/rfd/0019-rest-zone-lane-guidance.md)를 따른다.
_Avoid_: 휴지존, 비활성 레인

**차트 에셋**:
저장되거나 배포되는 차트 본문과 제작 보조 정보를 묶은 산출물이다.
_Avoid_: 곡 에셋

**제작 보조 정보**:
게임 플레이에는 쓰이지 않지만 차트 편집을 이어가기 위해 저장되는 정보이다.
_Avoid_: 플레이 데이터

**`ChartTiming`**:
차트 하나에서 파생되는 시간 뷰. 노트 시작/끝 ms, `trillZone` 시작 ms, 마디 시작 ms, 판정 수 집계를 소유하며 beat→ms 파생은 항상 이 뷰를 통해 읽는다. 풀 정의는 glossary의 `ChartTiming` 항목을 따른다.
_Avoid_: 노트 타임맵, 시간 맵

## Relationships

- 하나의 **차트**는 하나의 **차트 메타데이터**를 가진다.
- **차트 메타데이터**는 **난이도명**과 **Lv.**를 함께 가진다.
- **박**은 차트의 시간 좌표이고 **틱**은 배치 해상도를 설명하는 단위이다.
- **BPM 마커**와 **박자 마커**는 **박자 그리드**를 계산하는 기준이다.
- **시점 마커**는 한 시점 이후에 영향을 주고, **구간 이벤트**는 시작과 끝 사이에 영향을 준다.
- **`TextEvent`**, **`AutoEvent`**, **`StopEvent`**은 모두 **구간 이벤트**이다.
- **구간 노트**는 시작 박과 끝 박을 가지며, **포인트 노트**는 특정 박 하나에 놓인다.
- **구간 노트**는 release를 내장하지 않으며, 뗌을 요구할 때는 별도의 **릴리즈 노트**를 명시한다. 릴리즈 배치 여부와 Grace의 타이밍 등급 면제는 별개이다. 일반·그레이스 릴리즈 모두 실제 뗌을 요구한다([glossary](../../docs/context/glossary.md#release-판정)). 바디 자체는 점수 항목·가중치 집계에서 제외하되, 유지 실패 시 연결된 릴리즈 기회도 잃는다. 기존 저장 필드 `holdOnly`는 새 설계에서 폐지했으며 차트 포맷 이행 전이다([RFD 0035](../../docs/rfd/0035-release-presence-and-grace.md)).
- **유지 노트**는 바디 위에 명시하는 상태 확인 노트로 설계 중이다. 길이 0도 길이 0 바디 위에 배치하고, 바디 실패 시 연결된 미처리 유지 노트의 판정 기회도 잃는다. 코드 식별자·저장 포맷·이전 데이터 변환은 아직 결정하지 않았다([glossary](../../docs/context/glossary.md#유지-노트), [RFD 0036](../../docs/rfd/0036-sustain-notes.md)).
- 하나의 **차트**는 **`trillZone`** 목록을 가진다. **`trillZone`**과 **트릴 노트**는 상호 배타적이다 — 트릴 노트는 `trillZone` 안에만, 일반 노트는 밖에만 놓인다.
- 같은 레인·시각의 **바디 끝 + 릴리즈 노트**는 허용하는 조합이다. 내장 release가 있던 이전 모델의 중복 금지([NJ-C01](../../docs/spec/note-judgment-cases.md#nj-c01))를 새 조합에 적용하지 않는다. 저장 포맷과 코드 필드 구조는 [PRD §12](../../docs/prd.md#12-미정-사항)에서 추적한다.
- **트릴 롱노트**는 head가 필요하다. 이행 전 포맷의 양수 길이 `holdOnly` 허용·길이 0 금지 등 `holdOnly` 관련 배치 제약은 [glossary의 이전 규칙](../../docs/context/glossary.md#holdonly-구-표기-유지-전용-롱노트)에 남긴다. 새 릴리즈 표현의 저장·검증 이행은 [PRD §12](../../docs/prd.md#12-미정-사항)에서 추적한다.
- **차트 에셋**은 게임에서 소비되고 에디터에서 생성된다.
- **제작 보조 정보**는 에디터를 위한 정보이며 플레이 세션에는 등장하지 않는다.
- Gameplay는 **`ChartTiming`**을 통해 차트의 시간 파생을 읽는다.

## Example dialogue

> **Dev:** "BPM이 바뀌면 노트 낙하 속도도 바뀌나요?"
> **Domain expert:** "아니요. **BPM 마커**는 박과 시간의 관계를 바꾸지만, 플레이의 스크롤 속도는 별도 설정입니다."
>
> **Dev:** "메시지는 노트처럼 한 박에만 놓이나요?"
> **Domain expert:** "아니요. **`TextEvent`**는 시작 박과 끝 박을 가지는 **구간 이벤트**입니다."

## Flagged ambiguities

- **박**과 **틱**은 다르다. 박은 시간 좌표이고 틱은 배치 해상도이다.
- **차트 메타데이터**와 곡 자체의 메타데이터를 섞지 않는다.
- **`AutoEvent`**은 스코어에 반영되며 무점수 구간이 아니다.
- **`StopEvent`**은 BPM 변경이 아니라 차트 진행을 멈추는 구간이다.
