# Shared Chart Model

Shared chart model 컨텍스트는 게임 클라이언트와 차트 편집기가 공유하는 차트 언어를 다룬다.
개별 노트 타입과 피스의 의미는 루트 `CONTEXT.md`의 Core domain을 따른다.

## Language

**박**:
차트에서 음악적 위치를 표현하는 기본 시간 좌표이다.
_Avoid_: 초, 프레임

**마디**:
박자 마커가 정의하는 박 묶음이며 차트 탐색과 그리드 표시의 큰 단위이다.
_Avoid_: 섹션

**차트 메타데이터**:
곡 제목, 아티스트, 난이도명, Lv., 에셋 참조, 오프셋처럼 차트 전체를 설명하는 정보이다.
_Avoid_: 곡 메타데이터

**시점 마커**:
특정 박 이후의 시간 해석을 바꾸는 BPM 또는 박자 마커이다.
_Avoid_: 구간 이벤트

**BPM 마커**:
특정 박 이후의 BPM을 정의하는 시점 마커이다.
_Avoid_: 스크롤 속도

**박자 마커**:
특정 마디 이후 한 마디가 몇 박인지 정의하는 시점 마커이다.
_Avoid_: BPM 마커

**구간 이벤트**:
시작 박과 끝 박을 가지며 일정 구간 동안 의미가 유지되는 차트 이벤트이다.
_Avoid_: 시점 마커

**텍스트 이벤트**:
특정 구간 동안 튜토리얼 설명 문구를 보여주는 구간 이벤트이다.
_Avoid_: 메시지 이벤트

**Auto 구간**:
특정 구간 동안 사용자 입력 없이 노트가 자동 판정되는 구간 이벤트이다.
_Avoid_: 무점수 구간

**Stop 구간**:
차트 진행을 멈추며 해당 구간의 노트 배치를 금지하는 구간 이벤트이다.
_Avoid_: BPM 변경

**구간 노트**:
시작 박과 끝 박을 가지는 롱 노트 계열의 노트이다.
_Avoid_: 포인트 노트

**차트 에셋**:
저장되거나 배포되는 차트 본문과 제작 보조 정보를 묶은 산출물이다.
_Avoid_: 곡 에셋

**제작 보조 정보**:
게임 플레이에는 쓰이지 않지만 차트 편집을 이어가기 위해 저장되는 정보이다.
_Avoid_: 플레이 데이터

## Relationships

- 하나의 **차트**는 하나의 **차트 메타데이터**를 가진다.
- **차트 메타데이터**는 **난이도명**과 **Lv.**를 함께 가진다.
- **박**은 차트의 시간 좌표이고 **틱**은 배치 해상도를 설명하는 단위이다.
- **BPM 마커**와 **박자 마커**는 **박자 그리드**를 계산하는 기준이다.
- **시점 마커**는 한 시점 이후에 영향을 주고, **구간 이벤트**는 시작과 끝 사이에 영향을 준다.
- **텍스트 이벤트**, **Auto 구간**, **Stop 구간**은 모두 **구간 이벤트**이다.
- **구간 노트**는 시작 박과 끝 박을 가지며, **포인트 노트**는 특정 박 하나에 놓인다.
- **차트 에셋**은 게임에서 소비되고 에디터에서 생성된다.
- **제작 보조 정보**는 에디터를 위한 정보이며 플레이 세션에는 등장하지 않는다.

## Example dialogue

> **Dev:** "BPM이 바뀌면 노트 낙하 속도도 바뀌나요?"
> **Domain expert:** "아니요. **BPM 마커**는 박과 시간의 관계를 바꾸지만, 플레이의 스크롤 속도는 별도 설정입니다."
>
> **Dev:** "메시지는 노트처럼 한 박에만 놓이나요?"
> **Domain expert:** "아니요. **텍스트 이벤트**는 시작 박과 끝 박을 가지는 **구간 이벤트**입니다."

## Flagged ambiguities

- **박**과 **틱**은 다르다. 박은 시간 좌표이고 틱은 배치 해상도이다.
- **차트 메타데이터**와 곡 자체의 메타데이터를 섞지 않는다.
- **Auto 구간**은 스코어에 반영되며 무점수 구간이 아니다.
- **Stop 구간**은 BPM 변경이 아니라 차트 진행을 멈추는 구간이다.
